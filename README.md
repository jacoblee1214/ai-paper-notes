# AI Paper Notes

AI·ML 논문(모델 구조, 학습, 추론 효율, 멀티모달, 비전, 생성 모델, 에이전트, 평가, 해석 가능성)을 깊게 읽고, 공개된 수치를 재계산하거나 코드와 대조하며 정리한 노트입니다. 로봇 학습 논문은 [paper-notes](https://github.com/jacoblee1214/paper-notes)에 있습니다.

학회별로 묶었습니다(0편). 학회는 arXiv Comments·Journal ref, 원문, 프로젝트 페이지의 표기를 따랐고 각 글 머리말의 `venue`(묶음)와 `venue_note`(근거)에 적었습니다. 묶음 안에서는 날짜 역순입니다.



각 폴더에는 블로그 글(`index.md`), 통합 리포트 PDF, 분석 문서, 검증 스크립트가 있습니다. 논문 그림은 원 논문 라이선스가 허용하는 경우에만 실었습니다.
