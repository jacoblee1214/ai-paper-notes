# 01. AWQ 논문 분석

AWQ: Activation-aware Weight Quantization for On-Device LLM Compression and Acceleration (Lin, Tang, Tang, Yang, Chen, Wang, Xiao, Dang, Gan, Han; arXiv:2306.00978, MLSys 2024). 분석 판은 arXiv v6(2026-04-25)입니다. v1–v4와 v5의 arXiv 제목은 "…for LLM Compression and Acceleration"이고 학회 판과 이 PDF의 제목은 "On-Device LLM …"입니다. 아래 절·식·표 번호는 이 PDF(v6) 기준입니다. v1–v5 본문은 받아서 대조하지 않았으므로 판 사이 수치 차이는 확인하지 못했습니다.

## 1. 문제

- 온디바이스 LLM은 메모리 크기와 메모리 대역폭이 병목입니다. GPT-3 175B는 FP16에서 350 GB입니다(§1, 우리 계산 175e9 × 2 B = 350 GB로 일치).
- 양자화 인지 학습(QAT)은 비용이 크고, 학습 후 양자화(PTQ)는 저비트에서 정확도가 떨어집니다. 가장 가까운 선행 연구 GPTQ는 이차 정보로 오차를 보상하지만 보정 집합에 과적합해 분포 밖에서 흐트러질 수 있다고 주장합니다(§1, 그림 8).
- 목표는 **역전파·재구성 없이** 가중치만 저비트(W4A16, W3A16)로 줄이면서 하드웨어에서 실제 속도를 얻는 것입니다.

## 2. 방법

### 2.1 핵심 관찰: 가중치의 1%가 중요하고, 중요도는 활성이 정한다 (§3.1, Table 1, Figure 2)

INT3 g128로 양자화하되 입력 채널의 0.1–3%를 FP16으로 남깁니다. 남길 채널을 (a) 활성 평균 크기, (b) 가중치 노름, (c) 무작위로 고르면 (a)만 perplexity를 크게 줄입니다(OPT-6.7B RTN 23.54 → 1% 활성 기준 11.39, 가중치 기준 22.37, 무작위 24.23). 같은 단서가 "가중치가 크다고 중요한 게 아니라 큰 활성이 곱해지는 가중치가 중요하다"입니다. 한계: 혼합 정밀도 형식은 하드웨어에 불리합니다.

### 2.2 FP16을 쓰지 않고 보호하기: 채널별 스케일 (§3.2, 식 1–3, Table 2)

그룹 가중치 w에 대해 Q(w) = Δ · Round(w/Δ), Δ = max(|w|)/2^(N−1) (식 1). 입력 x를 s로 나누고 w에 s > 1을 곱하면

- Q(w·s)·(x/s) = Δ' · Round(ws/Δ') · x · (1/s) (식 2)
- 오차 비 = (Δ'/Δ) · (1/s) (식 3 직전 문장)

세 가정: ① Round의 오차 분포(평균 0.25 단위)가 변하지 않는다. ② 한 원소를 키워도 그룹의 최댓값이 거의 안 바뀌어 Δ' ≈ Δ. ③ Δ와 x는 FP16이라 자체 양자화 오차가 없다. 그러면 오차는 s배 커진 채널에서 1/s로 줄어듭니다(Table 2: OPT-6.7B에서 1% 채널을 s = 2로 키우면 perplexity 23.54 → 11.92, s = 4는 12.36으로 다시 나빠짐. 이유: 비중요 채널의 오차가 Δ'/Δ만큼 커짐).

### 2.3 스케일 탐색 (식 4, 5)

- 목적(식 4): s* = argmin ‖Q(W·diag(s))(diag(s)⁻¹·X) − W·X‖. 미분 불가이고 STE는 불안정하다고 합니다.
- 탐색 공간(식 5): s = s_X^α, s_X는 채널별 평균 |활성|, α는 [0, 1]에서 격자 탐색(α = 0은 스케일 없음). 격자 20개(§5.1).
- 가중치 clipping은 양자화 MSE를 줄이도록 추가로 탐색합니다(§3.2 끝, 세부는 코드: `04` D6).
- 보정 데이터는 Pile의 작은 집합. 활성의 평균 크기만 쓰므로 과적합이 적다고 주장(§3.2 "Advantages", Figure 8).
- 스케일의 역수는 앞 연산(LayerNorm, 앞 선형 층)에 흡수됩니다(§3.2). 공식 코드가 흡수할 수 없는 곳(예: GELU 뒤)을 어떻게 다루는지는 `04` D2.

### 2.4 TinyChat 시스템 (§4)

- 디코딩(배치 1)은 메모리 대역폭 병목: RTX 4090(165 TFLOPS, 1 TB/s)에서 FP16 산술 강도 ≈ 1 FLOP/byte로, 릿지(165) 아래입니다. W4A16은 산술 강도를 약 4배로 올립니다(Figure 3(b)).
- 가중치 접근이 활성 접근보다 훨씬 큽니다(Figure 3(c) 캡션 "orders of magnitude"): 가중치만 양자화하는 설정을 정당화합니다.
- 온더플라이 역양자화를 matmul 커널에 융합하고(INT4×FP16 곱셈 명령이 없어서), SIMD 인지 가중치 재배열(ARM NEON 128비트에서 최대 1.2배), 커널 융합(LayerNorm, QKV, 위치 임베딩, KV 캐시 갱신)을 씁니다.

## 4. 논문이 밝힌 한계와 우리가 본 한계

- 논문: 혼합 정밀도의 하드웨어 비효율(§3.1), s가 너무 크면 비중요 채널 오차 증가(§3.2). 지원 모델 구조(GQA의 v–o 스케일 건너뜀 등)는 코드에서만 드러납니다(`04` D8).
- 평가는 WikiText-2 perplexity가 중심이고 비교 표에 신뢰구간이나 반복 실행이 없습니다. INT4 g128에서 AWQ와 GPTQ-R의 차이는 0.01–0.05 PPL입니다.
- "GPTQ는 과적합한다"의 근거는 분포 이동 한 쌍(PubMed↔Enron)입니다(Figure 8(b), 1k 평가 샘플).
- 식 2–3은 s 채널 하나의 소거 논증이고, 스케일이 **층 단위** 손실로 탐색되는지 **블록 출력** 손실로 탐색되는지는 논문 본문에 명시가 없습니다(식 4는 층 단위로 쓰여 있고 공식 코드는 블록 출력, `04` D3).
- 속도 주장(3.2–3.3×)의 기준은 Hugging Face FP16이며 같은 연산을 융합한 FP16 기준은 이미 62/52 = 1.19배 빠릅니다(§5.4 본문). 이상적 상한과의 관계는 `03` §6.
