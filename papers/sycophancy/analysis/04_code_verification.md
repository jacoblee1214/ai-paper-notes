## 2. 재현 가능성 판정

- **재현 가능(승인 필요):** 피드백·답 아첨은 공개 프롬프트로 가능하지만 모델 호출(API)이 필요하고, 2023년 모델 `claude-1.3`, `claude-2.0`, `gpt-4`, `gpt-3.5-turbo`(0613 등)는 대부분 사용 불가일 가능성이 큽니다. 현재 모델로의 재측정은 새 연구입니다.
- **재현 불가:** 흉내 과제(데이터 없음, 15편 시와 20명 시인 목록은 그림 9에 있어 재구성은 가능), §4.1 선호 회귀(특징 라벨 없음, GPT-4로 hh-rlhf 15K 쌍을 재라벨하면 API 비용이 큼), §4.2·4.3(Claude 2 PM과 helpful-only 모델 비공개, 오해 266개는 부록 표 4에서 재구성 가능하나 PM과 사람 데이터는 없음).
- 이번 분석에서 이 맥에서 실행한 것: 공개 데이터셋 구성 감사, 그림 도형 복원, 통계 재계산, 합성 데이터 토이. 공식 코드 실행과 API 호출은 하지 않았습니다.

## 3. 요약

공개 코드는 평가 틀의 일부(두 데이터셋의 생성과 채점 예시)이고, 논문 결론의 절반 이상(§4)과 한 과제(흉내)는 재현 자료가 없습니다. 노트북은 논문보다 엄격한 점(피드백 순서 교환)과 관대한 점(형식 이탈을 정답·긍정으로 처리)이 섞여 있습니다. 이 저장소의 `03`에서 문항 단위 검정 대신 그림 복원과 문항 수로 근사한 이유입니다.
