# 01. 논문 분석: Language Models (Mostly) Know What They Know

Kadavath et al. (Anthropic), arXiv:2207.05221. 분석 판은 v4 (2022-11-21, 최신, 23+17쪽, 코멘트 "refs added, typos fixed"). 분석일 2026-11-22. 본문 인용 위치는 v4 기준 절·그림·표 번호입니다. 공식 코드와 결과 파일은 없고, 모델은 Anthropic 내부 모델(0.8B, 3B, 12B, 52B)이라 외부에서 재실행할 수 없습니다.

## 1. 문제

모델이 자기 주장이 맞는지(self-evaluation), 어떤 질문에 답할 수 있는지(self-knowledge)를 스스로 아는가 하는 문제입니다. 정직(honesty)의 전제 조건으로 제시합니다 (Sec 1, Sec 6). 세 단계로 쪼갭니다.

1. 보정(calibration): 객관식에서 모델이 준 확률이 실제 빈도와 맞는가 (Sec 2, 3).
2. 자기 평가 P(True): 모델이 만든 답을 모델이 "맞다/틀리다"로 평가한 확률이 정답 여부와 맞는가 (Sec 4).
3. 자기 지식 P(IK): 답을 만들기 전에, 질문만 보고 "내가 이걸 맞힐 확률"을 예측하도록 가치 헤드를 학습한다 (Sec 5).

## 2. 방법과 지표 (식 번호 그대로)

| 대상 | 정의 | 위치 |
|---|---|---|
| ECE (MAD형) | E = (1/N) Σ \|y_i − x_i\| (A.1). 같은 개수의 예측을 담은 10개 구간의 (평균 확률, 정답 빈도) 점들에 대해 계산 | App A.1–A.2, 용어집 |
| RMS 보정 오차 | E = sqrt((1/N) Σ (y_i − x_i)²) (A.2) | App A.2, Fig 21 |
| Brier | B = (1/N) Σ (p_i − c_i)² (A.3). 자기 평가에서 p_i = P(True). P(IK)는 정답 표본 비율 > 0.5로 이진화 | App A.3 |
| AUROC | 정답/오답 구분력. 보정에는 무관 | 용어집 |
| 정답 객관식 보정 곡선 | 모든 선택지의 확률(정답과 오답 모두)을 정렬해 10구간 | App A.1 |
| 그러나 ECE 수치는 | 가장 높은 확률의 선택지만 써서 계산 (문헌 관행) | App A.2 |
| 정답 P(IK) 기준값 | 한 질문에서 T=1 표본 30개 중 정답 비율 (soft label을 30개 하드 라벨의 복사로 근사) | Sec 5, App A.6 |
| 엔트로피 H(A\|Q) | 표본 N=200으로 추정한 −log P(A\|Q)의 기댓값 | App B.2 |

보정 입력 형식이 결과를 좌우합니다. 객관식은 `(A) (B) (C)`처럼 선택지를 모델이 먼저 보게 하고 문자 한 토큰만 고르게 한 형식이고 (Sec 2), 'None of the above'로 바꾸면 정확도와 보정이 모두 무너집니다 (Sec 3.1, Fig 7). True/False는 정답과 무작위 오답 하나를 짝지어 문항 수를 두 배로 만든 평가입니다 (Sec 3.2, Fig 8).

P(True) 설정: 모델이 T=1로 답을 만들고, 같은 모델이 `Is the proposed answer: (A) True (B) False`에서 (A)의 확률을 냅니다 (Sec 4.1). 변형: 같은 질문에서 뽑은 5개 표본을 함께 보여 주는 "comparison examples"(Sec 4.2, 프롬프트 전문 App A.5)와 20-shot 예시.

P(IK) 학습: 언어 모델 위에 값 헤드를 붙이고 모델 전체를 미세조정한다. 마지막 토큰 위치에서만 손실을 계산, 배치 7680, 학습률은 사전학습의 1/3 (App A.6). TriviaQA만, 또는 TriviaQA+LAMBADA+Mixed-Arithmetic+Python Function Synthesis 네 가지로 학습한다 (Sec 5.1–5.2). 자연어 방식("확신이 얼마나 되나?")은 초기 실험에서 이득이 없어 쓰지 않았다 (Sec 5).

모델: 0.8B, 3B, 12B, 52B, 850B 토큰 사전학습, 순수 언어 모델이 주이고 RLHF 정책은 Sec 3.3에서만 (Sec 1.2).

## 4. 실험 설정 요약

- 객관식: 모든 BIG-bench 객관식 과제, MMLU, TruthfulQA, LogiQA, QuALITY (Sec 1.2). 몇 문항인지 본문에 없습니다.
- 생성 과제: TriviaQA, LAMBADA, Codex HumanEval, GSM8k, 직접 만든 Mixed-Arithmetic, GitHub에서 모은 Python 함수 합성 8000개(6000/2000 분할, App D). 문항 수는 이 외에 대부분 적혀 있지 않습니다. 본문에 나오는 수는 Table 2의 650과 826, HumanEval이 "크지 않다"는 문장(Sec 5.2)뿐입니다.
- 자기 평가의 크기 추세 그림(Fig 1 우, Fig 11, 29–31)은 점이 세 개(3B, 12B, 52B)로 보이고 0.8B는 없습니다 (그림에서 확인, 판독은 `03`).
- 시드와 반복: 적혀 있지 않습니다. 모든 곡선은 한 번의 실행으로 보입니다.

## 5. 한계 (저자 서술 Sec 6.1과 우리 관찰)

저자 서술: 사전학습 모델 위주, RLHF 모델은 덜 보정되며 방법이 덜 통할 수 있음, "진실"과 "사람이 말하는 것"을 구분 못함, 기만을 다루지 않음, 데이터셋 다섯 개로 한 관찰이라 검정력과 범위가 제한됨.

우리가 추가로 본 것 (`03`, `04`에서 계산):

1. 크기 추세가 3–4개 점에 한 번의 실행이라, "크기에 따라 좋아진다"는 문장은 점추정 추세입니다. Fig 14는 TriviaQA 외 두 과제(LAMBADA, Python Function Synthesis)에서 3B에서 꺾이고 캡션의 "generally increasing"과 어긋납니다.
2. P(True)>0.5 조건부 정확도의 이득은 선택된 비율(coverage)을 함께 보고하지 않아 읽기 어렵습니다.
3. Codex에서 모델의 20-shot Brier는 기저율만 내는 상수 예측기보다 모든 크기에서 나쁩니다 (`03` §4). 저자도 "Brier가 크기에 따라 줄지 않는다"를 기저율 탓으로 돌립니다(Fig 11 캡션).
4. True/False 보정 평가의 오답은 같은 질문의 다른 선택지 중 무작위 하나라서 쉽습니다 (Sec 3.2). 자기 표본 오답(그럴듯한 오답)과는 난이도가 다릅니다. 저자도 자기 표본이 결정 경계 근처일 수 있다고 인정합니다 (Sec 4.1).
5. P(IK)는 모델 전체를 미세조정한 별도의 분류기입니다. 모델이 "말로" 자기 확신을 보고하는 능력(verbalized)이 아닙니다. 자연어 방식은 시도했으나 부정적 결과로 접었습니다 (Sec 5).
