## 1. 식 유도: 짝지은 검정의 검정력은 불일치율에 좌우된다

**설정.** n개 문항을 두 모델 M1, M2가 푼다. 문항마다 (둘 다 맞음, M1만 맞음, M2만 맞음, 둘 다 틀림)이 독립이고 확률이 (p11, p10, p01, p00)이다. 효과와 불일치율을

- Δ = p01 − p10 (M2의 정확도 − M1의 정확도), d = p01 + p10 = 1 − Pa (논문의 Pa = 두 모델이 같은 결과를 내는 비율)

로 두면 p10 = (d − Δ)/2, p01 = (d + Δ)/2이다. McNemar 검정(논문 §3.1)은 불일치 쌍의 수 b = n10, c = n01만 쓴다: χ² = (b − c)²/(b + c) (자유도 1). **p11과 p00, 곧 기준 정확도는 검정에 들어가지 않는다.** 기준 정확도는 (Δ, d)가 가질 수 있는 범위만 제한한다(아래 (v)).

**(i) 검정통계량의 분포.** 문항 하나가 D의 기여로 +1(확률 p01), −1(p10), 0(나머지)을 주므로 D = c − b에 대해
E[D] = nΔ, Var[D] = n(d − Δ²). 불일치 쌍 수 M = b + c는 평균 nd.

**(ii) 기각 영역과 검정력.** χ² ≥ z²(z = z₁₋α/₂)는 |D| ≥ z√M과 같다. M의 요동을 무시하고 M ≈ nd로 두면, 맞는 부호 쪽의 검정력은

> **power ≈ Φ( (√n·Δ − z·√d) / √(d − Δ²) )**  (식 A)

이다. 이 식은 (n, Δ, d) 세 수로만 정해지고 기준 정확도에 직접 의존하지 않는다. 저자 R 노트북의 `power_mcnemar_test`(Connett·Duffy 정규식)에 paid = (d−Δ)/2, ψ = (d+Δ)/(d−Δ)를 넣고 정리하면 같은 식이 되는 것을 손으로 확인했고(분자 √2(√nΔ − z√d)/√(d−Δ), 분모 √2·√(d−Δ²)/√(d−Δ)), 코드로도 두 식이 1e-9 안에서 일치함을 테스트했습니다(`test_analytic_formula_equals_connett_duffy_form`).

**(iii) 불일치율이 클수록 검정력이 낮다.** 식 A의 분자는 d가 커질수록 줄고(−z√d) 분모는 √(d−Δ²)로 커지므로 같은 n, Δ에서 power는 d에 대해 감소한다. 그림 3의 Pa = 0.70 대 0.95 패널이 이것이다. 우리 시뮬레이션(n = 1000, Δ = 0.02)에서 Pa = 0.98, 0.95, 0.9, 0.8, 0.6으로 갈수록 검정력이 단조 감소합니다(`test_power_decreases_with_disagreement`).

**(iv) 최소 검출 효과(MDE)의 닫힌 형태.** 검정력 1−β(z_b = Φ⁻¹(1−β))를 내는 Δ를 구한다. 식 A에서 (√nΔ − z√d)² = z_b²(d − Δ²)이므로

(n + z_b²)Δ² − 2√n·z·√d·Δ + (z² − z_b²)d = 0.

√nΔ > z√d인 큰 근을 취하면 판별식이 d·z_b²(n − z² + z_b²)가 되어

> **MDE(n, d) = √d · ( z·√n + z_b·√(n − z² + z_b²) ) / (n + z_b²)**  (식 B)

이고, n이 크면 MDE ≈ (z + z_b)·√(d/n) = **2.80·√(d/n)** (α = 0.05, 검정력 80%). 반대로 필요한 문항 수는 **n = (z√d + z_b√(d − Δ²))² / Δ²** (식 C). 식 B가 식 A의 근임을 5개 (n, d)에서 수치 근과 1e-6 안에서 확인했고(`test_mde_closed_form_is_root_of_power_equation`), 근사 2.80√(d/n)은 n=1725, d=0.058에서 0.0162(식 B 0.016234 대 근사 0.016245)로 0.1% 안, n=100, d=0.2에서 1.2% 높게 나옵니다.

**(v) 주변 합만 알 때의 범위.** 두 모델의 정확도 a1, a2만 알면 d는 |a2 − a1| ≤ d ≤ min(a1 + a2, 2 − a1 − a2)에서 움직인다(틀린 문항이 한쪽의 부분집합일 때 최소, 맞은 문항 또는 틀린 문항이 겹치지 않을 때 최대). 식 A와 B는 d가 이 범위 끝일 때의 **검정력 상·하한**과 **MDE 하·상한**을 준다. 이것이 논문 표 9의 "Lachenbruch min/max"이고, 이 저장소 15·16·18번이 "주변 합만으로 McNemar 가능 범위"로 쓴 것과 같은 제약입니다(§7).

**(vi) 짝지은 검정이 이득인 조건.** 짝짓지 않은 두 비율 검정(R `power.prop.test`)의 MDE는 (z + z_b)√(2p̄(1−p̄)/n) 꼴이므로, 식 B에서 d를 **2p̄(1−p̄)**로 바꾼 것이다. 두 모델이 독립이면 d = p1(1−p2) + p2(1−p1) ≈ 2p̄(1−p̄)이므로, 짝지은 분석이 이기는 조건은 d < 2p̄(1−p̄), 곧 두 모델의 오류가 양의 상관일 때다. 표 9 MRPC: 비짝 2.40 대 짝(회귀 겹침 사용) 1.62, 비 0.675. 식으로는 √(0.058/(2·0.92·0.08)) = 0.63(근사)입니다.

**(vii) 다중 비교.** 같은 데이터에서 m개 비교를 보정(Bonferroni)하면 z가 z₁₋α/₂ₘ로 바뀌어 MDE가 (z′ + z_b)/(z + z_b)배로 커진다(우리 계산). m = 3, 10, 20이면 1.16배, 1.30배, 1.38배. 논문은 이를 다루지 않습니다(각주 8).

## 2. 해석식 대 시뮬레이션 (최소 구현으로 확인)

시뮬레이터는 (b, c, 나머지)를 다항분포로 뽑고 McNemar p값을 벡터화로 구한다(`simulate_power`). 논문 그림 2의 알고리즘과 같고, 검정력은 "유의하면서 부호가 같은 비율", Type-M은 유의한 반복의 |관측|/|참값| 평균, Type-S는 부호가 틀린 비율입니다.

- **1종 오류율**(Δ = 0, n = 2000, Pa = 0.9, 20,000회): χ²형 0.05 ± 0.01, 정확 검정은 ≤ 0.055로 보수적입니다(테스트).
- **단조성:** n(200→5000), Δ(0.005→0.08)가 커질수록, d가 작을수록 검정력 증가(테스트 3개).
- **해석식 대 χ² 시뮬레이션(40,000회)**: 5개 조합 (n, Δ, Pa)에서 |차이| < 0.03 (`test_analytic_power_matches_simulation`). 예: n = 2000, Δ = 0.02, Pa = 0.9에서 시뮬레이션 0.811, 해석식 0.808.
- **MDE:** 해석식 대 시뮬레이션(이분법, 20,000회) — (n, d) = (500, 0.1): 0.0395 대 0.0388(χ²)/0.0407(정확); (1000, 0.1): 0.0280 대 0.0278/0.0288; (2000, 0.1): 0.0198 대 0.0197/0.0204; (500, 0.3): 0.0685 대 0.0683/0.0701. 정확 검정은 χ²보다 MDE가 3–5% 큽니다.
- **작은 n의 한계:** WNLI(n = 147)에서 논문의 MDE 5.26%p를 넣으면 불일치 쌍의 기대값이 약 8.9개뿐이라 정규 근사 검정력은 0.742, χ² 시뮬레이션은 0.828, 정확·연속성 보정 검정은 0.698입니다. 식 A는 불일치 쌍이 수십 개 이상일 때만 믿을 수 있습니다.

### 부록 C의 예와 검정 종류 (중요)

논문 본문(§3.1)은 McNemar를 χ² 식으로 적지만, **공식 노트북은 `statsmodels.mcnemar(sample)`을 쓰고 이 함수의 기본값은 정확 이항 검정**입니다(저자 `accuracy.ipynb`). 부록 C(n = 500, Δ = 0.02, Pa = 0.9)의 수치 대조(200,000회 시뮬레이션):

| 검정 | n = 500 검정력 / Type-M | n = 2000 검정력 / Type-M |
|---|---|---|
| χ² (식 그대로) | 0.291 / 1.83 | 0.811 / 1.12 |
| χ² + 연속성 보정 | 0.245 / 1.90 | 0.790 / 1.13 |
| **정확 이항** | **0.249 / 1.89** | **0.791 / 1.13** |
| 해석식 A | 0.292 | 0.808 |
| **논문 값** | **약 0.25 / 1.9** | **"거의 80%" / 1.1** |

논문의 0.25와 1.9는 **정확 검정 또는 연속성 보정에서만** 나옵니다. 본문 식의 χ²로는 0.29입니다. 결론이 바뀌는 차이는 아니지만, "본문의 검정 = 계산에 쓴 검정"이 아닙니다. 이 차이가 해석식(근사, 낙관적)과 논문 수치의 간극(0.29 대 0.25)을 설명합니다. 논문 수치를 인용해 계획을 세우면 해석식보다 정확 검정 시뮬레이션을 쓰는 것이 안전합니다.

## 5. 표 10: GLUE 주장 57개의 검정력 (저자 주석 CSV로 재계산)

`data/GLUE/Glue-Paper-Annotations.csv`(118행: 주장 + SOTA 비교 61행, 양의 개선 60행)에 저자 노트북의 절차를 그대로 옮겼습니다. 대상 주장마다 (과제 더미 + 이전 최고 정확도)로 개선폭을 회귀(leave-one-out)해 예상 효과를 만들고, Pa 회귀로 겹침을 만들어 식 A의 검정력을 구하고, 관측 효과로는 불일치 쌍을 만들어 McNemar(R `mcnemar.test` 기본값 = 연속성 보정 χ²)를 돌립니다.

| | 검정력 ≥ 0.8 | 검정력 < 0.8 | 유의(p < 0.05) | 검정력 ≥ 0.8 이면서 유의 | 대상 수 |
|---|---|---|---|---|---|
| 논문 표 10 ("% Powered" 등) | **45.6%** | | 50.9% | 36.8% | 57 |
| 우리: 저자 코드의 인덱싱 그대로 | 54.4% (31) | **45.6% (26)** | 50.9% (29) | 36.8% (21) | 57 |
| 우리: 올바른 leave-one-out | 53.6% (30) | 46.4% | 51.8% (29) | 35.7% (20) | 56 |

- **저자 코드를 그대로 따라 하면 표 10이 정확히 재현됩니다.** 검정력의 평균 0.698, 표준편차 0.352, 25·75분위 0.407·1.0, p 평균 0.22까지 논문 표 10의 요약 통계와 일치합니다.
- **그런데 45.6%는 "검정력이 충분한 비율"이 아니라 "검정력이 80% 미만인 비율"입니다.** 노트북 마지막 칸이 `powers$powered <- powers$Power < .8`이고 이 열의 평균이 "% Powered 0.456"으로 출력됩니다. 검정력 ≥ 0.8인 주장은 57개 중 31개(54.4%)입니다. 따라서 본문의 "46%만이 충분한 검정력을 예측"(§3.3)과 "검정력이 충분한 실험의 약 80%가 유의"는 코드 기준으로는 **"54%가 충분하고, 그중 21/31 = 68%가 유의"**가 됩니다. 정성적 결론(다수 비교가 약하다)은 약해지지만 본문 숫자는 코드와 반대로 읽힙니다. 확신 수준: 높음(분포 통계가 소수점 셋째 자리까지 맞고 코드 문장이 명확). 단 논문 PDF의 의도를 저자에게 확인한 것은 아닙니다.
- **leave-one-out 인덱싱:** 저자 코드는 `newdata[-i,]`에서 i가 "주장만 거른 표의 행 번호"인데 전체 표에 적용합니다. 그래서 "대상 주장을 뺀" 회귀가 아니라 다른 행을 뺀 회귀입니다. 이 인덱싱을 그대로 흉내 내면 논문 수치가 나오고, 올바른 방식은 56개로 약간 다릅니다(위 표 셋째 행). 결론에는 영향이 작습니다.
- **그림 14 재계산:** 60개 양의 주장 중 관측한 개선폭이 MDE 이상인 비율. 비짝 이항: 16개 = 26.7%(논문 26.7%), 불일치율 최대(Lachenbruch 상한): 16개 = 26.7%(26.7%), 불일치율 최소(가장 관대): 47개 = 78.3%(78.3%). 모두 일치합니다.
- 이 표 10은 "회귀로 예측한 효과"의 검정력이므로 사후 검정력은 아니지만, 예측 개선폭의 불확실성(회귀 R² 0.69, 14편)은 검정력 추정에 반영되지 않았습니다.

## 7. 주변 합만으로 가능한 McNemar 범위와의 연결 (15·16·18번)

`swe_agent/`의 54 대 33(300문항)을 이 구현으로 다시 계산했습니다. 정확 McNemar의 p는 불일치 최소 배치에서 9.5e-7, 최대 배치에서 0.0314로 그쪽 분석(≈1e-6, 0.031)과 같습니다. 같은 입력에서 d의 가능 범위는 [0.07, 0.29]이고, 관측한 Δ = 7%p가 참값일 때의 검정력은 d = 0.07이면 0.997, d = 0.29이면 0.616입니다. 즉 "p_max < 0.05"가 "최악의 배치에서도 유의"라면, 검정력 쪽에서는 "최악의 불일치율에서 검정력이 0.62이므로 같은 비교를 반복하면 약 38%는 유의하지 않을 것"입니다. 15·16·18번은 이 범위에서 p만 보고했으므로, 이 논문의 틀은 거기에 **검정력(재실행하면 같은 결론이 나올 확률)**을 더합니다. 이 불일치율을 데이터 없이 정하는 방법은 이 논문에 두 가지가 있습니다. (a) 다른 모델 쌍의 공개 결과나 같은 모델의 두 번 실행(`agentic_eval_randomness/`)에서 d를 재는 것, (b) Pa 회귀(GLUE에서 불일치 약 6%)인데 에이전트 벤치마크용 회귀는 없습니다.

## 8. 번역(그림 4, 표 3): Delta–Laplace 시뮬레이션

저자 `BLEU.ipynb`와 같은 절차(δ_i = 0 또는 Laplace, 관측 차이 = −Σδ_i/2, 무작위화 1,000회의 2.5·97.5 백분위)를 numpy로 짰습니다(`simulate_bleu_power`). 해석식은 관측 차이와 무작위화 귀무분포의 표준편차를 정규로 근사한 것입니다(`analytic_bleu_power`). P0 = 0.13, b0 = 25.8, ΔB = 1:

| n | 500 | 1,000 | 2,000 | 5,000 |
|---|---|---|---|---|
| 시뮬레이션 (400회) | 0.263 | 0.455 | **0.743** | 0.985 |
| 정규 근사 | 0.258 | 0.458 | 0.747 | 0.986 |

**논문의 "2000문장에서 약 75%"가 재현됩니다.** ΔB = 0.5, n = 2000이면 0.235입니다. 표 3의 P0 평균 0.125, b0 평균 25.8과 노트북 기본값(0.13, 25.8)이 일치합니다. 이 계산에는 BLEU 모수가 En-De 한 언어쌍에서 왔다는 한계(논문 §4)가 그대로 있습니다. 시뮬레이션 횟수가 적으면 흔들립니다. 300회짜리 한 번이 0.69, 600회짜리 두 번이 0.747, 0.74였으므로(표준오차 약 0.02–0.03) "약 75%"는 확인된 값이지만 ±0.03 안에서 읽어야 합니다.

## 9. 사람 평가(Likert): 혼합 효과의 단순화 시뮬레이션과 메타분석

**모형 (식 5, 부록 H.3).** Y = β0 + W0w + I0i + (β1 + W1w + I1i)·x + e, x = ±1(모델 A/B), 모든 평가자가 모든 문항을 두 모델에 대해 평가(저자 R 코드와 같은 완전 교차 설계). lme4 대신 **셀별 차이 D = Y(+1) − Y(−1)**를 만들면 절편 항이 상쇄되고 D̄ = 2β1 + (평가자 평균) + (문항 평균) + 잡음이 되어, 두 방향 ANOVA 평균제곱으로 Var(D̄) = (MS_W + MS_I − MS_E)/(WI)를 추정해 t = D̄/√Var > 1.96으로 검출을 셉니다(`simulate_likert_power`). 분산을 알 때의 해석식은

> Var(β̂1) = σ_w1²/W + σ_i1²/I + σ_e²/(2WI),  power ≈ Φ( β1/√Var − 1.96 ) (식 D)

입니다. 절편 분산(σ_w0, σ_i0)은 검정력에 영향이 없습니다. **평가자 수 W를 늘려도 σ_i1²/I(문항×모델 변동) 항은 줄지 않으므로 평가자를 무한히 늘려도 검정력에 상한**이 있습니다(`figures/own_likert_workers.png`: 문항 50개, 높은 분산 설정에서 두 모델 차이 0.1이면 평가자를 무한히 늘려도 최대 약 0.71). 논문의 "문항 100개에 평가자 10명 이상" 처방은 σ_w1 항이 지배적인 작은 W에서 맞고, W가 커지면 문항 수가 병목이 됩니다.

**저자 공개 결과(lme4, `highvar_lowmer_lmer.csv`, 48개 셀)와 비교:**

| 설정, 문항 100개 | β1 | 평가자 3 (lme4 / 우리 시뮬 / 해석식) | 평가자 10 (lme4 / 우리 / 해석식) |
|---|---|---|---|
| 높은 분산 | 0.05 | 0.27 / 0.22 / 0.12 | 0.32 / 0.29 / 0.26 |
| 높은 분산 | 0.10 | 0.56 / 0.43 / 0.33 | 0.80 / 0.75 / 0.75 |
| 높은 분산 | 0.20 | 0.89 / 0.83 / 0.86 | 1.00 / 1.00 / 1.00 |
| 낮은 분산 | 0.05 | 0.60 / 0.51 / 0.45 | 0.84 / 0.78 / 0.77 |

(우리 값은 2β1을 두 모델 평균 차이로 넣은 것.) 48개 셀 전체 RMSE: 우리 시뮬레이션 0.042, 해석식 0.075.

**두 가지 발견.**

1. **그림 6의 x축 "평균 차이"는 코드에서 ±1 부호화의 계수 β1입니다.** 저자 R 코드는 `model = c(-1, 1)`(숫자)이고 `beta = diff`를 그대로 넘겨서, 두 모델의 평균 차이는 2·diff입니다. 증거: 효과를 β1이 아니라 2β1으로 넣을 때 RMSE 0.042인데, 평균 차이를 β1(= 논문 x축 값)으로 넣으면 RMSE 0.373으로 전혀 맞지 않습니다. 따라서 그림 6에서 "평균 차이 0.2"로 읽은 점은 실제 두 모델 평균 차이 0.4이고, **실제 평균 차이 0.2의 검정력은 그림의 0.1 지점(높은 분산, 3명·100문항에서 lme4 0.56)입니다.** 즉 §5.2의 "높은 분산에서 3명·100문항은 0.2 이상이어야 충분"이 실제 평균 차이로는 **약 0.4 이상**이 됩니다. 논문의 결론(검정력 부족)은 더 강해집니다. 단 논문 본문에는 "mean difference"의 정의가 코드만큼 명시되어 있지 않아 읽는 방식에 따른 해석 차이일 수 있습니다. 코드와 공개 CSV가 근거입니다.
2. **t > 1.96 기준은 평가자가 적을 때 거짓 양성이 많습니다.** 우리 추정기로 효과 0일 때 t > 1.96의 비율(단측)에 2를 곱한 값이 평가자 3명 0.18, 10명 0.07, 30명 0.055(공칭 0.05)입니다. 평가자 3명에서 분산 추정이 불안정해 t 분포 대신 정규 임계값을 쓰기 때문입니다. lme4의 실제 1종 오류율은 우리가 lme4를 돌리지 않아 확인하지 못했지만 lme4 결과가 우리 추정기보다 일관되게 높은 검정력(작은 효과·적은 평가자에서 0.05–0.12 더 높음)을 보이는 것과 맞습니다. 그림 6의 작은 평가자 수 곡선에는 거짓 양성이 섞였을 가능성이 있습니다.
