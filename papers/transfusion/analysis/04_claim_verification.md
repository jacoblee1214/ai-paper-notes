# 04. 주장 검증 (공식 코드 없음)

Meta의 공식 Transfusion 코드는 공개되지 않았습니다(`01` §0). 그래서 논문 주장 C1–C14를 (a) 논문 안의 표·식 재계산, (b) PDF 벡터에서 읽은 그림 5 점의 재적합, (c) 작은 토이(`03` §1)로 검증했습니다. 마지막(§3)에 **비공식** 구현 `lucidrains/transfusion-pytorch`(MIT, 커밋 `a0a0949`)를 정적으로 읽어 논문과 다른 점 U1–U8을 적었습니다. 이 구현은 논문 저자가 만든 것이 아니므로 논문 주장의 증거가 아닙니다. 코드 실행·설치는 하지 않았습니다.

## 1. 주장 검증 C1–Cn

판정: **확인**(재계산 일치·견고), **조건부**(맞지만 단서 필요), **약함**(근거가 표본 변동 안), **반증 못함·미확인**.

| # | 주장(위치) | 판정 | 검증 근거 |
|---|---|---|---|
| C1 | 인과 + 이미지 블록 안 양방향 마스크(§3, 그림 4) | 확인 | 독립 구현 둘이 세 배치에서 같음, 정보 흐름 점검 통과(`03` §1.1) |
| C2 | $L=L_{LM}+\lambda L_{DDPM}$, λ=5(식 4, §4.1) | 조건부 | 식은 토이로 구현·확인. λ=5는 "예비 실험"으로만 정당화되고 ε 오차의 합/평균과 이미지별 가중이 서술되지 않아 λ의 의미가 정규화에 묶임(`03` §1.2). 크기·패치별 재조정 서술 없음 |
| C3 | 추론: BOI에서 diffusion으로 전환, EOI를 붙이고 LM으로 복귀(§3) | 확인(토이) | 캡션 뒤 BOI 방출 100%, 전환 뒤 생성 분류 100%(9모델, `03` §1.3). EOI 학습 여부는 논문에 서술 없음 |
| C4 | 동등 FLOPs(6ND)에서 모든 평가가 Chameleon보다 스케일링이 낫다(§4.2, 그림 5) | 조건부 | 그림 5 점 재적합이 논문 선과 기울기가 같고 방향은 6개 지표 모두 확인. 그러나 FLOPs 동등에서 이미지 수가 약 4배 다르고(`03` §2.3), 25점은 모델 5개 군집이며, Llama 정확도·CLIP은 군집 부트스트랩에서 불확정(`03` §3) |
| C5 | 이미지 생성에서 FID 기준 1/34 FLOPs(§4.2, 표 3 FID 0.029) | 조건부 | 재계산 0.031(명목 7B로 0.030). 구간 [0.020, 0.041](점), [0.003, 0.050](군집). "수십 배"는 확인, 정확한 배수는 근거가 약함. 학습 FLOPs 기준이고 생성 FLOPs는 Transfusion이 약 62.5배 많음 |
| C6 | 이미지 생성 CLIP에서 1/3 미만(§1) | 약함 | 점추정 0.31–0.33, 95% 구간 상한 0.39–0.43이 1/3을 포함 |
| C7 | 텍스트 PPL이 Chameleon의 50–60% FLOPs에서 동등(§1, 표 3) | 확인(PPL) / 약함(정확도) | C4·Wiki 비율 0.51–0.55, 모든 구간이 1 미만. Llama 정확도는 0.61이지만 군집 구간 상한 5.5 |
| C8 | Transfusion이 텍스트 열화가 적다(표 4) | 조건부 | 괄호 차이 산술 일치. 단일 실행, Chameleon의 안정성 수정(QK-norm 등)이 원인의 절반(+0.9)이라는 해석은 그 수정 없이 불안정했다는 각주 12에 의존 |
| C9 | 이미지 안 양방향 어텐션이 중요하다(§4.3.1, 표 5) | 확인(선형) / 차이 없음(U-Net) | 선형 FID 61.3 → 20.3(7.7 산포 단위). U-Net에서는 16.8 → 16.7이고 논문이 이유를 U-Net 내부의 양방향성으로 설명. 토이는 이미지 먼저 배치에서 ε-MSE 2.3배 개선으로 방향을 지지(`03` §1.4) |
| C10 | 패치를 크게 해도 U-Net이면 성능이 유지되어 서빙 비용이 최대 64× 준다(§4.3.2, 표 6) | 조건부 | 위치 수 1024/16 = 64는 산술로 맞음. 그러나 같은 토큰 예산에서 큰 패치는 더 많은 이미지를 보고(8×8은 380M을 41번), 64×는 Transfusion 1×1 대비이지 Chameleon 대비가 아님. U-Net 4×4·8×8의 FID 개선(−4%)은 표본 변동 안(`03` §2.3, §4.3) |
| C11 | U-Net 이득은 파라미터 증가 이상(§4.3.3, 표 7) | 조건부 | CIDEr·FID·CLIP이 5개 크기에서 5/5 방향 일치(부호 검정 p = 0.0625). 7B에서는 FID −14%(1.05 단위), CIDEr +24%(1.8 단위). "작은 U-Net 모델이 7B 선형보다 낫다"는 FID 0.76B·1.4B(차이 약 2 = 평가 설정 변화 크기), CIDEr는 1.4B(+3.3%)뿐 |
| C12 | 이미지가 캡션 앞일 때 t ≤ 500 제한이 캡션을 개선(§4.3.4, 표 8) | 약함 | 0.76B +15.7%(1.2 단위), 7B +4.5%(0.4 단위). 토이는 제한 밖 t의 성능 희생 방향만 재현 |
| C13 | 7B·2T 토큰에서 확산 모델 수준 이미지 + Llama 1 수준 텍스트(§4.4, 표 9) | 조건부 | 표 9 수치를 옮겨 일관성 확인. FID 6.78 대 DeepFloyd 6.66·Parti 7.23은 서로 다른 보고 프로토콜(CFG 벤치마크별 조정), GenEval 0.63 대 0.61은 표본 오차 안(프롬프트 수 미확인). 파라미터 "7.3B"는 6.74B + 0.27B = 7.0B와 0.29B 불일치(`03` §2.2) |
| C14 | 8천 개 편집 예제로 이미지 편집 일반화(§4.5) | 미확인 | 정량 지표 없음. EmuEdit 시험의 무작위 예제를 사람이 본 정성 평가 |

보조 확인: 표 간 일관성은 모두 일치, 표 5·6 열 머리의 "Acc (↓)"는 오타, VAE 잠재 크기 산술(256 → 32×32 → 2×2 패치 256개, 4×4 64개, 8×8 16개)은 맞습니다. 구현 가능성 판단용 크기(7B 학습 2T 토큰 ≈ 8.4e22 FLOPs, `03` §2)와 데이터(Shutterstock 380M, 비공개)는 이 맥에서 재현 불가임을 보여 줍니다.

## 2. 이 맥에서 할 수 있는 것과 없는 것
- **한 것:** 마스크·두 손실 토이(CPU, 약 6분), 그림 5 점 재적합과 부트스트랩, 6ND·파라미터·이미지 수 산술, 표 3–8 재계산, FID 편향 토이.
- **할 수 있지만 하지 않은 것(제안):** 토이를 MNIST류로 확장해 선형 대 U-Net 인코더와 양방향 대 인과를 이미지 품질로 보기, 비공식 구현의 `train_mnist.py`를 설치 후 MPS에서 실행(설치 승인 필요, 아래 §3). 이 맥(M4 Pro, 24 GB)에서 0.16B 수준은 메모리상 가능하나 데이터(Shutterstock)가 없고 논문 규모의 비교는 불가.
- **할 수 없는 것:** 7B 사전학습, Chameleon 대조군 재현(2T 토큰, 대형 GPU 클러스터), 논문 점수 재현.

## 3. 비공식 구현과의 정적 대조 U1–U8 (`repo/transfusion-pytorch/`, 비공식)

`lucidrains/transfusion-pytorch`(MIT, 별 1,412, 마지막 push 2026-09-04, `transfusion_pytorch/transfusion.py` 3,702줄)의 README는 "확산을 flow matching으로 대체하겠다"고 밝힙니다. 아래는 논문과 다른 점이고, **이 구현이 논문의 실험 결과를 재현한다는 증거는 없습니다.**

| # | 논문 | 비공식 구현 | 영향 |
|---|---|---|---|
| U1 | DDPM, ε 예측, 코사인 일정, 학습 1,000 timestep, 추론 250 스텝(§2.2, §4.1) | flow matching(rectified flow)의 속도 예측, 시간 [0, 1], `torchdiffeq.odeint`로 샘플링(`transfusion.py` 33, 2137줄) | 식 3과 식 4의 $L_{DDPM}$이 아님. 논문이 "미래 과제"로 둔 대체(§3) |
| U2 | λ = 5 | `flow_loss_weight = 1.`, `text_loss_weight = 1.`(1406–1407줄) | 기본값이 다름 |
| U3 | LM 손실은 토큰별, 확산 손실은 이미지별(§3) | 텍스트 CE와 flow MSE 둘 다 `total_tokens`로 나눔(3460–3500줄 부근) | 이미지당 길이가 다른 배치에서 상대 가중이 논문과 다를 수 있음 |
| U4 | 이미지가 캡션 앞일 때 노이즈를 **최대 t=500**까지로 제한(표본은 [0, 500])(§4.3.4) | `default_modality_length_to_time_fn`: 이전에 디코딩된 모달리티의 시간을 **0.5로 고정**(198–215줄, 주석이 "in paper, they fix …"라고 적음) | 논문 서술("limit the maximum")과 다름. 구현자의 해석 |
| U5 | 선형 변형: timestep 임베딩을 패치 벡터에 더함(각주 6) | `AdaptiveWrapper`로 adaLN-Zero식 게이트(`to_ada_ln_zero`, 736–810줄) | DiT 쪽 조건 주입. 논문의 선형 변형과 다름 |
| U6 | 마스크: 인과 + 이미지 안 양방향(그림 4) | `naive_attn_mask`: `is_causal \| is_modality`(519–540줄), `is_modality`는 같은 모달리티 블록 안의 쌍 | **마스크는 논문과 같은 규칙**(`03` §1.1의 식과 같은 형태). flex attention은 CUDA에서만 사용(1028줄) |
| U7 | 이미지 BOI/EOI 표지, 캡션 먼저 80%(§4.1) | 시작·종료 토큰 `sos_id`, `eos_id`, `null_text_id`(1525줄), 순서 비율은 사용자 데이터에 의존 | 이미지 길이를 `modality_default_shape`로 정하는 점 등 인터페이스가 다름 |
| U8 | 모달리티는 텍스트와 이미지 | 임의 개수의 모달리티, CFG, 속도 일관성 손실·EMA 등 확장(1406–1410줄) | 논문 범위를 넘는 기능. 속도 일관성 손실(`velocity_consistency_loss_weight = 0.1`)은 논문에 없음 |

- **정리:** 마스크(U6)는 논문과 같고, 손실의 종류(U1), 가중(U2, U3), 노이즈 제한(U4), 조건 주입(U5)은 모두 다릅니다. 이 구현은 "한 모델에서 텍스트 CE와 연속 모달리티 손실을 함께 학습하고 중간 시점에 diffusion/flow 샘플링으로 전환하는" 구조를 보여 주는 참고로 쓸 수 있으나, 논문 수치의 대조 대상은 아닙니다.
- 작업 트리 71 MB(`du -sh`). `.gitignore` 대상(`repo/`)이라 커밋하지 않습니다.
- Meta의 `facebookresearch/Mixture-of-Transformers`(BSD-3-Clause, `repo/Mixture-of-Transformers/`, 1 MB)는 MoT 튜토리얼과 모듈 3개(`src/`)뿐이고 Transfusion 학습·평가 코드가 없습니다. README의 "Transfusion 설정에서 7B MoT가 FLOPs 3분의 1"은 MoT 논문의 주장이며 이 분석에서 검증하지 않았습니다.
