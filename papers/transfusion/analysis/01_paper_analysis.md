## 1. 문제와 한 줄 요약

멀티모달 생성 모델은 이산 요소(텍스트)와 연속 요소(이미지)를 함께 다뤄야 합니다. 기존 길은 셋입니다. (a) 언어 모델에 확산 모델을 도구로 붙이기, (b) 사전학습 확산 모델을 접목하기, (c) 이미지를 양자화해 이산 토큰으로 만들어 언어 모델 하나로 학습하기(Chameleon). 이 논문은 (c)의 정보 손실 없이 **한 Transformer를 텍스트에는 다음 토큰 예측, 이미지에는 diffusion으로 동시에 학습**합니다(§1). 이미지는 VAE 잠재 패치(연속 벡터)로 두고, 텍스트와 이미지를 한 시퀀스에 BOI/EOI 표지로 섞습니다.

주장의 핵심은 세 가지입니다. (1) 같은 파라미터·데이터·FLOPs 조건에서 Transfusion이 Chameleon보다 모든 평가에서 스케일링이 낫다(§4.2, 그림 5, 표 3). (2) 이미지 안 양방향 어텐션과 U-Net 패치 인코더가 중요하다(§4.3). (3) 7B, 2T 토큰으로 키우면 확산 모델 수준의 이미지 생성(GenEval 0.63)과 Llama 1 수준의 텍스트를 한 모델이 낸다(§4.4, 표 9).

## 2. 방법

### 2.1 배경 식 (§2)
- 언어 모델 손실: $L_{LM} = \mathbb{E}_{y_i}[-\log P_\theta(y_i\mid y_{<i})]$ (식 1).
- 순방향 확산: $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$, $\bar\alpha_t=\prod_{s\le t}(1-\beta_s)$ (식 2).
- 확산 손실(ε 예측): $L_{DDPM} = \mathbb{E}_{x_0,t,\epsilon}\|\epsilon-\epsilon_\theta(x_t,t,c)\|^2$ (식 3). 노이즈 일정은 코사인(Nichol & Dhariwal), 학습 1,000 timestep.
- 잠재 표현: 86M 파라미터 VAE(Esser 외 방식), 256×256 이미지 → 32×32×8 잠재(잠재 픽셀 하나가 8×8 픽셀 패치에 해당, 잠재 차원 8, 100만 스텝 학습, §4.1, 부록 A). VAE 손실은 $L_1+L_{LPIPS}+0.5L_{GAN}+0.2L_{ID}+10^{-6}L_{KL}$(부록 A).

### 2.2 Transfusion (§3)
- **데이터 표현:** 텍스트는 정수 토큰, 이미지는 잠재 패치 벡터 열(왼쪽 위에서 오른쪽 아래 순). 이미지 앞뒤를 BOI, EOI 토큰으로 감쌉니다.
- **구조:** 파라미터 대부분이 Llama식 Transformer 하나(SwiGLU, RoPE)이고, 모달리티별 가벼운 입출력 층이 있습니다. 이미지는 $k\times k$ 잠재 패치를 Transformer 벡터 하나로 압축/복원하는 (1) 선형층 또는 (2) U-Net 업·다운 블록(AdaLayerNorm 대신 일반 LayerNorm, 각주 7)을 씁니다. 선형층 변형에서는 timestep 임베딩을 모든 패치 벡터에 더합니다(각주 6).
- **어텐션(그림 4):** 시퀀스 전체에 인과, 한 이미지 안의 패치끼리는 양방향. 이미지 패치는 앞의 텍스트와 앞 이미지를 보지만 뒤는 보지 못합니다.
- **손실(식 4):** $L_{Transfusion}=L_{LM}+\lambda L_{DDPM}$, **λ = 5**(§4.1, "예비 실험 후 결정, 추가 조정은 미래 과제"). LM 손실은 토큰별, 확산 손실은 이미지별(여러 패치)로 계산합니다. 입력이 BOI이면 손실을 계산하지 않습니다(각주 8). 노이즈는 패치화 이전에 잠재 이미지에 더하므로, 뒤따르는 토큰은 **노이즈 낀 이미지**를 조건으로 학습합니다(각주 9).
- **추론:** LM 모드에서 토큰을 하나씩 샘플링하다가 BOI가 나오면 diffusion 모드로 전환합니다. 원하는 크기의 순수 노이즈 $x_T$ 패치 n개를 시퀀스에 붙이고 T단계에 걸쳐 노이즈를 걷습니다. 매 단계에서 $x_{t-1}$이 $x_t$를 덮어쓰므로 모델은 항상 마지막 timestep만 봅니다. 끝나면 EOI를 붙이고 LM 모드로 돌아갑니다(§3 Inference). 이미지 생성은 250 스텝(학습 1,000 timestep), CFG 계수는 대조군 실험 5, 절제 3, 대규모 실험은 벤치마크별 조정(§4.1).

### 2.3 데이터와 학습 (§4.1)
- 0.5T 토큰(패치 포함)을 텍스트와 이미지에서 **1:1 토큰 비율**로 샘플링. 텍스트는 Llama 2 토크나이저·코퍼스, 이미지는 380M 라이선스 Shutterstock 이미지와 캡션(256×256 중앙 자르기). 캡션을 먼저 놓는 비율 80%, 이미지가 먼저인 비율 20%(§4.1, §4.3.4).
- 모델 크기(표 2): 0.16B(16층, d=768), 0.37B(24층, 1024), 0.76B(24층, 1536), 1.4B(24층, 2048), 7B(32층, 4096). 선형 인코더의 추가 파라미터는 모든 크기에서 0.5% 미만, U-Net은 모든 구성에서 약 0.27B(7B 대비 3.8%).
- 최적화: AdamW(β=0.9, 0.95), lr 3e-4(4,000 스텝 워밍업, 코사인으로 1.5e-5까지), 시퀀스 4,096, 배치 2M 토큰, 250k 스텝(=0.5T). 가중치 감쇠 0.1, 기울기 클립 1.0. 대규모(§4.4)는 배치 4M, 500k 스텝(=2T).
- 대규모 실험 데이터(§4.4): 텍스트 1T 토큰, 이미지 쪽은 Shutterstock + 공개 이미지 220M(사람 제외 필터) + 사람 포함 80M 상향 + CC12M, 에폭당 692M 쌍을 약 5 에폭(약 3.5B 쌍, 이미지당 256 패치), 학습 마지막 1% 동안 높은 미적 점수 이미지 가중.

### 2.4 Chameleon 대조군 (§4.1–4.2)
- Chameleon 레시피를 따른 데이터·계산량 통제 대조군. VAE와 같은 데이터·계산·구조로 VQ-VAE를 학습하고 차이는 양자화 층과 코드북 손실뿐(코드북 16,384, β=0.25, 부록 A). Chameleon은 query-key 정규화, post-norm, denominator loss, lr 1e-4를 쓰며(불안정성 관리), 이것을 빼면 불안정해졌다고 합니다(각주 12). 이 변경이 효율 비용을 낳는다고 §4.2가 인정합니다.
- **이미지당 시퀀스 길이:** Transfusion 2×2 패치는 이미지당 256 요소, Chameleon의 VQ는 1,024 토큰입니다(각주 13, 표 6). 토큰 비율이 1:1로 고정이므로 같은 토큰 예산에서 **Transfusion이 약 4배 많은 이미지를 봅니다**(`03` §2.3).

## 4. 논문이 말한 한계와 열린 질문

- λ 조정, flow matching 대체, 다른 구조(이름과 달리 Transformer 전용이 아님), 이미지 이외 모달리티(음성, 영상)는 "미래 과제"입니다(§3, 각주 5, §6).
- 텍스트 성능이 Transfusion에서 더 낫다는 점은 이유를 모른다고 밝힙니다. 가설 둘: 출력 분포에서 텍스트와 이미지 토큰의 경쟁, 또는 확산이 이미지 생성에 더 적은 파라미터가 필요해 텍스트에 용량이 남음(§4.2).
- U-Net 이득은 귀납 편향 때문이라고 주장하지만 U-Net을 스케일하지 않았습니다(각주 17).
- 이미지 편집은 정성 평가입니다(§4.5).

## 5. 이 분석에서 눈여겨본 점 (검증은 `03`)

- **FLOPs 동등 비교는 이미지 수가 다릅니다.** 6ND는 같지만 이미지당 길이가 256 대 1,024라서 Transfusion이 약 4배 많은 이미지를 봅니다. 논문은 각주 13에서 "더 많은 이미지를 볼 수 있다"고만 적습니다.
- **그림 5의 점은 모델 5개 × 체크포인트 5개(0.1–0.5T)입니다.** 25점이지만 독립된 실행은 크기마다 하나입니다. 중간 체크포인트는 코사인 감쇠가 끝나지 않은 상태입니다.
- **표 3과 표 7은 같은 7B 모델이지만 FID 평가 설정이 다릅니다.** 표 3은 30k 프롬프트에 CFG 5, 표 7은 5k에 CFG 3라서 같은 선형 7B의 FID가 16.8 대 18.6으로 다릅니다.
- **표 5·6의 열 머리 "Llama Acc (↓)"는 오타**(정확도는 높을수록 좋음, 표 7·8은 (↑)).
- **표 9의 "7.3B"**는 6.74B(Llama형 7B) + 0.27B(U-Net)의 7.0B와 0.3B 다릅니다(`03` §2.2).
- 시드 반복, 신뢰구간, 오차 막대는 어느 표에도 없습니다.
