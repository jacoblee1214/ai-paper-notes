# 01. 논문 분석: Why Do Multi-Agent LLM Systems Fail? (MAST)

- 논문: Cemri, Pan, Yang 외, UC Berkeley. arXiv:2503.13657. 분석 판은 **v3 (2025-10-26)**. v1(2025-03-17)과 v2도 읽고 차이를 §6에 적었습니다.
- 학회: NeurIPS 2025 Datasets & Benchmarks 트랙, 스포트라이트 (v3 첫 쪽 각주 "39th NeurIPS Track on Datasets and Benchmarks", neurips.cc 공식 페이지 확인, README 참고)
- 자료: 공식 저장소 `multi-agent-systems-failure-taxonomy/MAST`(커밋 `a70542e`), 주석 데이터 HF `mcemri/MAD`(현 이름 `mcemri/MAST-Data`, CC BY 4.0)

## 1. 문제

다중 에이전트 LLM 시스템(MAS)은 인기 벤치마크에서 단일 에이전트나 best-of-N보다 이득이 작은 경우가 많습니다(§1). 저자들은 왜 실패하는지를 **체계적으로 분류**하려 합니다. 실패는 "MAS가 의도한 과업 목표를 달성하지 못한 경우"로 정의합니다(§1).

## 2. 방법 (세 단계)

### 2.1 분류 체계 도출 (§3.1)

- 5개 오픈소스 MAS(HyperAgent, AppWorld, AG2, ChatDev, MetaGPT)에서 trace 150여 개를 모았습니다. 전문가 6명이 Grounded Theory(개방 코딩, 지속적 비교, 메모, 이론화)로 실패 양상을 도출하고 이론적 포화까지 반복했습니다. 사람당 20시간 이상(§3.1).
- 결과가 **MAST**입니다. 3범주 14모드(그림 1).

| 범주 | 모드 |
|---|---|
| FC1 시스템 설계 | 1.1 과업 명세 위반, 1.2 역할 명세 위반, 1.3 단계 반복, 1.4 대화 이력 손실, 1.5 종료 조건 미인지 |
| FC2 에이전트 간 불일치 | 2.1 대화 초기화, 2.2 명확화 요청 실패, 2.3 과업 이탈, 2.4 정보 은닉, 2.5 다른 에이전트 입력 무시, 2.6 추론-행동 불일치 |
| FC3 과업 검증 | 3.1 조기 종료, 3.2 검증 없음·불완전, 3.3 검증 오류 |

### 2.2 주석자 간 일치도(IAA)로 정의를 고정 (§3.2)

- 라운드마다 주석자 3명이 trace 5개를 독립 주석하고 불일치를 토론해 정의를 고칩니다(모드 추가, 병합, 삭제). 세 라운드를 했고 토론에만 약 10시간이 들었습니다.
- Cohen's κ를 쓰고 "마지막 라운드들에서 평균 κ = 0.88"을 보고합니다(§3.2). **v3에는 라운드별 κ가 없습니다.** v1·v2 본문에는 라운드 1 κ=0.24, 라운드 2 κ=0.92, 라운드 3 κ=0.84가 있습니다(`03` §2).
- 새 MAS 두 개(OpenManus, Magentic-One)와 새 벤치마크(MMLU, GAIA)에서 분류 체계를 고치지 않고 한 번 더 주석해 κ=0.79(§3.4).

### 2.3 LLM 판정자 (§3.3, 표 2)

- OpenAI o1에 trace, MAST 정의, few-shot 예시를 주고 14모드를 이진 판정(예/아니오)과 한 문장 요약으로 받습니다(부록 N, 공개 노트북).
- IAA 연구의 held-out 사람 주석과 비교한 결과가 표 2입니다.

| 모델 | 정확도 | 재현율 | 정밀도 | F1 | κ |
|---|---|---|---|---|---|
| o1 | 0.89 | 0.62 | 0.68 | 0.64 | 0.58 |
| o1 few-shot | 0.94 | 0.77 | 0.833 | 0.80 | 0.77 |

held-out 크기는 논문에 없습니다(`03` §3).

### 2.4 MAST-Data (§3.4, 표 1)

- 7개 MAS × 여러 LLM(GPT-4o, Claude 3.7 Sonnet, Qwen2.5-Coder-32B, CodeLlama-7B, GPT-4, GPT-4o-mini) × 여러 벤치마크에서 **1,642 trace**를 LLM 판정자로 주석했습니다. 표 1의 구성별 개수(30, 100, 206, 193, 168, 165)를 더하면 1,642입니다(`03` §4에서 공개 데이터로 확인).
- 사람이 주석한 별도 세트 MAST-Data-human(논문 본문 "21 traces", 공개 파일은 19개 기록)도 공개합니다.

## 4. 한계 (저자 서술과 우리 관찰)

- 저자: 분류가 모든 실패를 덮는다고 주장하지 않습니다(§1, §4).
- 우리 관찰: **MAS 실패 정의가 과업 미달성**이어서 모드가 곧 실패 원인이라는 보장은 없습니다. 24%(1,638 중 401)의 trace가 어떤 모드도 받지 않았고, 성공 trace에도 모드가 붙습니다(부록 J.1 자체가 인정).
- 사람 주석은 15 + 4 = 19개 trace뿐이고 대부분 모드가 거의 나타나지 않는 셀입니다(`03` §2).
- 모드 정의와 개수가 라운드마다 달랐습니다(공개 데이터: 18, 17, 17, 14개). **κ 0.88은 14모드 최종판의 값이 아닙니다**(`03` §2).
- 판정자는 단일 모델(o1), 단일 호출, temperature 1.0입니다(공개 노트북). 반복 일관성은 보고되지 않았습니다.

## 5. 우리 검증의 요약 (상세는 `03`, `04`)

- κ: 사람 주석 PDF 원표로 다시 계산해 라운드 2 = 0.95(3쌍 평균), 라운드 3 = 0.89, 새 벤치마크 4 trace = 0.73. 논문의 0.92·0.84는 3쌍 평균이 아니라 한 쌍의 값에 가깝습니다. **0.88은 라운드 2와 3의 κ 평균이고 라운드 1의 κ 0.24는 제외됩니다.**
- 공개 LLM 라벨로 계산한 모드 비율은 그림 1 값과 일부만 맞습니다. 표 6은 56칸 중 36칸이 맞습니다.
- 표 5와 표 7의 차이는 표본 크기(n=32, n=10–20)에서 통계적으로 확인되지 않습니다.

## 6. 판 사이의 차이

| 항목 | v1 (2025-03) | v2 | v3 (2025-10) |
|---|---|---|---|
| 이름 | MASFT | MAST | MAST + MAST-Data |
| trace 수 | 150+ (그림 2: 151) | 200+ | **1,642** |
| 모드 수 | 14 | 14 | 14 |
| IAA κ | 라운드 1 0.24, 2 0.92, 3 0.84 (본문 표기) | 같음 | "마지막 라운드들 평균 0.88"만 (라운드별 값 없음) |
| LLM 판정자 κ | 0.77 (서론: 사람 3명 주석 10 trace와 비교) | 0.77 | 0.77, "held-out set" |
| 새 MAS 일반화 | 없음 | 0.79 | 0.79 |

v1은 모드 수가 같지만 실험 규모가 작았고, v3에서 데이터셋이 주인공이 되었습니다. 라운드 1의 κ 0.24가 v3에서 사라진 점은 인용할 때 주의합니다.
