## 2. 식 유도 검산

기호: 프로토타입 K개, 배치 B, 교사 로짓 z_i ∈ R^K(머리 출력), 교사 온도 τ, 학생 온도 τ_s = 0.1.

### 2.1 손실의 분해와 붕괴의 두 해

이미지 수준 항은 L = −Σ_k p_t(k) log p_s(k)이고 이는 **L = H(p_t) + KL(p_t ‖ p_s)**로 분해됩니다(수치 확인: 최대 오차 1e-6). 학생은 KL을 줄이지만 H(p_t)는 교사가 정합니다. 그러면 자명한 해가 둘 있습니다.
- **(A) 한 차원 지배:** 모든 입력에서 같은 프로토타입이 1이면 p_t, p_s가 모두 원-핫이고 H = 0, KL = 0. 입력에 의존하지 않는 상수 출력입니다.
- **(B) 균등 분포:** 모든 입력에서 p_t = p_s = 1/K이면 KL = 0, L = log K. 역시 상수 출력입니다.
두 해 모두 **입력 정보를 버립니다.** 교사를 EMA로 천천히 움직이는 것만으로는 막지 못하고(BYOL류는 예측기·비대칭으로 막음), DINO는 교사 쪽 두 장치로 A와 B를 각각 막습니다.

### 2.2 중심화는 A를, 날카롭게 하기는 B를 막는다

교사 로짓을 입력 공통 성분 b와 입력 의존 성분 δ_i(배치 평균 0)로 나눕니다: z_i = b + δ_i.
- **중심화 없음.** p_t = softmax((b + δ_i)/τ). b의 최댓값과 둘째 값의 차이를 m, ‖δ_i‖∞ ≤ ε이라 하면 p_t(k*) ≥ 1 − (K − 1) exp(−(m − 2ε)/τ). m − 2ε ≫ τ log K이면 모든 입력에서 p_t ≈ e_{k*}(붕괴 A). 상수 편향이 생기면 학생이 그것을 따라가 편향이 더 커지는 양의 되먹임이 있습니다.
- **중심화 있음.** c를 배치 평균의 이동 평균(모멘텀 0.9)으로 두면 정상 상태에서 c → E[z] = b이므로 p_t = softmax(δ_i/τ). 공통 편향이 제거되어 A가 막힙니다. 수치: `test_centering_removes_a_constant_bias`(편향 5.0이 있는 입력에서 중심화 후 확률이 편향 없는 경우와 같음, 중심화 없이는 3번 프로토타입 질량 > 0.99).
- **그러나 중심화만으로는 B로 간다.** 입력과 무관한 상수 출력이면 δ_i = 0이므로 p_t는 균등입니다. `test_centering_alone_collapses_to_uniform_for_constant_outputs`: 200회 갱신 후 온도 0.04에서도 균등(오차 1e-3).
- **날카롭게 하기가 B를 막는 이유.** δ가 작지만 0이 아니면 softmax(δ/τ)는 τ가 작을수록 δ의 차이를 증폭합니다. u = δ/τ가 작을 때 2차 전개로
 H(softmax(u)) ≈ log K − ½ Var_k(u).
 δ_k ~ N(0, s²) 독립이면 Var_k(u) ≈ s²/τ² (K−1)/K이므로 **H ≈ log K − s²/(2τ²)**. 수치(`entropy_vs_spread_over_T`, K = 64, log K = 4.159): s = 0.05, τ = 0.07에서 예측 4.159 − 0.255 = 3.90, 측정 3.912. s = 0.02, τ = 0.04에서 예측 4.159 − 0.125 = 4.03, 측정 4.036. s = 0.1, τ = 0.04에서 2차 전개의 한계를 넘어 측정 2.18. 즉 **s/τ가 0.2 이하면 엔트로피가 log K의 0.02 안에 있어 사실상 균등**이고(s = 0.01, τ = 0.07: 4.149), 날카롭게 하려면 τ ≲ s여야 합니다.
- **정리.** 중심화는 입력 공통 성분(A)을 지우는 방향, 날카롭게 하기는 남은 입력 의존 성분을 증폭해 균등(B)에서 멀어지는 방향으로 서로 반대로 당깁니다. 두 장치 어느 쪽도 "입력 의존 성분 δ가 0이 아님"을 만들지는 못합니다. 그것은 학생과 EMA 교사의 자기 증류, 멀티 크롭의 일관성 요구, 데이터의 구조가 만듭니다.
- **함의.** 로짓 퍼짐 s는 머리 구조와 프로토타입 수에 따라 달라지므로 **적정 교사 온도는 설정에 의존**합니다. 우리 토이의 코사인 머리(K = 64)에서는 공식 값 0.04–0.07이 s에 비해 너무 높았습니다(§5).

### 2.3 Sinkhorn-Knopp 중심화의 행·열 합

교사 로짓에서 K×B 행렬 M_kb = exp(z_bk/τ)를 만들고 다음을 풉니다.
 min over Q ∈ U(r, c) of KL(Q ‖ M), U(r, c) = {Q ≥ 0 : Q1 = r, Qᵀ1 = c}, r = 1/K · 1, c = 1/B · 1.
라그랑주 조건에서 Q_kb = α_k M_kb β_b(M에 양쪽 대각 스케일링을 곱한 꼴)가 나옵니다. 수치 확인: `test_sk_is_diagonal_scaling_of_exp_kernel`(log Q − z/τ가 행 효과 + 열 효과의 합으로 분해되며 잔차 < 1e-4).
Sinkhorn 반복은 α, β를 번갈아 맞춥니다: 행 정규화(프로토타입 질량 1/K) 후 열 정규화(샘플 질량 1/B). **마지막 단계가 열 정규화이므로 열(샘플) 합은 정확히 1/B**(코드는 ×B로 샘플별 확률분포가 됨, `test_sk_rows_are_distributions_columns_balanced`가 행 합 1을 1e-5에서 확인), **행(프로토타입) 합은 근사**이고 반복할수록 1/K로 수렴합니다.

프로토타입 질량의 최대 상대 오차(B = 256, K = 32, τ = 0.05):

| 로짓 표준편차 | 1회 | 3회 | 10회 | 50회 | 200회 |
|---|---|---|---|---|---|
| 0.05 | 0.057 | 0.0002 | 0 | 0 | 0 |
| 0.1 | 0.255 | 0.020 | 0 | 0 | 0 |
| 0.3 | 1.89 | 0.596 | 0.049 | 0 | 0 |
| 1.0 | 1.40 | 1.20 | 0.456 | 0.035 | 0.0001 |

- 오차는 반복 수에 대해 단조 감소(`test_sk_converges_...`). 수렴 속도는 exp(z/τ)의 동적 범위(≈ exp(2s/τ))에 의존합니다.
- **DINOv2의 "3회"는 코사인 로짓 규모(|로짓| ≤ 1, 퍼짐 ≲ 0.1)에서 근사 균등을 주는 값입니다.** 로짓이 더 퍼지면 3회 뒤에도 프로토타입 질량이 크게 불균등합니다. 표 1의 SK 행이 개선을 보이지 않는 것(`04` C9)과 함께, 3회 SK는 "정확한 균등 분할"보다 "부드러운 균형 압력"으로 읽는 편이 정확합니다.
- 공식 코드는 B를 기기 전체로 보고(`all_reduce`), iBOT 쪽은 가린 패치 수로 합니다. 우리 구현은 단일 기기 배치만 봅니다.

### 2.4 KoLeo는 Kozachenko-Leonenko 엔트로피 추정량에서 나온다

밀도 f에서 n개를 뽑고 x_i의 최근접 이웃 거리를 ρ_i라 하면, 이웃이 반경 r 안에 없을 확률은 P(ρ_i > r) ≈ (1 − f(x_i) V_d r^d)^(n−1) ≈ exp(−(n−1) f(x_i) V_d r^d)(V_d = π^{d/2}/Γ(d/2+1)은 d차원 단위 공의 부피). 따라서 T_i = (n−1) f(x_i) V_d ρ_i^d는 근사적으로 Exp(1)이고 E[log T_i] = −γ(오일러 상수)입니다. 정리하면
 E[log f(x_i)] = −γ − log(n−1) − log V_d − d E[log ρ_i],
 **H(f) = −E log f ≈ ψ(n) + γ + log V_d + (d/n) Σ_i log ρ_i** (log(n−1)을 ψ(n)으로 바꾼 표준형, k = 1).
이것이 `kl_entropy`입니다. KoLeo = −(1/n) Σ log ρ_i이므로 **KoLeo = −(Ĥ − ψ(n) − γ − log V_d)/d**: 배치 안 최근접 거리의 로그를 키우는 것은 미분 엔트로피 추정량을 키우는 것의 아핀 변환입니다(`test_koleo_is_affine_in_kl_entropy`, 오차 1e-3).
- 수치(N(0, I_d)의 참값 d/2·log(2πe)와의 오차, 5회 반복): d = 2에서 편향 +0.044(n = 500), −0.004(n = 2000), +0.006(n = 8000), 표준편차 0.09, 0.06, 0.016. d = 8에서 편향 +0.04, −0.02, −0.04(표준편차 0.07–0.04). 테스트: N(0, I_2)와 [0,1]³ 균등에서 참값과 0.08 이내.
- **주의.** (1) KoLeo는 L2 정규화된 점에 적용되므로 점이 구면 위에 있어 내재 차원은 d − 1이고 d를 쓴 엔트로피 해석은 상수와 척도에만 영향을 줍니다. 단조성(퍼질수록 감소)이 핵심입니다. (2) ρ의 스케일이 n^(−1/d)이므로 **KoLeo의 값은 배치 크기에 의존**합니다(공식은 기기당 배치, 논문 부록 B.1). (3) 거리가 0이면 −log(eps) ≈ 18.4로 폭발하며 겹침을 강하게 벌합니다(`test_koleo_smaller_when_spread_larger_when_overlapping`: 원 위 균등 < 군집 < 겹침 > 10).
- 기울기 방향: 가까운 두 점 사이 거리가 늘어납니다(`test_koleo_gradient_pushes_points_apart`).

### 2.5 EMA 교사

θ_t^{(k+1)} = m θ_t^{(k)} + (1 − m) θ_s^{(k)}를 펼치면 **θ_t^{(T)} = m^T θ_t^{(0)} + (1 − m) Σ_{k<T} m^{T−1−k} θ_s^{(k)}**: 학생 이력의 지수 가중 평균입니다(`test_ema_is_exponentially_weighted_average_of_student_history`). 학생이 고정이면 θ_t − θ_s = m^T (θ_t^{(0)} − θ_s)로 기하적으로 수렴(`test_ema_extremes_and_closed_form`). m = 1이면 교사 불변, m = 0이면 학생 복사.
유효 창 길이 1/(1−m): m = 0.994에서 167 스텝, 마지막 167스텝에 가중치 63%(1 − m^167 = 0.634 근방). 논문은 m을 0.994에서 1로 **코사인**으로 올리므로(표 16, 625k 스텝) 초반 창은 약 167, 끝에서는 무한대가 되어 교사가 사실상 고정됩니다. 토이는 0.99 → 1(600 스텝)입니다.

### 5.3 한계

- **토이이며 논문 재현이 아닙니다.** 0.17M, 합성 이미지 6종, 600 스텝, 프로토타입 64개. 규모가 다르면 붕괴 조건(s/τ)이 달라집니다. "중심화 + 날카롭게 하기만으로 특징 차원 붕괴를 못 막는다"는 이 코사인 머리·작은 모델·짧은 학습의 결과이고 DINO 논문의 ImageNet 규모 결과와 모순이라고 읽을 수 없습니다(공식 설정은 머리 구조, 증강, 학습 길이가 달라 우리는 시험하지 않음).
- 합성 과제의 증강(채널 순열)이 색 불변을 강제하므로 도형이 유일한 지속 신호입니다. 프로브 정확도의 절대값은 의미가 없고 기준선과의 상대 비교만 봅니다.
- 시드 5개의 구간은 t 분포 근사이고 시드 간 분산 이질성이 큽니다(날카롭게만 조건의 유효 차원 구간 ± 7.7).
- 프로브는 학습 3000장에서 단일 분할이며 MPS 비결정성으로 같은 시드의 재실행이 소수 둘째 자리에서 다를 수 있습니다(예비 실험의 같은 조건이 0.654와 0.656).
- iBOT 손실의 소거(가린 패치 손실 유무)는 하지 않았습니다. 따라서 표 3b의 iBOT 효과에 대한 토이 증거는 없습니다.

## 6. 정리

- **확인한 것:** 교차 엔트로피 분해, 중심화·날카롭게 하기가 각각 한 차원 지배와 균등 붕괴를 막는 것(토이 5/5 시드, 식 H ≈ log K − s²/2τ²), SK의 행·열 합 성질과 반복 수 한계, KoLeo = KL 엔트로피 추정량의 아핀 변환, EMA 닫힌 꼴, 29개 테스트.
- **새로 알게 된 것:** (1) 3회 SK는 로짓 퍼짐이 크면 불균형이 큼(퍼짐 0.3에서 60%). (2) 교사 온도의 적정값은 로짓 퍼짐에 의존하고 공식 0.04–0.07을 작은 코사인 머리에 그대로 쓰면 균등 붕괴. (3) 이 토이에서 특징 품질을 올린 것은 중심화나 날카롭게 하기가 아니라 KoLeo였습니다. (4) 논문 표 1의 SK 행은 변화가 없고 토이에서도 SK와 softmax 중심화의 차이는 구분되지 않음.
- **하지 못한 것:** 사전학습 가중치의 벤치마크 평가(고노름 토큰 측정만 §7), 논문 규모 학습, 표 1·2·3의 재현, iBOT 소거.

## 7. 사전학습 가중치로 측정한 고노름 토큰 (`high_norm_tokens.py`)

`04` C7의 확인입니다. Darcet et al.(arXiv:2309.16588)이 보고한 고노름 토큰(약 2% 토큰, 노름 약 10배, ViT-L 이상에서만, DINO v1 예외)을 공개 가중치에서 직접 쟀습니다. 논문 원문은 이 저장소에 없어 정의는 `04` C7이 정리한 것을 따랐습니다.

**설정.** MMVP-VLM 이미지 270장(HF `MMVP/MMVP_VLM`의 `images/`)을 224×224로 줄여 패치 256개/장, 총 69,120토큰. 모델: DINOv2 ViT-S/14 원본(`facebook/dinov2-small`), register 4개 변형(`facebook/dinov2-with-registers-small`), OpenAI CLIP ViT-L/14의 비전 타워(`openai/clip-vit-large-patch14`). **측정 대상은 마지막 층 출력(최종 정규화 앞)의 패치 토큰 L2 노름**이고 CLS와 register는 제외했습니다(허깅페이스 `hidden_states[-1]`). SigLIP은 승인되지 않아 재지 않았습니다. 결과는 `high_norm_tokens_results.json`, 그림은 `figures/own_high_norm_tokens.png`입니다.

**임계값.** 전역 중앙값의 3배(CLIP 약 73, DINOv2는 해당 없음). CLIP의 로그 노름 히스토그램에서 두 번째 봉우리와 본 분포 사이의 골이 중앙값의 약 2.5–3배에 있어 고른 값입니다(상위 10% 꼬리의 최대 간극은 58→62로 비 1.07이라 골이 뚜렷하지는 않음). 절대값 150(Darcet의 ViT-g 기준)은 모델마다 노름 규모가 달라 쓰지 않았습니다. 민감도는 아래 표에 있고 2–7배에서 0.7–1.4%로 같은 수준이며 10배에서는 0이 됩니다.

| 모델 | 패치 노름 중앙값 | 최대 | 최대/중앙값 | 3배 초과 비율 | 2배 / 5배 / 7배 / 10배 초과 |
|---|---|---|---|---|---|
| DINOv2 ViT-S/14 | 20.2 | 28.7 | 1.42 | **0** (0/69,120) | 모두 0 |
| DINOv2 ViT-S/14 + register 4 | 59.6 | 90.5 | 1.52 | **0** | 모두 0 |
| CLIP ViT-L/14 | 24.3 | 242 | **9.95** | **1.09%** (753개) | 1.37% / 0.93% / 0.68% / 0 |

- **CLIP ViT-L/14는 뚜렷한 고노름 토큰이 있습니다.** 270장 모두에 2–7배 초과 토큰이 있고(이미지별 최대/중앙값의 중앙값 9.05), 비율은 약 1.1%로 Darcet의 약 2%보다 작습니다. 다만 Darcet이 본 모델은 DINOv2, DeiT-III, OpenCLIP이고 OpenAI CLIP과는 다른 가중치이며 임계값 정의도 달라 숫자를 직접 비교하지는 않습니다. 방향(큰 모델에서 소수 토큰이 큰 노름)은 일치합니다.
- **DINOv2 ViT-S/14는 원본과 register 변형 모두 고노름 토큰이 없습니다.** 최대/중앙값이 1.4–1.5이고 어떤 임계값(2배 이상)에서도 0개, 로그 히스토그램은 단봉입니다. 이는 Darcet의 "ViT-L 이상에서만"과 일치하지만(작은 모델은 ViT-g에서 증류한 것이기도 함, 논문 §6.5·`04` C3), **그래서 S 규모에서는 register가 고노름 토큰을 없애는지를 시험할 수 없습니다**(원본에 없애 줄 것이 없음). 두 모델의 노름 절대값이 다른 것(20.2 대 59.6)은 학습 실행이 달라서이고 비교는 비율로만 합니다.
- **층별 등장** (`hidden_states` 인덱스, 0은 임베딩). CLIP에서는 층 11까지 최대/중앙값이 3.3 이하이다가 **층 12(24층의 절반)에서 13.8, 층 13에서 32.1로 뛰고**(층 중앙값의 3배 초과 비율이 0.5% 이상이 되는 첫 층 = 12) 이후 1.1%에서 0.9%로 완만히 줄고, 마지막 층 최대/중앙값 9.95는 층 중앙값이 커져서 비가 줄어든 것입니다. DINOv2 S는 어느 층에서도 3배 초과 토큰이 0.5%에 못 미칩니다. Darcet이 ViT-g에서 보고한 "중간쯤 층부터"와 방향이 같지만 모델이 달라 층 번호는 비교하지 않습니다.
- **배경 패치 경향(CLIP).** 고노름 토큰은 이미지 안에서 14×14 패치의 픽셀 표준편차(회색조)가 낮은 쪽에 몰립니다: 이미지 내 백분위 평균 0.22(0.5가 경향 없음), 표준편차 0.036 대 나머지 0.093(Mann–Whitney p < 1e-100). 정보량이 낮은 배경이라는 Darcet의 서술과 맞습니다. 마지막 층에서 이웃 4개 평균과의 코사인 유사도는 고노름 토큰이 0.28, 나머지 0.74로 이웃과 크게 다릅니다(Darcet의 같은 지표 수치는 확인하지 않았고 우리는 마지막 층에서만 쟀습니다).
- **CLS→패치 attention 집중(CLIP).** 마지막 층, 헤드 평균 CLS 행에서 고노름 토큰 1.09%가 attention 질량의 40.6%를 받습니다(37배 농축). 전역 정보를 모으는 자리로 쓰인다는 Darcet의 해석과 일치하는 관찰이고, 인과를 보인 것은 아닙니다. 대조로 DINOv2 S에서 노름 상위 2% 토큰은 attention 농축이 2.0배이고 오히려 픽셀 표준편차가 높은 쪽(백분위 0.64)에 있어, 객체 쪽 토큰이 조금 큰 정상 변동일 뿐 artifact와 다릅니다.
- **register 변형의 register 노름.** 4개 register의 노름 중앙값은 44.5, **160.0**, 42.9, 41.3으로(패치 중앙값의 0.75, **2.7**, 0.72, 0.69배) 하나만 크고, CLS→register attention 질량은 평균 20.8%(register는 토큰의 1.5%)입니다. CLS 노름 중앙값은 42.4(원본 14.0). register가 전역 정보를 받는 자리일 수 있다는 정황이나, S 규모에서는 비교할 artifact가 없어 어떤 역할을 하는지는 이 측정으로 판단하지 않습니다.
- **정의 민감성.** 최종 정규화(CLIP `post_layernorm`)를 토큰 전체에 적용한 뒤에 재면 CLIP의 최대/중앙값이 1.06으로 사라집니다. 고노름 토큰은 **정규화 앞의 잔차 흐름에서** 보이는 현상이므로, 정규화 뒤 특징만 쓰는 하류에서는 노름이 아니라 방향이 문제인지를 따로 봐야 합니다. DINOv2 S도 정규화 뒤 최대/중앙값은 1.2–1.3입니다.

**한계.** 이미지 270장은 MMVP-VLM(자연 이미지, 쌍 구조)이라 ImageNet 분포의 비율과 다를 수 있습니다. 224 해상도 한 가지, 모델당 가중치 한 벌, 임계값은 히스토그램 골에서 눈으로 고른 값(민감도 표 병기)입니다. CLIP은 DINOv2와 데이터·목적이 달라 "DINOv2 계열의 규모 효과"가 아니라 "큰 ViT의 일반 현상"의 사례로만 읽습니다. 후속으로 DINOv2 ViT-L/14 원본과 register 변형 쌍(각 1,218 MB)이 있어야 register 효과를 DINOv2 안에서 시험할 수 있습니다.
