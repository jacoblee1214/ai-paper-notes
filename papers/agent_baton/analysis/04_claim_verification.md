# 04. 주장 검증 (공식 코드 없음)

공식 코드, 가중치, 궤적, 학습 라벨이 공개되어 있지 않아(`02` §4) 논문 ↔ 코드 대조(D1–Dn)는 할 수 없습니다. 대신 논문의 표와 본문 수치로 주장을 하나씩 재계산해 판정합니다(C1–C14). 재계산은 `table_check.py`, `power_check.py`, `cost_model.py`이고 코드·API 호출·설치는 하지 않았습니다. 통계 해석은 `03`에 있습니다.

판정 기준: **재현**(표에서 같은 값), **재현·단서**(값은 같고 해석에 단서), **부분**(일부만 지지), **지지 약함**(데이터로 가를 수 없음), **검증 불가**(근거 자료 없음).

## 같은 구성이 두 실행에서 다른 칸 (표 3 대 표 6)

`03` §2의 표. GLM-5.3 단독 DeepSWE max가 61.1(표 3, §3.2 인용)과 69.0(표 6, §4.5 인용)으로 두 번 나옵니다. 어느 쪽이 맞는지 저자에게 물어야 합니다.

## 구현 가능성

- **방법:** 탐지기 학습에는 SWE-rebench V2 궤적 4,000개(GPT-6 Astra, Sol, Opus 5, Kimi K3, GLM-5.3을 API로 돌려 만듦), Codex 사후 주석, H100 16장이 필요합니다. 이 맥(CPU·MPS)에서는 **불가**입니다. 논문 규모 재현도 API 비용과 외부 전송이 커서 하지 않습니다.
- **추론 시 사용:** AgentBaton 가중치가 공개되어 있지 않아 직접 학습한 탐지기가 필요합니다. 라벨 규칙(부록 B)은 공개되어 있어서 다른 LLM으로 사후 주석을 만들어 볼 수는 있습니다(승인과 비용 확인 필요).
- **인계 실험 자체:** mini-SWE-agent(MIT, v2.4.0)와 작업 공간 복원(`docker`), 문맥 전달 두 방식은 구현이 간단하지만, 강한 모델 API와 로컬 27B급 모델이 필요합니다. 이 맥에서 로컬 큰 모델은 미검증입니다. 승인 없이 하지 않습니다.
- **통계 재분석:** 저자가 과제별 결과를 공개하면 짝지은 McNemar와 불일치율을 바로 계산할 수 있습니다. `power_check.py`는 `k_handoff`, `k_capable`, `m` 값만 바꾸면 됩니다.
