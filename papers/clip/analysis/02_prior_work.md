# 02. 계보와 관련 자료: CLIP (arXiv:2103.00020)

- **근거 수준.** 이후 문헌은 arXiv 초록과 메타데이터(arXiv API, 2026-11-26)와 논문 자체의 서술만 읽고 썼습니다. 본문을 읽지 않은 곳은 "초록 수준"이라고 표시했습니다. 웹 검색은 쓰지 않았습니다.
- 이 저장소의 다른 분석은 폴더명으로만 가리킵니다. `siglip/`, `dinov2/`, `blip2/`, `llava/`도 같은 묶음에서 분석을 마쳤습니다.

## 1. 계보: CLIP이 기대는 것

| 갈래 | 논문 | CLIP이 가져온 것, 바꾼 것 |
|---|---|---|
| 자연어 지도로 시각 표현 | Mori 외(1999), Quattoni 외(2007), Joulin 외(2016, YFCC100M 캡션을 BoW 다중 라벨로), Li 외(2017, Visual N-Grams) | 자연어에서 시각 개념을 배운다는 아이디어와 제로샷 분류의 틀(클래스 이름으로 점수). Visual N-Grams는 ImageNet 제로샷 11.5%였고 CLIP은 76.2%(Table 1). 저자도 규모·모델·연산이 달라 방법 비교가 아니라고 선을 그음(§3.1.3) |
| 캡션 생성으로 표현 학습 | VirTex(2006.06666, CVPR 2021, 초록 수준: 의미 있는 캡션으로 이미지 인코더 사전학습) | 논문의 첫 시도. 63M Transformer LM은 BoW 예측보다 3배 느렸음(그림 2). 그 뒤 예측 목적을 버림 |
| 마스크 언어 모델과 이미지 | ICMLM(2008.01392, ECCV 2020, 초록 수준: 캡션 주석으로 시각 표현 학습) | 예측 쪽 대안. CLIP은 이 갈래를 대조 목적으로 바꿈 |
| 대조 학습, 이미지-텍스트 | ConVIRT(2010.00747, 의료 영상과 보고서 쌍, 초록 수준) | **직접 조상.** CLIP은 "단순화한 ConVIRT"라고 적음(§1). 단순화 내용: 비선형 투영 제거, 문장 샘플링 제거, 약한 증강, 학습되는 τ(§2.3) |
| 대조 손실 | N-pair loss(Sohn 2016), InfoNCE(Oord 2018), 이미지 자기지도 SimCLR 계열(Chen 외 2020b) | 손실은 새롭지 않음(§2.3) |
| 약지도 규모 | Mahajan 외(2018, Instagram 해시태그), Kolesnikov 외(BiT), ViT의 JFT-300M | "정해진 클래스 + 정적 softmax"의 한계를 지적하며 대안으로 제시(§1) |

한 줄 요약: **목적과 구조는 ConVIRT, 규모와 데이터는 WIT 4억 쌍, 새로운 점은 제로샷 평가 틀과 프롬프트 앙상블, 그리고 폭넓은 측정**입니다.

## 2. 같은 시기의 가까운 대안

- **ALIGN**(2102.05918, ICML 2021): CLIP(2021-02-26)보다 15일 앞서 올라온 병행 연구입니다. 초록 수준으로 확인한 바로는 거르지 않은 잡음 섞인 대규모 이미지-텍스트 쌍으로 이중 인코더를 대조 손실로 학습합니다. CLIP은 데이터 필터링(질의 기반 균형)에, ALIGN은 데이터 규모와 잡음 허용에 무게를 둔 대비로 읽을 수 있으나 두 쪽의 수치를 직접 비교하지는 않았습니다.
- **캡션 목적 결합 쪽**: CLIP 자신이 한계에서 "대조와 생성 목적의 결합"을 제안했고(§6), BLIP-2(`blip2/`)와 SigLIP 2의 캡션 사전학습이 이 방향입니다.

## 3. 이후 문헌: CLIP이 연 연구선 (초록 수준)

| 연구선 | 논문 | 무엇을 바꿨나 |
|---|---|---|
| 재현과 스케일링 | OpenCLIP, Cherti 외(2212.07143, CVPR 2023) | 공개 LAION 데이터와 OpenCLIP으로 최대 20억 쌍까지 제로샷·검색·선형 프로브·미세조정의 power law를 보고하고, **같은 구조·비슷한 레시피여도 OpenAI와 OpenCLIP 모델의 스케일링이 다르다**(데이터 분포가 핵심)고 보고 |
| 견고성의 원인 | Fang 외(2205.01397) | 견고성 이득의 원인으로 학습 집합 크기, 학습 분포, 학습·시험 시 언어 지도, 대조 손실을 가려냄. 초록: **더 다양한 학습 분포가 주된 원인이고 나머지는 거의 기여하지 않는다.** CLIP §3.3이 "원인은 모른다"고 남긴 질문에 답함 |
| 데이터 큐레이션 | MetaCLIP(2309.16671), DataComp(2304.14108, NeurIPS 2023 D&B), DFN(2309.17425) | 모델이 아니라 데이터가 핵심이라고 주장하며 CLIP의 질의 기반 큐레이션을 복원(MetaCLIP, 초록: ViT-B에서 OpenAI CLIP 68.3% 대비 70.8%)하고, 후보 풀 12.8B 위의 필터링 벤치마크(DataComp-1B로 ViT-L/14 79.2%)와 필터링 네트워크(DFN-5B로 ViT-H 84.4%)를 만듦 |
| 인코더 효율 | LiT(2111.07991, CVPR 2022), EVA-CLIP(2303.15389) | LiT: 이미지 인코더를 사전학습 모델로 고정하고 텍스트 쪽만 학습하는 대조 튜닝. EVA-CLIP: 표현 학습·최적화·증강 개선으로 같은 크기에서 더 높은 성능 (초록 수준) |
| 손실 | SigLIP(2303.15343, ICCV 2023 구두) → `siglip/` | softmax 정규화를 쌍별 sigmoid로 바꿔 배치 전체의 관점이 필요 없게 하고 작은 배치에서도 낫다고 보고. CLIP의 32,768 배치와 전역 softmax(§2.5)를 바꿈 |
| 다음 세대 | SigLIP 2(2502.14786) | 캡션 사전학습, 자기지도 손실(자기증류, 마스크 예측), 온라인 데이터 큐레이션을 합침(초록 수준) |
| 기하학 분석 | Liang 외(2203.02053, NeurIPS 2022) | 모달리티 간격: 두 모달리티가 표현 공간에서 떨어져 임베딩되는 현상. 초기화(좁은 원뿔)와 대조 학습(온도가 영향)이 원인이라고 초록에서 주장. CLIP 의사 코드의 τ가 이 간격과 연결됨 |
| 구성성 | Winoground(2204.03162, CVPR 2022), ARO(2210.01936, ICLR 2023 구두) | **같은 단어, 다른 순서의 두 캡션** 매칭에서 시험한 모델은 우연 수준을 크게 넘지 못함(Winoground 초록). ARO는 속성 결합, 관계, 순서에 민감하지 않다고 보고하고, 표준 검색 지표로는 이 결함이 드러나지 않으며 구성 정보 없이도 검색이 가능하다고 주장하고 hard negative 구성을 처방으로 제시(초록 수준) |

## 4. VLM과 VLA의 시각 인코더로서의 쓰임

- **LLaVA**(`llava/`): CLIP 시각 인코더 + LLM이 기준 설계입니다(초록 이상은 아직 분석 전).
- **Prismatic VLMs**(`prismatic_vlms/`): 인코더 선택을 통제 비교한 연구. 이 폴더의 요약에서 DINOv2+SigLIP 융합이 SigLIP 단독보다 낫다고 정리했고 DINOv2+CLIP의 TextVQA는 크게 떨어졌습니다. 즉 CLIP은 기본값이었으나 최선은 아닙니다.
- **Cambrian-1**(`cambrian1/`): 언어 지도(CLIP류)와 자기지도 인코더를 비교하는 인코더 평가 틀을 제시하고, 이 폴더 요약에서 "언어 지도 모델은 항상 이득은 아니다"로 정리했습니다.
- **Eyes Wide Shut?**(`eyes_wide_shut/`): CLIP 임베딩은 비슷하고 DINOv2 임베딩은 다른 이미지 쌍("CLIP-blind")으로 MLLM의 시각 실패(방향, 수 세기 등)를 겨냥합니다. 이 폴더에서 선별 방식이 CLIP에 불리하게 설계된 구조적 편향을 토이로 점검했습니다. CLIP의 한계를 인용할 때 두 분석을 함께 봐야 합니다.
- **ViT**(`vit/`): CLIP 이미지 인코더의 한 축. **PaliGemma**(`paligemma/`)는 SigLIP, **Qwen2-VL**(`qwen2_vl/`)은 자체 ViT를 씁니다. **DINOv2**(`dinov2/`)는 언어 지도 없는 자기지도 대안입니다.
- **로봇 정책**: OpenVLA, UniVLA 등은 Prismatic의 DINOv2+SigLIP을 백본으로 쓰고, LIBERO는 언어 조건 임베딩으로 CLIP을 비교 대상에 넣었습니다.

## 6. 이 저장소의 다른 분석과의 관계

- `eyes_wide_shut/`: CLIP 특징의 방향·수 세기 약점을 쓴 논문. 이 폴더의 토이 B(속성 결합)가 같은 방향의 메커니즘 질문(대조 손실이 결합을 강제하는가)을 작은 규모에서 시험합니다.
- `prismatic_vlms/`, `cambrian1/`: CLIP이 VLM 인코더로서 기본값에서 선택지 하나로 내려온 과정의 증거.
- `induction_heads/`, `toy_superposition/`, `statistical_precipice/`: 같은 구현 모드의 형식 참고.
