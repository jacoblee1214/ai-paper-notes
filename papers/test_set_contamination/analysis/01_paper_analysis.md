# 01. 논문 분석: Proving Test Set Contamination in Black Box Language Models (arXiv:2310.17623)

분석 판: arXiv v2 (2023-11-24, 최신). v1(2023-10-26)과의 차이는 §6. 위치 표기는 원문의 절·표·그림·알고리즘 번호이며, 이 논문은 번호 붙은 식이 거의 없어 정리 이름(Proposition 1, Theorem 2, Algorithm 1)과 본문 식(§3.1의 p, p̂)으로 가리킵니다.

## 1. 문제

- 모델 θ의 학습에 벤치마크 X가 쓰였는지를, **로그우도 질의 log p_θ(s)만으로**(가중치도 학습 데이터도 없이) 가린다. 가설은 H0: θ가 X와 독립, H1: θ가 X에 의존(§2).
- 목표는 **거짓 양성률이 α 이하임을 보장**하는 검정입니다. 기존 방법(n-gram 겹침, 멤버십 추론, 생성 기반 탐지)은 휴리스틱이라 "의심"은 되어도 "증명"은 안 된다는 주장(§1, §5).

## 2. 방법

### 2.1 핵심 성질: 교환성 (§2, Proposition 1)

- 벤치마크는 문항 집합 X = {x_1..x_n}이고 문항 순서에 의미가 없어(교환 가능) 모든 순열이 같은 확률을 가진다고 둡니다. i.i.d. 문항이면 성립(§2).
- Proposition 1: 교환 가능한 X와 H0 아래서 log p_θ(seq(X)) 와 log p_θ(seq(X_π)) 는 같은 분포(seq는 문항을 이어 붙임, π는 균등 무작위 순열).
- H1 쪽 직관: 모델이 공개 저장소의 정준(canonical) 순서를 외우면 log p_θ(seq(X)) ≫ log p_θ(seq(X_π)) (§2 "Detection rate under H1"). 이 쪽은 가정이며 보장이 아닙니다. 논문도 "암호화해 숨기면 못 잡는다"고 인정합니다.

### 2.2 순열 검정 (§3.1)

- p := E[1{log p_θ(seq(X)) < log p_θ(seq(X_π))}], 즉 정준보다 로그우도가 높은 순열의 비율. H0 아래서 균등분포.
- Monte Carlo 추정 p̂ = (Σ_{i=1..m} 1{ℓ(X) < ℓ(X_πi)} + 1) / (m+1) (Phipson & Smyth 2010 보정).
- 단점: 계산량 O(m|X|), **p̂ ≥ 1/(m+1)** (§3.1). 또 정준 순서가 순열의 거의 모든 값보다 높아야 합니다(모델이 순서에 대한 선호가 있으면 약함, §3.2).

### 2.3 분할 순위 비교 검정 (§3.2, Algorithm 1)

1. 문항을 r개의 인접 샤드로 나눔(각 샤드 ≥ ⌊n/r⌋개, 앞의 n mod r개 샤드는 1개 더).
2. 샤드마다 정준 순서의 로그우도 ℓ_canonical^(i)와 **샤드 안에서만 섞은** m개 순열 로그우도의 평균 ℓ_shuffled^(i)를 구해 s_i = ℓ_canonical^(i) − ℓ_shuffled^(i).
3. s̄ = (1/r) Σ s_i 에 단측 t 검정(E[s_i] > 0).
- Theorem 2: H0, i.i.d. X, 샤드 로그우도의 2차 모멘트 유한이면 |P(p<α) − α| → 0 (**점근**, 샤드 수가 커질 때). 증명은 샤드 독립 + CLT + Lehmann & Romano.
- 주장: "비교를 로그우도 순위에서 **평균 대비 비교**로 바꿔 p값 하한이 없고(1/m 하한 제거) 계산량 대비 검정력이 높다"(§3.2, §4.1).

### 2.4 논문의 표기 혼선 (우리가 확인)

- Algorithm 1은 r = 샤드 수, m = 샤드당 순열 수. §4.1은 "shard count m and permutation count r", "m = 50 shards and r = 51 permutations"로 뒤집혀 있고, Theorem 2의 증명도 "s → N(0, σ²/m)"로 m을 샤드 수로 씁니다. v1의 s̄ 식 "1/m"은 v2에서 "1/r"로 고쳐졌습니다.
- 우리는 Algorithm 1의 표기(r = 샤드 수, m = 샤드당 순열 수)를 씁니다.

## 3. 실험

### 3.1 의도적 오염으로 학습한 1.4B (§4.1, 표 1, 표 3, 부록 B·C)

- GPT-2 구조 1.4B(은닉 1536, 48층, 24 head, 시퀀스 2048)를 Wikitext(RedPajama)와 **10개 정준 벤치마크**(BoolQ, HellaSwag, OpenbookQA, MNLI, NaturalQuestions, TruthfulQA, PIQA, MMLU 3개 부분)를 섞어 처음부터 학습. 각 벤치마크는 무작위로 섞어 교환 가능하게 만든 뒤 1–100번 중복해 넣음. 총 20.2B 토큰 중 벤치마크는 19.235M(0.1% 미만)(§4.1, 부록 C).
- 설정: 50 샤드, 51(또는 50) 순열(§4.1 본문, 표기 혼선 있음), 순열 검정은 100번 순열.
- 결과(표 1): 중복 1회는 두 검정 모두 놓침(BoolQ 0.099/0.156, HellaSwag 0.485/0.478, OpenbookQA 0.544/0.462). 중복 ≥ 10회는 순열 p 0.009(하한), 샤드 p는 1.96e-11 ~ 1e-38.
- 그림 2: 중복 1, 2, 4, 7회 정준 벤치마크의 log p. 검출 문턱은 약 4회.
- §4.2·그림 3: 샤드 수/샤드당 문항 수와 순열 수의 영향. "샤드 10–20개 부근이 최적, 순열은 약 25회 이후 수익 체감"(본문). 그림 3a 캡션은 "examples per shard"라 축이 샤드 수인지 샤드당 문항 수인지 모호합니다(우리 03 §6 참조).

### 3.2 공개 모델 감사 (§4.3, 표 2, 표 4, 그림 4)

- 모델: LLaMA2-7B, Mistral-7B, Pythia-1.4B, GPT-2 XL, 음성 대조로 BioMedLM(PubMed 전용). 벤치마크 8종(Arc-Easy, BoolQ, GSM8K, LAMBADA, NaturalQA, OpenBookQA, PIQA, MMLU). 50 샤드, 250 순열/샤드, 5,000문항 초과는 앞 5,000개만(§4.3).
- 결과(표 2): Mistral의 Arc-Easy만 p = 0.001, 나머지는 비유의. 저자는 다중 검정 보정이면 경계선이라 주의를 줌.
- MMLU는 57개 파일의 모음이고 비교환 가능 의심 14개를 (GPT-2 XL이나 BioMedLM이 유의한 파일로) 제외한 43개를 Fisher로 합산: LLaMA2 0.014, Mistral 0.011, Pythia 0.362 (표 2 †, 부록 D 표 4, 그림 4). 이 p는 "증명"이 아니라 휴리스틱 증거라고 명시(§4.3).
- 계산량: 7B 모델로 65개 파일을 50 샤드 × 250 순열로 24시간 안에(§4.3).
