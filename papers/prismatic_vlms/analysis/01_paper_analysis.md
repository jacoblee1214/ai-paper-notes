## 1. 문제와 주장

- **문제.** LLaVA, InstructBLIP, PaLI-3 같은 패치-토큰 VLM(비전 백본의 패치 특징을 투영해 LM 입력으로 넣는 구조)이 쏟아지는데, 이미지 전처리, 아키텍처, 최적화 선택이 성능에 미치는 영향이 따로 분리되어 평가되지 않았고 평가 자체도 일관되지 않다(초록, §1).
- **기여 넷** (§1): (1) 12개 벤치마크의 표준 평가 묶음, (2) 학습 코드, (3) 설계 축 네 개(최적화 절차, 이미지 처리·시각 표현, LM, 학습 시간·데이터)를 LLaVA-1.5 재현 설정에서 한 번에 하나씩 바꾸는 실험, (4) 결과를 모은 PRISM 모델군(7B/13B)과 모든 체크포인트.
- **핵심 주장** (§4, §5, 그림 9):
  1. 정렬(projector-only) 단계는 필요 없고, 단일 단계 학습이 성능을 유지하면서 계산을 20–25% 줄인다 (§4.1, 그림 4).
  2. 시각 백본을 같이 미세조정하면 성능이 크게 떨어진다. 특히 위치 지정 과제 (§4.1, 그림 5).
  3. CLIP, SigLIP이 IN1K ViT, DINOv2보다 낫다 (그림 6 왼쪽). 해상도를 224에서 336/384로 올리면 좋아진다 (그림 6 오른쪽).
  4. letterbox보다 naive resize가 낫다(통계적으로 단정은 못 함, p=0.0176). resize&crop은 나쁘다 (그림 6 가운데).
  5. DINOv2+SigLIP 특징을 채널 방향으로 이어 붙이면 전반적으로 좋아진다. DINOv2+CLIP은 아니다 (그림 7 왼쪽).
  6. 지시 튜닝 LM(Vicuna)은 base LM(Llama-2)보다 유의하게 낫지 않고, 환각이 더 많다 (그림 7 오른쪽, 그림 11). 더 좋은 LM(Mistral)이 유의하게 낫지는 않다 (그림 12).
  7. 언어 전용 공동 학습 데이터는 점수에는 영향이 작지만 안전 장치에는 중요하다 (그림 8).
  8. 2 epoch까지 성능이 오르고, 다양한 이미지의 데이터(LRV, LVIS-4V)를 더하면 오른다 (그림 10).
  9. PRISM 모델은 InstructBLIP과 LLaVA-1.5를 "모든 평가에서 앞선다" (§5, 그림 9). 학습 계산은 30% 이상 절약 (그림 1 캡션).

## 2. 방법

### 2.1 아키텍처 (§2, 부록 A.2)

- 세 구성 요소: 비전 백본 V_ω(ViT, **끝에서 두 번째 층**의 패치 특징), 투영기 F_ψ(패치마다 독립 적용되는 **2층 GELU MLP**), LM. 투영된 패치 임베딩을 프롬프트 임베딩 **왼쪽에 이어 붙여** LM에 넣습니다(prefix 방식). 손실은 − log p(û_gen | x_img, u_prompt).
- 융합 백본(§4.2): 패치 특징을 **채널 방향으로 이어 붙여** 패치 수는 그대로, 특징 차원만 두 배가 되고 "투영기의 입력 차원만 키운다"고 서술합니다. 이 서술과 코드가 다릅니다 (`04` D1).
- 사전학습 데이터: LLaVA-1.5 혼합(정렬용 558K 캡션 + 지시 튜닝 665K, 부록 A.1). 지시 튜닝 665K = 합성 158K + VQA 224K + 객관식 50K + 캡션 22K + 참조 표현 116K + ShareGPT 언어 전용 40K (부록 A.1).
- 학습: PyTorch FSDP, BF16, 배치 128, lr 2e-5, AdamW, weight decay 0.1, warmup 0.03 + cosine (부록 표 1). 초기화 난수와 배치 순서를 고정했다고 씁니다 (§2).

### 2.2 평가 묶음 (§3, 부록 B)

| 묶음 | 벤치마크 | 지표 |
|---|---|---|
| 개방형 VQA | VQAv2, GQA(test-dev), VizWiz, TextVQA(OCR 입력 없음) | 공식 평가 스크립트 정확도 |
| 위치 지정 | RefCOCO, RefCOCO+, RefCOCOg, OCID-Ref | IoU 0.5(OCID-Ref는 0.25) 정확도 |
| 도전 집합(닫힌 집합) | VSR(zero-shot test), TallyQA, POPE, AI2D | 객관식으로 바꾼 정확도 |

- 생성은 **greedy**입니다(부록 B.1). 평가용 프롬프트는 학습 데이터의 trigger prompt를 씁니다.
- 점수 정규화: 모든 모델을 통틀어 벤치마크별 평균과 표준편차로 **z 점수**를 만들고, 12개를 평균한 "전체 점수"로 결론을 냅니다. 유의성은 기준 집합과 대안 집합의 모델 쌍마다 정규화 차이를 구해 "1-sided Fisher T-test"(p<0.01)로 판단합니다 (§4, 부록 B.2). 쌍을 어떻게 짓고 무엇을 단위로 t 검정을 하는지는 본문에 없습니다 (`03` §3.4).

## 3. 실험 (§4–§5)

- 모든 실험은 "LLaVA-1.5 재현을 기준으로 한 번에 하나만 바꾼다"는 틀입니다(§4). 기준: letterbox, CLIP ViT-L/14 336px, Vicuna v1.5, 2단계 학습. 재현은 그림 4 왼쪽.
- **§4.1 최적화:** 다단계 대 단일 단계(p=0.00558), 동결 대 미세조정(p=0.00381).
- **§4.2 이미지 처리:** 인코더 4종(p=7.11e-8), 전처리 3종(p=0.0176), 해상도(p=6.05e-4), 융합(DINOv2+SigLIP p=0.00164, DINOv2+CLIP p=0.37313).
- **§4.3 LM:** base 대 instruct(p=0.34854), Mistral(p=0.03097), 공동 학습 제거(p=0.13655).
- **§4.4 규모:** 1 대 2 epoch(p=0.00496), 데이터 추가(p=0.01459).
- **§5 PRISM:** 단일 단계, 융합 DINOv2+SigLIP + naive resize, base LM, 2 epoch, LLaVA + LVIS-4V + LRV. "Controlled" 모델은 LLaVA-1.5와 같은 데이터와 예산(1 epoch)으로 학습합니다. 7B Controlled는 8×A100에서 9시간 미만이라고 씁니다 (영향 진술, 부록).
- 결과 수치는 부록 표 2–4(58행)에 전부 있습니다. 이 분석의 재계산은 이 표를 `analysis/tables.json`으로 옮겨 씁니다.

## 4. 한계 (논문 §6, 영향 진술과 우리 관찰)

논문이 드는 것: (1) 세 구성 요소 아키텍처만 다룸(Perceiver 계열 다운샘플링, 교차 어텐션은 제외), 70B+ 규모 일반화 불명, (2) 객관적 평가만 써서 긴 대화를 평가하지 못함, (3) 로봇 같은 하류 응용과의 공동 설계는 미래 과제. 영향 진술은 서구·영어 편향, 환각, 안전 문제를 적습니다(그림 8의 혐오 발언 예시 포함).

우리가 추가로 본 것 (자세히는 `03`, `04`):

1. **모든 비교가 단일 학습 실행입니다.** 시드 분산이 보고되지 않았고, 검정의 단위가 벤치마크이지 학습 실행이 아닙니다.
2. **인코더 비교의 교란:** IN1K ViT-L은 패치 16(토큰 196), 나머지는 패치 14(토큰 256). SigLIP은 SO400M(약 4억 대 3억 파라미터), 사전학습 데이터도 다릅니다. "시각-언어 대조 목적이 낫다"로 해석하는 근거가 약합니다.
3. **융합의 교란:** 코드의 융합 투영기는 3층 MLP(7B에서 약 7,139만 파라미터)이고, 비융합은 2층(약 2,100만). 논문은 2층 MLP라고 씁니다.
4. **"모든 평가에서 앞선다"는 표와 맞지 않습니다.** 12개 PRISM 모델 중 9개가 공식 LLaVA-1.5보다 낮은 벤치마크가 하나 이상 있습니다 (`03` §6).
5. **VSR가 퇴화한 벤치마크입니다.** 고유 모델 48개 중 16개가 정확히 51.47%(항상 같은 답)이고 24개가 55% 미만입니다 (`03` §1.2).
