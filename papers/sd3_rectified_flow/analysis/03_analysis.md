## 1. 통합 손실과 시간 표본기 (§2–3.1)

### 1.1 식 (10)–(13)의 항등식

무작위 텐서(차원 7, 200개 시각)에서 RF와 코사인 스케줄에 대해 확인했습니다.

| 항목 | RF | 코사인 |
|---|---|---|
| 식 (10)(u = (a'/a)z − (b/2)λ'ε)의 최대 절대 오차 | 8.0e-15 | 1.0e-14 |
| 식 (12)(‖v_Θ − u‖² = (bλ'/2)²‖ε_Θ − ε‖²)의 상대 오차 | 3.7e-15 | 2.2e-15 |
| 식 (13), w_t = −½λ'b²일 때 −½ w λ' ‖·‖² 와의 상대 오차 | 3.4e-15 | 2.3e-15 |

즉 식 (10)–(13)과 "L_CFM ↔ w_t = −½λ'_t b_t²"는 성립합니다. 식 (12)의 계수 (−b_tλ'_t/2)²가 −½ w_t λ'_t = ¼λ'²b²와 같다는 뜻입니다.

### 1.2 논문이 적은 w_t는 정확히 어떤 상수 배인가

식 (13)에서 w_t는 "dλ 당 가중의 2배"입니다(t가 균일하면 L = ½∫w(λ)‖ε_Θ − ε‖²dλ). ε-오차에 시간당 c(t)의 가중을 주는 목적함수는 w = 2c/|λ'| 입니다. 이 규약으로 논문의 w_t를 정확히 도출해 비교했습니다(`loss_weighting.py` B).

| 정식화 | 정확한 w (우리 도출) | 논문 표기 | 정확/표기 비 |
|---|---|---|---|
| RF (속도 MSE) | c = 1/(1−t)² → w = t/(1−t) | t/(1−t) | **1** (상대 편차 4e-16) |
| 코사인 + ε-예측 | c = 1 → w = sin(πt)/π | sech(λ/2) = sin(πt) | **1/π** |
| 코사인 + v-예측 (v̂ − v = (ε̂ − ε)/a_t) | c = 1/a_t² → w = (2/π)·tan(πt/2) | e^{−λ/2} = tan(πt/2) | **2/π** |
| EDM (F-예측, σ_data=0.5) | c = (σ²+σ_d²)/σ_d², abs(λ') = 1/N(λ) → w = 8N(λ)(e^{−λ}+0.25) | N(λ)(e^{−λ} + 0.5²) | **8** (세 설정 모두) |

- 최적해는 시간 가중의 상수 배에 불변이라 학습 결과에는 영향이 없습니다. 그러나 **정식화 사이의 가중을 숫자로 비교할 때는 상수가 다릅니다.** 특히 코사인의 ε-예측과 v-예측은 논문 표기의 비가 정확한 비의 절반입니다(정확한 v/ε 가중비 1/a_t² = 1 + e^{−λ}, 표기 비 e^{−λ/2}/sech(λ/2) = (1 + e^{−λ})/2, 비율 2.0). v-손실에 ½을 두는 관례를 쓰면 설명되나 논문은 적지 않았습니다.
- LDM-Linear는 논문에 w_t가 없습니다. 우리는 LDM의 공개 구성값(β: 0.00085 → 0.012의 √ 선형, T=1000, **논문에 없는 값을 가정**)으로 λ를 계산해 ε-예측의 w = 2/|λ'|를 썼습니다. SNR 범위는 λ ∈ [−5.36, 7.07]이라 t=0, 1 끝점까지 닿지 않습니다.

## 2. 해석 토이: 정확한 속도장 (학습 없음)

### 2.1 설정과 닫힌 식

데이터는 2차원 가우시안 혼합 c(성분 3개, 같은 가중, 반지름 1, 표준편차 0.25를 좌표당 분산 1로 스케일, `unit_var_check` = 1.002)이고, **r번 복제해 n = 2r 좌표**로 늘렸습니다(각 "픽셀"이 같은 값을 갖는 구간). z_t = (1−t)x0 + tε이면 복제 평균 y = (1−t)c + (t/√r)η가 충분통계량이고, 직교 성분은 z⊥ = tε⊥라 속도가 정확히 예측됩니다.

- 정확한 속도장: u*(z, t) = E[ε − x0 | z] = (z − E[x0|z])/t. E[x0|z]는 GMM 사후(성분 책임도)로 닫힌 식입니다.
- **줄일 수 없는 속도 손실** E‖v − u*‖² = MMSE(x0|z_t)/t² (유도: ε − x0 = (z − x0)/t이므로 오차는 x0 오차를 t로 나눈 것). 좌표당 값 = MMSE_c/(2t²). 몬테카를로 60,000점, 시각 99개.
- 속도장의 국소 복잡도: 유한 차분 야코비안의 프로베니우스 노름의 제곱평균 제곱근.

## 3. 해상도 의존 시간 이동 (§5.3.2, 식 23–25)

### 3.1 식 (23) 재유도

상수 이미지 c ∈ R, n개 픽셀 z_{t,i} = (1−t)c + tε_i. 표본 평균 ĉ = (1/(1−t))·(1/n)Σz_{t,i}의 표준편차는 (t/(1−t))/√n = σ(t,n)입니다. σ(t_n, n) = σ(t_m, m)에서 t_m/(1−t_m) = √(m/n) · t_n/(1−t_n)이고 t_m을 풀면 t_m = √(m/n) t_n / (1 + (√(m/n) − 1) t_n), 식 (23)입니다. 오즈 t/(1−t)를 √(m/n)배 하는 변환입니다. log-SNR로는 λ = 2 log((1−t)/t)이므로 λ_{t_m} = λ_{t_n} − 2 log√(m/n) = λ_{t_n} − log(m/n), 식 (25)입니다(수치로 1.6e-14 이내 확인, α = 2, 3).

### 3.2 복제 픽셀 토이 (`gmm_toy.py`)

위 토이에서 전이 구간(MMSE 비율 0.5)의 오즈 t/(1−t) 비는 r=4, 16, 64에서 1.99994, 3.9991, 7.9980로 √r = 2, 4, 8과 같고, 식 (23)을 r=1의 t₅₀ = 0.5277에 적용한 예측이 측정값과 일치합니다(r=16: 0.81716 대 0.81713). 이것은 이 토이에서 **구성상 성립**하는 항등식입니다(MMSE가 √r(1−t)/t의 함수라서). 식 (23)이 "상수 이미지 가정에서 정확하다"는 것을 확인한 것이고 현실 데이터에 대한 증거는 아닙니다.

### 3.3 멱법칙 스펙트럼에서도 성립하나 (`spectrum_shift.py`, `own_spectrum.png`)

N×N 격자의 정상 가우시안 장, 스펙트럼 P(k) ∝ (1+|k|²)^(−β/2)을 **해상도와 무관한 같은 연속 스펙트럼**으로 두고(기준 N=32에서 픽셀당 분산 1) 푸리에 모드별로 MMSE를 더해 "MMSE 비율 0.5"의 오즈 이동비를 구했습니다. 식 (23)의 예측은 N/32 = 1, 2, 4, 8입니다.

| β | N=64 | N=128 (256² → 1024² 해당) | N=256 |
|---|---|---|---|
| 1 | 1.45 | 2.09 | 2.97 |
| 2 | 1.42 | 2.00 | 2.83 |
| 2.5 | 1.71 | **3.04** | 5.59 |
| 3 | 1.90 | 3.71 | 7.34 |
| 4 | 1.99 | 3.98 | 7.96 |
| 식 (23) | 2 | 4 | 8 |

- 스펙트럼이 가파를수록(저주파에 에너지가 몰릴수록) 식 (23)에 가까워지고 β=2(자연 이미지의 전형적 전력 스펙트럼 지수 근처)에서는 N=128에서 2.0으로 절반입니다. **식 (23)은 √(m/n)를 상한으로 보는 편이 맞고, 논문이 실험으로 고른 α = 3은 이 토이에서 β ≈ 2.5에 해당합니다.** 이 β는 VAE 잠재의 스펙트럼이 아니라 가정이라 "α=3이 이 스펙트럼으로 설명된다"는 주장이 아니라 "식 (23)의 √(m/n) = 4와 α = 3의 차이가 스펙트럼 가정의 범위 안"이라는 정도입니다.

### 3.4 정확한 속도장 + 오일러 (샘플링, 학습 아님) (`own_euler.png`)

3,000개 표본, 참 ODE는 4차 룽게-쿠타 400스텝(200스텝과의 차이 4e-9)으로 풀고, N 단계 오일러를 균일 격자(α=1)와 이동 격자(t' = αt/(1+(α−1)t))에서 비교했습니다. 오차는 끝점 좌표당 RMS입니다.

| r | α=1 (균일) | α=3 | α=4 | 최적 α (N=8) |
|---|---|---|---|---|
| 1 | **0.0964** | 0.1542 | 0.1974 | 1 (0.75도 0.0972) |
| 4 | 0.1073 | 0.1045 | 0.1180 | 2 |
| 16 | 0.1536 | 0.0972 | **0.0964** | 4 |
| 64 | 0.2582 | 0.1214 | 0.1073 | 8 |

- **정확한 대칭 E(r, α, N) = E(1, α/√r, N).** 표에서 E(16, 4) = E(1, 1) = 0.0964, E(4, 2) = 0.0964, E(16, 3) = E(1, 0.75) = 0.0972 등이 소수 넷째 자리까지 같습니다. 이 토이에서 최적 α ≈ √r는 대칭에서 곧바로 나오므로 독립 증거는 아닙니다. 새로 보이는 것은 다음입니다.
  - 기준 해상도(r=1)에서는 이동이 오히려 해롭습니다(α=3에서 오차 +60%). 이동은 해상도가 오른 만큼만 쓰라는 논문의 주장과 일치합니다.
  - 이동하지 않은 균일 격자는 r=16에서 최적의 1.6배, r=64에서 2.7배의 오차입니다(N=8).
  - **계곡이 넓습니다.** α/√r ∈ [0.75, 1] 구간에서 오차 증가가 1% 이내이고 0.5나 1.5에서도 +8–11%입니다. 그래서 α = 3(r=16의 √r = 4)은 최적과 1% 차이(0.0972 대 0.0964, N=8; N=4에서 0.1886 대 0.1869)입니다.
- 끝점 분포 오차(16방향 sliced-W1, 참 데이터와의 비교)는 참 ODE 해 자체가 0.034–0.040(표본 3,000개의 유한 표본 한계)이라 오일러 오차의 순서를 가릴 만큼 정밀하지 않습니다. 주 지표는 RMS입니다.

### 3.5 논문의 α=3과 참조 코드

- 논문은 1024² 모델에 α = 3.0을 학습과 샘플링 모두에 씁니다(§5.3.2). 256² → 1024²의 √(m/n)는 4이고 α=3에 해당하는 해상도 비는 (1024/341)² = 9, 즉 기준 격자 341² 입니다(`code_checks.py`). 논문은 √(m/n) = 4가 아니라 사람 선호 연구 결과(그림 6)로 3.0을 골랐다고 쓰며 이 불일치를 설명하지 않습니다.
- 참조 코드(`sd3.5`)의 sigma(t) = shift·t/(1+(shift−1)t)는 식 (23)과 같은 형태이고 `SHIFT = 3.0`(`sd3_infer.py`)입니다(`04` D2).

### 4.1 표 1: 61개 정식화의 평균 순위 (`table_checks.py`)

**읽을 수 있는 것은 상위 16행의 평균 3개뿐입니다.** 24개 조합별 순위, CLIP·FID 원값은 논문에 없습니다(부록 B.3의 6개 샘플러 설정 × EMA 유무 × 데이터셋 2개 = 24, 5스텝 열은 이 중 4개, 50스텝 열은 12개 설정의 평균).
