# 01. Scaling Rectified Flow Transformers for High-Resolution Image Synthesis (SD3) 논문 분석

분석 판: arXiv v1 (2024-03-05, 다른 판 없음), ICML 2024 구두·최우수 논문상(PMLR 235:12606–12633). 분석일 2026-11-28. 원문 위치는 "§절", "식 번호", "표·그림 번호"로 적었습니다.

## 1. 문제와 기여

텍스트 → 이미지 latent diffusion을 대규모로 만들 때 (a) 어떤 forward path·손실 가중·시간(timestep) 표본 분포가 좋은지, (b) 텍스트 조건을 어떻게 넣을지, (c) 크기를 키우면 예측 가능하게 좋아지는지를 한 번에 묻습니다. 기여는 셋입니다(§1).

1. **정식화 비교와 새 시간 표본기.** 61가지 정식화(ε/v-예측 × 선형·코사인, EDM, RF × 균일·logit-normal·mode·CosMap)를 같은 조건에서 비교하고, RF에 logit-normal(0,1) 시간 표본을 쓰면 가장 안정적으로 좋다고 보고합니다(§3.1, §5.1, 표 1).
2. **MM-DiT.** 텍스트와 이미지 토큰을 각자 다른 가중치(QKV, 출력 사영, MLP, adaLN)로 처리하되 어텐션에서만 한 시퀀스로 합칩니다(§4, 그림 2).
3. **스케일링.** 깊이 d(은닉 64d, 헤드 d)를 15–38로 키워(최대 8B) 검증 손실이 모델 크기와 학습량에 따라 매끄럽게 줄고, GenEval·T2I-CompBench·사람 선호와 강하게 상관한다고 보입니다(§5.3.3, 그림 8).

## 2. 방법 (식 번호는 논문 그대로)

### 2.1 시뮬레이션 없는 학습 (§2, 부록 B.1)

- ODE: dy_t = v_Θ(y_t, t) dt (식 1). forward: z_t = a_t x0 + b_t ε, ε ~ N(0,I) (식 2), 경계 a0=1, b0=0, a1=0, b1=1.
- 조건부 속도 u_t(z|ε) = ψ'_t(ψ_t^{-1}(z|ε)|ε) (식 5), 주변 속도 u_t(z) = E_ε u_t(z|ε) p_t(z|ε)/p_t(z) (식 6). 조건부 flow matching L_CFM (식 8)이 L_FM (식 7)과 같은 기울기를 가짐을 부록 B.1이 보입니다(식 26–36).
- SNR λ_t = log(a_t²/b_t²), λ'_t = 2(a'_t/a_t − b'_t/b_t) (식 10 앞)로 쓰면 u_t(z_t|ε) = (a'_t/a_t) z_t − (b_t/2) λ'_t ε (식 10). 이를 ε-예측으로 다시 쓰면 L_CFM = E (b_t λ'_t/2)² ‖ε_Θ − ε‖² (식 11–12), ε_Θ := (−2/(λ'_t b_t))(v_Θ − (a'_t/a_t) z) 입니다.
- **통합 목적함수** (식 13 앞, Kingma & Gao 2023): L_w = −½ E_{t~U, ε}[ w_t λ'_t ‖ε_Θ − ε‖² ], L_CFM은 w_t = −½ λ'_t b_t² 입니다.

### 2.2 궤적과 가중 (§3)

| 정식화 | forward | 논문의 w_t | 위치 |
|---|---|---|---|
| Rectified flow | z_t = (1−t)x0 + tε | w^RF_t = t/(1−t) | 식 13 뒤 문단 |
| EDM | z_t = x0 + b_t ε, λ_t ~ N(−2P_m, (2P_s)²) | N(λ_t; −2P_m, (2P_s)²)(e^{−λ_t} + 0.5²) | 식 14–16 |
| Cosine | z_t = cos(πt/2) x0 + sin(πt/2) ε | ε-예측: sech(λ_t/2), v-예측: e^{−λ_t/2} | 식 17 뒤 |
| LDM-Linear | 분산 보존, β_t가 √β 선형 보간(DDPM은 β 선형) | (식 없음, eps/linear) | §3 |

### 2.3 시간 표본기 (§3.1, 부록 B.4)

시간 분포를 U(t)에서 π(t)로 바꾸는 것은 w^π_t = t/(1−t) π(t) 로 가중하는 것과 같다고 합니다(식 18). 이유는 "t가 0이나 1 근처면 최적 예측이 각각 p1, p0의 평균이라 쉽고, 가운데가 어렵다"입니다.

- **Logit-normal** π_ln(t; m, s) = 1/(s√(2π)) · 1/(t(1−t)) · exp(−(logit(t) − m)²/(2s²)) (식 19). m>0이면 노이즈 쪽, 구현은 u ~ N(m,s)를 시그모이드에 통과.
- **Mode sampling with heavy tails**: f_mode(u; s) = 1 − u − s(cos²(πu/2) − 1 + u) (식 20). −1 ≤ s ≤ 2/(π−2) 에서 단조이고 π_mode(t; s) = |d f^{-1}/dt|. s=0은 균일. 끝점에서도 밀도가 양수입니다.
- **CosMap**: 코사인 스케줄의 log-SNR과 맞춘 f(u) = 1 − 1/(tan(πu/2)+1) (식 21), π_CosMap(t) = 2/(π − 2πt + 2πt²) (식 22).

### 2.4 텍스트 조건과 MM-DiT (§4, 부록 B.2)

- 잠재: 사전학습 오토인코더(8배 축소, 채널 d=16 선택, 표 3·그림 10). 텍스트: CLIP-L/14와 OpenCLIP bigG/14의 풀링 출력(768+1280 = 2048, c_vec)과 마지막 은닉 상태, T5-XXL 인코더 출력을 합친 시퀀스 c_ctxt ∈ R^{154×4096}.
- 블록(그림 2b): 이미지 패치(2×2)와 텍스트를 같은 차원으로 사영해 이어 붙이고, 모달리티마다 별도 가중치를 쓰되 어텐션은 합친 시퀀스에서 합니다. 시간 임베딩과 c_vec은 adaLN 변조(α, β, γ, δ, ε, ζ)로 들어갑니다.
- 크기: 깊이 d, 은닉 64·d, MLP 4·64·d, 헤드 d (§4).

### 2.5 대규모 학습 요령 (§5.3)

- **QK 정규화**: 고해상도·bf16에서 어텐션 로짓이 커져 발산하므로 두 스트림의 Q, K에 학습 스케일이 있는 RMSNorm (그림 5; 마지막 5블록에서 가장 두드러짐), AdamW ε=1e-15.
- **다중 종횡비**: 256² 사전학습 뒤 버킷 샘플링으로 고해상도·여러 종횡비 미세조정, 위치 격자를 확장+보간.
- **해상도 의존 시간 이동 (§5.3.2, 식 23–25)**: "모든 픽셀이 같은 값 c인 상수 이미지" 가정에서 z_t의 n개 관측으로 c를 복원하는 오차의 표준편차가 σ(t,n) = (t/(1−t)) √(1/n)이므로, σ(t_n, n) = σ(t_m, m)을 풀어 t_m = (√(m/n) t_n)/(1 + (√(m/n) − 1) t_n) (식 23), log-SNR 이동 λ_{t_m} = λ_{t_n} − log(m/n) (식 25). 이동값 α = √(m/n)를 1024² 모델에 적용한 사람 선호 연구에서 1.5 이상이 좋고 그 이상은 차이가 작아 **α = 3.0을 학습과 샘플링에 모두 사용**합니다(그림 6).
- **합성 캡션**: CogVLM으로 만든 캡션과 원 캡션 50:50 (표 4, d=15, 250k step).
- **사전 계산**: 오토인코더·텍스트 인코더 출력을 미리 저장(부록 E.1, 표 7), 중복 제거(SSCD, 군집 16,000)(부록 E.2).
- **DPO**: LoRA rank 128, 2B 4k·8B 2k iteration, Parti 128 캡션으로 사람 평가(부록 C).

## 4. 한계

논문이 인정하거나 읽으면 드러나는 한계입니다. 우리 재계산 결과는 `03`과 `04`에 있습니다.

- 표 1은 정식화마다 **학습 1회**이고 시드가 없습니다. 순위 차이에 불확실성 구간이 없습니다. 비교는 d가 작은 모델·낮은 해상도(ImageNet, CC12M, 25스텝 중심)에서 하고, 결론은 8B·1024²로 옮깁니다.
- 시간 이동 식은 **상수 이미지 가정**에서 유도했고 논문 스스로 "현실적이지 않다"고 적습니다(§5.3.2). 유도된 값 √(m/n)가 아니라 사람 선호 연구로 α=3을 골랐습니다.
- 스케일링 결론("포화 없음")은 5개 크기, 500k 스텝, 시각적 판단입니다. 맞춤 함수형과 불확실성이 없습니다.
- 검증 손실과 평가 지표의 상관은 점이 모델 5개의 체크포인트들이라 독립 표본이 아닙니다.
- 데이터(필터링한 내부 데이터), 사전 필터링 기준, 8B 학습 코드와 하이퍼파라미터는 공개되지 않았습니다. 공개 코드는 추론용입니다(`04`).
- "실험 데이터, 코드, 모델 가중치를 공개할 것"(초록)이라 했으나 실험 데이터(표 1의 61개 정식화 결과 전체, 그림 8의 원 수치)는 논문에 없습니다.
