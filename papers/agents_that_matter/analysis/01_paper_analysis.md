Kapoor, Stroebl, Siegel, Nadgir, Narayanan (Princeton). 분석 판은 arXiv v1(2024-07-01, 유일한 판)입니다. 학회 판은 TMLR 2025(OpenReview 포럼 Zy4uFzMviZ, `venue` "Accepted by TMLR", 게재 처리 시각 2025-06-13)이고, 저장소 README 첫 줄도 `[TMLR 2025]`입니다. TMLR 카메라 레디 PDF는 OpenReview가 자동 요청을 막아(403 challenge) 받지 못했습니다. OpenReview의 "changes since last submission"에는 (1) 문제를 지적할 뿐 해법을 제안하지는 않는다는 점 명확화, (2) human-in-the-loop 평가의 중요성은 논의하되 해법은 범위 밖이라는 점 명확화, (3) 인용 정정, (4) 카메라 레디 형식으로 갱신이 적혀 있습니다. 그래서 이 문서의 쪽 번호와 표 번호는 모두 v1 기준이고, 수치가 학회 판에서 바뀌었는지는 확인하지 못했습니다.

## 1. 문제 설정

에이전트 개발이 벤치마크 점수에 이끌리는데, 평가 관행에 네 가지 결함이 있다는 주장입니다. 이 논문은 새 에이전트나 새 벤치마크를 내는 논문이 아니라 **평가 관행 비판**입니다. 주장을 떠받치는 실험은 세 가지입니다. HumanEval에서 단순 기준선과 복잡한 에이전트의 정확도와 비용 비교(2절), HotPotQA에서 DSPy의 비용·정확도 결합 최적화(3절), NovelQA에서 롱컨텍스트 대 RAG 비용 비교(4.1절). 나머지(홀드아웃 분류, WebArena STeP 사례, 재현성 사례)는 조사와 재현 시도에 기반합니다.

기여 5가지(1절, 쪽 2):

| # | 주장 | 절 | 근거 |
|---|---|---|---|
| 1 | 에이전트 평가는 비용을 통제해야 한다 | 2 | HumanEval 164문항, 에이전트당 5회 실행(그림 1, 표 A1) |
| 2 | 정확도와 비용의 결합 최적화가 더 나은 설계를 연다 | 3 | HotPotQA 200문항, DSPy 수정 + Optuna(그림 2, 표 A3) |
| 3 | 모델 개발자와 하위 개발자의 평가 요구가 다르다 | 4 | NovelQA 1회 실행(표 A5), Mixtral 사례 |
| 4 | 에이전트 벤치마크는 지름길을 허용한다 | 5 | 17개 벤치마크 조사(표 1, 표 A4), WebArena STeP 사례 |
| 5 | 평가가 표준화되지 않아 재현되지 않는다 | 6 | HumanEval·WebArena 재현 시도(표 A6, A7) |

## 2. 방법과 실험 설정

### 2.1 HumanEval 비교 (2절, 부록 A)

- **대상.** 코드를 실행하고 실패하면 고치는 공개 에이전트 세 개: LDB(Zhong 외), LATS(Zhou 외), Reflexion(Shinn 외). 선정은 PapersWithCode 리더보드에서 코드를 공개한 에이전트이고, Reflexion은 리더보드에는 없지만 보고 정확도 91%라 포함했습니다(각주 1, 쪽 3). AgentCoder는 선정 시점(2024-04 말)에 코드가 없어 제외했습니다.
- **기준선 세 개.** Retry는 온도 0으로 최대 5번 재시도합니다. Warming은 재시도하되 온도를 0, 0.3, 0.3, 0.5, 0.5로 올립니다(부록 A.1). Escalation은 Llama-3 8B, GPT-3.5, Llama-3 70B, GPT-4 순으로 올립니다. 세 기준선 모두 **문제에 딸린 예시 테스트가 실패할 때만** 다시 시도하고, 하나라도 통과하면 멈춥니다. 최종 채점은 전체 숨은 테스트입니다.
- **벤치마크 판.** LDB 논문이 낸 수정판 HumanEval(164문항 전부에 예시 테스트 부여). 원판은 161문항에만 예시 테스트가 있습니다(6절, 쪽 10).
- **모델과 가격.** `gpt-3.5-turbo-0125`(입력 0.5 / 출력 1.5 USD per 1M), `gpt-4-turbo-2024-04-09`(10 / 30), 2024-04 가격(부록 A.1, 쪽 20). 부록 A.2는 2023-06판 모델(gpt-4-0613: 30 / 60)로 같은 분석을 반복한 견고성 검사입니다.
- **반복 수와 구간.** 에이전트당 5회 실행(LATS의 0613판만 1회). 표 A1은 평균(최소–최대), 그림 A1은 Student t 95% 구간(5회)입니다.
- **파레토 전선 정의.** 본문(2.3절)은 "다른 에이전트가 **유의하게** 두 차원 모두 더 낫지 않으면 전선 위"라고 쓰지만, 부록 A.1은 "평균 비용과 정확도에서 지배되지 않는 점의 집합, 볼록 껍질로 제한"이라고 씁니다(쪽 22). 각주 2는 두 에이전트를 확률 p로 섞는 에이전트가 항상 가능하니 전선은 볼록이어야 한다는 논리입니다.

### 2.2 결합 최적화 (3절, 부록 B)

- **대상.** DSPy의 간단한 Baleen식 다중 홉 QA(2홉, 홉당 2문서, ColBERTv2 검색, 2017 위키 첫 문단). 모델은 Llama-3-70B와 GPT-3.5.
- **데이터.** 훈련 100(그중 50은 후보 예시 수집, 50은 개발 검증), 평가 200. 평가 지표는 "정답 문서를 모두 검색했는가"이고 답 정확도가 아닙니다(3.1절, 부록 B.1).
- **다섯 설계.** Uncompiled, 형식 지시만, DSPy few-shot, DSPy random search, 결합 최적화. 결합 최적화는 Optuna로 (a) 모듈별 온도 {0, 0.2, 0.4, 0.6}, (b) 예시 수, (c) 예시 선택, (d) 형식 지시 여부를 탐색합니다. 최대 8개 예시, 시행 16회. Optuna가 낸 후보 중 **개발 정확도가 가장 높은 것**을 보고합니다(부록 B.1, 쪽 26).
- **비용.** 변동비(100건 추론당 USD)와 고정비(최적화에 쓴 총 USD)로 나눕니다. 그림 A6은 변동비가 고정비를 따라잡는 지점을 보입니다.

### 2.3 NovelQA (4.1절, 부록 D)

88권의 소설, 다지선다 부분집합(약 2,300문항). GPT-4에 소설 전체를 넣는 롱컨텍스트와 text-embedding-3-large 임베딩 + 10청크(각 1,000자) RAG를 비교합니다. 각 1회 실행. 정확도 67.81(롱컨텍스트)과 67.89(RAG), 총비용 99.80과 52.80 USD(표 A5). 소설 한 권에 문항을 한꺼번에 묻는 NovelQA의 방식과 문항마다 따로 묻는 실제 방식의 비용 차이를 계산해 "RAG가 20배 이상 싸다"(표 A5의 비 21.86)고 주장합니다.

### 2.4 홀드아웃 조사 (5절, 부록 C)

벤치마크 17개를 일반성 4수준(분포 특정, 과제 특정, 도메인 일반, 완전 일반)으로 분류하고, 수준별로 무엇을 떼어 놓아야 하는지 제안합니다(표 1). 분류는 "논문의 서술을 보고 최선으로 추정"한 것입니다(쪽 8).

### 2.5 재현성 (6절, 부록 E)

다섯 원인(평가 스크립트의 가정, LLM 벤치마크 전용, 비용 때문에 구간 부재, 환경 상호작용의 오류, 표준화 부재)과 에이전트별 사례(표 A6). 보고 정확도와 재현 정확도(표 A7).

## 4. 논문이 스스로 밝힌 한계 (부록 G)

가격 모델이 시간에 따라 바뀌고(웹앱으로 단가를 바꿔 재계산하게 함), 모든 과제 환경을 망라하지 않으며, 환경 비용·인력·유지보수 같은 다른 비용은 분석하지 않았습니다. 5.2절은 사람이 참여하는 평가를 다루지 않은 것도 한계로 둡니다.

## 5. 우리가 보기에 읽을 때 주의할 점

- 논문의 핵심 실증은 **한 벤치마크(HumanEval, 164문항, 포화 영역)와 한 모델 계열(OpenAI + Llama-3)** 의 결과입니다. 저자도 SWE-bench 같은 더 어려운 과제에서는 System 2 기법이 유용할 수 있다고 인정합니다(2.3절 끝).
- 에이전트별 구간은 **5회 실행의 Student t 구간**이라 모델 샘플링 변동만 담고 과제 표본 변동은 담지 않습니다. 부록 B의 그림 A5 설명도 같은 한계를 적습니다("최적화와 재표집의 변동은 포함하지 않음").
- 비교 대상 에이전트의 **재현이 설정 선택에 좌우**됩니다(LDB의 시드 프로그램, LATS의 반복 8과 온도 0.8 등, 부록 A.1). 이 선택은 저자와의 서신으로 정해진 것이 일부이고 논문 본문에는 안 적혀 있습니다.
- "비용 통제" 주장은 **비용이 거의 GPT-4 호출에서 나오는** 에이전트들끼리의 비교라서(2.3절) 비율이 가격에 안정적이라는 서술이 성립합니다. 단가 비율이 다른 모델 조합에서는 순서가 바뀔 수 있습니다(`03` §4).
