# 02. 계보와 관련 연구: BLIP-2 (arXiv:2301.12597)

**근거 수준.** 이전·이후 문헌 항목은 **arXiv 초록과 메타데이터(arXiv API, 2026-11-26)**, 이 저장소의 완료된 분석(`prismatic_vlms/`, `cambrian1/`, `eyes_wide_shut/`, `paligemma/`), BLIP-2 본문(v3), 공식 코드 정적 읽기로 썼습니다. 초록에 없는 세부는 "일반 지식, 본문 미확인"으로 표시했습니다. 웹 검색은 쓰지 않았습니다.

## 1. 계보: BLIP-2는 무엇을 이어받았나

| 구성 요소 | 출처 | BLIP-2에서의 쓰임 |
|---|---|---|
| ITC·ITM 두 손실의 틀, 어려운 음성 채굴 | ALBEF (arXiv:2107.07651). 초록: 융합 전에 대조 손실로 이미지·텍스트를 정렬("align before fuse") | BLIP-2 §3.2가 ITC, ITM을 쓰고 ITM의 어려운 음성은 "Li et al. 2021; 2022"를 따름. 공식 코드는 유사도 softmax에서 **표본추출**(03 D6) |
| ITC + ITM + ITG(LM)를 파라미터 공유로 함께 학습 | BLIP (arXiv:2201.12086). 초록: 이해와 생성 모두에 전이하는 VLP, CapFilt로 합성 캡션 | 세 목적과 "목적마다 다른 마스크"의 원형. BLIP-2 §3.2는 "BLIP에서 영감". CapFilt를 데이터에 그대로 사용(§3.4). 모멘텀 큐는 배치 내 음성으로 대체 |
| 이미지 인코더를 고정하고 텍스트 쪽만 학습 | LiT (Zhai 외 2022, BLIP-2 §2.2가 인용) | 고정 이미지 인코더의 근거. 일반 지식, 본문 미확인 |
| 고정된 LM + 이미지에서 온 연속 임베딩 프롬프트 | Frozen (arXiv:2106.13884). 초록: 비전 인코더를 학습해 이미지를 연속 임베딩열로 바꾸고 고정 언어 모델에 접두로 줌 | 2단계의 **소프트 프롬프트** 방식. 차이: Frozen은 이미지 인코더를 학습하고(BLIP-2 §2.2) BLIP-2는 인코더를 고정하고 Q-Former만 학습 |
| 학습 가능한 잠재 질의로 시각 토큰을 고정 개수로 압축 + 고정 LM에 교차 attention 주입 | Flamingo (arXiv:2204.14198). 초록: 사전학습된 비전 전용·언어 전용 모델을 잇는 구조, 이미지와 텍스트가 임의로 섞인 입력. **Perceiver Resampler, 게이트 교차 attention 층은 본문의 설계(일반 지식, 본문 미확인)** | BLIP-2 §2.2는 Flamingo가 LLM 안에 교차 attention 층을 새로 넣고 수십억 쌍으로 학습한다고 설명하고, §4.1은 1단계를 빼면 Q-Former가 "Perceiver Resampler와 비슷하다"고 씀. 차이: BLIP-2는 **LLM에 손대지 않고** 입력 쪽에 소프트 토큰 32개만 붙임 |
| 질의 + BERT 트랜스포머 | BERT (일반 지식) | Q-Former는 BERT-base로 초기화(§3.1). 공식 코드는 층마다 질의용 FFN을 따로 둠(03 D2) |

**한 줄 요약.** BLIP-2의 새로움은 부품이 아니라 **조합**입니다. (1) 고정 인코더와 고정 LLM 사이에 학습 가능한 질의 병목을 두고, (2) 그 병목을 LLM에 연결하기 **전에** 텍스트와 대조·매칭·생성으로 따로 학습하는 2단계 순서, (3) 출력 토큰 수가 입력 해상도와 무관한 설계입니다.

## 2. 같은 시기의 대안

| 연구 | 근거 | BLIP-2와의 관계 |
|---|---|---|
| Plug-and-play VQA, Img2Prompt (BLIP-2 v2부터 인용: Tiong 외 2022, Guo 외 2022) | BLIP-2 참고문헌(본문 미확인) | 학습 없이 이미지를 캡션 같은 텍스트 프롬프트로 바꿔 LLM에 주는 방식. 연결기를 학습하지 않는 쪽의 대안 |
| MAPL (Mañas 외 2023, v2부터 인용) | BLIP-2 참고문헌(본문 미확인) | 파라미터 효율적인 단일 모달 모델 적응 |

## 3. 이후 문헌: 연결기 설계가 어떻게 바뀌었나

| 연구 | 근거 | BLIP-2의 무엇을 바꿨나 |
|---|---|---|
| **InstructBLIP** (arXiv:2305.06500) | 초록: BLIP-2 사전학습 모델에서 시작하는 시각-언어 **지시 튜닝** 연구, 26개 공개 데이터셋을 지시 형식으로 변환, **지시를 인식하는 Query Transformer**(지시에 맞는 특징을 뽑음) 도입, 13개 held-in으로 학습해 13개 held-out에서 BLIP-2와 더 큰 Flamingo를 크게 앞선다고 보고 | 질의가 **질문을 본다**: BLIP-2 §4.3의 VQA 미세조정(질문 토큰을 Q-Former에 넣음)을 일반 지시 튜닝으로 확장. 병목을 유지하되 병목이 과제를 인식하게 바꿈 |
| **MiniGPT-4** (arXiv:2304.10592) | 초록: **고정 시각 인코더를 고정 Vicuna에 투영 층 하나로** 정렬. 짧은 캡션만으로 학습하면 반복·단편 같은 부자연스러운 출력이 나와 2단계에서 상세 이미지 설명 데이터로 미세조정 | 초록에는 BLIP-2가 나오지 않으나 BLIP-2의 사전학습된 비전 쪽(ViT + Q-Former)을 쓴다고 알려져 있음(일반 지식, 본문 미확인). 2단계를 선형 투영 하나로 줄인 가장 단순한 후속 |
| **LLaVA** (arXiv:2304.08485) → **LLaVA-1.5** (arXiv:2310.03744) | LLaVA 초록: GPT-4로 만든 시각 지시 데이터, 시각 인코더와 LLM을 잇는 end-to-end 학습 모델. LLaVA-1.5 초록: LLaVA의 **완전연결 교차 모달 연결기가 "놀랄 만큼 강력하고 데이터 효율적"**, CLIP-ViT-L-336px + **MLP 투영**과 학술 VQA 데이터 추가로 11개 벤치마크 최고, 13B가 공개 데이터 1.2M, 8-A100 한 대에서 약 1일 | **압축을 하지 않는 반대 설계**. 패치 토큰을 모두(336px 기준 576개) MLP로 투영해 넘김. 병목을 없애고 데이터와 지시 튜닝에 투자. 다음 폴더: `llava/`(46번) |
| **Qwen-VL** (arXiv:2308.12966) | 초록: "visual receptor", 입출력 인터페이스, 3단계 학습 파이프라인, 다국어 말뭉치로 구성. 위치 지정과 글자 읽기 능력을 이미지-캡션-박스 튜플 정렬로 부여 | 시각 수용기가 **학습 가능한 질의의 단일 층 교차 attention 압축기**(256개 질의)라는 점은 본문 내용(일반 지식, 본문 미확인). Q-Former 계열 압축기를 위치 정보와 함께 쓴 사례 |
| **Honeybee** (arXiv:2312.06742) | 초록: 투영기가 갖춰야 할 두 성질을 제시 — (i) **시각 토큰 수를 유연하게** 다룰 것(효율), (ii) 시각 특징의 **국소 문맥 보존**(공간 이해). 두 성질을 만족하는 투영기를 제안, MME·MMBench·SEED-Bench·LLaVA-Bench에서 이전 SOTA를 앞서며 훨씬 효율적 | Q-Former류(토큰 수 조절 가능, **국소성 약함**)와 MLP(국소성 보존, **토큰 수 조절 불가**)의 장단을 한 틀에서 비교. BLIP-2 설계의 약점(국소성)을 지목한 후속 |
| **MM1** (arXiv:2403.09611) | 초록: 이미지 인코더, **비전-언어 연결기**, 사전학습 데이터 선택을 통제 절제 — "이미지 인코더와 **해상도, 이미지 토큰 수**가 큰 영향을 주고 **연결기 설계는 비교적 무시할 만한 중요도**" | 중심 질문을 "연결기 종류"에서 "시각 토큰 수와 해상도"로 옮김. BLIP-2의 "Q-Former가 좋아서"라는 서사를 약화 |
| **Idefics2** (arXiv:2405.02246) | 초록: 사전학습 모델, 구조, 데이터, 학습 방법에 대한 광범위한 실험, 근거 없이 정해지던 설계 결정을 비판. 8B 모델 | 연결기 비교가 이 논문의 절제에 포함됨(초록만 읽음, 세부 미확인). `paligemma/`가 부록 A를 같은 맥락으로 인용 |
| Prismatic VLMs (`prismatic_vlms/`, arXiv:2402.07865) | 이 저장소 분석: 통제된 설계 공간(전처리, 구조, 최적화)에서 비교, InstructBLIP은 Q-Former 구조라 위치 지정 평가는 N/A(표 3) | Q-Former 연결기를 **직접 절제 대상으로 두지 않고** 패치 토큰 투영기 쪽 설계 공간을 평가. 같은 질문(연결기)이지만 다른 결론이 나오는 지점은 `04` C5 |
| Cambrian-1 (`cambrian1/`, arXiv:2406.16860) | 이 저장소 분석(`03` §6.2): 표 4에서 **SVA − Resampler = General +5.4, Knowledge +3.2, OCR +28.4, Vision +10.6**(모두 표본 변동 안정 한계 밖) | SVA는 질의 + 교차 attention 구조를 이어받아 **질의마다 부분 영역을 고정**해 공간 구조를 보존. Resampler(Q-Former류 압축기)의 공간 정보 손실을 정면으로 다룸 |
| PaliGemma (`paligemma/`, arXiv:2407.07726) | 이 저장소 분석: 연결기를 **선형 투영**으로 쓰고 선형이 MLP와 같거나 약간 낫다는 절제(§5.5) | 압축기 없이 모든 SigLIP 패치를 넘기는 쪽의 또 다른 사례 |
| Qwen2-VL (`qwen2_vl/`, arXiv:2409.12191) | 이 저장소 분석 참고 | 동적 해상도(이미지에 따라 토큰 수가 변함)와 MLP로 인접 토큰을 합치는 방식. "토큰 수를 연결기가 정한다"(BLIP-2)에서 "이미지 크기가 정한다"로 이동 |
| Eyes Wide Shut? (`eyes_wide_shut/`, arXiv:2401.06209) | 이 저장소 분석: MLLM의 시각적 약점을 CLIP 인코더와 연결 | 표 5의 InstructBLIP 상관 0.71은 그림에서 읽으면 0.61(`eyes_wide_shut` `03`)이라 Q-Former 계열 모델 쪽 증거는 불확실. 압축 병목의 효과는 분리되지 않음 |

## 4. 이 저장소의 다른 분석과의 관계

- `clip/`: BLIP-2의 이미지 인코더 후보(ViT-L/14 CLIP, EVA-CLIP ViT-g)와 ITC(대칭 InfoNCE의 질의별 최댓값 변형). `siglip/`, `dinov2/`: 고정 인코더 후보. `vit/`: 고정되는 패치 특징의 출처(257 = 256 패치 + CLS).
- `llava/`(46번): 패치 토큰 전부를 MLP로 넘기는 반대 설계. 이 폴더의 토이가 같은 조건에서 두 방식을 비교합니다(`03` §4).
- `cambrian1/`, `prismatic_vlms/`: 연결기 비교의 대규모 실험. 이 폴더는 **같은 질문을 합성 데이터로 구조 수준에서** 봅니다(`03` §4, `04` C5–C6).

## 6. 리뷰 원고에서의 위치

- 분류 축(7축 멀티모달 표현·결합) 중 **연결기** 축의 원형: "무엇을 넘기나(압축된 질의 출력 대 모든 패치 토큰)", "어떻게 학습하나(2단계 대 1단계)", "토큰 수는 누가 정하나(연결기 대 이미지 해상도)". 이후 문헌은 이 세 축에서 갈립니다: LLaVA는 "모두, 1단계, 이미지 해상도", BLIP-2는 "압축, 2단계, 연결기", Qwen2-VL은 "모두 + 합치기, 1단계, 이미지 해상도", Honeybee·SVA는 "압축하되 국소성 유지".
- 다음 읽을 순서: `llava/` → `cambrian1/`(연결기 비교 표 4, 5) → `prismatic_vlms/`.
