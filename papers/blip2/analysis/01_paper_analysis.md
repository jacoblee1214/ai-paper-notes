# 01. 논문 분석: BLIP-2 (arXiv:2301.12597)

*BLIP-2: Bootstrapping Language-Image Pre-training with Frozen Image Encoders and Large Language Models*, Junnan Li, Dongxu Li, Silvio Savarese, Steven Hoi (Salesforce Research), ICML 2023. 분석 판은 **arXiv v3**(2023-06-15, 13쪽)이고 분석일은 2026-11-26입니다. 이전 판(v1 2023-01-30, v2 2023-05-01)과의 차이는 §6에 있습니다. 논문에는 번호 붙은 식이 없어서 근거 위치는 절, 그림, 표 번호로 적습니다. 인용 형식 "§3.2"는 논문 절입니다.

## 1. 문제

- 비전-언어 사전학습(VLP)은 모델과 데이터가 커지며 end-to-end 학습 비용이 매우 커졌고, 이미 있는 단일 모달 모델(이미지 인코더, LLM)을 가져다 쓰기도 어렵습니다(§1).
- 해법의 방향은 두 단일 모달 모델을 **고정**하고 둘 사이만 학습하는 것입니다. 이미지 인코더 고정은 비용을 줄이고, LLM 고정은 망각을 막습니다(§1). 어려운 점은 LLM이 사전학습에서 이미지를 본 적이 없다는 것입니다. 이전 방법(Frozen, Flamingo)은 이미지에서 텍스트를 생성하는 손실 하나로 정렬하는데, 논문은 이것이 "양식 간 간격을 메우기에 불충분하다"고 주장합니다(§1, 근거는 그림 5).

## 2. 방법

### 2.1 Q-Former (§3.1, 그림 2 왼쪽)

- 구성: **같은 self-attention 층을 공유하는 두 하위 모듈**입니다. (1) 고정 이미지 인코더와 상호작용하는 이미지 트랜스포머, (2) 텍스트 인코더와 디코더를 겸하는 텍스트 트랜스포머.
- 입력은 학습되는 질의 임베딩 **32개(각 768차원)**입니다. 질의끼리는 self-attention으로, 고정 이미지 특징과는 **교차 attention(트랜스포머 블록 하나 건너 하나)**으로 상호작용합니다. 질의는 같은 self-attention을 통해 텍스트와도 상호작용할 수 있고, 과제에 따라 마스크를 바꿔 그 상호작용을 조절합니다(§3.1).
- 초기화: BERT-base 가중치, 교차 attention 층은 무작위 초기화. 총 **188M** 파라미터(질의도 파라미터로 셈)(§3.1).
- 출력 Z는 32 x 768이고, 이미지 특징(예: ViT-L/14의 257 x 1024)보다 훨씬 작습니다. 이 병목이 사전학습 목적과 함께 "텍스트와 가장 관련된 시각 정보"만 뽑게 한다고 설명합니다(§3.1). **출력 토큰 수는 입력 이미지 해상도와 무관하게 고정**입니다.

### 2.2 1단계: 표현 학습 (§3.2, 그림 2)

고정 이미지 인코더에 Q-Former를 붙여 이미지-텍스트 쌍으로 세 목적을 함께 최적화합니다(BLIP에서 영감, 같은 입력 형식과 파라미터 공유). 목적마다 **질의-텍스트 self-attention 마스크**가 다릅니다.

| 목적 | 마스크 | 내용 |
|---|---|---|
| ITC (이미지-텍스트 대조) | 단일 모달: 질의와 텍스트가 서로 못 봄(정보 누설 방지) | 질의별 출력과 텍스트 [CLS] 출력의 유사도 중 **최댓값**을 이미지-텍스트 유사도로 씀. BLIP의 모멘텀 큐 대신 배치 내 음성(고정 인코더라 GPU당 샘플을 더 넣을 수 있음) |
| ITG (이미지 기반 텍스트 생성) | 다중 모달 인과(UniLM식): 질의는 서로만, 텍스트는 모든 질의와 앞쪽 텍스트를 봄. [CLS] 대신 [DEC] | 텍스트 생성에 필요한 정보는 먼저 질의가 뽑아 self-attention으로 텍스트에 넘겨야 함(이미지 인코더와 텍스트 사이에 직접 경로가 없으므로) |
| ITM (이미지-텍스트 매칭) | 양방향: 모두가 모두를 봄 | 질의 출력마다 2-클래스 선형 분류기 로짓을 만들어 **평균**을 매칭 점수로 씀. BLIP(Li 외 2021, 2022)의 어려운 음성 채굴 사용 |

### 2.3 2단계: 생성 학습 (§3.3, 그림 3)

- 질의 출력 Z를 **선형(FC) 층 하나**로 LLM 임베딩 차원에 맞춰 입력 텍스트 임베딩 앞에 붙입니다. 이 소프트 시각 프롬프트가 LLM을 시각 표현에 조건화합니다. 1단계에서 "언어 정보를 담는 시각 표현"을 뽑도록 학습했으므로 Q-Former가 정보 병목으로 작동해 LLM의 정렬 부담을 줄이고 망각을 완화한다고 설명합니다.
- 디코더 전용 LLM(OPT)은 언어 모델링 손실, 인코더-디코더 LLM(FlanT5)은 접두 언어 모델링 손실(텍스트를 둘로 나눠 접두는 인코더에 시각 표현과 함께, 접미는 디코더의 목표로) (§3.3, 그림 3).

### 2.4 사전학습 설정 (§3.4)

- 데이터 129M 이미지(COCO, Visual Genome, CC3M, CC12M, SBU, LAION400M에서 115M). CapFilt로 합성 캡션 10개를 만들어 CLIP ViT-L/14 유사도로 순위를 매겨 상위 2개를 쓰고 스텝마다 하나를 무작위로 뽑음.
- 고정 이미지 인코더: CLIP ViT-L/14 또는 EVA-CLIP ViT-g/14(**마지막 층을 제거하고 끝에서 둘째 층 출력을 사용**). 고정 LLM: OPT 계열, FlanT5 계열.
- 1단계 250k 스텝, 2단계 80k 스텝. 배치 2320/1680(ViT-L/g, 1단계), 1920/1520(OPT/FlanT5, 2단계). 가장 큰 모델이 16 x A100(40G)에서 1단계 6일 미만, 2단계 3일 미만. AdamW(β = 0.9, 0.98, 가중치 감쇠 0.05), 코사인 감쇠 피크 1e-4, 2k 워밍업. 이미지 224 x 224. FP16(FlanT5는 BF16).

## 4. 학습되는 파라미터, 표마다 다른 숫자

- 표 1은 BLIP-2를 **188M**, 표 2는 104–108M, 표 3·4(미세조정)는 1.1–1.2B로 적습니다. 188M은 **1단계 Q-Former 전체**(텍스트 쪽 임베딩·FFN 포함), 104–108M은 2단계에서 실제 쓰는 질의 경로, 1.1B는 미세조정에서 이미지 인코더까지 갱신하기 때문입니다(§4.2, §4.3). 이 해석은 `03` §1에서 파라미터 산술로 확인했습니다.
- "54배 적다"(초록, §4.1)는 **10.2B / 188M = 54.3**입니다. 표 2의 같은 모델(ViT-g FlanT5-XXL, 108M)로 나누면 **94배**입니다. 표 2의 비교는 Flamingo80B(학습 10.2B)와 BLIP-2(학습 108M)이므로, 더 맞는 배수는 후자입니다. 어느 쪽이든 두 모델이 **학습 데이터, 사전학습 비용, 고정된 모델의 크기가 다른** 비교라서 "54배" 자체가 효율의 동일 조건 비교는 아닙니다(§5 `04` C1).

## 5. 한계와 논문 안의 모호함

논문 본문이 적은 한계(§5): in-context 학습 불가(P9), 부정확한 지식·잘못된 추론 경로·오래된 정보로 인한 오류(그림 6, 7), 고정 LLM이 가진 위험(유해 발언, 사회적 편향, 개인정보 노출)을 그대로 물려받음.

우리가 본 모호함이나 보고 누락:

1. **세 목적의 수식, 온도, 투영 차원이 논문에 없음.** 논문은 ITC의 유사도 정의(질의별 최댓값)와 마스크를 말로만 적습니다. 온도 초기값 0.07, 라벨 평활화 0.1, ITC 투영 차원 256, 텍스트 최대 길이 32는 **공식 코드에서만** 알 수 있습니다(`04` D3–D5).
2. **질의용 FFN이 따로 있음이 본문에 없음.** 188M은 층마다 질의용 FFN이 텍스트용 FFN과 별개일 때만 맞습니다(§3.1은 "같은 self-attention 층을 공유"만 말함). `03` §1, `04` D2.
3. **그림 5는 모델 두 개, 실행 한 번씩.** (ViT-g + OPT-6.7B, ViT-g + FlanT5-XL) 5개 시점의 곡선이고 시드, 구간, 수치 표가 없습니다. 그림에서 읽으면 80k 스텝에서 OPT는 약 54(1단계 있음) 대 약 15(없음), FlanT5-XL은 약 63 대 약 44입니다(우리가 그림에서 읽은 근사값). "없음"은 **1단계를 건너뛰는 것 말고도 총 학습량이 다릅니다**(250k + 80k 대 80k 스텝). 대조군의 Q-Former가 BERT 초기화를 쓰는지, 학습률이 같은지도 적혀 있지 않습니다.
4. **"1단계 없으면 Flamingo Perceiver Resampler와 비슷하다"**(§4.1)는 구조 동일이 아니라 역할 비유입니다. Q-Former는 질의끼리 self-attention하고 교차 attention이 격층에 있으며 BERT에서 초기화합니다. Resampler 구조를 직접 비교한 실험은 없습니다.
5. **표 6의 ITG 효과(COCO 미세조정 검색)는 단일 학습 실행.** 이미지→텍스트 R@1 84.5 → 85.4(+0.9), 텍스트→이미지 R@1 67.2 → 68.3(+1.1), R@5는 96.2 → 97.0과 87.1 → 87.7입니다. 시드 분산이 없고, 테스트 표본(COCO 5K 이미지) 때문에 생기는 오차만으로 R@1 이미지→텍스트의 표준오차가 약 0.5점입니다(`03` §2.3).
6. **표 2의 "더 큰 LLM이 낫다"는 비교는 한 번씩의 점 추정.** OPT-2.7B → 6.7B는 test-dev에서 +0.3(52.3 → 52.6)이고, GQA에서는 ViT-L FlanT5-XL(44.4)이 ViT-g FlanT5-XL(44.2)보다 높습니다(`03` §2.2).
7. **OPT 대 FlanT5의 격차(test-dev 52.6 대 63.0)가 인코더나 LLM 크기 차이보다 훨씬 큼.** 논문은 "지시 튜닝된 LLM이 낫다"고만 요약합니다. VQA 평가 프롬프트가 OPT는 "Question: {} Answer:", FlanT5는 "Question: {} Short answer:"로 다른 점(§4.1)과 FlanT5가 VQA 유형 데이터로 지시 튜닝된 점이 섞여 있어 원인을 분리할 수 없습니다.
8. **VQA 미세조정에서는 Q-Former가 질문에 조건화**됩니다(§4.3, 그림 7). 즉 제로샷 평가(질문과 무관한 32개 토큰)와 구조가 다릅니다. 표 4의 82점대는 "질문 인식 Q-Former + 이미지 인코더 미세조정"의 결과입니다(미세조정 시 학습 파라미터 1.2B).
9. **이미지는 224 x 224 고정**입니다(§3.4, 부록 표 7–9에서 미세조정은 364, 490, 224). 압축 병목이 해상도·세부(작은 글자, 개수)에 미치는 영향은 실험하지 않았습니다.
