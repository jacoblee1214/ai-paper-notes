# 01. 논문 분석: Visual Instruction Tuning (LLaVA, arXiv:2304.08485)

분석 판은 **arXiv v2**(2023-12-11, 최신, NeurIPS 2023 camera-ready 계열)입니다. v1은 2023-04-17입니다(arXiv API, 2026-11-26). 위치 표기 `Ln`은 `paper/paper.txt`(`pdftotext -layout`, 두 단 조판이라 줄이 섞이므로 근처 줄 범위로 읽을 것)의 줄 번호이고, 절·그림·표 번호는 v2의 것입니다.

## 0. v1과 v2의 차이

v1 PDF를 따로 받아 `pdftotext`로 비교했습니다.

- **수치는 같습니다.** COCO 벤치마크 85.1%(v1 표 3, v2 표 4), ScienceQA 90.92%·92.53%(v1 표 6, v2 표 7), 절제 표(v1 표 7, v2 표 8)의 값이 같습니다.
- **v2에서 새로 생긴 것.** (1) **LLaVA-Bench (In-the-Wild)**: 24장 60문항, 표 5에서 BLIP-2(38.1)·OpenFlamingo(19.1)·LLaVA(67.3 ± 2.0)를 비교하고 표 6에서 실패 사례를 보입니다(L430–L470). v1은 BLIP-2·OpenFlamingo를 질적 예시(표 4, 5)로만 비교했습니다. (2) **"bag of patches" 한계 문장**과 Limitations 단락(L440–L450). (3) 부록 A의 Broader Impact(악성 입력, 환각, 편향, 에너지)와 B의 추가 질적 예시. (4) LLaVA-1.5(arXiv:2310.03744)를 가리키는 문장(결론 L668, 부록 B L823). (5) COCO 벤치마크 설명이 "짧은 질문·상세 질문·복잡한 추론 질문 한 개씩"(v1)에서 "대화·상세 설명·복잡한 추론"(v2)으로 바뀌었고 "NeurIPS 2023"이 표지에 붙었습니다.

## 1. 문제

- 언어 전용 LLM은 지시 튜닝(Alpaca, Vicuna 등, 기계가 만든 지시 데이터)으로 지시 따르기가 좋아졌지만, 시각 입력을 다루는 모델은 과제마다 따로 학습되거나(분류, 검출, 캡셔닝) 이미지·텍스트 쌍으로만 학습되어 사용자 지시에 맞게 답하는 능력이 약합니다(§1 L28–L50, §2 L75–L100).
- **병목은 시각 지시 데이터가 없다는 점**입니다. 사람이 만들기는 비싸고 정의가 모호합니다(§3 L120–L135).
- 기여는 셋입니다(§1 L55–L70). (1) 이미지-텍스트 쌍을 GPT-4로 지시 형식으로 바꾸는 파이프라인과 158K 데이터, (2) CLIP 시각 인코더와 Vicuna를 선형 투영으로 이은 LMM과 두 단계 학습, (3) LLaVA-Bench 두 벌.

## 2. 방법

### 2.1 데이터 생성 (§3)

- **이미지에 접근하지 않는 텍스트 전용 GPT-4**에게 이미지를 두 가지 기호로 보여 줍니다. 캡션(5문장 내외), 경계 상자(물체 개념 + 위치)(L135–L150, 표 1). 사람이 쓴 것은 유형마다 몇 개의 시드 예시뿐이고 이를 in-context 예시로 씁니다(L150–L165, 부록 표 15·16).
- 세 유형(L160–L180): 대화(물체 종류, 개수, 행동, 위치, 상대 위치를 묻고 답이 확실한 질문만), 상세 설명(상세 설명을 요청하는 질문 목록에서 하나를 뽑음, 표 12), 복잡 추론(단계별 추론이 필요). **158K = 대화 58K + 상세 23K + 추론 77K**, COCO 이미지 약 80K장(L183, L372).
- GPT-4가 ChatGPT보다 일관되게 질이 높다고 쓰지만(공간 추론) 비교 수치는 없습니다(L184).

### 2.2 구조 (§4.1, 그림 1, 식 1)

- 시각 인코더 g는 **CLIP ViT-L/14**, 격자 특징 Z_v = g(X_v)를 쓰며 "마지막 Transformer 층 앞과 뒤의 격자 특징을 모두 실험"했다고 쓰고 L245, 본문은 앞의 것(식 1, 아래 ScienceQA 절제)을 씁니다.
- **식 1: H_v = W · Z_v**, W는 학습되는 투영 행렬(선형 층 하나). H_v는 LM의 단어 임베딩과 같은 차원의 시각 토큰열입니다(L250). 그림 1은 시각 토큰 H_v와 언어 지시 H_q를 이어 LM f_φ에 넣어 답 X_a를 얻는 구조입니다.
- LM은 **Vicuna**("공개 체크포인트 중 언어 과제 지시 따르기가 가장 좋아서")입니다(L192). Flamingo의 gated cross-attention이나 BLIP-2의 Q-Former 같은 "더 정교한 연결"은 "가능한 후속 과제"로 미룹니다(L252–L256).
- 시각 토큰 수는 본문에 없습니다. ViT-L/14가 224 해상도에서 256개(CLS 제외)이고, 224 해상도는 LLaVA-1.5 논문의 표 2(행 0 "LLaVA 7B 224")로 확인됩니다.

### 2.3 학습 (§4.2, 식 2, 3, 표 2)

- 다중 턴 대화 (X_q^1, X_a^1, ..., X_q^T, X_a^T)를 하나의 열로 만듭니다. 첫 턴의 지시는 **[X_q, X_v] 또는 [X_v, X_q] 중 무작위**, 이후 턴은 X_q^t만 씁니다(식 2). 템플릿은 Vicuna-v0(시스템 메시지 + `Human :` / `Assistant:` + 구분자 `###`)를 따릅니다(표 2, L284).
- **식 3: p(X_a | X_v, X_instruct) = Π_{i=1..L} p_θ(x_i | X_v, X_instruct,<i, X_a,<i)**. 표 2의 설명대로 **답과 어디서 멈출지(<STOP>)만 손실에 들어갑니다**("only green sequence/tokens are used to compute the loss").
- **1단계(특징 정렬 사전학습, L293–L303).** CC3M을 명사구 빈도 기준으로 **595K쌍**으로 걸러(부록 E: 명사구 빈도 3 미만 제외, 100 초과는 100개로 표집), "간단히 설명하라"는 질문(표 11의 11개 중 하나)을 무작위로 붙여 한 턴 대화로 만듭니다. **시각 인코더와 LLM을 동결하고 W만 학습**합니다("compatible visual tokenizer for the frozen LLM").
- **2단계(종단 미세조정, L304–L320).** 시각 인코더는 계속 동결하고 **W와 LLM φ를 학습**합니다. 챗봇: 158K를 쓰고(대화는 다중 턴, 나머지는 한 턴, 유형은 균일 표집). ScienceQA: 질문·맥락이 X_instruct, 추론과 답이 X_a인 한 턴 대화.
- 하이퍼파라미터(§5, L321, 부록 C L1144): 1단계 1에폭, 학습률 2e-3, 배치 128. 2단계 3에폭, 2e-5, 배치 32. Adam, weight decay 0, 코사인, 워밍업 3%, FSDP, BF16/TF32, **8×A100에서 1단계 4시간, 2단계 10시간, ScienceQA 4시간**(L1150).

### 2.4 평가 (§5)

- **LLaVA-Bench (COCO)**(L417): COCO-Val-2014에서 무작위 30장, 장마다 세 유형 질문(위의 파이프라인으로 생성) → **90문항**. 참조는 **텍스트 전용 GPT-4가 정답 캡션과 상자를 보고 낸 답**이고, 판정도 텍스트 전용 GPT-4가 질문, 시각 정보(텍스트), 두 어시스턴트의 답을 보고 도움됨·관련성·정확성·상세함으로 1–10점을 줍니다(L389–L400). **상대 점수 = 후보 점수 / 참조 점수**. 표 4가 학습 데이터 절제를 담습니다.
- **LLaVA-Bench (In-the-Wild)**(L430): 24장 60문항(실내외, 밈, 그림, 스케치), 장마다 사람이 쓴 매우 상세한 설명과 질문 세트(표 6의 예). 표 5.
- **ScienceQA**(§5.2): 21K 문항, 12,726/4,241/4,241 분할(L485). LLaVA는 12에폭 학습(이유를 먼저 예측하고 답). GPT-4(텍스트 전용)에 2-shot을 주면 82.69%. 합치는 방식 두 가지: 보완(GPT-4가 답을 못 낼 때 LLaVA 사용) 90.97%, **GPT-4를 판정자로 사용(두 답이 다르면 GPT-4에게 최종 답을 다시 묻기) 92.53%**(L497–L520).

## 4. 한계 (논문이 인정한 것과 우리가 본 것)

- 논문(L440–L450): In-the-Wild 벤치마크는 일부러 어렵게 만들었고 지식 범위(식당 이름, 요거트 상표), 고해상도 처리(작은 글자), 다국어가 필요합니다. 또한 **"딸기 맛 요거트가 있는가"에 "예"라고 답한 사례**를 들며 모델이 이미지를 **"bag of patches"**처럼 본다고 해석합니다(L447). 부록 A: 환각, 편향, 평가의 견고성(텍스트 전용 GPT-4 판정의 다른 상황에서의 견고성은 후속 과제), 다른 평가 측면(환각 정도, 세밀한 이해).
- 우리가 본 것(`03`, `04`).
  1. 상대 점수는 **GPT-4 자신이 만든 참조와 GPT-4 판정**의 비입니다. 참조 답이 학습 데이터와 같은 파이프라인(캡션 + 상자 → 텍스트 전용 GPT-4)에서 나오므로 COCO 벤치마크는 분포 안(in-distribution) 평가이고 판정자 편향이 섞여 들 수 있습니다.
  2. **초록의 85.1%는 COCO 합성 벤치마크이고 In-the-Wild는 67.3%**입니다.
  3. 표 4의 **괄호 차이 16칸 중 4칸이 뺄셈과 0.2–0.8 다릅니다**(`03` §7.2).
  4. 선택은 **ScienceQA 4,241문항 단일 학습 실행**의 정확도 차이로 이뤄집니다(층 선택 0.96점, 크기 1.08점, 새 SOTA 0.85점). 시드와 짝지은 비교가 없습니다(`04` C5–C8).
  5. 시각 토큰 수, 해상도, 투영 행렬 크기가 본문에 없습니다. 층 선택은 코드 기본값(`mm_vision_select_layer=-2`, CLS 제외)으로만 정확히 알 수 있습니다(`03` §4).

## 5. 논문 안의 모호함과 불일치

1. **1단계 입력.** §4.2(L293–L298)는 "간단한 설명을 요청하는 질문을 무작위로 뽑아" X_instruct를 만든다고 쓰지만, 공개 코드의 1단계 템플릿 `plain`은 질문과 시스템 메시지를 버리고 `<image>` + 캡션 + 구분자만 넣습니다(`03` §5 D1).
2. **ScienceQA 순서 절제의 문장.** L545는 "답 먼저가 가장 좋은 수치 89.77%를 12에폭에 내고, 이유 먼저는 6에폭에 89.77%에 이른다"고 쓰는데, 표 8은 "Best variant 90.92"(이유 먼저)와 "Predict answer first 89.77(−1.15)"입니다. 문장의 "answer-first reports the best number"는 표와 맞지 않고 "reasoning-first reports the best number"의 오타로 보입니다.
3. **구분자.** 논문은 `<STOP> = ###`(Vicuna-v0)이라고 하지만 공개 학습 스크립트의 기본 값은 Vicuna v1.3/v1.5 계열의 `</s>` 템플릿입니다(`03` §5 D3). 실제로 논문 모델이 어느 쪽인지는 코드로는 구분되지 않습니다.
4. **이미지 위치.** 식 2는 첫 턴에서 [X_q, X_v]와 [X_v, X_q] 중 무작위라고 쓰지만 공개 코드는 항상 이미지를 질문 앞에 둡니다(`preprocess_multimodal`).
5. **"before / after the last layer"의 정의.** 앞/뒤가 CLIP의 사후 LayerNorm을 포함하는지, 마지막 블록의 출력인지 본문에 없습니다(코드: 블록 출력, 사후 LN 없음, `03` §4).
6. **표 4 괄호 차이**(앞의 4번 한계).
7. **상대 점수의 집계.** 표 5의 "전체"는 범주 상대 점수의 문항 수 가중 평균과 일치하지만(BLIP-2 38.1 정확), 본문은 비의 정의(합의 비인지 점수 평균의 비인지)를 쓰지 않습니다. 코드(`summarize_gpt_review.py`)는 점수 평균의 비를 계산합니다(`03` §7).
8. **표 5의 ±.** 앞 세 행은 "3번의 추론 실행"의 표준편차이고 LLaVA†는 "같은 디코딩 결과를 GPT-4에 3번 물어본" 표준편차(0.3)입니다. 둘 다 **문항 표본 오차를 포함하지 않습니다**.
9. 그림 1이 투영 W 뒤의 시각 토큰 수를 표시하지 않습니다.
10. **본문 §3의 "Table 14"** 참조는 같은 쪽의 표 1을 가리키는 것으로 보이는 깨진 상호 참조입니다.

## 6. 다른 폴더와의 위치

- 같은 축(7축)의 비교 논문: 연결기 대조는 `blip2/`(Q-Former), 설계 공간 비교는 `prismatic_vlms/`(단일 단계, MLP 투영기 기준), `cambrian1/`(연결기 사전학습 재검증), 인코더는 `clip/`, `siglip/`, `dinov2/`, `vit/`, 인코더 약점은 `eyes_wide_shut/`. 계보는 `02`.
