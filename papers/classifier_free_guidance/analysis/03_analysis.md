# 03. 검산과 재계산

구현 모드입니다. **학습은 하지 않았습니다.** 신경망 대신 2차원 클래스 조건부 가우시안 혼합에서 닫힌 식으로 나오는 정확한 ε*(z, c)와 ε*(z)를 썼습니다. 그래서 식 (6)과 알고리즘 2의 성질에서 모델 오차가 빠집니다. 이 토이에서 확인한 것은 "정확한 점수를 줘도 CFG가 무엇을 하는가"이고, **"학습된 모델에서 CFG가 얼마나 잘 되는가"는 아닙니다.** 코드는 `minimal_impl.py`(구현), `test_minimal_impl.py`(pytest 15개), `derivation_checks.py`(식 검산), `toy_experiments.py`(E1–E4), `paper_arithmetic.py`(표 재계산), `plot_figures.py`(그래프)입니다. 모두 float64 CPU입니다.

## 0. 설정

- **토이 데이터.** 클래스 3개(사전 0.5 / 0.3 / 0.2), 클래스마다 성분 2개(가중 0.5/0.5, 0.7/0.3, 0.5/0.5), 성분은 반지름 2.0의 원 위에서 클래스 중심 각 ±0.5 rad, 성분 표준편차 0.8. 이웃 클래스의 가장자리가 겹칩니다(참 사후 확률의 평균 E[p(c|x)] = 0.859).
- **점수.** z = αx + σε이면 p(z|c)는 평균 α μ, 분산 V = α²s² + σ²인 혼합이라 점수가 닫힌 식입니다. ε*(z,c) = −σ∇log p(z|c). 자동미분과 1.4e-14 안에서 같습니다(`derivation_checks.py` D2).
- **표집기.** 논문 알고리즘 2(식 3, 4의 조상 표집, v = 0.3)와 결정적 DDIM(η = 0). λ 격자는 논문 §2의 λ = −2 log tan(au + b), λ_min = −20, λ_max = 20, u 균등. 마지막 걸음은 x̃를 반환합니다.
- **통계.** 표본은 클래스당 10,000개, 시드 5개(0–4), z_1은 w와 표집기가 달라도 같은 시드를 공유합니다(공통 난수). 신뢰구간은 시드에 대한 퍼센타일 부트스트랩(1만 회)입니다. 점수가 정확하므로 **시드 분산은 표집 잡음뿐이고 학습 분산은 없어서 구간이 매우 좁습니다.** 이 구간을 "학습된 모델에서도 이만큼 확실하다"로 읽으면 안 됩니다. 다중 비교는 홀름 보정, 표집기 간 비교는 시드 쌍 t 검정입니다.
- **실행.** CPU 약 15분(중단한 시도 포함), 최대 메모리 0.54 GB(`memguard` 4 GB 한도). pytest 15개 4초.

## 1. 식 유도 검산

### 1.1 λ 매개변수화와 ε–점수 관계 (식 1, 5)

α² = sigmoid(λ)이면 dα/dλ = ασ²/2, dσ/dλ = −α²σ/2, log(α²/σ²) = λ이고 최대 오차 1.2e-12입니다(D1). ε* = −σ∇_z log p(z)는 닫힌 식과 자동미분이 1.4e-14 안에서 같습니다(D2). 논문의 "ε_θ ≈ −σ_λ∇ log p(z_λ)"와 같은 식입니다.

### 1.2 분류기 안내와 CFG의 유도 (§3.1, §3.2, 식 6)

분류기 안내의 표적은 p̃(z_λ|c) ∝ p(z_λ|c) p(c|z_λ)^w이므로 점수는 ∇log p(z|c) + w∇log p(c|z)이고 ε = −σ·점수에서

ε̃ = ε(z,c) − wσ ∇_z log p(c|z).

베이즈 p(c|z) = p(z|c)p(c)/p(z)에서 p(c)는 z에 무관하므로 ∇log p(c|z) = ∇log p(z|c) − ∇log p(z) = −[ε*(z,c) − ε*(z)]/σ. 이것이 논문의 암시적 분류기 p^i(c|z) ∝ p(z|c)/p(z)의 기울기입니다(p^i와 p(c|z)는 상수 p(c) 배 차이라 기울기가 같음). 대입하면

ε̃ = ε_c + w(ε_c − ε_u) = (1 + w)ε_c − wε_u (식 6).

**검산:** 토이에서 ∇log p(c|z)를 베이즈 사후(softmax)로 따로 계산해 자동미분한 값이 −(ε_c − ε_u)/σ와 3.5e-14 안에서 같고(D4), 분류기 안내 ε_c − wσ∇log p^i와 식 (6)이 1.3e-13 안에서 같습니다(D5, w = 0.5, 2, 7, λ = −4, 0, 5, 클래스 3개). pytest `test_implicit_classifier_identity`, `test_cfg_equals_classifier_guidance_with_implicit_classifier`.

**표적 분포.** 각 λ에서 안내된 장은 p_λ(z|c)^{1+w} p_λ(z)^{-w}의 점수입니다. 지수가 1 + w와 −w라서 λ = ∞(t = 0)에서는 p(x|c)^{1+w}p(x)^{-w} = p(x|c)(p(c|x)/p(c))^w ∝ p(x|c)p(c|x)^w, 곧 분류기 안내의 표적과 같습니다. 이 식이 "의도된 기울임"이고 §3 이하에서 격자로 정확히 계산해 비교합니다(`TiltedGrid`, 280×280, 한 칸 0.05).

### 1.3 w 규약: 논문 대 γ

논문은 ε̃ = (1+w)ε_c − wε_u입니다(w = 0이면 안내 없음, w = −1이면 무조건). 흔한 다른 규약은 ε̃ = ε_u + γ(ε_c − ε_u)입니다(γ = 1이 안내 없음, γ = 0이 무조건). **γ = 1 + w**이고 두 식은 최대 오차 3.6e-15로 같습니다(D6). x̂ = (z − σε)/α는 같은 z에서 ε에 대해 선형이라 x̂ 공간에서도 같은 외삽입니다. 다른 논문의 "guidance scale"을 이 논문의 w와 비교하려면 먼저 규약을 확인해야 합니다. 예: 논문의 w = 0.3은 γ = 1.3이고 γ = 7.5 같은 텍스트-이미지 설정은 이 논문의 w = 6.5입니다(규약이 γ형일 때). 어느 코드가 γ형인지는 `02` 표를 보세요.

### 1.4 무조건 항: p_uncond 드롭아웃의 최소해 (알고리즘 1)

c를 ∅로 바꾼 표본에서 E‖ε_θ(z,∅) − ε‖²의 최소해는 E[ε|z] = −σ∇log p(z) = ε_u입니다(denoising score matching). 이 값은 **조건부 점수의 사후 가중 평균**과 같습니다: ε_u = Σ_c p(c|z)ε_c (오차 3.1e-14, D3). 중요도 표집으로 E[ε|z_0]를 직접 추정(200만 개, 유효 표본 수 10⁵–8.6×10⁵)해도 닫힌 식과 1e-3 안에서 같습니다(D3: 예 λ = 0, z_0 = (1, 0.5)에서 0.01235 대 0.01248, 0.0661 대 0.0656). 사전 확률이 아니라 **사후** 가중이라는 점이 중요한데, 이는 `meanflow/` 분석이 식 14의 𝔼_c에서 지적한 것과 같은 사실입니다(`meanflow/analysis/03_analysis.md` §5).

**오차 증폭(이 저장소의 유도).** 학습된 ε_θ = ε* + δ라면 ε̃_θ − ε̃* = (1+w)δ_c − wδ_u입니다. w가 커질수록 두 오차가 모두 증폭되고 무조건 항의 오차는 반대 부호로 들어갑니다. p_uncond가 작으면 무조건 가지가 보는 표본이 적어 δ_u가 커질 수 있다는 추정은 가능하지만 이 토이로는 검증하지 못했습니다(학습 없음). §6.2의 표 1 해석은 이 가정 아래의 추정입니다.

### 1.5 DDIM은 확률 흐름 ODE의 오일러 단계

DDIM 한 걸음 z' = α' x̃ + σ' ε̃의 연속 극한은 dz/dλ = (σ²/2)z − (σ/2)ε̃입니다(dα, dσ에 1.1을 대입). 작은 Δλ에서 DDIM과 이 ODE의 오일러가 Δλ = 0.1, 0.01, 0.001에서 1.7e-3, 1.7e-5, 1.7e-7로 Δλ²에 비례해 어긋납니다(D7). 이후 "DDIM"은 이 ODE의 이산화이고, 조상 표집은 같은 장 위의 SDE입니다.

## 2. 안내된 장은 어떤 확산된 분포의 점수도 아닙니다

### 2.1 가우시안 닫힌 식 (`GaussPair`, D8, `own_gaussian.png`)

조건부 N(m_c, v_c I)와 무조건 N(m_u, v_u I) 두 가우시안을 두면(서로 혼합 관계일 필요는 없음, 식 (6)은 두 점수만 씁니다) 확산해도 가우시안입니다(V_c = α²v_c + σ², V_u = α²v_u + σ²). 안내된 ODE dz/dλ = a(λ)z + b(λ)는 선형이라 끝점의 평균과 분산이 닫힌 상미분방정식으로 풀립니다. 분산은 d ln P/dλ = σ²[1 − (1+w)/V_c + w/V_u]에서 P_end = exp(∫…dλ)입니다. 의도한 표적(t = 0)은 정밀도 (1+w)/v_c − w/v_u의 가우시안입니다.

- **v_c = v_u**: 안내된 장이 N(m_c + w(m_c − m_u), v)의 확산 점수와 정확히 같고(m_c + w(m_c − m_u)는 "평균 외삽") ODE 끝점이 표적과 일치합니다. w = 0.5, 1, 2, 4에서 분산비 1.0000000064, 평균 오차 ≤ 1.4e-4(시작 분포를 N(0,I)로 둔 데서 오는 값). pytest `test_equal_variance_gaussian_cfg_is_exact_extrapolation`.
- **v_u > v_c(조건부가 주변보다 좁음, 보통의 경우), v_c = 0.4, v_u = 1.3**: 표적 분산은 0.297, 0.236, 0.168, 0.106(w = 0.5, 1, 2, 4)인데 ODE 끝점 분산은 0.222, 0.123, 0.0379, 0.0036입니다. 비는 0.75, 0.52, 0.23, **0.034**로 w에 지수적으로 줄어듭니다. w = 2에서 평균도 표적 1.258이 아니라 1.615입니다(m_c = 1.0, 첫 좌표).
- **v_u < v_c**: 표적의 정밀도 2.5 − 1.5w가 w ≥ 5/3에서 0 이하라 표적이 정규화되지 않지만, 안내 ODE는 끝점을 내놓습니다(w = 2: 평균 4.20, 분산 1.02. w = 4: 평균 9.96, 분산 2.62). **표적이 없는데도 표본이 나오는** 경우입니다.
- DDIM의 아핀 사상(잡음 없이 z = 0, 1에서 평가)이 ODE 끝점과 T = 2048에서 평균 3e-3, 분산 3e-3 안에서 같습니다(`test_gaussian_ddim_matches_closed_form_ode`, w = 0, 0.5, 2, 5).

**λ별 격차.** 같은 v_u = 1.3 경우 w = 2에서 CFG의 ε̃와 "표적을 확산한 가우시안의 정확한 ε"의 상대 차이는 λ = −12에서 0.0025, −3에서 0.22, **0에서 0.62**, 2에서 0.30, 8에서 1e-3, 14에서 3e-6입니다(D9). **t = 0 쪽(λ 큼)과 순수 잡음 쪽(λ 작음)에서는 두 장이 같고 중간 잡음 수준에서 가장 어긋납니다.** 중간 잡음은 클래스가 정해지는 구간이라서, 이 격차가 가장 큰 곳에서 안내가 성격을 바꿉니다(§5의 E4와 같은 방향).

### 2.2 포커-플랑크 잔차: 닫힌 식 (D10, D12)

안내된 장 ε̃의 퍼텐셜 후보 ℓ̃ = (1+w)log p_λ(z|c) − w log p_λ(z)가 순방향 VP 확산(dz = −½β z dt + √β dW)을 따르는 분포족의 로그 밀도(정규화 상수 제외)이려면 포커-플랑크 방정식이 필요하고, λ로 쓰면

R(z,λ) ≡ ∂_λℓ̃ + (σ²/2)(d + z·∇ℓ̃ + Δℓ̃ + |∇ℓ̃|²)

이 z에 무관해야 합니다(∂_t = −(β/σ²)∂_λ를 썼습니다). p_λ(z|c)와 p_λ(z)는 각각 확산이므로 R이 상수이고, ℓ̃의 선형 항은 모두 상쇄됩니다. 남는 것은 제곱항 하나입니다. a = ∇log p(z|c), b = ∇log p(z)라 하면 (1+w)|a|² − w|b|² − |(1+w)a − wb|² = −w(1+w)|a − b|²이므로

**R(z,λ) = c(λ) + (σ²/2) w (1+w) ‖∇_z log p_λ(c|z)‖².**

즉 안내된 장이 확산된 분포의 점수가 되는 필요조건은 **분류기 기울기의 노름 ‖∇_z log p_λ(c|z)‖²가 z에 따라 변하지 않는 것**이고, 오차의 크기는 w(1+w)/2에 비례합니다. 자동미분으로 계산한 R과 이 식의 z 변동이 최대 2.3e-9 안에서 같습니다(9개 (λ, w), 최대 오차는 λ 미분의 유한차분 한계. D12, pytest `test_fp_residual_closed_form`). R의 표준편차는 w = 0에서 3e-11(0), λ = 0에서 w = 0.5, 1, 2, 4일 때 0.49, 1.30, 3.91, 13.0이며 정확히 1.305 × w(1+w)/2입니다(D10). 가우시안 v_c = v_u 경우는 ∇log p(c|z) = α(m_c − m_u)/V가 z에 무관한 상수라서 R이 상수이고, 그래서 §2.1의 일치가 나옵니다. 이 유도가 문헌에 같은 꼴로 있는지는 확인하지 못했습니다. 문헌 쪽 진술은 `04` C2, C3에 있습니다.

**함의.** 논문 §3.2의 "ε̃_θ는 어떤 분류기의 기울기도 아닐 수 있다"는 신경망 오차(비보존성)에 대한 말이었지만, **정확한 점수에서도** 식 (6)은 각 λ에서 서로 일관되지 않은 기울임의 곱입니다. 따라서 ODE/SDE를 끝까지 풀어도 p(x|c)p(c|x)^w 표본이 나오지 않습니다(§3–§5).

2. **하지만 CFG-DDIM은 표적보다 훨씬 더 줄고 더 멀리 갑니다.** w = 2에서 분산이 표적 0.863 대 0.618, 재현율 0.943 대 0.501, 클래스 평균의 원점으로부터 거리가 데이터 1.77, 표적 2.00, CFG-DDIM 2.85로 벌어집니다(바깥쪽으로 과하게 이동). 정밀도는 거의 안 변하고(0.98) 재현율만 무너져서, "품질은 좋아지고 다양성이 준다"를 넘어 **표적이 요구하지 않는 수축**입니다.
3. **지지집합 밖 표본:** 표적은 w가 8이어도 0.0005(데이터 0.0003과 같은 자릿수)인데 CFG-DDIM은 w = 4에서 1.5%, w = 8에서 **25.7%**입니다. 정밀도도 0.774로 떨어집니다. 이것이 논문 Fig. 3의 "포화된 색", 이후 문헌의 "큰 w에서 일그러짐"과 같은 현상의 토이 버전으로 보입니다(추정: 이미지에서의 대응은 확인하지 않음).
4. **모드 탈락은 보이지 않습니다.** 클래스 1(성분 가중 0.7/0.3)의 작은 성분 쪽 질량이 0.352(w = 0, 최근접 할당이라 사전 0.3보다 큼)에서 CFG-DDIM w = 8의 0.480으로 **늘어납니다**(표적 0.374). 이 토이에서 일어나는 것은 모드 소실이 아니라 이웃 클래스에서 멀어지는 방향으로의 이동과 수축입니다. 성분들이 클래스 중심 바깥쪽으로 같이 밀려납니다.
5. **조상 표집은 같은 w에서 훨씬 약하게 안내됩니다.** w = 4에서 분산 0.740 대 DDIM 0.518. 둘의 sW1 차이는 w ≥ 0.25의 8개 w에서 모두 유의합니다(시드 쌍 t 검정, 홀름 보정 p ≤ 3.8e-4, n = 5 시드, 표집 잡음만 반영. w = 0에서는 차이 없음, p = 0.37). 조상 표집이 표적에 더 가깝긴 하지만(w = 4에서 sW1 0.319 대 0.899) 표적 대비 바닥(0.02)보다는 약 15배 큽니다. **같은 식 (6)이 표집기에 따라 다른 분포를 만듭니다**(문헌 C3과 같은 방향).
6. **FD(2차원 가우시안 적합 Fréchet 거리, 데이터 대비)는 w = 0에서 최소**이고 w에 따라 단조 증가합니다(DDIM 0.001, 0.163(w = 1), 0.534(w = 2), 4.03(w = 8)). 점수가 정확해서 w = 0이 이미 데이터 분포이기 때문입니다. **논문의 FID가 w = 0.1–0.3에서 최소인 것은 정확한 기울임의 성질이 아니라 모델 오차나 FID·IS 지표 쪽의 사정**일 가능성이 높습니다(추정, 이 토이는 모델 오차가 없어서 직접 확인하지 못함).

## 4. E2: 단계 수 T (w = 2, `own_mismatch.png` 가운데)

T = 4, 8, 16, 32, 64, 128, 256, 1024에서 표적 대비 sW1(시드 5개): DDIM 0.699, 0.629, 0.594, 0.578, 0.571, 0.567, 0.566, **0.564**, 조상 0.503, 0.342, 0.278, 0.255, 0.246, 0.244, 0.241, **0.238**. 표본 잡음 바닥은 0.022입니다. 단계를 늘리면 줄어들지만 **T = 1024에서도 바닥의 11–25배에서 수렴**합니다. 분산도 DDIM 0.621, 조상 0.792로 표적 0.863에 못 미칩니다. 즉 불일치는 이산화 오차가 아니라 장에서 옵니다(§2). 반대로 논문 표 2의 T = 128 대 256 격차(§6.3)는 이 토이에서 T ≥ 32 이후 거의 없는 것과 비슷한 모양입니다. 다만 토이는 정확한 점수라서 학습된 모델의 이산화 민감도와 직접 비교할 수 없습니다.

## 5. E3, E4: 장을 바꾸면 불일치가 사라지는가 (후속 문헌의 아이디어를 토이에 옮김)

**E3 (일관된 기울임 오라클).** 표적 p̃_0 = p(x|c)p(c|x)^w를 순방향 확산시킨 주변 q_λ의 정확한 점수(격자 합, 80×80)로 DDIM을 돌려 같은 z_1에서 CFG(식 6)와 비교합니다(n = 2000/클래스, 시드 2, T = 64와 128, 계산량 때문에 규모를 줄였습니다). w = 2: sW1 CFG 0.572 → 오라클 **0.042**(바닥 0.033), w = 4: 0.906 → **0.043**. 분산은 w = 4에서 CFG 0.501, 오라클 0.758, 표적 0.815입니다(오라클이 격자 양자화로 약간 작음). **같은 표집기와 같은 단계 수에서 점수만 일관된 것으로 바꾸면 불일치가 표본 잡음 수준까지 내려갑니다.** 불일치의 원인이 표집기가 아니라 식 (6)의 장입니다. 이 오라클은 표적을 알고 있어야 하는 이상화라서 실용 방법이 아닙니다.

**E4 (구간 안내: Kynkäänniemi 외 2024의 아이디어를 토이에 옮김, 후속 작업).** 안내를 λ ∈ [−3.38, 2.55](EDM σ = e^{-λ/2}의 (0.28, 5.42]에 해당)에만 적용. T = 256 DDIM, 시드 5개.

## 6. 논문 수치 재계산 (`paper_arithmetic.py`, `own_paper.png`)

표 1·2는 논문 PDF에서 옮겨 적었습니다. FID, IS 자체는 재계산할 수 없습니다(모델, 이미지, Inception 필요). 아래는 표의 산술과 서술 주장의 확인이고 **모든 값은 단일 실행이라 시드 분산이 없습니다.** 잡음 크기의 대리값으로 (a) T = 256 대 1024의 FID 차이(거의 같은 표집기: 중앙값 0.03, 최대 0.21)와 (b) 같은 w에서 p_uncond 0.1 대 0.2 모델의 FID 차이를 씁니다. 둘 다 근사입니다.

### 6.1 최적 w와 "단조" 서술 (표 1, 표 2)

- 표 1(64×64): 세 p_uncond 모두 FID 최소는 **w = 0.1**입니다(1.55, 1.62, 1.91). w = 0 대비 개선 −0.25, −0.18, −0.30. 표 2(128×128): T = 256, 1024는 w = 0.3(2.43)이고 T = 128은 w = 0.4(3.02)입니다. T = 256에서 w = 0.3 대 0.4는 2.43 대 2.49로 차이 0.06이고 위 잡음 대리값(중앙값 0.03)과 같은 자릿수라 **w = 0.3과 0.4는 구별되지 않습니다.** 논문의 "w = 0.1 또는 0.3, 데이터셋에 따라"는 맞습니다.
- **본문 "FID monotonically decreasing and IS monotonically increasing with w"는 표와 맞지 않습니다.** FID는 여섯 곡선(표 1의 3개, 표 2의 3개) 모두 최적 w 이후 단조 증가합니다(w = 4의 FID가 w = 0보다 큼: 26.22 대 1.8, 21.53 대 7.27). IS만 여섯 곡선 모두 w에 대해 단조 증가이고 w = 4가 표의 끝이라서 "최선 IS는 w ≥ 4"는 표 범위의 경계값입니다. 의도는 "FID가 처음에는 줄다가 오른다"로 보입니다(추정).
- w = 0 → 최적에서 표 2의 개선은 7.27 → 2.43(3.0배)로 잡음 대리값보다 두 자릿수 큽니다. **안내가 FID를 개선한다는 결론은 견고하고** 최적 w의 정확한 위치는 ±0.1 정도 불확실합니다.

### 6.2 p_uncond (표 1, 그림 4)

- **0.5가 더 나쁘다**: 같은 w에서 FID는 w ≥ 0.3부터 0.5가 낮지만(예 w = 1: 9.13 대 12.6) IS도 낮아서(131.1 대 170.1) 이는 같은 w가 같은 안내 세기가 아닌 효과입니다. IS–FID 전선에서 0.1 곡선을 IS에 대해 선형 보간해 0.5의 13개 점과 같은 IS에서 비교하면 **13개 모두 0.5가 나쁩니다**(평균 +1.20 FID, 최소 +0.16, 최대 +1.94, 가장 높은 IS에서 +0.51). 논문의 "0.5가 전 전선에서 일관되게 나쁘다"는 방향이 맞습니다.
- **0.1 대 0.2는 "거의 같다"가 거의 맞지만 균등하지 않습니다.** 같은 w에서 FID는 0.1이 앞서는 것이 w = 0.1, 0.2 두 점뿐이고(w = 0은 동률) w ≥ 0.3부터 0.2가 낮습니다(11 대 2, 부호 검정 p = 0.022이나 w들은 같은 두 학습의 상관된 점이라 기술 통계일 뿐). 그러나 IS는 14개 w 모두에서 0.1이 높아서 같은 w가 같은 세기가 아닙니다. 전선으로 보면 IS ≤ 170(w ≤ 1, 격자가 촘촘한 구간)의 10개 점에서 0.2가 0.04–0.47 FID **나쁘고**, w = 2–4 구간은 0.1 쪽 격자가 성겨서(w = 1 → 2 사이 IS 55) 선형 보간이 볼록한 곡선의 FID를 과대평가하므로 0.2가 −0.34 ~ −0.77 좋아 보이는 값은 신뢰할 수 없습니다. 결론: 낮은 IS에서 0.1이 조금 낫다는 증거는 있으나 차이(0.04–0.47)는 잡음 대리값과 같은 자릿수라서 **0.1과 0.2는 구별되지 않는 것으로 두는 편이 안전합니다.**
- 이 표 해석은 1.4의 가정(무조건 가지의 오차가 p_uncond와 연결)과 독립입니다. 표에서 읽을 수 있는 것은 위 숫자뿐입니다.

### 6.3 단계 수 (표 2, 그림 5)

- T = 128 대 256의 FID 차이는 w = 0에서 0.84, w = 0.3에서 0.61, w = 0.6에서 0.33, w = 1에서 0.02이고 w ≥ 2에서는 |차이| ≤ 0.03으로 T = 256 대 1024의 잡음 수준입니다. **단계 수 민감도는 약한 안내에서만 큽니다.** T = 256 대 1024는 모든 w에서 |ΔFID| ≤ 0.21(중앙값 0.03)이라 T = 256이 "균형"이라는 논문 서술을 지지합니다.
- **그림 5의 범례 "T = 512"는 표 2의 T = 1024와 일치하지 않습니다**(PDF 텍스트 추출). 표 값이 본문(T ∈ {128, 256, 1024})과 맞으므로 범례 오기로 보입니다.

### 6.4 비교 서술 (§4.1, §4.3)

- "w = 0.3에서 128×128 FID가 ADM-G를 앞선다": 2.43 대 2.97(T = 256). 맞습니다. 단, ADM-G의 FID는 논문에서 인용한 값이고 평가 구현이 같은지는 확인하지 않았습니다.
- "w = 4에서 BigGAN-deep(최대 IS 설정)을 FID, IS 모두 앞선다": 21.53 대 25, 421.03 대 253. 산술은 맞지만 두 IS 값의 척도가 다른 모델 사이의 비교라서 "앞선다"는 FID 쪽만 의미가 있고 IS는 해석하기 어렵습니다(추정).
- **공정한 비교(T = 128)에서 ADM-G보다 나쁘다**는 서술: T = 128의 최선 FID는 3.02(w = 0.4)이고 ADM-G는 2.97로 차이 0.05입니다. 이는 위 잡음 대리값 안이라 "나쁘다"가 아니라 **구별되지 않는다**가 맞습니다. 게다가 ADM-G는 단계마다 분류기의 순전파와 역전파가 더 듭니다(논문 §5도 분류기가 작을 수 있다고 인정).
- 64×64의 최선 FID 1.55는 CDM의 1.48에 못 미칩니다(논문 본문은 "favorably"라고만 씀).

## 7. 한계

- 토이는 2차원 가우시안 혼합이고 점수가 정확합니다. 학습된 신경망의 비보존성과 근사 오차, 고차원 이미지의 구조는 반영하지 않습니다. §2의 유도는 일반적이지만 크기(예 25.7%)는 이 토이의 값입니다.
- 지표(분산, 재현율, 지지집합 밖, FD, IS 모사)는 FID, IS와 같지 않습니다. 같은 방향이라는 것까지만 주장합니다.
- E3의 오라클은 표적을 알아야 하는 이상화이고 E3는 규모를 줄여서(n = 2000, 시드 2) 구간이 넓습니다. 결론(표본 잡음 수준)은 두 배 이상 여유가 있어 견고합니다.
- 표 1·2는 논문에서 옮겨 적은 값이고 PDF와 대조해 다시 읽었습니다. 표에서 읽은 값의 잡음은 대리값으로만 가늠했습니다.
