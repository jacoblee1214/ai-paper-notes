## 3. 이 저장소의 관련 분석과의 관계

모두 읽기만 했고 아래는 각 폴더의 README 인용 카드에서 가져온 사실입니다.

| 폴더 | 관계 |
|---|---|
| `eval_error_bars/` (21번) | 이 논문의 일치도·점수에는 표본 오차가 없습니다. 21번의 군집 SE, 짝지은 SE, 문항 단위 군집 부트스트랩 틀을 그대로 적용해 일치도 구간과 MT-Bench 순위 구간을 만들었습니다(`03` §1, §5). 21번의 "군집 SE는 단순 SE보다 크다"가 여기서도 재현됩니다(설계 효과 약 2, `03` §1). |
| `mast/` (8번) | LLM 주석자(o1 few-shot)와 사람의 κ 0.77을 보고하는 논문(표 2에서 κ 0.765 역산 일치, 사람 주석 약 19 trace에 의존). 이 논문의 "LLM이 사람과 85% 일치"와 같은 **판정자 신뢰도** 문제입니다. 차이: MAST는 우연 보정 κ를 씀(이 논문은 쓰지 않음, `03` §2에서 보정 시 S2 일치가 0.15–0.33으로 내려감). |
| `who_and_when/` (9번) | LLM 방법이 단계 수준 귀인 정확도 3.5–8.8%로 단순 규칙과 구분되지 않음. 이 논문은 LLM 판정이 "쌍 우열"에선 사람과 잘 맞는다고 보지만, 세밀한 판정(어느 단계)에선 어려움을 보여 주는 대조. 판정 난이도가 과제 설계에 달림. |
| `agentdebug/` (18번) | LLM 디버거의 임계 단계 탐지(직접 질의 기준선 대비)와 사람이 주석한 200 궤적. 이 논문의 틀로 보면 "LLM 판정자의 정답은 사람 주석이고, 그 사람 주석의 일치도가 상한"입니다. 18번에서 라벨 품질을 재계산한 방식이 여기 사람-사람 일치(`03` §1)와 같은 계열. |
| `lm_know_what_they_know/` (14번) | 모델이 자기 답의 정오를 P(True)로 가르는 자기 평가. 이 논문의 자기 선호와 대응: 자기 평가가 잘 보정된다는 결과(14번)와 판정자가 자기 답을 편애한다는 의심(이 논문 §3.3)이 같은 현상의 두 면이며, 14번은 LAMBADA 밖에서는 보정이 약했음을 확인. 이 논문은 자기 선호에 결론을 보류했고 우리 재계산(`03` §4)에서는 자기 선호와 "강한 쪽을 더 강하게 보는" 효과가 분리되지 않습니다. |
| `trace_reward_hacking/` (12번) | LLM CoT 모니터가 암묵적 보상 해킹을 놓치는 반례(모니터 F1이 모델이 커질수록 하락). LLM 감시자의 한계를 보이는 점에서 이 논문의 "LLM 판정자가 수학 문제에서 틀린 답에 속는다"(표 4)와 같은 계열: 판정자가 문맥에 끌려갑니다. |
| `llm_nondeterminism/` (11번) | temperature 0에서도 출력이 실행마다 다름. 이 논문의 판정(코드 `temperature=0`)도 GPT-4 호출 한 번이라 같은 입력에 판정이 달라질 수 있는데 논문은 반복 측정이 없습니다(`04` D5). |
| `agentic_eval_randomness/` (10번), `little_power/` (20번), `statistical_precipice/` (19번) | 표본 오차·검정력을 다루는 계열. 80문항 MT-Bench의 순위 검정력을 `03` §5에서 같은 방식으로 보았습니다. |
| `agentic_benchmark_checklist/` (23번) | 작성 중이라 링크만 겁니다. 판정자·채점 타당성(결과 타당도)을 체크리스트로 다루는 인접 논문입니다. |
