# 04 주장 검증 (TRACE, arXiv:2510.01367)

공식 코드와 점수 로그가 없어(`02` §4) 코드 대조(D) 대신 주장별 검증(C)입니다. "재계산"은 그림 라벨로 한 산수(`recompute_trace.py`), "토이"는 가상 곡선 시뮬레이션입니다. 이후 문헌이 이 논문의 주장을 확인·반박한 사례는 이번 검색 한도(2회)에서 찾지 못했습니다.

## 재현 제안 (실행하지 않음, 사용자 승인 필요)

- **R-a (이 맥, 승인 시 토이 확장):** 작은 정책(예: 공개 소형 모델 한 개)로 TRACE 점수 계산 파이프라인만 구현하고, 정직·해킹 곡선의 임계값 민감도를 재는 것. 모델 가중치 내려받기와 설치가 필요하므로 먼저 보고합니다.
- **R-b (GPU 필요, 이 저장소 규칙상 하지 않음):** 논문 설정(Qwen2.5-3B RLOO 수학 IC)의 학습 재현. 부록 F 표 1로 구성은 가능하나 학습 비용이 큼.
- **R-c (API 필요):** 모니터 루브릭(부록 H)을 다른 모니터 모델로 돌려 모니터 기준선의 민감도를 재는 것. LLM API 호출이라 승인이 필요합니다.
