## 2. 이후 문헌의 주장 검증 (C1–C8)

판정: 확인 / 한정 / 수정 / 미확인. "우리 검증"은 `03`의 정확한 denoiser 토이입니다.

### C1. "σ_t² = β_t와 β̃_t는 비슷한 결과" (§3.2) → **한정**

- 이후 문헌: N&D 2021(§3, 그림 1)은 β̃_t/β_t가 t = 0 근처를 빼면 거의 1이라서 T = 1000에서는 선택이 무관해 보이지만 "단계 수를 줄이면 둘 다 크게 나빠진다"고 보입니다(그림 8, ImageNet 64×64를 T = 4000으로 학습한 모델에서: 고정 σ(β_t와 β̃_t 모두)의 L_simple은 표본 단계를 줄이면 품질이 크게 떨어지고 학습한 σ의 L_hybrid는 100단계에서 거의 최적. 단계 건너뛰기는 1과 T를 포함한 등간격 반올림으로 우리 `steps_for`와 같은 방식). DDIM 2021(표 1, CIFAR10 FID): 같은 사전학습 모델로 σ = β̃ 쪽(η = 1.0)은 S = 10에서 41.07, S = 100에서 5.78, S = 1000에서 4.73이고 σ̂ = √β 쪽은 367.43, 9.99, **3.17**입니다.
- **S = 1000에서도** η = 1.0의 4.73과 σ̂의 3.17은 1.56 차이이고 FID에서는 작지 않습니다. 논문의 "비슷한 결과"와 어긋나는 증거로 보이지만 같은 구현(클리핑 등)인지 확인하지 못했습니다.
- 우리 검증: 정확한 ε*의 표본기에서 σ² 선택은 단계 수 S ≤ 250에서 유의하게 다르고 **방향은 데이터에 따라 뒤집힙니다**(넓은 혼합은 β, 점질량에 가까운 혼합은 S ≤ 100에서 β̃). S = 1000에서는 두 선택이 구별되지 않거나 바닥 근처입니다(`03` §3.3). 방향을 가르는 변수는 f_t = (σ*² − β̃_t)/(β_t − β̃_t)입니다(`03` §3.1).

### C2. "L_simple은 NLL에서 L보다 나쁘고 표본 품질은 가장 좋다. 우리 모델은 likelihood 경쟁력이 없다"(표 1, §4.3) → **방향 확인, "diffusion의 한계"로는 수정**

- N&D 2021(표 2, CIFAR10, 50만 스텝): T = 1000 선형 L_simple은 NLL 3.73, FID 3.29(논문의 3.75, 3.17과 가까운 독립 재현). T = 4000과 코사인, 학습 Σ, L_vlb로 **NLL 2.94**(FID 11.47), L_hybrid로 3.17 / 3.19. 즉 likelihood와 표본 품질의 상충은 있으나(L_vlb의 FID가 11.47) NLL 3.7은 하한의 최적화 문제이지 diffusion 모델 자체의 한계가 아닙니다.
- Score SDE 2021(표 2): 같은 계열의 모델을 확률 흐름 ODE로 평가한 NLL이 3.28(FID 3.37)입니다. 표 1의 VLB 3.70–3.75와 비교하면 같은 모델 계열도 평가 방식(하한 대 ODE)에 따라 0.4 bits/dim 달라집니다(서로 다른 학습이므로 직접 비교는 아닙니다).
- 우리 검증: 가중표(`03` §2.1)에서 L_simple은 작은 t를 최대 49배 낮추고 하한의 62–79%가 t ≤ 100에서 쌓입니다(§2.2). 정확한 denoiser에서 하한 간격은 σ_t² = β_t, T = 1000에서 0.0097 nat(넓은 혼합)으로 0에 가깝습니다(§4.2). 모델 오차가 없으면 하한이 거의 조여집니다.

### C3. "학습한 대각 Σ는 불안정하고 표본이 나쁘다"(표 2, §4.2) → **수정**

- N&D 2021(식 15): Σ_θ = exp(v log β_t + (1−v) log β̃_t)로 보간 매개변수화하고 L_hybrid = L_simple + λL_vlb(λ = 0.001)로 학습하면 안정이고 FID는 유지(표 2의 L_hybrid 행)하며 NLL이 좋아집니다. 논문은 σ가 합리적인 범위가 매우 좁다는 점(그림 1, 둘의 비 ≈ 1)이 로그 영역에서도 직접 예측을 어렵게 한다고 N&D가 설명합니다. 논문의 불안정은 해당 매개변수화에서의 결과로 읽어야 합니다.
- 우리 검증: 최적 σ*²의 구간 [β̃_t, β_t]는 매우 좁고(β̃_t/β_t = 0.455(t = 2) ~ 0.9999992(t = 1000)) 위치 f_t가 데이터에 따라 0.52–1.0으로 움직입니다(`03` §3.1). N&D의 보간 구조와 일치합니다.

### C4. "ε-예측은 여러 잡음 크기의 denoising score matching이고 알고리즘 2는 Langevin을 닮았다"(§3.2) → **확인(정확한 형태), 표현은 한정**

- Score SDE 2021(§1, §3.4, 부록 E): "DDPM 학습 목적은 각 잡음 크기에서 점수를 암묵적으로 계산"하고, 알고리즘 2(조상 표본)는 역방향 VP SDE의 **한 이산화**이며 β_i → 0에서 역확산 해법과 일치합니다("essentially a different discretization to the same reverse-time SDE"). 어닐링 Langevin의 보정(corrector)은 없습니다.
- 우리 검증: 정확한 denoiser에서 ε* = −√(1−ᾱ_t) ∇log q_t(x_t)를 autograd로 확인했습니다(최대 오차 5e-14). 그래서 알고리즘 2의 한 걸음은 x_{t-1} = (x_t + β_t ∇log q_t(x_t))/√α_t + σ_t z입니다(`03` §1.4). L_simple은 가중 (1−ᾱ_t) 곱의 점수 매칭이라는 식 (12) 이후의 서술도 정확합니다.
- 단서: "Langevin을 닮았다"는 비유이고 정확한 대응은 VP SDE의 이산화입니다(Song의 서술을 따름).

### C5. "선형 스케줄 β: 1e-4 → 0.02, T = 1000은 L_T ≈ 0이면서 SNR을 작게"(§4, 부록 B) → **확인, 후반은 낭비**

- N&D 2021(§3.2, 그림 4): 선형 스케줄은 후반부에서 정보를 너무 빨리 파괴해 역방향 과정의 **마지막 20%를 건너뛰어도 FID가 크게 나빠지지 않습니다**(ImageNet 64×64). 코사인 스케줄 ᾱ_t = f(t)/f(0), f(t) = cos²(((t/T + s)/(1+s))·π/2), s = 0.008을 제안합니다.
- 우리 검증: ᾱ_T = 4.04e-5(SNR −43.9 dB), L_T = 7.5e-6 bits/dim으로 논문의 약 1e-5와 같은 자릿수이고, t ≥ 800에서 SNR < 1.5e-3, 단위 분산 데이터의 상호정보 < 7.7e-4 nat/좌표, SNR < 1e-2인 스텝이 32.6%입니다(`03` §1.5). N&D의 관찰과 같은 방향입니다. FID 영향 자체는 학습 없이는 확인하지 못했습니다.

### C6. 변분 하한의 SNR 형태 → **확인(DDPM의 식 (12)가 이미 그 꼴)**

- VDM(Kingma 외 2021, 식 13, 15): L_T(x) = E_{ε,i}[(SNR(s) − SNR(t)) ‖x − x̂_θ(z_t;t)‖²]/2 꼴이고 연속시간 극한의 VLB는 스케줄에서 끝점의 SNR만 남깁니다. "더 많은 시간 단계가 더 좋은 하한을 준다"(§4의 서술).
- 우리 검증: σ_t² = β̃_t이면 L_{t-1} = ½(SNR_{t-1} − SNR_t) E‖x_0 − x̂_0‖²가 정확합니다(상대 오차 7.7e-13). σ² = β_t이면 (1−ᾱ_{t-1})/(1−ᾱ_t) 배(`03` §2.3). 정확한 denoiser의 하한 간격은 단계 수에 거의 반비례합니다(S × 간격 = 8.3–11.9, `03` §4.2). L_simple = E[SNR_t ‖x_0 − x̂_0‖²](ε-MSE = SNR·x_0-MSE)도 같은 항등식에서 나옵니다. 이 가중이 이후의 가중 설계 논의의 출발점입니다(`../sd3_rectified_flow/` `03` §1).

### C7. "FID 3.17, IS 9.46은 CIFAR10 비조건부 최고 수준"(초록, 표 1) → **독립 재현은 가깝고, 순위는 약함**

- N&D 2021의 같은 설정 재학습(다른 코드, 50만 스텝): FID 3.29, NLL 3.73. Score SDE 2021 표 3은 논문의 3.17 / 9.46을 인용하고 연속시간 SDE 학습 모델을 2.4–2.8로 갱신합니다(DDPM++ 계열). 순위는 이후에 바뀝니다.
- 우리 검증: 표 1의 비교 대상 StyleGAN2+ADA(v1) 비조건부 3.26과의 차이 0.09는 N&D 재현의 차이 0.12보다 작아 순위로 인용하기 어렵습니다(`03` §6.3). 학습 시드 분산은 측정할 수 없었습니다.

### C8. "x_0 예측은 초기 실험에서 표본 품질이 나빴다"(§3.2) → **미확인**

논문에 표가 없고 이번에 이를 직접 다룬 문헌은 읽지 않았습니다. 정확한 denoiser에서 세 매개변수화(μ̃, ε, x_0)는 같은 최적해를 가지므로 차이는 가중(L_simple은 SNR 가중, x_0-MSE는 가중 1)과 신경망의 조건화에서 옵니다(`03` §5).

## 3. 코드 대조 요약

- 일치: t 표본, L_0 근사, EMA, 모수 수, 식 (7), (11)의 대수, L_T 정의.
- 논문에 없는 선택: **t = 1의 분산 β̃_2**(D4), **x_0 클리핑**(D5), 학습률 웜업과 경사 클리핑(D2, D7), 평가 구현 TF-GAN(D10).
- 데이터셋마다 다른 것: σ_t²(CIFAR10은 β_t, LSUN·CelebA는 β̃_t)(D3).
