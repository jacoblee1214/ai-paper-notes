## 1. 문제와 기여

- 문제: diffusion probabilistic model(Sohl-Dickstein 2015)은 정의가 간단하고 학습이 쉬운데도 고품질 표본을 만든 사례가 없었습니다(§1).
- 기여 세 가지(초록과 §1, §3):
  1. **ε-예측 매개변수화**: reverse 평균을 잡음 예측기로 쓰면(식 11) 변분 하한의 한 항이 여러 잡음 크기에서의 denoising score matching과 같은 꼴이 되고(식 12), 표본기(알고리즘 2)는 Langevin 동역학과 닮습니다(§3.2). 논문은 이 연결을 "주요 기여 중 하나"로 봅니다.
  2. **단순화 목적 L_simple**(식 14): 식 (12)의 t별 가중을 버립니다. 작은 t의 항을 낮추어 어려운 잡음 크기에 집중하게 하고 표본 품질이 가장 좋았다고 보고합니다(§3.4, 표 2).
  3. **CIFAR10 FID 3.17, IS 9.46**, 256×256 LSUN에서 ProgressiveGAN 수준(초록, 표 1·3). 그리고 점진적 손실 압축 해석(§4.3), 자기회귀 디코딩의 일반화라는 해석(식 16).

## 2. 방법 (식 번호는 논문 그대로)

| 번호 | 내용 | 위치 |
|---|---|---|
| (1), (2) | reverse 과정 p_θ(x_{t-1}\|x_t) = N(μ_θ, Σ_θ), forward q(x_t\|x_{t-1}) = N(√(1−β_t) x_{t-1}, β_t I) | §2 |
| (3) | 하한 L = E_q[−log p_θ(x_{0:T})/q(x_{1:T}\|x_0)] | §2 |
| (4) | q(x_t\|x_0) = N(√ᾱ_t x_0, (1−ᾱ_t) I), ᾱ_t = ∏ α_s | §2 |
| (5) | L = E[ D_KL(q(x_T\|x_0)‖p(x_T)) (L_T) + Σ_{t>1} D_KL(q(x_{t-1}\|x_t,x_0)‖p_θ) (L_{t-1}) − log p_θ(x_0\|x_1) (L_0) ] | §2, 부록 A (17)–(22) |
| (6), (7) | q(x_{t-1}\|x_t,x_0) = N(μ̃_t, β̃_t I), μ̃_t = √ᾱ_{t-1}β_t/(1−ᾱ_t) x_0 + √α_t(1−ᾱ_{t-1})/(1−ᾱ_t) x_t, β̃_t = (1−ᾱ_{t-1})/(1−ᾱ_t) β_t | §2 |
| §3.2 | Σ_θ = σ_t² I (학습 안 함). σ_t² = β_t는 x_0 ~ N(0,I)에서, σ_t² = β̃_t는 x_0가 한 점일 때 최적. 둘의 결과가 비슷했음. 둘은 좌표별 단위 분산 데이터에서 역과정 엔트로피의 상한과 하한 | §3.2 |
| (8) | L_{t-1} = E_q[‖μ̃_t − μ_θ‖²/(2σ_t²)] + C | §3.2 |
| (9), (10), (11) | x_t = √ᾱ x_0 + √(1−ᾱ) ε를 넣어 μ̃ = (x_t − β_t/√(1−ᾱ_t) ε)/√α_t. μ_θ(x_t,t) = (x_t − β_t/√(1−ᾱ_t) ε_θ(x_t,t))/√α_t | §3.2 |
| (12) | L_{t-1} − C = E_{x_0,ε}[ β_t²/(2σ_t²α_t(1−ᾱ_t)) ‖ε − ε_θ(√ᾱ_t x_0 + √(1−ᾱ_t) ε, t)‖² ] | §3.2 |
| (13) | L_0의 이산 디코더: 화소마다 N(μ_θ(x_1,1), σ_1²)를 빈 폭 1/127.5(= 2/255)로 적분. 가장자리는 ±∞ | §3.3 |
| (14) | L_simple(θ) = E_{t,x_0,ε}[‖ε − ε_θ(√ᾱ_t x_0 + √(1−ᾱ_t) ε, t)‖²], t ~ U{1..T}. t=1은 L_0에서 σ_1과 가장자리 효과를 무시한 근사 | §3.4 |
| 알고리즘 1 | 학습: x_0, t, ε를 뽑아 식 (14)의 경사 | §3.2 |
| 알고리즘 2 | 표본: x_T ~ N(0,I), x_{t-1} = (x_t − β_t/√(1−ᾱ_t) ε_θ)/√α_t + σ_t z, 마지막 단계는 z = 0 | §3.2 |
| (15) | x̂_0 = (x_t − √(1−ᾱ_t) ε_θ(x_t))/√ᾱ_t, 점진적 복원과 왜곡 측정 | §4.3 |
| (16) | L = D_KL(q(x_T)‖p(x_T)) + E[ΣD_KL(q(x_{t-1}\|x_t)‖p_θ(x_{t-1}\|x_t))] + H(x_0) | §4.3, 부록 A (23)–(26) |
| 알고리즘 3, 4 | minimal random coding을 가정한 점진적 압축. 고차원에서는 실행 불가라고 논문이 인정(부록 "Progressive compression") | §4.3 |

설정(§4, 부록 B): T = 1000, β_t는 1e-4에서 0.02까지 선형(L_T ≈ 1e-5 bits/dim), 데이터는 [−1, 1]로 스케일, PixelCNN++ 계열 U-Net + 그룹 정규화 + 16×16 self-attention + 시간 사인 임베딩. CIFAR10 3570만, LSUN·CelebA-HQ 1.14억, 큰 LSUN Bedroom 약 2.56억 모수. CIFAR10: dropout 0.1, 무작위 좌우 반전, Adam 2e-4(256×256은 2e-5), 배치 128, **EMA 0.9999**, 80만 스텝(TPU v3-8에서 10.6시간). "최종 실험은 한 번 학습했고 학습 중 평가한 최소 FID를 보고"(부록 B). FID 50,000 표본, 훈련 집합 기준.

## 5. 한계

논문이 인정한 것:

- NLL이 다른 likelihood 모델과 경쟁하지 못합니다(§1, §4.3). 표 1의 NLL ≤ 3.70·3.75는 Sparse Transformer의 2.80과 차이가 큽니다.
- 알고리즘 3, 4(점진적 압축)는 개념 증명입니다(부록).
- 표본 추출은 1000번의 신경망 호출이 필요합니다(§4). 공식 코드 기준 CIFAR 256개를 17초에 뽑습니다(부록 B).

논문이 쓰지 않은 것(우리 검토):

- **단일 학습, 최소 FID 선택.** 표 2의 FID에는 ±가 없고 IS의 ±는 학습 시드가 아니라 표본 분할로 보입니다(`03` §6.3).
- **σ_t² 선택의 일반화 여부.** §3.2의 "비슷한 결과"는 T = 1000 CIFAR10에 대한 말입니다. 단계 수가 줄면 선택이 달라집니다(`03` §3.3, `04` C1).
- **t = 1의 분산.** 논문은 σ_1²를 따로 말하지 않고 공식 코드는 별도 값을 씁니다(`04` D4).
- **이산 디코더의 가정.** 식 (13)은 모든 화소를 독립 가우시안으로 모형화하며 §3.4는 t = 1 항을 가우시안 밀도 근사로 쓴다고 인정합니다.
- **x_0 예측 비교는 서술뿐.** "x_0 예측은 초기에 더 나빴다"(§3.2)는 표가 없습니다.
