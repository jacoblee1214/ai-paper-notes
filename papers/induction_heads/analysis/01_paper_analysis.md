# 01. 논문 분석: In-context Learning and Induction Heads (arXiv:2209.11895)

Olsson, Elhage, Nanda 외 (Anthropic), Transformer Circuits Thread, 2022-03-08 게시(arXiv 업로드 2022-09-24, v1만 있음). 분석 판은 arXiv v1 PDF의 `pdftotext` 결과(`paper/paper.txt`)입니다. 원문은 HTML 기사이고 PDF에는 대화형 시각화가 빠져 있어서(Argument 4의 attention·logit attribution 그림, Model Analysis Table), 아래에서 그 부분의 수치는 "PDF에서 판독하지 못함"으로 적습니다. 위치는 절 이름과 `paper.txt` 줄 번호로 씁니다(절 번호나 식 번호가 없는 글입니다).

## 1. 문제

in-context learning(ICL)의 정의를 둘로 나눕니다(Key Concepts › In-context Learning, L142–L162).

- 미시: Brown et al.식 few-shot 과제 수행.
- 거시: Kaplan et al.식, 토큰 위치가 뒤로 갈수록 손실이 줄어드는 정도. 이 논문은 이쪽을 씁니다.

질문은 "거시 ICL의 상당 부분이 induction head라는 회로에서 나오는가"입니다. 큰 모델은 MLP와 많은 층 때문에 회로를 수학적으로 풀 수 없으므로, 학습 과정을 관찰·교란해 간접 증거를 쌓는 전략을 씁니다(L53–L80).

## 2. 정의와 측정 (Key Concepts, Appendix)

| 대상 | 정의 | 위치 |
|---|---|---|
| ICL 점수 | 문맥의 500번째 토큰 손실과 50번째 토큰 손실의 차(길이 512). 보고하는 값은 양수(약 0.4 nats)이므로 사실상 "50번째 − 500번째" | L163–L170, L343–L347, L1824–L1826 |
| induction head | 반복된 무작위 토큰 열에서 (1) prefix matching과 (2) copying을 모두 보이는 head | L218–L225 |
| prefix matching | `[A][B] … [A]`에서 현재 토큰 `[A]`가 앞서 나온 위치 바로 뒤의 `[B]`로 attend | L220–L222 |
| copying | head 출력이 attend한 토큰의 logit을 올림 | L223 |
| prefix matching evaluator | 무작위 토큰 25개(가장 흔한 것과 가장 드문 것 제외) × 4번 반복 + 시작 토큰. 반복 구간에서 이전 반복의 해당 위치로 간 attention의 평균 | L1695–L1698 |
| copying evaluator | 무작위 토큰 25개. head의 직접 logit 기여에서 평균을 빼고 ReLU를 씌운 뒤, attend한 토큰의 몫을 전체에 대한 비로 계산해 −1~1로 맞춤 | L1689–L1694 |
| 이전 토큰 점수 | 학습 분포 예시에서 i에서 i−1로 간 attention의 평균 | L1699–L1700 |
| QK 고유값 대각합 | 앞 층의 "이전 토큰 head"를 거친 순수 K-composition 항 W의 대각합(양수이면 같음 매칭) | L1704–L1763 |
| per-token loss 벡터 + PCA | 모든 스냅샷에서 같은 10,000개 무작위 토큰의 손실을 모아 PCA | L251–L270 |
| pattern-preserving ablation | head 출력을 0으로 하되, 깨끗한 실행의 attention 패턴을 모든 층에 강제 | L1645–L1662 |

## 3. 여섯 논거 (본문 L81–L106, 각 절)

| # | 논거 | 한 줄 요약 | 근거 종류 | 위치 |
|---|---|---|---|---|
| 1 | 거시적 동시 출현 | 학습 초기 좁은 구간에서 ICL 점수가 급증(0.15 nats 미만에서 약 0.4 nats로)하고, induction head가 생기고, 손실에 혹이 생기고, PCA 궤적이 꺾입니다. 층이 1개이면 어느 것도 없습니다 | 관찰(상관) | L323–L482 |
| 2 | 거시적 동시 교란 | smeared key로 키를 앞 토큰과 보간하면 1층 모델에서도 ICL이 생기고, 2층 이상에서는 더 일찍 생깁니다 | 개입(구조 변경) | L483–L545 |
| 3 | 직접 ablation | 작은 attention-only 모델에서 induction head를 끄면 ICL 점수가 크게 줄어듭니다. 대부분의 다른 head를 끄면 오히려 늘어납니다(각주 17) | 개입(인과) | L546–L587 |
| 4 | 일반성의 구체 예 | 13B(40층) 모델에서 induction head의 정의(무작위 열 복사)를 만족하면서 번역, 추상 패턴 매칭도 하는 head 3개 | 사례(일화) | L589–L714 |
| 5 | 메커니즘적 타당성 | 작은 모델에서 OV 회로(복사)와 QK 회로(K-composition)로 head가 어떻게 작동하는지 풀어, ICL에 기여해야 함을 논리로 보입니다 | 메커니즘(이론적) | L715–L830 |
| 6 | 소→대 연속성 | 단계 변화, ICL 점수 크기, PCA 궤적이 모든 크기에서 닮았으니 같은 메커니즘이 가장 단순한 설명 | 유추 | L831–L860 |

논문이 각 논거에 붙인 강도 표(소형 attention-only / MLP 있는 소형 / 대형 × "일부에 기여" / "대부분에 기여")는 `03_analysis.md` §5에서 그대로 옮겨 정리합니다. 모델은 34개(소형 attention-only 1–6층, 소형 MLP 1–6층, full-scale 6개, smeared-key 1·2층, 책 데이터만 쓴 소형 변형. 계열별 개수 합은 본문이 따로 적지 않았습니다)이고 head ablation은 소형 모델에서만 합니다(5만 번 이상, L126, L572, L1811). full-scale 모델 스냅샷은 15개뿐이라 시간 해상도가 낮습니다(L464–L466).

## 4. 모델과 학습 설정 (Model Details)

- 소형: 1–6층, attention-only와 MLP 두 계열, d_model 768, head 12개/층, 어휘 2^16, 문맥 8192, 10,000 스텝(약 100억 토큰), 스냅샷 200개(50 스텝 간격). 위치 정보는 Press et al.의 변형(잔차에 더하지 않음)입니다(L886–L902).
- full-scale: 4층 13M ~ 40층 13B 파라미터, d_model = 128 × 층 수, 스냅샷 15개(2배 간격)(L904–L944).
- smeared key: 식 `k_j ← σ(α) k_j + (1−σ(α)) k_{j−1}`, head마다 학습 가능한 α. 소형 1, 2층에만 씁니다(L513–L517, L947–L959).
- 데이터: 필터링한 Common Crawl과 인터넷 책 등, 약 10%가 Python 코드. 책만 쓴 데이터로 다시 학습한 변형이 있습니다. 모든 모델이 같은 예시를 같은 순서로 보고, 같은 데이터를 두 번 보지 않습니다(L875–L881). **모델당 학습은 1회**라서 시드 변동은 보고되지 않았습니다(L863).

## 5. 이후 첨부된 내용

- 외부 복제 두 건(Comments & Replications, L1220–L1264). Redwood(Scherlis)는 2층 attention-only에서 induction head가 안정적으로 나타나고, 이상적인 이전 토큰 패턴으로 바꾸면 손실 차이의 99%, 단순 `[A][B]…[A]` 근사 패턴으로 바꾸면 약 65%(`[A][B][C]…[A][B]→[C]` 항을 더하면 10%p 추가)를 복원한다고 했습니다. Lieberum은 GPT-2와 GPT-Neo에서 같은 경험적 기준으로 중간 깊이에서 후보 head를 찾았다고 했고, 데이터 의존성을 지적했습니다(문맥 길이 4의 합성 데이터에서도 induction이 쉽게 학습됨).
- 변경 기록: 2022-09-20에 prefix matching 정의의 표현을 고치고 copying evaluator가 ReLU를 쓴다는 설명을 추가했습니다(L1266–L1270).

## 6. 우리가 읽다가 확인한 불일치와 모호함

- **D1. ICL 점수의 부호.** Key Concepts는 "500번째 토큰 손실 − 50번째 토큰 손실"(L164–L165), Argument 1은 "50번째 − 500번째"(L343), 부록은 `Loss(500) − Loss(50)`(L1826)이라고 쓰고, 보고되는 값은 양수(약 0.4)입니다. 후자(50 − 500)라야 양수이므로 정의 문장이 부호를 잘못 썼거나 생략한 것으로 읽습니다. 03에서 양수 쪽을 씁니다.
- **D2. prefix matching 정의의 문장이 모호합니다.** 본문 정의는 "현재 및/또는 최근 토큰이 뒤따랐던 이전 토큰으로 attend"(L220–L221), 부록은 "현재 토큰과 일치하는 토큰이 뒤따르는 이전 토큰"(L1677–L1678)이라고 씁니다. 변경 기록은 이 정의를 한 번 고쳤다고 적었습니다. 문자 그대로 읽으면 `[A][B]…[A]`에서 B(=A 다음)가 아니라 A 직전 토큰을 가리키는 것으로 읽히는데, 그림과 Argument 5의 서술은 모두 "이전 A 바로 다음 토큰 B로 attend"입니다. 03·minimal_impl은 후자로 구현합니다.
- **D3. 점수 정규화가 모호합니다.** prefix matching 점수는 "attention 항목의 평균"이라고만 적었고 합과 평균 중 어느 쪽인지 알 수 없습니다. copying 점수의 비율이 "0에서 0.5"이고 −1~1로 맞춘다는 설명(L1693–L1694)도 식이 없습니다. 논문 표(L620–L624)의 값(literal copying head 0.89/0.75 등)을 우리 정의로 직접 비교할 수 없습니다. 우리는 prefix 점수를 "이전 반복들의 표적 위치에 둔 attention 질량의 평균"으로, copying 점수를 "(몫 − 1/K)/(1 − 1/K)"로 정의했고, 이 값들은 논문 수치와 같은 눈금이 아닙니다.
- **D4. 단계 변화의 토큰 구간이 두 곳에서 다릅니다.** Argument 1은 "약 25억–50억 토큰"(L344), Model Details는 소형 모델에서 "약 10–30억 토큰"(L895)이라 합니다. 서로 다른 모델 집합의 수치일 수 있으나 본문이 밝히지 않습니다.
- **D5. 학습률 예열이 구간과 겹칩니다.** 예열이 처음 15억 토큰이라(L902) 단계 변화의 시작과 가깝습니다. 논문은 예약된 변화와 대응하지 않는다고 하지만(L416–L418), 예열이 끝나는 지점과 가까운 점은 확인 대상으로 남습니다.
- **D6. 모델당 한 번 학습.** 단계 변화 시점의 시드 분산과 ablation 효과의 불확실성은 보고되지 않았습니다(L863). 04 C7, 03에서 토이 시드 3–5개로 시점 변동을 잽니다.
- **D7. 메커니즘 기술은 소형 모델에 한정됩니다.** Argument 5의 "작은 모델에서는 이전 토큰 head와 K-composition" 설명은 이전 논문에서 하나의 head를 해부한 결과입니다(L752–L754). GPT-2에서는 위치 임베딩을 이용하는 다른 구현("pointer arithmetic", Q-composition)도 있다고 논문이 적었습니다(L805–L817). 즉 "induction head = 이전 토큰 head + K-composition"은 유일한 구현이 아닙니다.

## 7. 한계(저자 자신이 적은 것)

- 대형 모델은 상관 증거뿐이고 head ablation이 없습니다(L572, L287–L289).
- full-scale은 시간 해상도가 낮아 동시 출현이 덜 놀랍습니다(L464–L466).
- 공통 잠재 변수(예: 층 합성을 배우는 시점) 때문에 동시 출현이 나올 수 있다는 대안을 인정합니다(L467–L472, L855–L860).
- ICL 점수가 약 0.4로 일정한 것이 "메커니즘이 일정"을 뜻하지 않을 수 있고, 위치 50의 손실이 학습 중 개선되므로 같은 차이를 줄이는 일이 더 어려워집니다(L473–L478, 각주 13–14).
- MLP가 있는 모델에서는 head ablation이 head의 진짜 중요도를 보여 주지 못할 수 있습니다(L576–L584, 각주 20).
- 서로 비슷한 일을 하는 head가 있으면 하나씩 끄는 ablation은 중요도를 가립니다(L582–L584).
