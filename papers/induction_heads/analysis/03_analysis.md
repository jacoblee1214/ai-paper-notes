## 1. 정의와 식 검산

### 1.1 ICL 점수

논문 정의: 위치 500의 손실 − 위치 50의 손실(길이 512)을 예시 평균. 보고하는 값(약 0.4 nats, 단계 변화 이후 일정)은 양수이므로 부호가 반대입니다(`01` D1). `minimal_impl.icl_score`는 **(이른 위치 손실) − (늦은 위치 손실)**, 양수일수록 문맥에서 많이 배운다로 정의했습니다. 우리 문맥은 256이라 위치 22–28(이른)과 244–250(늦은)의 평균 손실을 씁니다(논문의 50 대 500은 10배 비율이고 우리는 약 10배).

이 점수가 0이 되는 조건을 따져 보면, 한 위치의 손실이 앞쪽 k 토큰(k < 이른 위치)에만 의존하는 모델(예: n-gram, n−1 ≤ k)은 두 위치에서 같은 분포의 손실을 내므로 기대값이 0입니다(문서 시작 효과 제외). 즉 이 점수는 "k 토큰을 넘는 문맥을 쓴 정도"의 거친 척도입니다. 위치 50 이전의 정보로도 줄어드는 손실은 안 잡히고, 문서가 뒤로 갈수록 주제가 안정되어 예측이 쉬워지는 효과(비정상성)도 함께 잡힙니다. 논문도 이 점(위치 50의 손실이 학습 중 개선되므로 같은 차이를 줄이는 것이 어려워짐)을 한계로 적었습니다(`01` §7).

### 1.2 prefix-matching 점수

`prefix_matching_score(pattern, L, n_rep)`: 시퀀스 = BOS + 길이 L 열 × n_rep. 둘째 사본 이후의 각 목적지 i에서 현재 토큰 `t_i`가 이전 사본의 위치 i−kL(≥1)에 있으므로, induction이 가리키는 위치는 **j = i − kL + 1**(k = 1, 2, ...)입니다. 점수 = 이 위치들에 둔 attention 질량의 목적지 평균(질량의 합, 논문의 "평균"이 합인지 평균인지는 불명확: `01` D3).

- 이상적 head(표적에 균등 분배) = 정확히 1. 균등 causal attention이면 목적지 i에서 표적 수 k_i = ⌊(i−1)/L⌋를 (i+1)로 나눈 값의 평균이므로 우연 수준이 정해집니다: **L = 25, n = 4: 0.031, L = 12, n = 4: 0.062, L = 8, n = 4: 0.091**(`definition_checks_results.json`). 합성 실험은 L = 12를 써서 우연 0.062입니다.
- 이전 토큰 head(i → i−1)는 표적이 아니므로 0입니다. 손으로 만든 패턴(L=3, n=3, 총 10 토큰)으로 이 값들(이상적 1, BOS에 몰림 0, 이전 토큰 0, 균등 causal (1/5+1/6+1/7+2/8+2/9+2/10)/6)을 pytest에서 확인했습니다. 처음 구현에서 이전 사본의 같은 토큰이 BOS인 위치(i = kL)까지 표적에 넣는 오류가 있었는데 이 시험이 잡았고, 고친 뒤 모든 결과를 다시 돌렸습니다.

### 1.3 copying 점수

두 가지를 구현했습니다.

1. **OV 고유값 점수** `ov_copy_eig_score`: 임베딩 E, 헤드 OV(잔차 좌표) O, 언임베딩 U의 토큰 → 토큰 회로 E·O·U의 고유값 중 양의 비율 `Σ Re λ / Σ |λ|`(−1~1). 0이 아닌 고유값은 d×d 곱 O·U·E와 같아서 d×d에서 계산합니다. 무작위 가우시안 OV의 우연 수준은 평균 0, 표준편차 0.023(d=64), 0.012(d=128)로, 0.1 이상은 우연이 아닙니다(`definition_checks_results.json`). LayerNorm의 정규화 크기와 위치 임베딩은 무시한 근사입니다.
2. **직접 logit 경로 점수** `copy_scores_logit`: 반복 구간 목적지마다 head 출력을 언임베딩에 통과시켜(ln_f gamma 포함) 어휘 평균을 빼고 ReLU를 씌운 뒤, **head가 가장 크게 attend한 토큰**의 몫 ÷ 표본 토큰들의 몫 합을 구하고 (몫 − 1/K)/(1 − 1/K)로 맞춥니다(우연 0, 완전 복사 1). 논문 evaluator의 정확한 정규화(0~0.5를 −1~1로)는 식이 없어 재구성할 수 없어서(`01` D3) 우리 정의를 쓰며 논문 표의 값(0.89, 0.20, 0.69)과 직접 비교할 수 없습니다.

두 점수는 다른 것을 잽니다. OV 고유값 점수는 "attend한 것을 복사하는 능력"이고, logit 점수는 "실제로 attend한 토큰을 복사하는가"입니다. 합성 1층 head는 고유값 점수 0.87–1.0인데 logit 점수는 0.10 근처입니다(복사는 하지만 attend 대상이 표적이 아님). 합성 2층의 마지막 층에서는 고유값 0.78–1.0, logit 0.40–0.47입니다.

### 1.4 K-composition: 왜 두 층이 필요한가 (식과 시험)

층 ℓ 헤드의 attention 점수는 `s_ij = x_iᵀ W_QK x_j`(pre-LN의 정규화 크기를 무시)입니다.

- **1층:** `x_j = e(t_j) + p_j`이므로 s_ij는 (t_i, p_i, t_j, p_j)만의 함수입니다. 키 위치 j의 점수가 앞 토큰 t_{j−1}에 의존할 수 없어서 `[A][B]…[A] → [B]`에서 B를 "A 다음"이라는 이유로 고를 수 없습니다. 그래서 어떤 위치 m의 토큰을 바꿔도, m이 아닌 두 키 위치 사이의 attention 비(softmax 비 = exp(점수 차))는 변하지 않습니다. pytest `test_one_layer_scores_ignore_previous_token`이 이를 정확히(허용 오차 1e-5) 확인합니다.
- **2층:** 층 1의 입력 `x_j = e(t_j) + p_j + Σ_g Σ_k A^g_{jk} (e(t_k) + p_k) W_OV^g`에서, 층 0의 이전 토큰 head g의 `A^g_{j,j−1} ≈ 1` 항이 `e(t_{j−1}) W_OV^g`를 x_j에 더합니다. 그러면 층 1 헤드의 점수는 `s_ij ⊃ e(t_i) B (e(t_{j−1}) W_OV^g)ᵀ`(B는 W_Q W_Kᵀ에서 오는 d×d)를 포함합니다. 이 항의 행렬 `E B W_OV^gᵀ Eᵀ`의 대각이 양수이면 `t_{j−1} = t_i`인 j를 선호합니다. 논문 부록 (4)의 "QK 고유값 대각합"이 이 항을 이전 토큰 head의 attention 가중으로 모은 것입니다. `kcomp_trace`가 이를 구현합니다(`tr(B W_OVᵀ EᵀE)`, 행벡터 규약). pytest는 2층에서 층 1의 attention 비는 앞 토큰에 의존하고(차이 > 1e-3), 층 0의 비는 의존하지 않음을 확인합니다.
- **실험적 확인:** 학습한 2층 합성 모델에서 층 0의 모든 head를 끄되 attention 패턴을 깨끗한 실행의 것으로 고정하면(패턴 유지 ablation) 반복 손실이 거의 오르지 않고(시드 0, 2, 3, 4에서 −0.04–+0.09, 시드 1에서 +1.68), 패턴을 고정하지 않으면 +4.3–5.3 오릅니다(`synthetic_results.json`, §2.4). 층 0이 induction에 기여하는 길이 거의 K(패턴) 경로뿐이라는 뜻이고, 논문의 K-composition 서술과 일치합니다.

1층이 전혀 배우지 못하는 것은 아닙니다. 1층도 "이미 나온 토큰을 복사"해서 반복 손실을 4.19에서 약 2.05까지 줄입니다(§2). 문맥에 나온 서로 다른 토큰 수로 균등 예측하는 기준선(반복 구간의 ln(본 토큰 수) 평균)은 2.39이고(`definition_checks_results.json`, 하한은 아님) 1층은 이보다 0.3 낮습니다. 논문 각주 23의 "기본 복사 head는 1층에도 있다"와 같은 이야기이고, ICL 점수가 0이 아닌 이유를 설명합니다.

### 1.5 smeared key

`k_j' = σ(α) k_j + (1−σ(α)) k_{j−1}`이면 점수 `s_ij' = σ s_ij + (1−σ) s_{i,j−1}`입니다. σ → 0이면 키가 앞 토큰의 키로 바뀌어 한 층 안에서 prefix 매칭이 가능합니다(이전 토큰 head를 키 계산에 접어 넣은 것). pytest: α = −30에서 토큰 m을 바꾸면 위치 m+1의 점수만 변하고, α = +30에서는 smear 없는 모델과 출력이 같습니다(1e-4). 학습 결과는 §2.3.

### 1.6 합성 과제의 기준선 (`definition_checks_results.json`)

- 첫 사본의 토큰은 무작위(어휘 63개)라서 손실 하한 ln 63 = 4.143. 측정된 첫 구간 손실은 4.23–4.32로 이보다 높습니다. induction이 생긴 뒤 반복이 아닌 곳에서도 "이전에 본 토큰 뒤"를 잘못 예측하는 비용입니다(논문이 해리포터 예에서 보인 "앞과 다른 토큰이 오면 단계 변화 이후 더 나빠지는" 현상, L428–L431의 토이판). 1층 기본형은 4.31–4.32, 2층은 4.23–4.30, smeared 1층은 4.28–4.31입니다.
- 이상적인 induction의 반복 구간 손실은 0, 균등 어휘 예측은 ln 64 = 4.159.

## 2. 합성 반복 토큰 토이 (a)

설정: 어휘 64(BOS 포함), 문맥 64, 시퀀스마다 길이 L ∈ [6, 20]의 무작위 토큰 열을 순환 반복(L이 고정이면 위치 임베딩만으로 "L칸 앞"을 보는 지름길이 생겨서 가변으로 둠), d = 128, head 4개, attention-only, pre-LN, 학습형 절대 위치 임베딩, AdamW(lr 5e-4, warmup 50 스텝 후 일정), 배치 64, 1,500 스텝, 평가는 10 스텝마다. 논문 모델과 달리 위치 정보를 잔차에 더합니다.

### 2.1 요약표 (5시드)

| 구성 | 반복 구간 손실 (시작 → 끝) | 손실 중간점 (스텝) | prefix 최대 (끝) | prefix 중간점 (스텝) |
|---|---|---|---|---|
| 1층 | 4.19 → 2.05–2.07 | 120 (점진적 하락, 단계 변화 아님) | 0.12–0.14 (우연 0.062) | 없음 |
| 2층 | 4.18–4.20 → 0.054–0.164 | 220, 230, 230, 250, 250 | 0.68–0.91 (모두 층 1) | 260, 260, 260, 280, 300 |
| 1층 + smeared key | 4.18–4.19 → 0.176–0.189 | 110–120 | 0.37–0.40 | 90–100 |

"중간점"은 반복 손실이 시작값과 끝값의 중간(1층 기본형은 판정 기준을 통과하지만 평탄한 하락이라 단계 변화로 보지 않음)을 처음 넘은 평가 스텝이고, prefix 중간점은 최댓값이 끝값의 절반을 처음 넘은 스텝입니다. 측정 간격이 10 스텝이라 해상도는 ±10입니다.

### 2.2 단계 변화의 모양과 시드 변동

2층 손실은 "느린 하락 → 평탄 → 급락"의 두 단계입니다. 100 스텝에서 3.24–3.25, 180 스텝에서 2.74–2.78(이 평탄은 1층이 닿는 수준과 같은 "이미 나온 토큰 복사" 단계이고 앞의 기준선 2.39 부근), 300 스텝에서 0.52–0.90, 급락 폭(평탄에서 끝까지의 90% 지점부터 10% 지점)은 140–190 스텝입니다. 손실 급락의 중간점은 시드 5개에서 220–250(평균 236), prefix 점수의 중간점은 260–300(평균 268)으로 **prefix 점수가 손실보다 30–50 스텝 늦습니다**(측정 해상도 10). 손실 급락이 prefix 점수가 "끝값의 절반" 기준을 통과하기 전에 시작하는 이유는, 손실은 attention이 어느 정도만 맞아도 떨어지기 시작하고 prefix 점수는 위치별 질량이 쌓여야 끝값의 절반에 닿기 때문으로 해석하는데 이 설명은 시험하지 않았습니다. 논문 L406–L410은 두 변화가 같은 구간에서 일어난다고만 하고 순서를 따지지 않았습니다. 시드 변동은 손실 기준 범위 30 스텝으로 평균 중간점(236)의 약 13%입니다. 논문은 모델당 1회라 이 변동이 없습니다(`01` D6).

### 2.3 smeared key (논문 Argument 2의 토이판)

1층 + smeared key는 5시드 모두 반복 손실을 0.18 부근까지 낮추고 시점이 2층보다 이릅니다(110–120 대 220–250). 논문 예측("1층에서도 생기고 2층에서는 더 일찍")의 1층 부분과 일치합니다. 2층 smeared는 시험하지 않았습니다. 1층 + smeared key의 최대 prefix 점수는 0.37–0.40으로 2층(0.68–0.91)보다 낮은데 손실은 0.18 대 0.05–0.16으로 비슷합니다. 한 층에서는 표적 위치에 질량을 더 몰지 못하거나(키 보간이 σ의 학습으로 제한됨) 다른 위치도 같이 쓰는 것으로 보이지만 확인하지 않았습니다.

### 2.4 head ablation (논문 Argument 3의 토이판)

반복 구간 손실의 증가(nats). 전체 ablation은 head 출력을 0으로 하고 패턴을 다시 계산하며, 패턴 유지 ablation은 깨끗한 실행의 모든 attention 패턴을 고정합니다(논문 각주 29–30). 2층 모델, 시드 5개.

| ablation | 전체 | 패턴 유지 |
|---|---|---|
| 층 1의 head 하나씩 (최대) | +0.03–0.06 | +0.03–0.06 |
| 층 1 head 4개 전부 | +4.43–4.72 | +4.43–4.72 (층 1은 같은 값: 뒤에 층이 없음) |
| 층 0의 head 하나씩 (최대) | +0.61–3.30 | +0.01–0.67 |
| 층 0 head 4개 전부 | +4.28–5.28 | −0.04–+0.09, 시드 1만 +1.68 |

- 층 1의 4개 head가 모두 induction head(prefix 0.62–0.91, 고유값 copying 0.78–1.0)라서 **하나씩 끄면 거의 무영향**이고 함께 끄면 크게 오릅니다. 논문이 경고한 "비슷한 head가 있으면 하나씩 끄는 ablation은 중요도를 가린다"(L582–L584)가 토이에서 그대로 나옵니다. 모두 끈 뒤의 반복 손실(4.6–4.8)은 균등 예측(4.16)보다 나쁜데, 마지막 층을 통째로 잃은 모델이 문맥 밖으로 벗어나기 때문이어서 "ICL만 제거"가 아닙니다.
- 층 0은 전체 ablation에서만 큽니다(층 전체 +4.3–5.3). 패턴 유지에서는 거의 0이므로, 층 0의 기여는 거의 전부 층 1의 attention 패턴(K 경로)으로 흐릅니다. 논문의 패턴 유지 ablation은 이런 K 경로 head(이전 토큰 head)의 중요도를 과소평가합니다(각주 29–30이 암시).
- 층 0에서 하나씩 끄면 시드마다 효과가 가장 큰 head가 다르고 크기도 다릅니다(시드 0–4의 최대 효과 +3.30, +0.61, +1.41, +0.88, +2.03, `synthetic_results.json`). 가장 큰 효과를 내는 head가 이전 토큰 점수가 가장 높은 head와 같지 않았습니다(시드 0: 이전 토큰 점수 최대 head 0.0(0.37)인데 효과 최대는 head 1(+3.3, 점수 0.21)). 이전 토큰 점수는 "i → i−1" 평균이어서 반복 구간에서 쓰는 역할을 정확히 잡지 못합니다.

## 3. 자연 텍스트 토이 (b) (31번에 넘길 모델)

### 3.1 코퍼스와 설정

다운로드 없이 이 맥의 파이썬 표준 라이브러리를 씁니다(Anaconda Python 3.12.7). `.py` 소스(`site-packages`, `test`, `tests`, `idlelib`, `lib-dynload`, `turtledemo`, `ensurepip`, `lib2to3` 제외) + `pydoc_data.topics`(파이썬 문서의 영어 산문). 코드와 영어 문서가 섞인 텍스트입니다. 토큰은 정규식 `\w+ | 문장부호 | 개행`(공백은 버림), 어휘는 학습 청크의 상위 2,046개 + `<unk>`(id 1) + `<bos>`(id 0)로 2,048개입니다. 총 2,666,154 토큰, 1,000 토큰 청크로 잘라 20번째마다 검증용(학습 2,533,154, 검증 133,000 토큰, 256 토큰 창 519개). 코퍼스 sha256 `9d26b37d…`는 결과 json에 있습니다. 모든 창은 첫 토큰이 BOS입니다.

모델: 2층, d = 128, head 4개, MLP 512(GELU), 문맥 256, pre-LN, 학습형 절대 위치 임베딩, 952,832 파라미터. AdamW(lr 1e-3, warmup 100 후 일정), 배치 32 × 256 = 8,192 토큰/스텝, 4,000 스텝(약 3,280만 토큰, 코퍼스를 약 13번 봄), 50 스텝마다 평가. MPS에서 시드당 약 2.4분.

### 3.2 자연 텍스트만으로 학습: induction head가 생기지 않음 (음성 결과)

3시드, 4,000 스텝: 검증 손실 1.809–1.819, 최대 prefix 점수 0.04–0.05(우연 수준: L = 25, n = 4의 균등 attention이 0.031), 반복 구절 세트의 둘째 사본 손실이 첫 사본과 같음(1.86–1.90 대 1.88: 문맥 복사 없음). 자연 텍스트 ICL 점수(위치 25 대 250)는 학습 후반 0.06–0.09로 약하게 양수입니다(논문의 약 0.4와 직접 비교할 수 없음: 위치, 문맥 길이, 데이터가 다름).

시험한 변형(모두 시드 1개, 결과는 `.scratch`에 두고 커밋하지 않음): 8,000 스텝 + lr 2e-3에서 최대 prefix 0.10, 배치 128(약 1억 토큰) 3,000 스텝에서 0.03. 어느 쪽도 단계 변화가 없었습니다. 논문의 소형 모델은 약 10–30억 토큰에서 단계 변화가 일어나고(L895) 우리는 최대 약 1억 토큰이므로 규모가 20–100분의 1입니다. 따라서 "자연 텍스트에서 단계 변화가 안 생긴다"가 아니라 **"이 규모와 이 코퍼스에서는 안 생긴다"**입니다. 이 저장소의 27번(`attention_sink_emerges/`)에서도 소형 토이에서 현상이 생기지 않은 음성 결과가 있었습니다.

### 3.3 반복 구절 증강: 자연 텍스트 + 반복 구절 50%

학습 창의 50%를 `[BOS, p, p, x]`(p = 창 앞쪽 127 토큰의 자연 텍스트 구간, x = 창의 마지막 토큰)로 바꿉니다. 같은 구절이 두 번 나오는 문서를 흉내 낸 증강이고 **자연 텍스트만이 아닙니다**. 평가는 검증 창으로 같은 방식으로 만든 반복 구절 세트(둘째 사본 손실)와 증강 없는 검증 창(ICL 점수) 둘 다에서 합니다.

| 시드 | 둘째 사본 손실 (1,000 스텝 → 4,000 스텝) | 손실 중간점 (스텝) | 최대 prefix (4,000 스텝) | induction head 후보 | 검증 손실 | 자연 텍스트 ICL (마지막 20회 평균) |
|---|---|---|---|---|---|---|
| 0 | 2.14 → 0.18 | 1,800 | 0.41 | 층 1 head 2 | 1.849 | 0.061 |
| 1 | 2.11 → 0.11 | 1,800 | 0.28 | 층 1 head 3 | 1.859 | 0.025 |
| 2 | 2.03 → 0.07 | 1,300 | 0.19 | 층 1 head 2 | 1.871 | −0.002 |

- **단계 변화는 있습니다.** 둘째 사본 손실이 약 2.1에서 0.1–0.2로 떨어지는 구간(시드 0: 약 1,400–2,600 스텝, 시드 1: 약 1,600–2,200 스텝, 시드 2: 약 1,000–1,600 스텝)에 prefix 점수가 함께 오릅니다(그림 `own_natural_text.png`). 첫 사본 손실은 1.88–1.89로 변하지 않습니다.
- 시드에 따라 시점이 500 스텝(약 30%) 다르고 최종 prefix 점수도 0.19–0.41로 갈립니다. 합성 데이터(범위 30 스텝)보다 훨씬 큽니다.
- **prefix 점수의 절대 크기는 작습니다**(0.19–0.41, 합성의 0.9에 비해). 둘째 사본 손실은 0.07–0.18로 거의 완전히 낮아졌는데도 prefix 점수가 낮은 것은, 평가용 입력(무작위 토큰 25개 × 4)이 학습한 자연 텍스트의 분포와 달라서(무작위 토큰의 손실이 11–13 nats로 큼) 자연 텍스트에서 쓰는 head가 무작위 열에서 약하게 반응하거나, 반복 구절 모델이 prefix 매칭 외 다른 신호(위치 오프셋 등)도 쓰기 때문일 수 있습니다. 어느 쪽인지 확인하지 않았습니다. 무작위 토큰의 반복 손실은 개선되지 않았습니다(7.65 → 11.3–13.2, 자연 텍스트만 쓴 모델은 13.4–14.0).
- **자연 텍스트 ICL 점수는 올라가지 않았습니다.** 증강 모델 0.061, 0.025, −0.002, 자연 텍스트만 쓴 모델 0.068, 0.061, 0.082(마지막 20회 평균). 학습 중 ICL 점수가 −0.2까지 내려갔다 돌아오는 구간이 있는데(1,000–2,500 스텝, 시드 2에서 가장 깊음) 증강 창이 "후반부는 앞의 복사"라는 신호를 주어 자연 텍스트의 후반 위치를 오히려 나쁘게 했을 가능성이 있습니다(가설, 시험하지 않음). 즉 반복 구절로 만든 induction 회로가 자연 텍스트 ICL 점수의 개선으로 옮겨가지 않았습니다. 논문의 "induction head 형성과 ICL 점수 급증의 동시 출현"(자연 텍스트)은 이 토이로 재현하지 못했습니다.

**ablation(둘째 사본 손실 증가, 전체 / 패턴 유지, 기준 0.07–0.18):**

| 시드 | 층 1 최대 한 head | 층 0 최대 한 head | 비고 |
|---|---|---|---|
| 0 | head 2: +2.31 / +2.31 | head 2: +1.79 / +0.07 | 층 1 head 2 = prefix 0.41 head. 층 0 head 2(이전 토큰 점수 0.33)는 패턴 유지에서 거의 무영향(K 경로) |
| 1 | head 3: +0.41 / +0.41 | head 1: +1.13 / +0.93 | prefix 0.28 head(층 1 head 3)를 꺼도 +0.41뿐이고 층 0 head 1이 더 큼. 층 0 head 3(이전 토큰 0.33)는 +0.52 / +0.01 |
| 2 | head 3: +0.16 / +0.16 | head 0: +1.48 / +1.41 | prefix 0.19 head(층 1 head 2)는 +0.10. 층 0 head 0이 값(V) 경로로 큰 영향 |

- 시드 0은 "층 1의 induction head + 층 0의 이전 토큰 head" 구조로 논문의 서술과 맞고, 시드 1·2는 다른 구조(값 경로를 통한 층 0 head, 중복)입니다. **head 하나의 ablation 크기를 일반화하면 안 됩니다.**
- 검증 손실도 같이 오릅니다(예: 시드 0의 층 1 head 2 ablation에서 +0.39). 이 head가 반복 구절 외의 자연 텍스트 예측에도 쓰이므로 "induction head를 끄면 ICL만 줄어든다"가 아닙니다. 같은 ablation에서 자연 텍스트 ICL 점수가 0.075에서 약 −0.87로 내려가 늦은 위치 손실이 크게 오르는 것(−0.95)은 이 모델이 후반 위치 예측에 그 head를 많이 쓴다는 뜻이지만, 반복 구절 증강으로 훈련한 결과일 수 있어 일반 모델로 해석하지 않았습니다.

## 4. 평가 지표의 검증 (논문 부록 "Validating head activation evaluators"의 토이판)

- **prefix 점수 대 K-composition 대각합** (논문: 소형 attention-only에서 상관이 좋음). 합성 2층의 층 1 head 20개(5시드 × 4)에서 피어슨 r = 0.77. 한 모델 안의 head들이 비슷해서(같은 모델의 head 4개가 모두 induction) 독립 표본이 아니고, 시드 평균(n = 5)으로 보면 r = 0.87입니다. 시드 1이 prefix 점수가 가장 낮고(평균 0.65) 대각합도 가장 낮습니다(0.19). 약한 증거입니다. 자연 텍스트 + 반복 구절 3시드에서는 **대각합이 가장 큰 head가 모두 prefix 점수가 가장 큰 head**(대각합 6.22, 6.68, 5.60, 나머지 head는 −0.9–1.25)입니다. 이 경우 지표가 induction head를 매우 선명하게 고르는 반면 prefix 점수의 절대값(0.19–0.41)은 낮았습니다.
- **고유값 copying 대 logit copying**. 합성 2층의 head 40개에서 r = 0.86, 자연 텍스트 모델 head 48개에서 r = 0.37. 1층과 smeared 모델까지 합치면 상관이 없습니다(r = −0.02): 고유값 점수는 0.9 근처로 포화하고(1층 attention-only head의 OV는 거의 모두 복사 행렬) logit 점수만 attend한 토큰에 따라 달라집니다. 논문처럼 고유값을 "복사 능력의 구조적 지표"로 쓰려면 attend 대상(prefix 점수)과 함께 봐야 합니다.

## 6. 한계

- 합성 데이터는 반복을 직접 요구하므로 단계 변화가 쉽게 나옵니다. 논문이 주장하는 자연 텍스트에서의 동시 출현은 우리 토이로 시험하지 못했습니다(§3.2, §3.3).
- 모델은 1층·2층에 위치 임베딩을 잔차에 더하는 학습형 절대 위치 임베딩을 씁니다. 논문의 소형 모델은 위치를 잔차에 더하지 않는 방식이라 GPT-2식 "pointer arithmetic" 구현(L805–L817)도 가능한 모델입니다. 학습된 head가 어느 쪽 구현인지는 가리지 않았고, prefix 점수가 높은 head가 K-composition 항으로 설명되는 정도만 §4에서 봤습니다.
- 지표 정의의 정규화가 논문과 달라(`01` D3) 논문 표의 수치와 비교할 수 없습니다.
- 자연 텍스트 설정은 시드 3개, 합성은 5개입니다. 시점 변동의 범위는 이 시드 수의 표본 범위입니다.
- 자연 텍스트 모델의 head ablation은 각 head 하나씩의 효과만 잰 것이고, 묶음 ablation은 합성에서만 했습니다.
