## C1. 분포 보존

- **증명 재유도**: P(받고 x) = q(x)·min(1, p/q) = min(p, q), P(거절하고 x) = (1 − β)·p′(x) = p(x) − min(p, q)(p′의 정규화 상수가 1 − β). 합이 p(x). (`03` §1)
- **우리 검증**: 합성 분포 8개 시나리오(서로소 지지집합, q = 0인 칸, 날카로운 p, greedy 포함)와 γ ∈ {0, 1, 3, 5}의 3토큰 결합분포, Pythia 14M/70M/160M의 top-10 표준화 처음 2토큰에서 모두 정확한 분포와 구별되지 않았습니다(Holm 후 p ≥ 0.15). 같은 표본 크기에서 틀린 변형 3개(residual 없음, q 재표집, 항상 수락)는 p < 1e-300으로 걸렸습니다.
- **이후 문헌**: Chen et al.의 초록은 "modified rejection sampling scheme which preserves the distribution of the target model within hardware numerics"라고 씁니다. 같은 알고리즘의 독립 발견입니다(Leviathan v2 §6도 이를 인용). SpecTr(arXiv:2310.15141, NeurIPS 2023)은 이 방법을 maximal-coupling 문제의 확장으로 다시 정식화합니다(초록).

## C2. α와 효율

- **정의 확인**: α = Σ min(p, q) = 1 − TV(p, q). 우리는 새 발산 D_LK가 총변동 거리와 같음을 보였습니다(`03` §1). 이것이 "새 발산"이 아닌 TV에 새 이름을 붙인 것이라는 점은 인용할 때 알아 둘 만합니다.
- **우리 유도(최적성)**: 초안 토큰 x ~ q를 받는 사건을 "출력 = x"로 정의하면, 어떤 무손실 방식에서도 P(출력 = 초안 토큰 = x′) ≤ min(q(x′), p(x′))입니다(출력 주변분포가 p이고 초안 주변분포가 q이므로 결합확률은 두 주변확률 중 작은 쪽 이하). 합하면 수락 확률 ≤ α이고 Alg. 1이 이 상한에 도달하므로, **단일 초안 토큰 수준에서 Alg. 1의 수락 확률은 무손실 방식 중 최대**입니다(maximal coupling). 논문은 이것을 명시하지 않습니다. 이후 문헌: SpecTr가 같은 틀에서 초안이 k개일 때의 최적 수락 규칙을 다룹니다(초록: 단일 초안 규칙의 확장, 최적 수락은 선형계획, (1 − 1/e)-최적 근사 알고리즘). 우리 유도는 k = 1에 한정됩니다.
- 부록 A.2: 비반복 rejection sampling도 분포는 p지만 수락률 1/M ≤ α (`03` §2).

## C3. "분포가 같다"의 범위

- 분포 보존은 **정확한 산술**에서의 보장입니다. 검증 호출(접두사 + γ개 추측을 한 번에)과 일반 디코딩(접두사만, 또는 KV 캐시로 한 토큰)은 같은 위치에서 부동소수점상 조금 다른 p를 냅니다.
- **우리 측정**(`numerics_check.py`, Pythia-70M, 문서 100개의 위치 31): 캐시 없이 32토큰 대 40토큰을 넣은 호출은 float32와 bfloat16 모두 TV 0(비트 단위로 같음). **KV 캐시로 1토큰 대 9토큰을 넣은 호출은 float32에서 TV 평균 1.2e-4(최대 4.1e-4), 최대 확률의 상대 차이 최대 0.11%**, argmax 뒤바뀜 0/100이었습니다(bfloat16은 0). 이 크기는 §6.3의 표본 잡음(TV 0.03)보다 훨씬 작아 샘플링에서 보이지 않지만, "문자 단위로 같은 출력"의 보장은 아닙니다. greedy에서는 두 후보 로짓이 거의 같을 때 뒤바뀔 수 있어 문장 단위 일치가 부동소수점에서 깨질 수 있습니다(우리 측정에서는 20개 greedy 설정이 모두 일치했지만 이는 이 CPU 경로에서 한정).
- Chen et al.의 "within hardware numerics" 단서가 같은 점을 말합니다(초록).
- 따라서 인용할 때는 "출력 분포가 같다(정확한 산술)", "같은 시드에서 같은 문장"이 아님으로 쓰는 것이 정확합니다.

## C4. 식의 예측력

- **Thm 3.8 자체**는 유도가 맞고 Table 1은 정확히 재현됩니다. Table 4의 EXP 12행은 α, c의 반올림 범위에서 재현됩니다(`03` §5).
- **실측 EMP와의 차이**: 12행 중 5행만 ±15% 안이고, EnDe T5-large는 30–32% 낮습니다(EMP/EXP 0.68–1.29). 저자는 "대체로 맞는다"고 썼습니다(부록 A.3). 같은 표에서 EMP가 EXP보다 큰 행이 8개라 식이 일관되게 낙관적이지도 비관적이지도 않습니다.
- 우리 Pythia 측정: 반복당 토큰 수(식 (1))는 5–10% 안으로 맞고(관측과 −11%–+4%), 시간 예측(Thm 3.8)은 이 CPU에서는 하드웨어 가정이 깨져 맞지 않습니다(C6).

## C5. i.i.d. 근사

- 저자 표현은 "simplifying assumption … only an approximation"입니다(§3.1, 부록 A.3).
- **우리 측정**(Pythia, 실제 디코딩, 프롬프트 60개): 위치별 평균 β가 j와 함께 단조 증가(70M, T = 1, γ = 5에서 0.586 → 0.653, 첫째와 다섯째 위치의 95% CI가 겹치지 않음), n 히스토그램이 geometric과 TV 0.02–0.10 다름(T = 0에서 최대). 그래도 반복당 토큰 수는 식 (1)이 5–10% 안으로 맞췄습니다(`03` §6.2).
- 판정: 가정은 데이터로 기각되지만 평균 토큰 수 예측에는 쓸 만합니다. 식에 넣는 α의 정의(첫 위치 β 대 평가된 모든 위치의 평균)에 따라 예측이 약 5%(T = 1)–15%(T = 0) 달라집니다.

## C6. 병렬 검증이 공짜

- 논문은 Thm 3.8의 가정으로 명시합니다("we can run γ + 1 concurrent evaluations of Mp in parallel without increasing the walltime"). 하드웨어 가정입니다.
- **우리 측정**: 이 맥 CPU에서 Pythia 70M의 1토큰 대 2토큰 이상 호출 시간은 4.5배, 160M은 6.1배 차이(스레드 1–8개 모두에서 같은 도약)로 가정이 성립하지 않았고, 검증 비용을 넣으면 모든 γ에서 속도가 0.4–0.7배였습니다(`03` §6.4). 가정이 성립하는 장치(메모리 대역폭 병목, 병렬 계산 여유)는 이 측정으로 검증하지 못했습니다.

## C7. 초안 모델의 조건

- 논문은 "초안은 목표보다 약 두 자릿수 작은 것이 보통 최선"이라 쓰고(§3.6) 기성 소형 모델을 초안으로 씁니다.
- **우리 측정**은 크기 비 1 : 5(14M/70M)와 1 : 11(14M/160M)이라 이 영역이 아닙니다. c가 0.34와 0.145로 커서 최적 γ가 1–3이고 이득이 작았습니다(`03` §6.4). 두 자릿수 영역에서의 α·c 균형은 검증하지 못했습니다.
- **이후 문헌**: Medusa(arXiv:2401.10774)는 별도 초안 모델을 얻고 유지하는 어려움을 문제로 삼아 목표 모델에 디코딩 헤드를 붙입니다(Medusa-1은 동결 백본에서 무손실이라고 주장, 초록). EAGLE(arXiv:2401.15077)은 특징 수준 초안으로 LLaMA2-Chat 70B에서 2.7–3.5배 지연 속도 향상을 보고합니다(초록, 분포 유지 주장). DistillSpec(arXiv:2310.08461)은 초안을 증류해 정렬하면 표준 SD보다 10–45% 속도 향상을 보고합니다(초록). 즉 "기성 소형 모델을 그냥 쓴다"는 이 논문의 방식은 후속 연구에서 학습으로 개선되는 지점입니다. 이들 수치는 초록 수준으로만 읽었고 직접 확인하지 않았습니다.

## C8. lenience (부록 A.5)

- **상한 보장 확인(우리 검증)**: 수락 확률 min(1, p/(l·q)), 거절 시 norm(max(0, p − l·q))이면 모든 토큰의 출력 확률이 p/l 이하이고 l = 1이면 p와 정확히 같습니다(분포 쌍 100개 × l 4개, `03` §2). 논문은 거절 분포를 적지 않았고 이 선택이 보장을 만족합니다.
- **분포는 바뀝니다**(저자도 인정). "최소 확률 보장은 없다"(저자 문장)이므로 희귀 토큰이 사라질 수 있습니다.
- **Table 5**: T = 0 열(γ = 8, c = 0.015)은 식으로 재현(3.30, 3.30, 3.87, 4.91 대 3.3, 3.3, 3.9, 4.9)되지만 **T = 1 열(2.5, 3.1, 3.6, 5.0)은 Thm 3.8로 재현되지 않습니다**(최적 γ에서도 2.33, 2.94, 3.45, 4.79, `03` §5).

## C9. 실측 속도

- Table 2의 1.4–3.4배는 TPU-v4, T5-XXL, 배치 1, 저자의 T5X 구현 대비 값입니다. 우리는 TPU도 T5도 쓰지 않고 공식 코드도 없어서 **재현하지 못했습니다**(GPU·TPU는 규칙상 금지).
- 같은 시기 독립 구현(Chen et al.)은 Chinchilla 70B 분산 설정에서 2–2.5배를 보고합니다(초록). 서로 다른 모델·하드웨어에서 같은 범위의 이득이 나왔다는 점이 이 논문의 주장을 간접적으로 지지합니다(독립 재현은 아님: 같은 알고리즘의 두 구현이고 기준선이 다름).
- 우리 CPU 측정은 C6처럼 이득이 없었습니다. 이것은 논문과 모순이 아니라 전제 조건이 다른 장치입니다.
