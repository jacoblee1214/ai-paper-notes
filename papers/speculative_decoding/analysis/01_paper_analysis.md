# 01. 논문 분석: Fast Inference from Transformers via Speculative Decoding

Leviathan, Kalman, Matias (Google Research). arXiv:2211.17192v2(2023-05-18), ICML 2023 구두(PMLR 202:19274–19286). 분석 대상은 v2(최신, 판은 2개)입니다. 아래 식·표·절 번호는 이 판의 번호입니다.

## 1. 문제

큰 자기회귀 모델에서 K개 토큰을 만들려면 모델을 K번 순차로 돌려야 합니다. 저자들의 관찰은 둘입니다(§1).

1. 언어 모델링에는 작은 모델이 잘 근사하는 쉬운 단계가 섞여 있습니다.
2. 큰 모델의 디코딩 한 단계는 산술 연산이 아니라 메모리 대역폭·통신이 병목이라서, 같은 시간에 더 많은 토큰 위치를 병렬로 계산할 여유가 있습니다.

그래서 **모델 구조도 학습도 출력 분포도 바꾸지 않고** 지연만 줄이는 방법을 찾습니다. 기존의 적응형 계산(조기 종료 등)은 구조·학습을 바꾸고 출력도 바뀌며(§5), Blockwise Parallel Decoding(Stern et al., 2018)은 greedy만 지원하고 별도 학습이 필요합니다.

## 2. 방법

### 2.1 표준화 샘플링 (§2.2)

argmax, top-k, nucleus, 온도는 모두 "조정된 분포 p(x)에서의 표준 샘플링"으로 바꿔 쓸 수 있다고 보고, 이후 p, q를 이미 조정된 분포로 둡니다. argmax는 최대가 아닌 원소를 0으로 만들고 정규화한 one-hot입니다.

### 2.2 Speculative sampling (§2.3, 부록 A.1)

x ~ q(x)를 뽑습니다. q(x) ≤ p(x)이면 그대로 받고, q(x) > p(x)이면 확률 1 − p(x)/q(x)로 거절해 **p′(x) = norm(max(0, p(x) − q(x)))** 에서 다시 뽑습니다. 부록 A.1의 증명: P(받고 x = x′) = min(q(x′), p(x′)), P(거절하고 x = x′) = (1 − β)p′(x′) = p(x′) − min(q(x′), p(x′)). 합하면 p(x′)이고, p′의 정규화 상수가 1 − β이므로 q가 무엇이든 성립합니다.

### 2.3 Algorithm 1 (SpeculativeDecodingStep)

1. Mq로 γ개 추측 x₁..x_γ를 자기회귀로 뽑습니다(q_i 저장).
2. Mp를 **한 번 병렬로** 돌려 p₁..p_{γ+1}을 구합니다(접두사 + 추측 i개에 대한 분포).
3. r_i ~ U(0, 1), n = min({i − 1 | r_i > p_i(x_i)/q_i(x_i)} ∪ {γ}).
4. n < γ이면 p′ = norm(max(0, p_{n+1} − q_{n+1})), 아니면 p′ = p_{γ+1}. t ~ p′.
5. prefix + [x₁..x_n, t]를 돌려줍니다.

한 번의 Mp 호출은 최소 1개(t), 최대 γ + 1개 토큰을 만듭니다. 그래서 Mp의 순차 호출 수는 최악에도 기준선보다 늘지 않습니다(§2.1).

## 3. 분석 (§3)

|---|---|---|
| Def. 3.1 | 수락률 β_{x<t}: Mq에서 뽑은 x_t가 받아질 확률 | §3.1 |
| 식 (1) | β가 i.i.d.이고 α = E(β)이면 한 번의 Alg. 1이 만드는 토큰 수는 성공확률 1 − α, 상한 γ + 1인 capped geometric이고 기댓값 (1 − α^{γ+1})/(1 − α) | §3.1 |
| Def. 3.2 / Lemma 3.3 | D_LK(p, q) = Σ\|p − M\|, M = (p + q)/2. D_LK = 1 − Σ min(p, q) | §3.2 |

그 밖의 주장(§3.4): 메모리 접근은 줄 수 있습니다(목표 모델 가중치·KV 캐시를 알고리즘 한 번에 한 번 읽음). 연산량은 늘고, Transformer 디코더에서 Mp 연산(Mq 제외)은 같은 크기 인코더 한 번 이하로 상한이 있습니다. §3.5 끝: 오라클 γ가 있으면 고정 γ보다 약 60%까지 더 좋아질 수 있다고 적었습니다(근거 계산은 없음, 같은 절 각주 4의 조건부).

## 6. 한계 (저자가 인정한 것과 우리가 본 것)

저자: 연산량이 늘어 추가 계산 여유가 없으면 도움이 안 됩니다(§6). 빔 서치와의 호환은 미해결(부록 A.4). γ와 Mq를 고정했고 가변은 후속 과제입니다.

우리가 본 것(분석은 `03`, `04`):

1. **샘플링에 한정된 보장입니다.** 출력 "분포"가 같다는 말은 확률 변수 수준의 동치입니다. 같은 시드에서 같은 문장이 나온다는 뜻이 아니고, 온도 0에서만 문장 단위로 같습니다. 부동소수점·배치 형상에 따른 수치 차이는 이 보장 밖입니다(`04` C3).
2. **식 (1)의 i.i.d. 가정은 근사입니다**(저자도 §3.1, 부록 A.3에서 인정). 우리 측정에서 이 근사의 오차는 온도 1에서는 작고(Pythia, 아래 `03`), 온도 0의 반복 루프에서는 커집니다.
3. **Thm 3.8의 "병렬 검증은 공짜"는 하드웨어 가정입니다.** 가속기에서 메모리 병목이면 맞지만 이 맥 CPU에서는 맞지 않았습니다(`03` §6).
4. **실험은 T5 한 계열의 TPU 측정뿐**이고 속도 비교 기준은 저자 자신의 T5X 구현과의 비교입니다. 공식 코드가 공개되지 않아 재현할 수 없습니다. α는 T5, LaMDA, 작은 GPT류에서만 보고되었습니다(Table 3).
5. **Table 3의 α 측정 방법**("Mp가 생성한 10K 토큰")은 표본이 프롬프트 몇 개에서 나왔는지, 신뢰구간이 있는지 적혀 있지 않습니다.
