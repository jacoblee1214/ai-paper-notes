# On Randomness in Agentic Evals (arXiv:2602.07150) 논문 분석

*Bjarni Haukur Bjarnason, André Silva, Martin Monperrus (KTH). arXiv v3 (2026-03-25), "Published at ICLR 2026 Workshop on Agents in the Wild". 분석한 판본은 v3이고 이전 판(v1 2026-02-06, v2)과의 차이는 확인하지 않았습니다. 이하 쪽·절·표 번호는 v3 기준입니다.*

## 1. 문제

에이전트 벤치마크 점수는 보통 과제마다 한 번 돌린 pass@1입니다(§1). 이 단일 실행 점수가 얼마나 믿을 만한지, 그 흔들림이 어디서 오는지, 몇 번을 돌려야 하는지를 묻습니다. 영역은 SWE-Bench-Verified 500문항 하나입니다(§2.1).

## 2. 방법과 설정

| 항목 | 내용 | 근거 |
|---|---|---|
| 에이전트 | 모델 3개(Qwen3-32B, DeepSWE-preview, Devstral-2-123B) × 스캐폴드 2개(nano-agent, R2E-Gym) | §2.1 |
| 온도 | 모델 권장값(0.6 / 1.0 / 0.2)과 0.0 → 설정 12개 | 표 4 |
| 반복 | 설정당 10회, 총 120회 × 500문항 = 60,000 궤적, 25.58B 토큰, 1.88M 도구 호출 | §2.4 |
| 단일 실행 해결률 | r_j = (실행 j에서 푼 문항 수)/N, N=500 | 식 2 |
| pass@k, pass^k | 문항별 성공 횟수 c_i와 실행 수 m=10으로 계산하는 불편추정 | 식 3 |
| 첫 토큰 분기 | τ_div(i,j) = min{k : t_ik ≠ t_jk} (두 궤적이 처음 달라지는 위치) | 식 4 |
| 필요 실행 수 | 두 표본 z 검정의 n ≥ 2((z_{α/2}+z_β)/(Δ/σ))² | 식 5–11, 부록 A |
| 정규성 | 12개 설정의 10회 해결률에 Shapiro-Wilk, 11개 통과 | 표 3, 부록 B |

- 스캐폴드는 컨텍스트를 줄이지 않는 append-only입니다(§2.1). 컨텍스트 압축이 만드는 분산은 다루지 않습니다.
- 도구 호출 상한은 nano-agent 500, R2E-Gym 100입니다(부록 C). Qwen3-32B와 DeepSWE-preview는 vLLM(A100 80GB 약 3,500 GPU시간), Devstral-2는 Mistral API입니다.

## 3. 결과 (논문이 보고하는 것)

1. **실행 간 분산이 큽니다.** 표 1의 12개 설정에서 10회 해결률의 최소–최대 범위가 2.2–6.0 %p, 표준편차 0.7–1.8 %p입니다(§2.4.1). 온도 0에서도 줄지 않는다고 합니다.
2. **온도 효과는 모델마다 다릅니다.** DeepSWE-preview는 nano-agent에서 31.4% 대 20.4%(11.0 %p, 유의), Devstral-2는 63.5% 대 63.8%(차이가 잡음 안)입니다(§2.4.1).
3. **pass@5와 pass^5의 격차가 큽니다.** DeepSWE-preview/R2E-Gym은 pass@1 34.4%, pass@5 52.9%, pass^5 15.5%입니다(그림 1). 12개 설정에서 pass@1→pass@5 최대 증가는 24.9 %p(Devstral-2/R2E-Gym 온도 0)입니다(§2.4.2).
4. **분기는 매우 일찍 일어납니다.** 두 실행이 처음 달라지는 토큰 위치의 중앙값이 DeepSWE-preview nano-agent에서 5(온도 1.0, 궤적의 0.5%), 56(온도 0)입니다(그림 2). 그 뒤 다른 전략으로 갈라진 사례를 하나 제시합니다(그림 3, django-9296).
5. **권고 세 가지**(§3.2): 과제마다 여러 번 돌려 pass@1을 추정, 검정력 분석으로 실행 수 결정(표 2: 2 %p는 9회, 1 %p는 36회, σ=1.5 %p, α=0.05, 검정력 80%), pass@k와 pass^k를 함께 보고.

## 5. 한계 (논문이 인정한 것과 우리가 본 것)

- **논문이 인정:** 컨텍스트 압축 미포함, 긴 과제 확장은 future work(결론), 비용 증가(§3.2). n=10에서 Shapiro-Wilk는 검정력이 낮다(부록 B).
- **도메인:** SWE-bench Verified 한 벤치마크입니다. 다른 에이전트 과제(도구 사용, 웹, 장기 계획)로의 일반화는 보이지 않았습니다.
- **분산의 정의:** σ는 "같은 문항 500개에 대한 실행 간" 표준편차입니다. 문항을 모집단에서 뽑았다는 불확실성은 들어 있지 않아, 표 2의 "필요 실행 수"는 이 500문항에 한정한 판정에만 맞습니다 (`03` §6).
- **비교 대상이 모델 하나·설정 하나의 반복:** 같은 모델을 다시 돌리는 분산을 쟀을 뿐, 학습 시드, 프롬프트 변형, 서로 다른 모델 사이의 순위 안정성은 재지 않았습니다.
- **분산의 원인 분해는 정성적:** 분기 위치(그림 2)와 사례 하나(그림 3)로 "초기 분기 → 연쇄"를 보였으나, 분기가 해결 여부로 이어지는 비율이나 인과를 재지 않았습니다.
- **공식 라이선스·코드:** 코드 저장소와 결과 데이터는 공개되어 있습니다(`04`). 저장소는 라이선스 파일이 없습니다.
