# 04. 주장 검증: 이후 문헌과 이 저장소 재계산의 확인·수정·반박 (C1–C10)

## 판정 요약

- **살아남은 것:** CLT SE와 군집 SE의 형태(C2), 짝지은 비교의 유용성(C4), 분산 분해와 K번 샘플링(`03` §4), 보고 형식(C1).
- **한정된 것:** CLT·군집 SE는 문항·군집 수가 적으면 과소(C3), 온도 권고는 분산 측면에서만 실측 확인(C5), 문항 모집단 가정은 군집 정의에 민감(`03` §8.1).
- **고쳐야 하는 것:** 4.2절 감소율 산술(C6)과 5절 문항 수 예시(C7), 부록 C의 ω̂² 편향(`03` §4.2), 표 2·5의 HumanEval 행(`03` §1.1, §3.4).
- **한계:** 이후 문헌 검색은 웹 검색 3회와 arXiv API 조회로 제한했고, 논문을 인용한 문헌을 체계적으로 모으지 못했습니다(인용 그래프 접근 없음). Bowyer 외 항목은 초록·문서 수준입니다.

## 재현 제안 (실행하지 않음)

- 사용자 승인이 필요한 일: 실제 LLM으로 다음 토큰 확률 점수(§3.2)와 문항당 K번 샘플링의 분산 감소를 MATH·MGSM 같은 평가에서 실측하는 것(API 호출 비용, 외부 전송). 이 논문의 핵심 새 주장 중 이 저장소에서 실측하지 못한 부분입니다.
- 승인이 필요 없는 일(CPU): 군집 수가 매우 적은 설계(G=4–8)에서 Bowyer식 군집 베이즈 대 군집 SE + t 보정의 coverage 비교(토이).
