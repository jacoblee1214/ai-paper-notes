# 01. 논문 분석: Adding Error Bars to Evals (arXiv:2411.00640)

Evan Miller (Anthropic), *Adding Error Bars to Evals: A Statistical Approach to Language Model Evaluations*. arXiv v1 (2024-11-01, stat.AP, cs.CL 교차), 14쪽, 판본은 v1 하나뿐입니다. 학회 표기는 찾지 못했습니다(`README` 참고). 같은 내용의 Anthropic 엔지니어링 글이 2024-11-19에 올라왔습니다. 공식 코드는 없고, 표 1·2·3·5는 가상의 모델 "Galleon"과 "Dreadnought" 수치입니다. 표 4만 실제 Anthropic 모델의 수치입니다.

## 1. 문제

LLM 평가는 "가장 높은 숫자가 최고" 식으로 보고되고(§1) 점수의 통계적 유의성을 따지지 않습니다. 평가는 곧 실험이므로 실험 분석·계획 문헌의 도구(표준오차, 군집 보정, 짝지은 비교, 검정력)를 가져오자는 것이 논문의 요지입니다. 독자는 "통계 훈련을 조금 받은 연구자"입니다(초록).

## 2. 틀: 문항은 보이지 않는 초모집단에서 뽑힌 표본 (§2, 초록)

- 문항 i의 점수 s_i = x_i + ε_i. x_i는 문항이 주어졌을 때의 조건부 평균, ε_i는 영평균 잡음이고 분산 σ_i² = Var(ε_i)가 조건부 분산입니다(§2.1).
- µ = E[s] = E[x]를 추정합니다. 평균 s̄가 추정량이고 문항이 독립이면 중심극한정리로 SE가 나옵니다.
- 이 틀의 핵심 가정: (a) 문항이 초모집단에서 독립으로 뽑힘(고정된 문항 집합이 아님), (b) 군집은 독립으로 뽑힘(§2.2), (c) 한 문항에 대한 두 모델의 잡음은 서로 무상관(§4.2, "cross-model residuals are uncorrelated").

## 3. 식 (논문 번호 그대로)

| 식 | 내용 | 절 |
|---|---|---|
| (1) | SE_CLT = sqrt(Var(s)/n), Var는 1/(n-1) 표본 분산 | §2.1 |
| (2) | 이진 점수: SE_Bernoulli = sqrt(s̄(1-s̄)/n). Llama 3 보고서가 분수 점수(F1)에도 이 식을 써서 보수적(과대)이라 지적 | §2.1 |
| (3) | CI95 = s̄ ± 1.96 SE | §2.1 |
| (4) | 군집 SE: SE² = SE_CLT² + (1/n²) Σ_c Σ_i Σ_{j≠i} (s_ic − s̄)(s_jc − s̄) | §2.2, 부록 A |
| 3절 식 | Var(µ̂) = Var(s)/n = (Var(x) + E[σ_i²])/n (전체 분산 법칙) | §3 |
| 3.1절 식 | 문항당 K번 샘플링하고 평균하면 Var(s_i) = σ_i²/K. 균등 난이도 이진 예에서 Var(µ̂\|K) = Var(µ̂\|K=1) × (1+2/K)/3 | §3.1 |
| (5), (6) | 두 모델 차이의 CI와 z. 비짝 SE_{A−B} = sqrt(SE_A² + SE_B²) | §4.1 |
| (7) | 짝지은 SE: 문항별 차이 s_A,i − s_B,i의 SE | §4.2 |
| 4.2절 식 | Var(paired) = Var(unpaired) − 2Cov(x_A, x_B)/n. 같은 값: SE_paired = sqrt(SE_A² + SE_B² − 2 SE_A SE_B Corr) | §4.2 |
| (8) | 짝지은 군집 SE: (1/n) sqrt(Σ_c Σ_i Σ_j (d_ic − d̄)(d_jc − d̄)), d는 문항별 차이 | §4.2 |
| (9) | 필요 문항 수 n = (z_{α/2} + z_β)² (ω² + σ_A²/K_A + σ_B²/K_B)/δ², ω² = Var(x_A) + Var(x_B) − 2Cov(x_A, x_B) | §5, 부록 B |
| (10) | 최소 검출 효과 δ = (z_{α/2} + z_β) sqrt((ω² + σ_A²/K_A + σ_B²/K_B)/n) | §5 |
| 부록 C | 군집 보정 ω²_clustered, σ²_clustered와 이전 데이터(K≫1)에서의 추정법 | 부록 C |

## 4. 권고 (§1 목록, §3.3, §6)

1. CLT로 평균의 표준오차를 계산하고 점수 아래 괄호에 적는다(표 2). 부트스트랩은 복잡한 표집이나 추정량이 아니면 불필요.
2. 문항이 같은 지문·원문을 공유하면 군집 SE를 쓰고 군집 수를 문항 수와 함께 적는다(표 3). 실제 Anthropic 모델에서 군집 SE는 단순 SE의 최대 3.05배(DROP), 1.10배(RACE-H), 1.88배(MGSM)입니다(표 4).
3. 분산 줄이기: 문항당 K번 재샘플링해 문항 평균 위에서 SE를 낸다(KN개를 풀링하면 안 됨, §3.1). 사고 연쇄가 없는 평가는 정답 토큰의 다음 토큰 확률을 점수로 쓰면 문항 안 분산이 0이 된다(§3.2).
4. 온도를 낮춰 분산을 줄이지 않는다(§3.3): 문항 안 분산이 문항 간 분산(바꿀 수 없는 항)으로 옮겨 가거나 편향이 생긴다.
5. 두 모델을 비교할 때는 문항별 짝지은 차이로 추론하고, 차이·SE·CI·점수 상관을 표로 보고한다(표 5).
6. 검정력 분석으로 필요한 문항 수·K, 또는 주어진 n에서의 최소 검출 효과를 정한다. 예: 새 평가는 약 1,000문항 이상이 좋다(§5).

## 6. 한계 (이 분석이 본 것)

- 정당화가 점근적입니다. CLT와 군집 SE 모두 문항·군집 수가 적을 때의 행동을 다루지 않습니다(논문은 "large number of questions"만 언급, §2.1). 이후 문헌이 이 부분을 비판했습니다(`04` C3).
- 군집 SE는 군집이 초모집단에서 무작위로 뽑혔다는 가정을 합니다. 고정된 하위 집합(저장소 12개 등)에는 이 가정이 맞지 않을 수 있습니다(`03` §6).
- 짝지은 분산 감소의 4.2절 산술 예와 5절 검정력 예에 연결된 값이 어긋납니다(`03` §3.3, §5.2).
- 다중 비교, 점수가 이진이 아닐 때의 정당화, 모델 간 잡음 상관(같은 하네스·같은 시드), LLM 판정자 같은 평가 오류는 다루지 않습니다.
- 본문 식 (4)의 SE_CLT는 1/(n−1), 부록 A의 첫 항은 1/n²로 n/(n−1)배 어긋나지만 실질 영향은 없습니다.
