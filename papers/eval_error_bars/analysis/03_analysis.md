## 1. 식 (1)–(3): 평균의 SE

- 식 (1) SE = sqrt(Var(s)/n)에서 Var는 1/(n−1) 표본 분산입니다. 이진이면 Var(s) = n/(n−1)·s̄(1−s̄)이므로 식 (2)에 sqrt(n/(n−1))을 곱한 값과 같습니다(테스트 `test_bernoulli_is_clt_scaled`). n=2,294에서 차이는 0.02%입니다.
- 분수 점수에 식 (2)를 쓰면 과대: Beta(5,2) 점수 2,000개에서 SE_Bernoulli/SE_CLT = 1.3 이상(테스트). 논문이 Llama 3 보고서를 지적한 내용이 맞습니다(§2.1).
- 이진 점수에서 CI95 포함률은 n=300, p=0.6에서 시뮬레이션 0.935–0.965 안(테스트).

## 2. 식 (4): 군집 SE

### 2.1 유도 (부록 A)

si,c = µ + δ + ε에서 잔차 u = s − s̄, X = 1_n이면 샌드위치 추정량이 (X'X)⁻¹(Σ_c X_c' u_c u_c' X_c)(X'X)⁻¹ = (1/n²) Σ_c (Σ_i u_ic)²입니다. 군집 안 합의 제곱을 대각항(i=j)과 교차항(i≠j)으로 나누면 대각항의 합 = Σ u²/n²는 단순 분산이고, 식 (4)의 SE_CLT²는 1/(n−1)을 쓰고 부록 A는 1/n을 써서 n/(n−1)배만 다릅니다(`01` §6). `minimal_impl.se_clustered`는 교차항 = Σ_c(Σu)² − Σu²로 O(n)에 계산하고, 12문항 예에서 명시적 삼중합과 일치함을 확인했습니다(`test_clustered_cross_term_matches_explicit_triple_sum`). 문항마다 군집이 다르면 식 (1)과 같습니다(테스트).

### 2.2 설계 효과와 표 4

군집 크기가 m으로 같고 군집 내 상관이 ρ이면 군집 SE²/단순 SE² ≈ 1 + (m−1)ρ입니다(시뮬레이션: 400개 군집, m=10, ρ=0.5에서 설계 효과가 이론 5.5의 ±15% 안, 테스트). 이를 표 4의 비율에 거꾸로 적용하면 내재 군집 내 상관은 다음과 같습니다(군집당 문항 수는 표 3의 문항·군집 수).

| 평가 | 비율(표 4) | 설계 효과 = 비율² | 군집당 문항 m | 내재 ρ = (deff−1)/(m−1) |
|---|---|---|---|---|
| DROP | 3.05 (1.34/0.44 = 3.045) | 9.27 | 16.4 (9,622/588) | 0.54 |
| RACE-H | 1.10 (0.51/0.46 = 1.109) | 1.23 | 3.35 (3,498/1,045) | 0.10 |
| MGSM | 1.88 (1.62/0.86 = 1.884) | 3.55 | 10 (2,500/250) | 0.28 |

표 4의 세 비율은 SE 값에서 재계산되며 일치합니다. 군집 구조와 점수 상관이 있으면 "유효 표본 수"는 DROP에서 9,622 → 약 1,040 문항입니다(9,622/9.27).

## 3. 짝지은 차이 (식 (5)–(8))

### 3.1 식 (7)과 상관 형태

식 (7)은 차이 d_i = s_A,i − s_B,i의 평균에 대한 SE이고, 같은 ddof(1/(n−1))를 쓰면 SE_A² + SE_B² − 2 SE_A SE_B Corr와 정확히 같습니다(`test_paired_formula_equals_correlation_form`).

### 3.2 분산 감소와 가정

Var(paired) = Var(unpaired) − 2 Cov(x_A, x_B)/n는 Cov(s_A, s_B) = Cov(x_A, x_B), 즉 같은 문항에서 두 모델의 **잡음 ε_A, ε_B가 서로 무상관**일 때 성립합니다. 같은 시드·같은 하네스·같은 샘플링 부산물이 있으면 Cov(ε_A, ε_B) ≠ 0이라 달라집니다. 또 비짝 SE는 같은 문항을 쓴 두 모델에서는 **과대(보수적)**이고, 문항 집합이 다른 보고서끼리만 쓸 수 있습니다(4.1절 끝).

### 3.3 4.2절 산술 예의 오류

논문: 두 모델의 점수가 U[0,1]이고 조건부 분산 0, 상관 0.5이면 Var(s_A) = Var(s_B) = 1/12, Cov = 0.5·1/12 = 1/24이고 "짝지은 분산이 1/3 줄어 1/6에서 1/9가 된다".

- 올바른 계산: Var(s_A) + Var(s_B) − 2 Cov = 1/12 + 1/12 − 2/24 = **1/12**. 비짝 1/6에서 짝지음 1/12이므로 감소율은 **1/2 = ρ**입니다. 일반적으로 두 분산이 같을 때 감소율은 ρ입니다.
- 몬테카를로(`mc_results.json` E2, 가우시안 코퓰라로 U[0,1] 주변분포, 40만 점): ρ = 0, 0.25, 0.5, 0.75, 0.9에서 감소율 −0.001, 0.250, **0.501**, 0.750, 0.901. 테스트 `test_paired_variance_reduction_is_rho_not_one_third`가 같은 확인입니다.
- 이 오류는 §5의 검정력 예로 이어집니다(§5.2).

### 3.5 식 (8)

식 (8)은 차이 d의 군집 샌드위치 SE (1/n) sqrt(Σ_c(Σ_i(d − d̄))²)입니다. i = j 항을 포함하고 소표본 보정이 없는 CR0입니다. 구현 `se_paired_clustered`는 수작업 계산과 일치(테스트)하고, 군집 100개·군집당 8문항·군집 내 상관 0.4에서 포함률이 0.92–0.965 안입니다.

## 4. 3절: 분산 분해와 K번 샘플링

- Var(µ̂) = (Var(x) + E[σ_i²])/n은 전체 분산 법칙입니다. 문항 i를 뽑은 뒤 K번 샘플링해 평균하면 Var(s_i | i) = σ_i²/K이므로 Var(µ̂) = (Var(x) + E[σ²]/K)/n입니다.
- 균등 난이도 이진 예: x ~ U[0,1]이면 Var(x) = 1/12, E[σ²] = E[x(1−x)] = 1/2 − 1/3 = 1/6이며 논문과 일치합니다. 비율 (1/12 + 1/(6K))/(1/4) = (1 + 2/K)/3. K = 2: 감소 1/3, K = 4: 1/2, K = 6: 5/9, K → ∞: 2/3. 논문 §3.1의 값이 모두 맞습니다.
- 몬테카를로(6,000회, n=200): K = 2, 4, 6에서 분산비가 이론 (1+2/K)/3의 ±8% 안(`test_resampling_reduces_only_within_question_variance`).
- **풀링 경고(§3.1)는 맞습니다.** K=5, n=100에서 KN개를 풀링한 SE는 실제 표준편차의 0.8배 미만이고 문항 평균 위의 SE는 일치(±5%, `test_pooled_se_over_all_samples_is_too_small`).
- 다음 토큰 확률(§3.2): ε = 0이므로 Var = Var(x)/n, 위 예에서 2/3 감소 = K → ∞ 한계와 같습니다. 이 점은 산술로만 확인했고 모델 호출은 하지 않았습니다.

### 4.1 §3.3 "온도를 만지지 마라" 산술

- x_{T=1} ~ U[0,1], x_{T=0} = 1{x_{T=1} > 0.5}: Bernoulli(1/2), Var = 1/4. 1/12에서 1/4로 3배가 맞습니다.
- x_{T=1} ~ U[1/3, 1]이면 E = 2/3, Var = (2/3)²/12 = 1/27입니다. P(x > 0.5) = 0.5/(2/3) = **3/4**이므로 x_{T=0}은 p = 3/4인 Bernoulli(평균 3/4, 분산 3/16, 3/16 ÷ 1/27 = 5.06배). 논문 본문은 "p = 1/4"로 적었는데 **오타**이고 뒤의 E = 3/4, Var = 3/16은 p = 3/4에 맞습니다.
- 이 예는 "온도 0이 문항 간 분산을 키운다"는 구성적 예이지 LLM에서의 실측이 아닙니다. 실측은 `04` C5.

### 4.2 분산 성분 추정과 부록 C의 편향

`variance_components`는 E[σ²]를 문항 안 표본 분산(ddof=1)의 평균으로, Var(x)를 Var(x̂) − E[σ²]/K로 추정합니다. 균등 난이도 이진 예(문항 2만 개, K=8)에서 Var(x) = 1/12, E[σ²] = 1/6의 이론값과 5% 안에서 일치합니다(테스트 `test_variance_components_recovered`). 부록 C가 "x̂로 ω̂²를 추정하면 충분하다"고 쓴 부분은 **x̂의 잡음 σ²/K 만큼 ω²를 과대추정**합니다. 같은 독립 두 모델(ω² = 1/6) 예에서 보정하지 않으면 K=4에서 2·(1/6)/4 ≈ 0.083만큼 커지고(테스트 `test_omega2_estimators_unbiased_with_noise_correction`는 0.03 이상의 차이를 확인), 보정한 `omega2_paired`는 이론값 1/6과 4% 안에서 맞습니다. 부록 C의 σ̂²_clustered는 같은 반복 k의 서로 다른 문항 i, j의 잔차 곱까지 포함하는데, 모델이 문항마다 독립으로 샘플링하면 교차항은 기댓값이 0이라 구현은 대각항만 씁니다.

## 5. 검정력 (식 (9), (10))

### 5.1 유도 (부록 B)

귀무 가설에서 z = s̃/se, 대립 가설에서 z_β = (δ − s̃)/se이며 se = sqrt((ω² + σ_A²/K_A + σ_B²/K_B)/n)입니다. s̃를 소거하면 δ = (z_{α/2} + z_β) se, 즉 식 (10)이고 n을 풀면 식 (9)입니다. 이것은 **정규(z) 근사의 한쪽 꼬리**를 무시한 식입니다. 양측 검정의 반대 꼬리 기여(10⁻⁶ 수준)는 무시해도 되고, 작은 n에서는 t 분포 때문에 검정력이 낮아집니다. 정확한 비중심 t 검정력(MDE를 z 식으로 정한 뒤 계산): n = 10에서 0.70, n = 20에서 0.76, n = 50에서 0.78, n = 969에서 0.799. 논문의 "n이 크다"는 가정 아래서는 문제 없습니다.

### 5.2 논문 예의 산술

- 식 (9)에 ω² = 1/9, δ = 0.03, α = 0.05, β = 0.2: (1.96 + 0.8416)² × (1/9)/0.0009 = 968.998, 논문의 "≈ 969"와 **산술은 일치**합니다.
- 그러나 이 ω² = 1/9는 "§4.2의 조건"(U[0,1], 상관 0.5, 조건부 분산 0)에서 가져온 것인데, 올바른 ω²는 **1/12**입니다(§3.3). 그러면 n = **727**(= 969 × 3/4)입니다. "새 평가에는 약 1,000문항"이라는 권고의 근거 수치는 과대입니다. 일반 지침으로서의 방향은 같습니다(수백~천 문항).
- MDE 예(σ_A² = σ_B² = 1/6, ω² = 1/9, n = 198): K = 1에서 13.27%, K = 10에서 7.57%. 논문은 13.2%, 7.5%(소수 첫째 자리 절사 수준의 차이). ω² = 1/12이면 12.85%와 6.80%입니다.
- 폐쇄식이 시뮬레이션과 맞는지: 이항 점수(난이도 U[0,1], 상관 0.5, δ ≈ 0.03)로 식 (9)가 정한 n(K = 1: 3,634, K = 4: 1,454, K = 16: 909)에서 시뮬레이션 검정력은 0.792, 0.794, 0.791로 식의 역(실제 분산 성분으로 계산한 0.786–0.790)과 맞고 목표 0.8에 가깝습니다(`mc_results.json` E3). 여기서 n이 969·727보다 훨씬 큰 것은 이항 점수의 σ²가 1/6이라 K = 1의 분산 항이 ω² + 2σ² = 0.42로 크기 때문입니다(`test_simulated_power_near_target_at_required_n`은 가우시안 차이로 0.77–0.83).
- 군집 보정 식(부록 C): ω²_clustered를 식 (9)에 넣어 정한 문항 수에서 군집 SE 검정의 검정력이 0.74–0.86(테스트 `test_clustered_sample_size_power`, 군집 내 상관 0.5, 군집당 10문항). 여기서 ω²_clustered는 문항 수로 나눈 군집 합(식 (8)의 제곱 × n)입니다.

### 8.2 반복 실행 (agentic_eval_randomness/ 10번의 결과 JSON, SWE-bench Verified 500문항, 12설정 × 10회)

점수 = 문항별 실행별 해결 여부. 군집 = 저장소(12개)이지만 여기서는 요약만 둡니다.

**분산 분해(식 3절)** — 12설정 중 10개에서 문항 간 분산이 문항 안 분산보다 큽니다(전체 Var(x) 0.082–0.166 대 E[σ²] 0.054–0.120. r2e Devstral 기본·0은 오히려 E[σ²]가 약간 큼). K=10으로 평균하면 단일 실행 대비 분산비 0.53–0.75(균등 이진 예의 이론 K=10 값 0.4에는 못 미침: 문항 안 분산의 비중이 작아서). 실제로 문항 안 분산만 1/K로 줄고 문항 간 분산은 그대로입니다.

대표 행(n=500, SE는 %p):

| 설정 | 해결률 | SE(1회) | SE(10회 평균) | Var(x) | E[σ²] | 분산비 K=10 / K=1 | 실행별 해결률의 실제 SD | 문항 안 분산으로 예측한 SD(sqrt(E[σ²]/n)) |
|---|---|---|---|---|---|---|---|---|
| nano-agent Qwen3-32B | 16.4% | 1.66 | 1.32 | 0.082 | 0.056 | 0.64 | 0.75 | 1.05 |
| nano-agent Devstral | 63.5% | 2.15 | 1.86 | 0.166 | 0.066 | 0.75 | 1.13 | 1.15 |
| r2e-gym Qwen3-32B | 23.9% | 1.91 | 1.42 | 0.092 | 0.090 | 0.56 | 1.45 | 1.34 |

(실행 10회의 표준편차는 표본 SD라 상대 오차 약 24%입니다. 12설정에서 관찰/예측 비는 0.7–1.4배입니다.) 이것은 §4의 "잡음 σ²/n이 실행 간 변동을 설명한다"를 실측으로 확인한 것입니다.

**두 설정의 비교(짝지음과 K, 문항 모집단 기준)**:

| 쌍 (A − B) | 차이 | 비짝 1회 | 짝지은 1회 | 비짝 10회 | 짝지은 10회 | 짝지은 10회+저장소 군집 | 문항 점수 상관 | MDE K=1 | MDE K=10 | MDE K→∞ |
|---|---|---|---|---|---|---|---|---|---|---|
| Qwen3 nano 기본 − 0 | +0.02 | 2.34 | 1.52 | 1.88 | **0.48** | 0.50 | 0.94 | 4.1 | 1.3 | 0.3 |
| Devstral nano 기본 − 0 | −0.28 | 3.04 | 1.65 | 2.62 | **0.54** | 0.52 | 0.96 | 4.6 | 1.5 | 0.4 |
| DeepSWE r2e 기본 − 0 | +15.28 | 2.76 | 2.03 | 2.20 | 1.14 | 1.97 | 0.75 | 5.7 | 3.2 | 2.8 |
| Devstral r2e − nano | −28.60 | 3.03 | 2.26 | 2.43 | 1.33 | 1.28 | 0.71 | 6.3 | 3.7 | 3.3 |
| Qwen3 r2e − nano | +7.52 | 2.53 | 1.83 | 1.94 | 0.87 | 0.73 | 0.80 | 5.1 | 2.4 | 1.9 |
| r2e Devstral − Qwen3 | +11.04 | 2.86 | 2.33 | 2.12 | 1.29 | 1.26 | 0.63 | 6.5 | 3.6 | 3.1 |

(MDE는 식 (10), α=0.05, 검정력 0.8, n=500, ω²·σ²를 이 데이터에서 추정, 단위 %p.)

- **짝지음과 10회 평균의 효과는 함께 쓸 때 가장 큽니다.** 상관이 0.9 이상인 같은 모델의 온도 쌍은 SE가 비짝 1회의 약 5분의 1(2.34 → 0.48, 3.04 → 0.54). 서로 다른 설정의 쌍은 비짝 1회에서 짝지은 10회로 2.2–2.9배 감소합니다.
- **이 논문의 식 (10)으로 보면 1회 실행의 MDE는 4–6.5 %p, 10회 평균은 1.3–3.7 %p입니다.** 10번 분석(`agentic_eval_randomness/` 인용 카드 4번)이 "10회면 약 2 %p 개선을 80% 검정력으로 탐지한다"고 한 것은 **문항 500개를 고정**한 실행 잡음만의 계산이고, 문항 표본 오차(ω²)를 넣으면 쌍에 따라 1.3–3.7 %p입니다. 같은 설정의 쌍은 ω² ≈ 0이라 1.3–1.5입니다. 2 %p를 탐지하려면 K=10에서도 문항 수는 223–285(같은 모델 쌍), 743–1,744(다른 설정)이 필요합니다(`n_required`, `apply_results.json`의 `n_for_2pp_k10`).
- 저장소 군집(12개)은 짝지은 10회 SE를 쌍에 따라 0.8–1.7배로 바꿉니다(예: DeepSWE r2e 기본 − 0에서 1.14 → 1.97). 저장소별 효과가 이질적일 때 커집니다. G = 12에서 이 값의 신뢰도에는 §8.1의 경고가 그대로 적용됩니다.
- 한 쌍(Devstral r2e − nano, −28.6 %p)은 하네스가 다른 비교라 "차이가 크다" 외의 추론은 의미가 없고, 효과가 SE의 20배 이상이라 검정력의 문제가 아닙니다.

### 8.3 이 적용이 보여 준 것

1. 짝지은 비교의 이득은 **점수 상관에 달려** 있습니다. 이진 점수이고 해결률이 낮은 SWE-bench BM25 기준선(상관 0.2–0.3)에서는 SE 11–15% 감소, 같은 설정을 반복한 쌍(0.9 이상)에서는 SE 약 3–4배 감소입니다. "공짜 감소"이긴 하지만 논문이 말한 0.3–0.7 상관(블로그)이 모든 평가에서 나오지는 않습니다.
2. K번 반복은 문항 안 분산만 줄입니다. 실행 1회와 10회 평균의 SE 비는 12설정에서 1.15–1.36배에 그칩니다(문항 간 분산이 지배).
3. 군집 SE는 군집을 어떻게 정의하느냐(저장소 = 무작위 추출인가 고정 층인가)와 군집 수에 크게 의존합니다.
