# 02. 계보, 가까운 대안, 구성 요소의 출처, 관련 분석

## 1. 계보 (이 논문이 어디에 서 있나)

```
Hyvarinen 2005 점수 매칭 ── Vincent 2011 잡음 제거 점수 매칭 ──┐
Sohl-Dickstein 2015 확산 확률 모형 ──┐                         ├─→ Song & Ermon 2019 NCSN (SMLD)
Anderson 1982 역방향 확산 SDE ───────┤                         │      · 2020 NCSNv2
Chen 2018 신경 ODE · Grathwohl 2018 FFJORD(허친슨 대각합)       │
Ho 2020 DDPM (VP의 이산화) ─────────────────────────────────────┤
                                                               ▼
                 이 논문 (Song 2021, ICLR 2021 구두·우수 논문): 연속 시간 SDE로 통일
                  · 역방향 SDE · PC 표집기 · 확률 흐름 ODE(정확한 우도) · 조건부 생성
                                                               │
   ┌──────────────────┬──────────────────────┬────────────────┴───────────────┐
   ▼                  ▼                      ▼                                ▼
DDIM (Song 2021,   Song 2021b 우도 가중치   Karras 2022 EDM, Lu 2022 DPM-Solver,   Flow Matching (Lipman 2022),
같은 ICLR 2021)    VDM (Kingma 2021)        DEIS (Zhang & Chen 2022)              Rectified Flow (Liu 2022),
확률 흐름의 이산화  우도 중심 재설계         PF-ODE 풀이기와 설계 공간             Stochastic Interpolants (Albergo 2022)
                                                                                 ──→ SD3 (`../sd3_rectified_flow/`), MeanFlow (`../meanflow/`)
```

- **이 논문이 새로 한 것.** (1) 두 모델 계열을 같은 연속 SDE 틀의 이산화로 묶었고, (2) 역방향 SDE의 이산화를 일반 풀이기와 교정기로 분리했으며, (3) 같은 주변분포를 갖는 결정적 ODE를 제시하고 우도·인코딩에 썼고, (4) 점수 모델 하나로 조건부 생성(식 49)을 했습니다. 역방향 SDE 자체(Anderson 1982), 신경 ODE의 순간 변수 변환(Chen 2018), 허친슨 추정(Grathwohl 2018)은 선행 도구입니다.
- **같은 시기 병행 연구.** DDIM(Song, Meng, Ermon, arXiv:2010.02502, ICLR 2021)은 같은 학습 목표로 결정적 표집을 얻고, 이후 판에서 ODE와의 연결을 적었습니다. 두 논문은 PF-ODE를 서로 다른 방식으로 유도했습니다. DDIM은 비마르코프 순방향 과정에서, 이 논문은 포커-플랑크 방정식 비교에서 얻습니다. DDIM 분석은 같은 묶음에서 작성 중입니다.
- **이후 논문이 바꾼 것.** 우도 가중치(Song 2021b, arXiv:2101.09258), 설계 공간과 풀이기 선택(EDM, arXiv:2206.00364, DPM-Solver, arXiv:2206.00927), 경로·목표의 재정의(flow matching, 정류 흐름). `04`에 주장별로 정리했습니다.

## 2. 구성 요소별 출처

| 구성 요소 | 출처 | 이 논문의 변경 |
|---|---|---|
| 점수 추정 목표 | 잡음 제거 점수 매칭(Vincent 2011), NCSN | 연속 시간 가중 합(식 7), $\lambda\propto 1/\mathbb E\|\nabla\log p_{0t}\|^2$ |
| 어닐링 랑주뱅 | Song & Ermon 2019 | 교정기로 재해석, 신호 대 잡음비 $r$로 스텝 크기를 정함(알고리즘 4–5) |
| 조상 표집 | Ho 2020 (식 4) | VP 역방향 SDE의 한 이산화로 규정(부록 E) |
| 역방향 SDE | Anderson 1982 | 식 6, 일반 확산 행렬은 식 16 |
| 확률 흐름 ODE | Maoutsa 등(2020)에서 영감, 부록 D.1이 일반 형태를 직접 유도 | 식 13, 우도·인코딩에 사용 |
| 정확한 우도 | Chen 2018, Grathwohl 2018 | 점수 모델의 ODE에 적용(식 39–40) |
| 예측기-교정기 | 수치 연속법의 PC 방법(Allgower & Georg) | 이름과 구조 차용, 알고리즘 1–3 |
| sub-VP SDE | 새 제안 | 식 12, VP의 분산 상한 |
| 구조 | NCSN++ (BigGAN형 잔차 블록, FIR 재표본), DDPM++ | 부록 H, 깊이 두 배 |
| 조건부 생성 | 분류기 점수 합(식 49) | 시간 의존 분류기, 인페인팅의 관측 섭동 대체 |

## 3. 가까운 대안 비교

| 방법 | 같은 점 | 다른 점 |
|---|---|---|
| DDPM / SMLD (이산) | 이 논문이 이산화로 포함 | 이산 수준 수에 고정, 표집기가 모델에 종속 |
| DDIM | PF-ODE의 이산화와 같은 업데이트(1차 지수 적분) | 학습 목표는 DDPM, 연속 SDE 틀 없이 비마르코프 과정으로 유도 |
| Flow Matching / 정류 흐름 | 속도장을 따라 ODE를 풀어 표집 | 점수 대신 속도를 회귀하고 경로를 설계함. 가우시안 경로 족이면 속도와 점수가 일대일(`03` §7) |
| Neural ODE / FFJORD | 순간 변수 변환 우도 | 시뮬레이션 기반 학습, 이 논문은 점수 매칭으로 학습 후 ODE 사용 |
| EDM (Karras 2022) | PF-ODE와 같은 틀에서 $\sigma(t)$, $s(t)$ 설계 | 하이퍼파라미터를 분리하고 2차 하운 풀이기, 전처리 도입 |

## 4. 이 저장소와 이웃 저장소의 관련 분석

| 분석 | 관계 |
|---|---|
| `../ddpm/` | 같은 묶음에서 작성 중. VP SDE의 이산화인 DDPM의 ELBO와 단순 손실 |
| `../sd3_rectified_flow/` | 직선 경로 가중 비교. 이 논문의 VP/VE 경로와 같은 가우시안 경로 족의 한 점(`03` §7) |
| `../meanflow/` | 순간 속도 $v$ 대신 평균 속도 $u$. 이 논문의 PF-ODE는 $v$를 점수로 쓴 것(`03` §7.4) |
| `../ddim/`, `../classifier_free_guidance/` | (같은 묶음에서 작성 중) |
| Flow Matching(arXiv:2210.02747)의 별도 분석 | 새로 만들지 않고 연결만 합니다. 그 논문의 일반 가우시안 경로 속도(식 15)와 VP 벡터장(식 19)이 이 분석의 `03` §7에서 닫힌 식으로 확인한 변환과 같은 종류입니다 |
