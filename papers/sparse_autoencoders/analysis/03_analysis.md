# 03. 식 검산과 최소 구현 결과: Sparse Autoencoders (arXiv:2309.08600)

구현 모드. 식을 유도해 검산하고, PyTorch 최소 구현(`analysis/minimal_impl.py`, CPU)으로 (a) 정답 있는 합성 데이터, (b) 29번 모델의 activation에서 SAE를 학습해 확인했습니다. 논문의 자동 해석 점수는 LLM API가 필요해 하지 않았고, API 없이 쓸 수 있는 거친 대용 지표를 따로 정의했습니다. 결과 수치는 `results_a.json`, `results_a2.json`, `results_b.json`, `results_c.json`, `results_d.json`에 있습니다(학습 설정 포함). 시드는 합성 시험대 3개, 29번 모델 SAE는 시드 1개(시드 간 일치만 3개)입니다.

## 1. SAE 정의와 정규화 검산

**식**(논문 (1)–(4)). x ∈ R^d, 사전 M ∈ R^{n×d}(행 f_i가 사전 원소, n = R·d), 편향 b ∈ R^n.

- c = ReLU(Mx + b), x̂ = Mᵀc = Σ_i c_i f_i, L = ‖x − x̂‖² + α‖c‖₁, ‖f_i‖ = 1.
- 파라미터 수(d = 128, R = 4): 묶음 n·d + n = 65,536 + 512, 비묶음(인코더 따로) 2·n·d + n = 131,584. 우리 구현의 `SAE(tied=True)`는 `W_enc`가 없고 `encoder_matrix()`가 `W_dec`를 그대로 돌려줌(테스트로 확인).
- 묶으면 인코더 사전활성 = f_i·x + b_i = ‖x‖cos θ_i + b_i(f_i가 단위 노름이므로). 편향 −b_i는 "x가 f_i 방향으로 얼마나 투영돼야 켜지는가"의 문턱입니다.

**왜 노름을 고정하나**(논문 각주 3). 노름을 풀면 (c_i, f_i) → (c_i/s, s f_i)가 x̂를 바꾸지 않고 α‖c‖₁만 1/s배로 줄입니다. 그러면 s → ∞에서 벌점이 0으로 가고 L1이 희소성을 만들 수 없습니다. 노름을 1로 고정하면 이 꼼수가 막힙니다. 우리 구현은 매 step 뒤에 W_dec의 행을 단위 노름으로 되돌리고(`renorm_`), 테스트가 학습 뒤 노름이 1 ± 1e-5임을 확인합니다.

**죽은 특징은 흡수 상태입니다.** 어떤 i에서 모든 x에 대해 f_i·x + b_i ≤ 0이면 c_i ≡ 0이라 (f_i, b_i)로 가는 그라디언트가 없습니다. 게다가 b_i에 대한 L1 항의 그라디언트는 α·P(c_i > 0) ≥ 0이라 켜져 있는 동안 b_i를 계속 낮춥니다(재구성 항이 막아 주지 않는 한). 즉 α가 클수록 특징이 문턱 아래로 밀려 죽기 쉽습니다. 논문이 MLP에서 죽은 특징이 많다고 한 것(부록 C.3, E)과, 이후 문헌이 재샘플링을 도입한 이유와 일치하는 구조입니다(`04` C5). 우리의 (a) 격자에서 α = 1에서 죽은 특징 비율이 R=4에서 8%, R=8에서 12%로 오르는 것이 이 방향의 증거입니다(§5).

## 2. L1 페널티의 수축(shrinkage) 편향

**한 특징, 직교 사전.** 정답 방향 {g_i}가 정규직교이고 x = Σ a_i g_i, a_i ≥ 0라 하고 사전이 D = G라면 식 (4)는 특징별로 분리됩니다.

  L = Σ_i [(a_i − c_i)² + α c_i],  c_i ≥ 0 ⇒ ∂/∂c_i = −2(a_i − c_i) + α = 0 ⇒ **c_i\* = max(a_i − α/2, 0)** (소프트 임계).

- 이 해는 ReLU 인코더 c_i = ReLU(g_i·x + b_i)에서 b_i = −α/2일 때 정확히 표현됩니다(g_i·x = a_i). 즉 묶은 SAE는 (사전이 맞으면) 고정된 사전에 대한 식 (4)의 전역 최소를 인코더로 낼 수 있습니다.
- **수축**: 켜진 특징의 크기가 α/2만큼 작게 추정되고, a_i < α/2인 약한 활성은 0으로 잘립니다. 재구성 오차는 a_i > α/2이면 (α/2)², 아니면 a_i².

**a ~ U[0,1], 켜질 확률 p**(30번 `generate_batch`의 분포)에서 t = α/2 ≤ 1일 때, 특징 n개 직교 사전:

| 양 | 식 |
|---|---|
| 표본당 재구성 오차 | n p [t³/3 + t²(1 − t)] |
| 총분산 | n (p/3 − p²/4) |
| FVU | [t³/3 + t²(1−t)] / (1/3 − p/4) ≈ 3t² − 2t³ (p ≪ 1) |
| 평균 L0 | n p (1 − t) |
| c를 a에 회귀한 기울기 | E[c a]/E[a²] = 3[(1−t³)/3 − t(1−t²)/2] (`shrinkage_theory`) |
| FVU–L0 곡선 | (p ≪ 1) FVU ≈ 3(1 − L0/L0⁰)² − 2(1 − L0/L0⁰)³, 이 곡선에 꺾임이 없음 |

마지막 줄은 논문 부록 B가 본 "α를 훑으면 희소도와 정확도가 매끄럽게 교환되고 무릎이 없다"(그림 6, 7)의 한 설명입니다. 크기 분포가 U[0,1]처럼 매끄러우면 어떤 α에서도 특징이 "켜졌다 꺼졌다"의 이산 구조를 보이지 않으므로 L0–FVU 곡선에서 정답 α를 읽을 수 없습니다.

**검산(`results_a2.json`).** n = d = 16(직교 정답), p = 0.1, R = 1, 시드 3개, 6,000 step, 6개 α. 표는 시드 평균입니다.

| α | L0 학습 / 이론 | 기울기 학습 / 이론 | FVU 학습 / 이론 | MMCS (정답→학습) |
|---|---|---|---|---|
| 0 | 13.0 / 1.60 | (짝 없음 또는 1.14) / 1.00 | 0.0000 / 0 | 0.569 |
| 0.03 | 1.58 / 1.58 | 0.976 / 0.978 | 0.0011 / 0.0007 | 1.000 |
| 0.1 | 1.53 / 1.52 | 0.919 / 0.925 | 0.0133 / 0.0078 | 0.997 |
| 0.3 | 1.36 / 1.36 | 0.751 / 0.777 | 0.107 / 0.066 | 0.977 |
| 0.6 | 1.09 / 1.12 | 0.515 / 0.563 | 0.335 / 0.234 | 0.933 |
| 1.0 | 0.75 / 0.80 | 0.258 / 0.313 | 0.681 / 0.541 | 0.866 |

- L0와 기울기는 이론과 0.05 이내(α ≤ 0.3에서 0.03 이내)로 맞습니다. 즉 **유도한 수축은 학습된 SAE에서 그대로 나타납니다.**
- FVU는 이론의 1.3–1.7배입니다. 이론값은 사전이 정답과 정확히 같을 때의 값인데, 학습된 사전은 정답과 코사인 0.95–0.99(α = 0.3, 시드 0에서 최소 0.951, 평균 0.975)에서 멈춰 있어 재구성 오차가 더 큽니다. 사전이 완전히 맞지 않는 이유(최적화 부족인지 다른 정류점인지)는 확인하지 않았습니다.
- **α = 0은 정답을 못 찾습니다**(MMCS 0.569, L0 13): 재구성 오차는 0이지만 사전이 정답 기저의 임의 회전이어도 됩니다(직교 기저 둘의 무작위 회전 사이 평균 최대 코사인이 약 0.48이므로 0.569는 거의 우연 수준). 희소성 벌점이 사전을 정답 기저로 고정하는 것은 이 식으로도 설명됩니다.
- α가 크면 MMCS가 떨어지는 것(α = 1에서 0.866)은 수축으로 코드가 작아져 작은 활성이 사라지고 일부 특징의 방향이 어긋나기 때문입니다.

**수축을 푼 후속 방법**(초록 기준, `04` C3): Gated SAE는 "어느 방향을 쓸지"와 "얼마나 쓸지"를 분리해 L1이 방향 선택에만 걸리게 하고, JumpReLU SAE는 문턱을 L0로 직접 학습해 수축 같은 문제를 피한다고 주장합니다. 위 식에서 보면 둘 다 "문턱(α/2)과 크기 추정 사이의 결합"을 끊는 변경입니다.

## 3. 지표 정의

- **FVU** = Σ‖x − x̂‖² / Σ‖x − x̄‖² (x̄는 평가 집합의 평균). 공식 코드의 `fraction_variance_unexplained`와 같은 비(`04` D8). 평균을 빼지 않고 x̂ = 0을 쓰면 FVU = ‖x‖² 합 / 분산 합으로 1을 넘을 수 있음(α = 1의 29번 모델 결과).
- **L0** = E[#{i : c_i > 0}], **죽은 특징 비율** = 평가 집합 전체에서 한 번도 안 켜진 특징의 비율. 논문 부록 E의 "활성 특징"은 1,000만 점에서 10번 넘게 켜진 것이라 정의가 다릅니다.
- **MMCS**(Sharkey et al. 2022 중간 보고에서 도입, 이 논문 본문에는 없음): MMCS(F, D) = (1/G) Σ_g max_j cos(D_j, F_g). 정답 F 대 학습 사전 D. 우리는 **부호 있는** 코사인을 씀(코드가 비음수이므로 −g 방향은 일치가 아님). **우연 수준이 높습니다**: 단위 구에서 무작위로 뽑은 사전이 64개 정답과 갖는 MMCS는 d = 16에서 R = 1, 2, 4, 8에 대해 0.44, 0.50, 0.54, 0.60이고 d = 32에서 0.37, 0.39, 0.44, 0.49. 그래서 평균만이 아니라 **최대 코사인 > 0.9인 정답의 비율**(`recovered_frac`)을 함께 봅니다(무작위 사전은 이 비율이 0). 방향이 다른 `mmcs(D, G)`(학습→정답, 공식 코드 `mcs_duplicates`)도 기록: 사전이 정답보다 크면 낮아짐.
- **loss recovered** = 1 − (L_rec − L_clean)/(L_abl − L_clean). L_rec는 모델 forward 중 해당 지점의 활성(위치 1 이상)을 SAE 재구성 x̂로 바꿔 끼운 다음 토큰 교차 엔트로피, L_abl은 같은 지점을 영 또는 평균 벡터로 바꾼 값. 1이면 재구성이 원래와 같은 손실, 0이면 활성을 지운 것과 같음. 영 대치는 잔차 흐름에서 매우 약한 기준선(ln_f에 0이 들어가 분포가 무너짐)이므로 **평균 대치를 주 기준**으로 둡니다. 공식 코드에는 이 비율이 없고 L_rec만 있음(`04` D8).
- **자동 해석 점수**(논문 §3, 부록 A): 특징 f의 점수 = 시뮬레이터가 예측한 토큰별 activation과 실제 activation의 상관. 구성: 64토큰 조각 중 상위 20개에서 5개를 GPT-4에 주어 설명을 쓰게 하고, 나머지 5개 상위와 5개 무작위 조각(총 640토큰)에 대해 GPT-3.5급 시뮬레이터가 토큰별 0–10 activation을 예측. 우리는 하지 않았고(API 호출은 승인 필요), §7에서 API 없는 대용 지표를 따로 둠.

## 4. ReLU 인코더와 lasso의 차이

식 (4)를 사전 D에 대해 고정하고 c를 구하는 문제는 lasso이고, 직교 사전에서는 소프트 임계로 닫힙니다(§2). 사전이 직교가 아니면(특징 수 > 차원) lasso의 해는 한 번의 아핀+ReLU로 쓸 수 없습니다. SAE의 인코더는 이 해를 **한 번의 선형·문턱 연산으로 근사(상각 추론)** 합니다. 그래서 정답 사전을 줘도 인코더가 정확한 희소 코드를 못 낼 수 있고, 이 간격이 아래 §5의 "n/d = 4일 때 실패"를 일부 설명할 수 있습니다(우리는 정답 사전을 고정하고 lasso 해와 비교하는 실험은 하지 않았습니다).

## 5. 정답 있는 시험대 (실험 a)

**설정.** 정답 특징 n = 64개를 d차원 단위 구에 무작위로 놓고(`make_truth`), 30번 `generate_batch`로 만든 희소 계수(밀도 p, 켜지면 U[0,1])로 x = Σ a_i g_i를 만듭니다. 사전 크기 n_feat = R·d, α ∈ {0, 0.01, 0.03, 0.1, 0.3, 1.0}, R ∈ {1, 2, 4, 8}, 시드 3개(정답 방향과 초기화 둘 다 시드로 바꿈), 6,000 step, 배치 512, Adam 1e-3, 별도 디코더(비묶음). 두 설정: **main**(d = 32, 정답/차원 비 n/d = 2, 표본당 켜진 정답 평균 3.2개), **hard**(d = 16, n/d = 4). p = 0.05. 평가는 새 표본 20,000개.

|---|---|---|---|---|---|---|

| R=8 (256) | 0.77 ± 0.04 | 0.02 | 0.39 | **0.98** | **1.00** | 0.93 |

같은 격자의 평균 L0 (정답 평균 3.2개 켜짐):

| | α=0 | 0.01 | 0.03 | 0.1 | 0.3 | 1.0 |
|---|---|---|---|---|---|---|
| R=2 | 53.2 | 30.9 | 24.0 | 6.8 | 3.7 | 1.8 |

- **정답 복원은 α의 좁은 띠에서만 일어납니다.** α = 0.1과 0.3(L0가 정답의 켜진 수 3.2의 1–3배일 때)에서 거의 전부 복원하고, α ≤ 0.03(L0 24–38)에서는 FVU가 0.002–0.02로 재구성이 거의 완벽한데도 복원율이 0.02–0.39입니다. 같은 FVU 0.012에서 복원율이 0.11(α = 0.03, R = 2)이므로 **재구성 지표는 정답 복원을 보장하지 않습니다.**
- α = 0이면 R = 2–8에서 복원율 0.60–0.77로 오히려 "절반 이상은 찾지만" 일관되지 않습니다(관찰만 했고 원인은 확인하지 않음).
- 사전이 정답 수(64)보다 작으면(R = 1, 사전 32개) 최대 0.39까지만 복원됩니다. 사전이 크면(R = 4, 8) 정답은 복원하지만 **사전 원소의 절반 이상이 정답과 안 닮습니다**(학습→정답 방향 0.9 초과 비율: R = 2는 0.99, R = 4는 0.51, R = 8은 0.25, α = 0.1). 즉 R이 정답 수보다 큰 만큼 정답과 닮지 않은 원소가 생깁니다. 이 원소들이 중복·분할·잡음 중 무엇인지는 확인하지 않았습니다. 이후 문헌의 feature splitting(`04` C7)과 같은 계열일 수 있지만 우리 데이터에는 계층 구조가 없습니다.
- 죽은 특징은 α = 1에서만 의미 있게 늘어 R = 4에서 8%, R = 8에서 12%(그 외는 2% 이하). 1절의 흡수 상태 논증과 일치합니다.

- 이 결과는 "SAE가 superposition을 풀 수 있다"(초록)가 **superposition의 정도에 의존한다**는 직접적 증거입니다. n/d = 2에서 되고 4에서 안 됩니다. 후속 문헌의 "정답 있는 합성 설정에서 SAE는 정답 특징의 9%만 복원"(Korznikov et al., `04` C2)과 같은 방향이며, 두 설정이 같다는 뜻은 아닙니다(그쪽의 설정은 읽지 않았음).

### 5.3 묶은 가중치 대 별도 디코더, 밀도

### 6.2 읽을 것

- **이 모델의 활성은 희소하게 분해되지 않습니다.** 512개 사전에서 FVU 0.05를 얻으려면 표본당 L0가 100–140개 켜져야 하고(켜진 비율 20–27%), L0 35–40(약 7%)에서 FVU는 0.17–0.23입니다. 128차원 안에 담긴 정보가 작은 모델이라 특징이 빽빽한 것으로 해석되지만 확인하지는 않았습니다. 논문의 그림 6·7(Pythia 레이어 0 MLP 등)과 같은 축이지만 값을 비교하지는 않았습니다(논문은 L0 수치를 표로 주지 않음).
- **사전 크기를 키워도 FVU–L0 곡선은 거의 안 움직입니다.** α = 0.1에서 R = 2 → 4 → 8로 가면 `resid_post_l1`의 FVU는 0.266 → 0.230 → 0.206인데 L0도 31.9 → 38.8 → 47.9로 같이 올라, 그림(왼쪽)에서 세 R의 점이 사실상 같은 곡선 위에 놓입니다. R을 키우면 같은 α에서 L0가 올라가는 식으로 α와 R이 서로 대체됩니다.
- **FVU와 loss recovered는 비슷하지만 같지 않습니다.** α = 0.1, R = 4에서 FVU가 0.166–0.230인 세 지점의 엄격한 loss recovered는 0.883–0.894로 서로 비슷합니다. 그러나 ΔL은 +0.37–0.45 nats로 작지 않습니다. 논문 §6.2의 "Pythia-70M 층 2 잔차를 재구성으로 바꾸면 perplexity 25 → 40"은 +0.47 nats에 해당하고(ln 40/25), 우리 α = 0.1의 ΔL(+0.31–0.56)과 같은 크기입니다(이쪽 모델·사전·α가 다르므로 대응은 아님). 즉 **재구성이 "거의 맞아 보여도"(FVU 0.2) 손실은 눈에 띄게 오릅니다.** 후속 문헌(TopK/Gated/JumpReLU)이 재구성-희소도 경계를 개선하려는 이유입니다(`04` C4).
- **영 대치와 평균 대치가 서로 다른 답을 줍니다**(`resid_post_l1`에서 평균 대치가 더 나쁨). loss recovered는 기준선 선택에 따라 0.894 대 0.948(α = 0.1)처럼 달라지므로, 값을 인용할 때는 기준선을 같이 적어야 합니다. 공식 코드에는 이 비율 자체가 없습니다(`04` D8).
- **평가 집합 FVU가 학습 집합보다 높습니다**(α ≥ 0.03에서 약 30–40%, 예: `resid_post_l1`, R = 4, α = 0.1에서 0.230 대 0.168. α = 0.01에서는 거의 같음). 학습 벡터가 9.8만 개로 512개 특징에 비해 적어 과적합이 보입니다. 논문은 500만–5,000만 벡터를 썼습니다(부록 B). 이 격차가 크면 loss recovered도 학습 집합에서 재면 더 좋게 나옵니다(우리는 평가 집합에서만 쟀음).
- **죽은 특징은 모든 실행에서 0.1% 이하입니다**(최대 0.098%, 32,640 벡터 기준 512개 중 0–1개). 논문 부록 C.3은 MLP에서 죽은 특징이 많다고 했으나 거기서 MLP는 **은닉 뉴런**의 활성이고 우리 `mlp_out_l0`는 MLP **출력**(128차원)이라 대상이 다르고, 이 설정(R ≤ 8, 데이터가 dense)에서는 재현되지 않았습니다. α = 1 같은 더 큰 α는 이 모델에서 시험하지 않았습니다(합성 시험대에서는 α = 1일 때 죽은 특징이 늘었음, §5.1).
- **시드 간 일치(`resid_post_l1`, R = 4, α = 0.1, 시드 0·1·2).** 서로 다른 시드로 학습한 사전 쌍의 MMCS는 0.760–0.770이고 최대 코사인 > 0.9인 원소의 비율은 0.34–0.36입니다. 무작위 사전 두 개(512개씩, 128차원)의 MMCS는 0.27(비율 0)이므로 일치는 우연보다 훨씬 높지만, **사전 원소의 3분의 2는 다른 시드의 어떤 원소와도 0.9 이상 닮지 않습니다.** 이후 문헌(Paulo & Belrose, 131K 잠재 변수 SAE에서 시드 간 공유 약 30%)과 같은 방향이지만 모델·크기가 매우 달라 같은 현상의 재현이라고는 못 합니다(`04` C6).
- **28번 massive activation과의 관계.** 위치 0의 노름은 `resid_post_l0`에서 22.7로 다른 위치 평균 8.5의 약 2.7배, `resid_post_l1`에서 25.3 대 11.2의 약 2.3배입니다. 이 정도는 SAE 재구성 오차를 지배할 크기가 아니라고 판단했으나, 위치 0을 넣어 학습해 보지는 않았습니다. 따라서 "BOS가 SAE에 해로운가"는 확인하지 못했고, BOS를 따로 처리한 것은 선택입니다. 큰 모델의 massive activation(채널 하나가 지배)은 이 모델에는 없습니다.

## 7. 해석 가능성의 대용 지표 (실험 c, API 없음)

**이것은 논문의 자동 해석 점수를 대신하지 않습니다.** 논문 §3의 점수는 GPT-4가 쓴 설명을 시뮬레이터가 맞히는 정도(맥락·의미까지 포함)이고, 우리 지표는 "특징이 켜지는 현재 토큰이 얼마나 한 토큰에 몰려 있는가"만 봅니다. 토큰 정체성에 대한 단의성(token-level monosemanticity)의 거친 대용이며, **맥락 특징(예: 반복 구간에서 켜짐)이나 의미 범주 특징(여러 토큰이 같은 개념)은 점수가 낮게 나옵니다.**

위쪽 다섯은 줄바꿈, 마침표, 따옴표, `<unk>`, `is` 같은 **단일 토큰 특징**입니다(논문 §5.1이 아포스트로피·마침표·` the`·줄바꿈 특징을 보인 것과 같은 종류). 아래쪽 다섯은 상위 20개 토큰이 거의 겹치지 않아 이 지표로는 해석할 수 없습니다. 토큰이 아니라 맥락(예: 주석 안, 함수 정의 인자)이나 위치에 반응하는 특징일 수 있으나 우리는 맥락을 보지 않았습니다.

### 7.1 대조: 학습 안 한(랜덤 초기화) 모델의 SAE

Heap et al.(`04` C7)이 지적한 문제를 이 지표로 직접 확인했습니다. 29번과 같은 구조의 **랜덤 초기화 모델**(학습 없음, 시드 123)의 `resid_post_l1` 활성을 같은 토큰에서 뽑아 같은 방식으로 SAE(R = 4, α = 0.1)를 학습했습니다. 활성 구조가 달라 FVU 0.069, L0 5.7(학습된 모델의 0.23, 38.8과 다른 동작점)이라 **같은 동작점의 비교가 아닙니다.**

| | 기저 | 무작위 128 | SAE R=4 |
|---|---|---|---|
| 학습된 29번 모델 | 0.34 / 2.88 | 0.36 / 2.78 | **0.52 / 2.07** |
| 랜덤 초기화 모델 | 0.47 / 2.32 | 0.42 / 2.51 | 0.48 / 2.30 |

- **랜덤 초기화 모델에서는 SAE의 이점이 사라집니다**(0.48 대 기저 0.47, 무작위 0.42). 또한 이 모델에서는 **기저와 무작위 방향의 토큰 집중도가 학습된 모델보다 오히려 높습니다**(0.47, 0.42 대 0.34, 0.36): 잔차가 거의 토큰 임베딩과 위치 임베딩의 합이라 어떤 방향이든 입력 토큰을 직접 읽기 때문입니다.
- 학습된 모델의 SAE(0.52)와 랜덤 초기화 모델의 SAE(0.48)는 이 지표로 거의 구별되지 않습니다. 즉 **이 대용 지표가 높다는 것은 "SAE가 모델이 계산에 쓰는 특징을 찾았다"는 증거가 아닙니다.** 토큰 정체성이 잔차에 남아 있다는 사실만 반영할 수 있습니다. Heap et al.의 결론(높은 점수만으로 학습된 특징을 찾았다고 할 수 없음)과 같은 방향이지만, 그들은 Pythia와 자동 해석 점수를 썼고 우리는 2층 토이와 토큰 집중도라 같은 실험이 아닙니다.
- 시드 1개 대조입니다. 랜덤 초기화의 다른 방식(가우시안 초기화 크기, 층별 재초기화)은 시험하지 않았습니다.

## 8. 29번 A1: 층 1 induction head와 SAE 특징 (실험 d)

**질문.** `resid_post_l1`의 SAE 특징 중, 층 1 induction head 출력 방향과 코사인이 높은 것이 있는가, 그리고 그 특징이 반복 구간에서 켜지는가.

**설정.** 자연 텍스트 평가 창 128개의 앞 L = 64토큰(위치 1–64)을 BOS 뒤에 4번 되풀이해(위치 1–256) 반복 시퀀스 128개를 만들었습니다(복사본 0 = 첫 등장, 복사본 1–3 = 반복). 29번 모델의 다음 토큰 손실이 복사본 0에서 2.273, 복사본 1에서 1.003, 2에서 0.351, 3에서 0.305 nats로 떨어져 모델이 반복을 복사함을 확인했습니다(반복 구간에서 induction head가 작동한다는 29번의 결과와 같은 방향). SAE는 두 가지를 학습했습니다(R = 4, α = 0.1, `resid_post_l1`): **nat** = 실험 b와 같은 학습 집합(자연 텍스트, 97,920 벡터), **mix** = nat에 학습 창 앞 192개로 만든 반복 시퀀스의 활성 48,960개를 더한 것. head 출력은 모델의 캐시(`head_out`)에서 읽습니다. 층 1 head는 잔차에 더해지기만 하므로 `resid_post_l1`에서 네 head의 출력 합을 뺀 값 x − Σ_h o_h에 같은 SAE 인코더를 돌리면 **head의 직접 기여를 뺀 activation**을 얻습니다(층 1 MLP를 통한 간접 경로는 이 뺄셈에 들어 있지 않음).

**지표.** 평가 반복 시퀀스에서
- cos: SAE 특징 f의 디코더 방향과 head h의 반복 구간 평균 출력 방향(단위화)의 코사인, 특징별 head에 대한 최댓값.
- 선택성: 복사본 1–3의 평균 activation ÷ 복사본 0의 평균 activation.
- 의존도: 네 head의 직접 출력을 뺐을 때 반복 구간 평균 activation의 감소율(`rel_drop`).
- 후보 특징: 선택성 ≥ 3이고 반복 구간에서 2% 이상의 위치에서 켜지는 특징.

**결과.**

| | nat | mix |
|---|---|---|
| 반복 구간에서 한 번이라도 켜진 특징 | 512 / 512 | 512 / 512 |
| 후보(선택성 ≥ 3, 반복 구간 켜짐 ≥ 2%) | **34** | **57** |
| 후보의 평균 의존도(네 head를 빼면 줄어드는 비율) | **0.55** | **0.56** |
| 모든 특징의 평균 의존도 | 0.23 | 0.19 |
| 특징의 head 방향 최대 코사인: 평균 / 95% / 최대 | 0.092 / 0.215 / 0.341 | 0.092 / 0.226 / 0.392 |
| 같은 차원 무작위 방향 512개의 같은 값: 평균 / 95% | 0.084 / 0.192 | (같음) |
| 후보의 head 방향 코사인 평균 | 0.113 | 0.100 |
| 스피어만 상관: cos 대 의존도 / cos 대 log 선택성 | 0.42 / 0.17 | 0.40 / 0.12 |

head 평균 출력 방향끼리의 코사인은 head 0–3 0.29, 0–1 0.13, 1–3 0.24, 나머지 0.03 이하로 서로 달랐습니다(`results_d.json`).

**읽을 것.**
- **반복 구간에서 선택적으로 켜지는 특징이 있고 그 켜짐은 층 1 head 출력에 크게 의존합니다.** 자연 텍스트만으로 학습한 SAE에서도 34개, 반복을 섞으면 57개가 선택성 3 이상이고(최대 약 19), 이 후보들의 activation은 네 head의 직접 출력을 빼면 평균 55% 줄어듭니다(전체 특징의 평균 감소 23%의 2배 이상). 29번이 보인 "층 1 head 4개가 induction head"와 일치하는 방향입니다.
- **그러나 이 특징들의 디코더 방향은 head 출력 방향과 거의 겹치지 않습니다.** 특징의 최대 코사인 평균 0.092는 무작위 방향의 0.084와 같고, 후보 특징의 평균은 0.10–0.11입니다. 가장 높은 특징도 0.34(nat)–0.39(mix)입니다. 즉 "induction head의 출력 방향 = SAE 특징 하나"라는 1대1 대응은 **찾지 못했습니다.** 한 가지 가능한 이유(검증 안 함): head의 출력은 반복되는 토큰 하나를 읽어내는 방향(다음 토큰 후보의 임베딩 방향)이라 반복 구간 평균 출력 방향은 토큰마다 다른 방향의 평균이어서 한 방향으로 모이지 않습니다. 따라서 "평균 출력 방향과의 코사인"이 이 질문에 맞는 지표가 아닐 수 있습니다(대안: 토큰별 head 출력과의 코사인, 또는 특징을 켜는 인코더 방향과 head OV 행렬의 정렬; 하지 않음).
- 특징의 head 방향 코사인과 의존도 사이에 중간 정도의 순위 상관(0.40–0.42)이 있습니다. head 출력 방향에 더 가까운 특징일수록 head를 빼면 더 많이 줄어드는 경향은 있지만(전체 512개 특징 기준), 후보 중 코사인이 높은 것(예: 특징 24, 코사인 0.34, 선택성 6.5, 의존도 0.74)과 낮은 것(예: 특징 313, 코사인 0.06, 선택성 19.1, 의존도 0.24)이 섞여 있습니다.
- **반복 데이터를 섞으면 후보가 34 → 57로 늘지만, 방향 정렬은 늘지 않습니다**(평균 코사인 0.113 → 0.100). 자연 텍스트에서 학습한 SAE가 반복 구간에서만 쓰이는 특징을 일부만 갖는다는 뜻이며(학습 집합 분포가 특징 발견을 좌우함), 반복 특징이 SAE에서 안정적으로 나타나는지는 시드 1개로는 말할 수 없습니다.
- 한계: (1) 시드 1개. (2) 선택성 문턱(3)과 빈도 문턱(2%)은 임의로 정한 것이라 후보 수는 문턱에 의존합니다. (3) 의존도는 층 1 head의 **직접** 경로만 뺀 값이고 층 1 MLP를 통한 간접 경로나 층 0 head는 포함하지 않습니다. (4) "후보"가 induction 기능을 한다는 인과 증거는 아닙니다. 이들이 켜질 때 다음 토큰 로짓에 무엇을 하는지(복사 방향인지)는 보지 않았습니다.

## 10. R2: Pythia-70M 잔차 흐름에 SAE (`analysis/pythia_sae.py`, `pythia_sae_results.json`, `figures/own_pythia_sae.png`)

논문 §6.2(`paper/paper.txt` L405–L410)의 "Pythia-70M 층 2 잔차를 재구성으로 바꾸면 Pile perplexity가 25에서 40으로 오른다"를 직접 재 본 것입니다. 논문은 이 문장에 층 번호 규약, 데이터 크기, 문맥 길이, 사전 크기, α를 적지 않았습니다(부록 B는 활성 500만–5,000만 개, 그림 8은 활성 2,000만 개와 α = 8.6e−4만 적음, L653).

**설정.** 모델 `EleutherAI/pythia-70m`(HF 최종 체크포인트, d = 512, 6층; 논문이 어느 변형을 썼는지는 적혀 있지 않음). 텍스트 `NeelNanda/pile-10k`(Pile 일부)를 문서 사이에 EOS를 넣어 이어 붙인 뒤 길이 256 창 60,001개로 자르고, 앞에서 6,000개를 SAE 학습(활성 벡터 1,530,000개), **마지막 400개를 평가 전용**(102,400 토큰, 활성 벡터 102,000개)으로 씁니다. 활성은 HF 모델의 `gpt_neox.layers[l]` 출력(= 층 l을 0부터 세었을 때의 resid_post, 최종 LayerNorm 이전)에서 forward hook으로 읽고 끼웠습니다(TransformerLens 없음). **위치 0(창의 첫 토큰, 어텐션 싱크)은 학습·평가·끼우기에서 건드리지 않습니다**(§6과 같은 선택). SAE는 §6과 같은 `minimal_impl.SAE`(별도 디코더, 행 정규화, 식 (4), Adam 1e-3)이고 활성을 평균 ‖x‖² = 1로 나눠 학습(상수 8.90, 15.8), 배치 1,024, 12,000 step(약 8 에폭), **시드 1개**, R = 4(사전 2,048), α ∈ {0.01, 0.03, 0.1, 0.3}. perplexity는 창당 255개 다음 토큰의 평균 교차 엔트로피의 exp, loss recovered는 §6과 같은 식과 엄격한 기준선(영 대치와 평균 대치 중 낮은 쪽)입니다.

**읽을 것.**
- **정상 perplexity 25.4는 논문의 "25"와 맞습니다.** 같은 데이터·문맥이라는 뜻은 아닙니다(논문은 적지 않음, 우연일 수 있음).
- **"25 → 40"은 크기로는 재현됩니다.** 40은 층 1에서 α 0.03–0.1 사이(34 → 60, L0 164 → 34), 층 2에서 α 0.01–0.03 사이(28.7 → 46.3, L0 408 → 148)에 놓입니다. 즉 perplexity가 1.5–2배가 되는 재구성이 FVU 0.09–0.15(L0 약 150–400/2048)에서 나옵니다. **그러나 이 비율은 α(= L0)를 어디에 놓느냐에 거의 전적으로 달려** α = 0.3(L0 4–8)이면 층 2에서 5,949까지 올라갑니다. 논문이 어느 α와 L0에서 40을 얻었는지 모르므로 "재현했다"가 아니라 "40은 이 α 범위의 값"입니다.
- **층 번호 규약에 따라 같은 α에서 답이 다릅니다.** 논문의 "층 2"가 0부터 센 블록 2의 출력이면 우리 층 2, 블록 2 입력(= 블록 1의 출력)이면 우리 층 1입니다. 어느 쪽인지 논문에서 알 수 없습니다. 같은 α에서 층 2가 층 1보다 perplexity가 더 오릅니다(α = 0.03: 46 대 34): 층 2의 활성이 더 크고(상수 15.8 대 8.9) 영 대치 기준선도 더 나쁜데도(22,897 대 10,334) 재구성 손실이 크게 남습니다.
- **α 규약을 논문 값에 맞춰 보면** 공식 코드 규약(제곱 오차를 차원으로 나눔, `04` D3)을 따랐다고 *가정할 때* α = 8.6e−4는 우리 규약(제곱 오차 합, 정규화 전 활성)의 0.44이고, 정규화한 활성에서는 0.44/상수 = 0.049(층 1), 0.028(층 2)입니다. 우리 α = 0.03에 가깝고 그때 perplexity는 34(층 1), 46(층 2)로 논문의 40 근처입니다. 가정이 틀릴 수 있어 **약한 정합 증거**일 뿐입니다.
- **loss recovered 0.95(층 1), 0.90(층 2)에서도 perplexity는 34–46으로 40 안팎입니다.** loss recovered가 0.9대여도 perplexity는 눈에 띄게 오르는 것은 §6의 29번 모델 결과(0.88–0.89에서 ΔL +0.37–0.45)와 같은 방향입니다. loss recovered는 영 대치의 손실(약 9–10 nats, perplexity 1만 이상)이 분모라 값이 부풀려 보이는 지표이므로 perplexity 증가와 함께 적어야 합니다.
- 죽은 특징은 α ≤ 0.1에서 0.2% 이하이고 α = 0.3에서 18–36%로 급증합니다. 합성 시험대(§5.1)에서 α가 클 때 죽은 특징이 늘던 것과 같은 방향입니다(재샘플링 없음, `04` D6).
