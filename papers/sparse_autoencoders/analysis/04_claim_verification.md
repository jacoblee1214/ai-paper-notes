# 04. 주장 검증과 공식 코드 대조

구현 모드: 이후 문헌이 이 논문의 주장을 확인·수정·반박한 것을 C1–C12로, 공식 코드(`HoagyC/sparse_coding`)와의 정적 대조를 D1–D9로 적습니다. 판정은 "확인 / 부분 확인 / 수정 / 미검증"이고 **우리 측정이 있으면 근거에 적었습니다**. 이후 문헌은 arXiv 초록(arXiv API, 2026-11-25)과 아래 두 게시 페이지(Towards Monosemanticity, Sharkey et al. 중간 보고)에서 읽은 대목만 근거로 하고 본문 전체는 읽지 않았습니다. 재현하지 않았습니다(논문 규모 재현은 승인 필요). 웹 검색 도구는 쓰지 않았고 arXiv API·OpenReview API·`gh api`와 4개 사이트 페이지(Transformer Circuits, LessWrong, iclr.cc, proceedings.iclr.cc) 조회를 썼습니다.

**30번 `toy_superposition/analysis/04_claim_verification.md`와의 분담.** 30번의 C5(SAE가 실행됨, Cunningham·Bricken·Templeton)와 C6(사후 분해로 참 특징을 열거할 수 있나: 시드 불안정, 흡수, 정규 단위 아님, 프로빙 열세, 무작위 기준선, 합성 설정 9%)가 후속 문헌 다수를 이미 정리했습니다. 여기서는 그 문헌을 되풀이하지 않고 **이 논문의 주장 S1–S8**(`01` §4)에 하나씩 걸고, **우리가 직접 측정한 것**을 붙입니다.

## 1. 주장 검증 C1–C12

| C1 | SAE 특징은 기저·무작위·PCA·ICA 방향보다 해석 가능하다(자동 해석 점수) (S1, §3.2, 그림 2) | **부분 확인(대용 지표에서) + 수정(해석)** | 우리 대용 지표(상위 20개 중 최빈 토큰 비율, `03` §7): 29번 모델 세 지점에서 SAE 0.46–0.56 대 기저 0.31–0.34, 무작위 0.29–0.36, PCA 0.26–0.28로 순서가 논문 그림 2와 같음. **그러나 랜덤 초기화 모델의 SAE는 0.48로 학습된 모델의 SAE(0.52)와 거의 같고 이 모델에서는 기저(0.47)와도 비슷**(`03` §7.1, 같은 동작점이 아니고 시드 1개). Korznikov et al.(arXiv:2602.14111, 초록 기준): 무작위 방향으로 제약한 SAE 기준선이 해석 0.87 대 0.90으로 맞먹음. 논문은 랜덤 모델 대조를 하지 않았음 |
| C2 | SAE는 superposition을 풀어 모델의 특징을 복원한다(정답 복원은 Sharkey et al. 토이에 근거) (S5, §2 L143–L145, 초록) | **조건부 확인(우리 합성 시험대)** | `03` §5: 정답 64개가 차원 32(n/d = 2)이고 켜진 정답이 평균 3.2개이면 α = 0.1–0.3에서 복원율(최대 코사인 > 0.9) 0.98–1.00, 사전 크기 R ≥ 2. **α ≤ 0.03에서는 FVU가 0.002–0.02로 재구성이 거의 완벽한데 복원율 0.02–0.39**(재구성은 정답 복원을 보장하지 않음). **n/d = 4(차원 16)에서는 어떤 (α, R)에서도 최대 0.46**(시드 3개). 밀도를 3배로 올리면 맞는 α가 올라감. Korznikov et al.: 정답을 아는 합성 설정에서 설명 분산 71%인데 참 특징의 9%만 복원(그쪽 설정은 읽지 않았고 같은 설정이 아님). Song et al.(arXiv:2505.20254, 초록 기준): 시드 간 일관성 지표 PW-MCC가 정답 복원의 믿을 만한 대용임을 합성 모델에서 보였다고 주장하고 TopK SAE에서 0.80 달성 |
| C3 | (논문에 없음) L1 벌점 SAE는 활성 크기를 체계적으로 과소추정한다 | **확인(우리 유도 + 측정), 후속이 해결책 제시** | `03` §2: 직교 정답에서 최적 코드 c = max(a − α/2, 0)를 유도, 학습한 SAE의 L0·회귀 기울기가 이론과 0.05 이내(α = 0.03–1.0, 시드 3개). 겹친 정답에서는 기울기가 이론보다 더 낮음(α = 0.1에서 0.74 대 0.93, `03` §5.4). Gated SAE(arXiv:2404.16014, 초록 기준): "L1은 수축 등 여러 편향을 낳는다"고 보고 방향 선택과 크기 추정을 분리, 수축이 해결되고 비슷한 재구성에 절반의 켜진 특징으로 충분하다고 주장. JumpReLU(arXiv:2407.14435): L0를 STE로 직접 학습해 수축을 피함 |
| C4 | 재구성이 불완전해 모델 손실이 오른다(Pythia-70M 층 2 perplexity 25 → 40, 한계로 적음) (§6.2) | **확인(우리 측정), 후속이 경계를 개선** | `03` §6: 29번 모델에서 FVU 0.17–0.23(L0 35–40/512)일 때 ΔL +0.37–0.45 nats(논문의 +0.47 nats와 같은 크기), loss recovered 0.88–0.89(엄격한 기준선). FVU 0.05–0.06(L0 100–140)에서야 0.97–0.98. 영 대치와 평균 대치가 다른 답을 줌(`resid_post_l1`에서 평균 대치가 더 나쁨). 논문 §6.2가 제안한 "출력 변화를 최소화하는 학습"은 하지 않음. TopK(arXiv:2406.04093)는 희소도를 직접 지정해 재구성-희소도 경계를 개선, 새 지표(정답 복원·설명 가능성·하류 효과의 희소성)를 도입, JumpReLU는 Gemma 2 9B에서 같은 희소도의 재구성 충실도가 최고라고 주장(초록 기준) |
| C5 | 잔차 흐름에서는 되고 MLP에서는 죽은 특징 때문에 과완비 사전이 안 된다 (S6, §6.2, 부록 C.3, E) | **부분 확인(우리 설정에서는 죽은 특징 미관측)** | 우리 29번 모델에서는 `mlp_out_l0`(MLP **출력**, 128차원)와 두 잔차 지점 모두 죽은 특징이 모든 실행에서 0.1% 이하(R ≤ 8, α ≤ 0.3). 논문의 MLP는 **은닉 뉴런**이라 대상이 다르고 데이터도 다름(`03` §6). 합성 시험대에서는 α = 1일 때만 죽은 특징이 늘어 R = 4에서 8%, R = 8에서 12%(`03` §5.1, 1절의 흡수 상태 논증과 일치). 죽은 특징을 줄이는 쪽으로는 Bricken et al.의 주기적 재샘플링(게시 페이지에서 확인: 오래 안 켜진 뉴런의 인코더를 재구성이 나쁜 데이터점으로 재설정하면 "주어진 은닉 크기에서 더 많은 특징"), TopK의 "죽은 잠재 변수가 거의 없는" 수정(초록 기준) |
| C6 | (논문에 없음) 같은 데이터·구조에서 시드만 바꿔도 특징 집합이 같은가 | **반박(논문은 침묵) — 우리 측정도 불일치** | 우리: `resid_post_l1`, R = 4, α = 0.1에서 시드 쌍의 MMCS 0.76–0.77, 최대 코사인 > 0.9인 원소 비율 0.34–0.36(무작위 사전 쌍의 MMCS는 0.27, 비율 0)(`03` §6). Paulo & Belrose(arXiv:2501.16615, 초록 기준): 131K 잠재 변수 SAE에서 시드 간 공유 약 30%, 세 LLM·두 데이터셋·여러 구조에서 관찰, **ReLU+L1 SAE는 TopK보다 시드 간 안정**. 이들은 SAE 특징을 "모델이 실제로 쓰는 특징의 목록이 아니라 실용적으로 유용한 활성 공간의 분해"로 봐야 한다고 결론 |
| C7 | 해석 점수는 사전 크기에 거의 무관하다(작은 사전 R < 1에서도 높음) (부록 C.1, 그림 8) | **부분 확인 + 수정(사전이 클수록 원소가 쪼개지거나 중복)** | 우리 합성 시험대(`03` §5.1): 사전이 정답 수보다 크면(R = 4, 8; 정답 64개, 사전 128·256개) 정답은 복원되지만 사전 원소 중 정답과 0.9 이상 닮은 것의 비율은 α = 0.1에서 R = 2 0.99, R = 4 0.51, R = 8 0.25: 정답과 닮지 않은 원소가 늘어남(정체는 확인 안 함: 중복·분할·잡음 가능). Bricken et al.의 feature splitting(게시 페이지: 사전이 커지면 토큰 특징·맥락 특징이 "토큰-맥락" 특징으로 쪼개짐). Chanin et al.(arXiv:2409.14507, NeurIPS 2025 구두, 초록 기준): 계층적 특징이 자식에게 **흡수**되어 있어야 할 곳에서 안 켜짐, 희소성 최적화 자체가 원인이며 크기·희소도 조절로 해결 안 됨. 우리 합성 데이터에는 계층 구조가 없어 흡수는 시험하지 않았음 |
| C8 | SAE 특징이 IOI 과제의 인과 특징을 PCA보다 정밀하게 지목한다 (S3, §4, 그림 3) | **미검증(우리) / 이후 문헌은 엇갈림** | 우리는 IOI·활성 패칭을 하지 않았음. 논문의 비교 대상은 PCA와 α = 0 사전뿐이고 시드 반복과 오차 막대가 없음(그림 3). 이후: Marks et al.(arXiv:2403.19647, ICLR 2025, 초록 기준)은 SAE 특징으로 인과 회로를 찾고 분류기 일반화를 개선하는 SHIFT를 제시. 반면 Kantamneni et al.(arXiv:2502.16681, 초록 기준)은 프로빙 네 영역(데이터 부족, 클래스 불균형, 라벨 잡음, 공변량 이동)에서 SAE가 기준선을 일관되게 못 넘고, AxBench(arXiv:2501.17148, 초록 기준)는 조향에서 프롬프팅·미세조정이 앞서고 개념 탐지에서 difference-in-means가 최고이며 SAE는 경쟁력이 없다고 보고. 즉 "해석 가능한 단위"의 하류 이점은 과제와 기준선에 의존 |
| C9 | 특징은 단의적(monosemantic)이다 (S2, §5.1, 초록) | **부분 확인(토큰 수준) + 수정** | 우리 대용 지표: SAE 특징의 약 절반(중앙값 0.3–0.5)이 상위 20개 중 최빈 토큰이 6–10개뿐이고, 가장 집중된 특징은 줄바꿈·마침표·따옴표 같은 단일 토큰 특징(`03` §7). 이는 논문 §5.1이 보인 아포스트로피·마침표 특징과 같은 종류. 단의성의 정의가 "한 토큰"이면 일부만 성립. Leask et al.(arXiv:2502.04878, ICLR 2025, 초록 기준): SAE 잠재 변수가 정규적·원자적 단위가 아님. Engels et al.(arXiv:2405.14860, ICLR 2025): 일부 특징은 1차원이 아니라 다차원(원형) |
| C10 | (v1 주장) 특징을 절제하면 정밀한 모델 편집(대명사 예측 제거)이 가능하고 LEACE·평균 차이 투영이 실패하는 곳에서 된다 | **논문이 철회(v1 → v2)** | `01` §6: v1 §4와 초록에 있었고 v2(2023-09-19)와 v3에는 없음, 이유는 적혀 있지 않음. 우리는 시험하지 않았음. 이후 AxBench의 "SAE는 조향에서 경쟁력이 없다"는 같은 종류의 응용에 대한 부정 결과(초록 기준, 과제는 다름) |
| C11 | α를 훑으면 희소도-정확도가 매끄럽게 교환되고 "무릎"이 없다 (S7, 부록 B, 그림 6·7) | **확인(우리 유도 + 측정), 함의는 수정** | `03` §2: 크기 분포가 U[0,1]인 직교 정답에서 FVU ≈ 3u² − 2u³ (u = 1 − L0/L0⁰)로 꺾임이 없음. 학습 결과(`results_a2.json`)가 L0·기울기에서 이론과 맞음. **그러나 정답 복원은 α의 좁은 띠에서만 일어나고 그 위치는 데이터의 희소도(밀도)에 따라 이동**(`03` §5.1, §5.3): 곡선에는 무릎이 없어도 정답 α가 존재하며, 곡선만으로 그것을 고를 수 없음 |
| C12 | 해석 점수가 활성의 왜도·첨도와 양의 상관이 있고 ICA가 가장 강한 기준선인 이유다 (S8, 부록 C.4) | **미검증, 문서 내 불일치** | 우리는 ICA와 자동 해석 점수를 쓰지 않아 검증하지 못함. 본문(L702–L703)은 상관 0.19(왜도), 0.24(첨도)이고 표 2(L711–L717)는 왜도 0.20, 첨도 0.15로 서로 다름(`01` §5) |

### 우리가 직접 확인한 것(요약)

- 식과 성질: L1 수축의 닫힌 형식(c = max(a − α/2, 0))과 L0·기울기 일치(`03` §2). 정규화 없이는 L1이 의미 없음(`03` §1). 테스트 13개가 정규화, 직교 정답 복원, α = 0에서 재구성, α 증가에 따른 L0 감소, 항등 재구성에서 손실 불변을 확인.
- 합성 시험대: n/d = 2에서 되고 4에서 안 됨, 재구성 ≠ 복원, 정답 α는 좁은 띠(`03` §5).
- 29번 모델: FVU·L0·loss recovered 관계, 시드 불일치, 해석 대용 지표에서 기준선보다 높으나 랜덤 모델 대조에서 구별 안 됨, induction 후보 특징은 head 의존이 크나 방향 정렬은 우연 수준(`03` §6–§8).

### 요약해서 인용에 쓸 때

- C2, C3, C4, C11은 **조건을 달아** 인용할 수 있습니다(우리 합성·토이 결과).
- C1, C6, C7, C9, C8은 이 논문의 서술보다 **약하게** 인용해야 합니다("높은 해석 점수 = 학습된 특징", "특징 집합이 유일", "단의적", "하류 과제 이점").
- C5, C8의 "실제 LLM에서"와 C10은 우리가 시험하지 못했습니다.

### 우리 구현과의 차이 요약

- 같은 것: 식 (1)–(4)의 구조, 행 정규화, ReLU, Adam lr 1e-3, 인코더 편향만, 재샘플링 없음.
- 다른 것: 우리는 α를 제곱 오차 **합**에 대한 값으로 씀(식 (4) 그대로, 공식 코드 규약과 d_in배 차이), 정규화를 사영 방식으로 함, 배치 512, 평균을 빼지 않은 활성에 학습하되 FVU의 분모는 평균을 뺀 분산, 위치 0 제외.
- 우리가 하지 않은 것: 공식 코드 실행, `interpret.py`(OpenAI API), 앙상블 동시 학습, 센터링 옵션, 죽은 특징 재샘플링(공식 코드에도 없음).
