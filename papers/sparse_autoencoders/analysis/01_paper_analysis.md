# 01. 논문 분석: Sparse Autoencoders Find Highly Interpretable Features in Language Models (arXiv:2309.08600)

*Cunningham, Ewart, Riggs, Huben, Sharkey* (EleutherAI, MATS, Bristol AI Safety Centre, Apollo Research). ICLR 2024 포스터. 분석 판은 arXiv v3(2023-10-04, 20쪽)이고 `paper/paper.txt`의 줄 번호(L)로 위치를 적습니다. 구현 모드 분석입니다.

## 1. 문제

- 뉴런은 서로 무관한 여러 입력에 반응하는 **다의성(polysemanticity)** 을 보이고(L48–L53), 트랜스포머 잔차 흐름에는 뉴런 기저가 특별할 이유도 없습니다(L52–L53).
- 가설: 원인은 **superposition**, 곧 모델이 차원 수보다 많은 특징을 과완비(overcomplete) 방향 집합에 배정하는 것입니다(L54–L58, Elhage et al. 2022b = 30번 `toy_superposition/`). 특징이 충분히 희소해야만 간섭 비용이 이득보다 작아 superposition이 생긴다는 논리입니다(L58–L71).
- 따라서 활성 벡터를 **희소한 선형 결합**으로 쓸 수 있는 방향 집합을 찾으면 모델의 특징을 복원할 수 있다고 봅니다. 이는 Olshausen & Field(1997)의 희소 사전 학습(sparse dictionary learning)과 같은 문제입니다(L71–L75).

## 2. 방법 (§2, 식 (1)–(4))

활성 벡터 x ∈ R^d_in (Pythia-70M 잔차 d=512, Pythia-410M d=1024, 각주 1).

| 식 | 내용 | 위치 |
|---|---|---|
| (1) | c = ReLU(M x + b), M ∈ R^{d_hid×d_in}, d_hid = R·d_in | L123–L124, L132 |
| (2) | x̂ = Mᵀ c  (인코더와 디코더가 **묶인 가중치**) | L125 |
| (3) | x̂ = Σ_i c_i f_i, f_i = M의 i번째 **행** (사전 원소) | L127–L129 |
| (4) | L(x) = ‖x − x̂‖₂² + α‖c‖₁ | L136–L140 |
| (5)(6) | MLP용 비묶음: c = ReLU(M_e x + b), x̂ = M_dᵀ c | L688–L690 (부록 C.3) |

- **M은 행 정규화(row-normalised)**: 사전 원소 노름을 1로 고정해 ‖c‖₁을 줄이려고 원소를 키우는 꼼수를 막습니다(각주 3, L177–L178).
- 묶은 가중치의 이유 세 가지(각주 2, L118–L120): 감지 방향과 정의 방향이 같을 것이라는 기대, 메모리 절반, 인코더/디코더 방향 해석의 모호성 제거. 잔차 흐름에서는 성능이 줄지 않지만 MLP에서는 줄어드는 것을 보았다고 적습니다(L173–L175).
- 학습(부록 B, L595–L601): Pile 활성, Adam lr 1e-3, 5–50M 활성 벡터를 1–3 에폭, A40 GPU 한 장에서 1시간 미만. α 훑기에서 희소도-정확도가 매끄럽게 교환되고 "무릎"이 없음(L603–L605, 그림 6·7).
- 대표 하이퍼파라미터: 잔차 α = 8.6e−4, MLP α = 3.2e−4(L788–L789), 그림 2는 R = 2, 10 에폭.

**논문에 없는 것(우리 03·04에서 다룸)**: MMCS(정답 특징과의 평균 최대 코사인) 지표는 이 논문 본문에 없고 Sharkey et al. 2023 중간 보고의 지표입니다. 이 논문은 정답을 모르는 실제 모델에서만 평가하므로 정답 복원율이 없습니다. 죽은 특징 재샘플링도 없습니다(부록 E는 "앞으로 재초기화할 계획", L787–L788).

## 5. 한계와 문서 내 불일치

- **평가는 간접적입니다.** 자동 해석 점수는 LLM(GPT-4 설명 + GPT-3.5 시뮬레이션)에 의존하고, 정답 특징이 없는 실제 모델에서 "해석 가능성"만 잽니다. 표본이 작음(점수당 약 640 토큰, 부록 A 하단 L586–L590), 상위 조각이 섞인 "top-and-random" 점수가 기본이라 쉬운 시험입니다. 논문도 무작위만으로 재면 점수가 크게 낮아진다고 적습니다(L642–L644).
- **재구성이 불완전**: 위 §6.2의 perplexity 25 → 40. 논문은 이를 한계로 적고 "재구성 손실 대신 출력 변화를 최소화하는 학습"을 미래 과제로 둡니다(L410–L414).
- **오차 막대와 시드**: 그림 2에는 특징 150개에 대한 95% CI가 있으나 SAE 시드 간 반복은 없습니다. 시드마다 특징이 달라지는지 보고하지 않았습니다.
- **Table 2와 본문의 수치 불일치(v3)**: 본문 L702–L703은 활성의 왜도·첨도와 해석 점수의 상관이 각각 0.19, 0.24라고 쓰는데, 표 2(L711–L717)는 왜도 0.20, 첨도 0.15입니다. 표가 맞는지 본문이 맞는지 이 PDF만으로는 알 수 없습니다.
- 그림 2의 "층 4에서 ICA와 비슷"은 L211–L212에 문장으로만 있고 표가 없어서 값을 재계산할 수 없습니다.
- 사전 초기화·묶은 가중치의 세부(초기화 분포, 배치 크기, 에폭 수)는 부록 B에 일부만 있습니다(배치 크기 없음). 공식 코드로 확인(04 D 절).
