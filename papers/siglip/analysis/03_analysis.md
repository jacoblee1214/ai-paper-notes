# 03. 분석: 식 유도 검산, 최소 구현, 표 재계산, 토이 (SigLIP, arXiv:2303.15343)

구현 모드입니다. 논문의 실험(TPU 수십 장, WebLI 수십억 예제)을 재현하지 않았고, 아래 수치 중 "토이"로 표시한 것은 이 저장소가 만든 합성 도형 데이터의 값입니다. 수치의 출처는 `derivation_results.json`(식 검산), `table_recalc_results.json`(논문 표 재계산), `toy_results.json`(토이)입니다. 테스트는 `test_minimal_impl.py` 18개입니다.

기호: B = 배치, b_dev = 장치당 배치(논문의 b와 헷갈리므로 이 문서에서는 **편향을 β, 장치당 배치를 m**으로 씁니다), t = exp(t′), 로짓 ℓ_ij = t x_i·y_j + β, 라벨 z_ij = +1(i=j)/−1. 손실 L = (1/B) Σ_ij softplus(−z_ij ℓ_ij) (`log σ(u) = −softplus(−u)`).

## 1. 식 유도 검산

### 1.1 식과 알고리즘 1의 일치, 그리고 편향 부호 (D1)

논문 §3.2의 식은 항마다 1/(1 + e^{z_ij(−t x_i·y_j + b)}) = σ(z_ij(t x_i·y_j − b))입니다(L221–L222). 알고리즘 1(v4)은 `logits = dot(zimg, ztxt.T) * t + b`, `l = −sum(log_sigmoid(labels * logits)) / n`(L73–L75)이고 big_vision 코드도 `logits * t + b`입니다(`siglip.py` L291–L292). **둘은 b의 부호가 반대입니다.** 테스트 `test_matches_paper_formula_and_algorithm1`이 이를 확인합니다. 알고리즘(코드) 쪽 부호의 손실은 식을 이중 반복문으로 옮긴 값에서 b → −b로 바꾼 것과 상대오차 1e-10으로 같고, b = −10, t = 10, 무작위 임베딩 64쌍에서 식을 글자 그대로 쓰면 초기 손실이 630.7, 알고리즘 1은 9.5입니다. 따라서 "b = −10 초기화"는 알고리즘·코드의 부호에서만 의미가 있고 §3.2 식의 b는 `−b`입니다. 이 문서는 이후 코드 부호를 씁니다.

v1의 의사 코드는 `−dot(...) * t + b`였습니다(코사인 부호 반대). 같은 입력에서 정렬된 쌍의 손실이 v4 식 0.69, v1 식 20.0이고 무작위 쌍은 v4 10.2, v1 9.8이라 v1 식은 **정렬을 벌줍니다**(`derivation_results.json`, `v1_pseudocode_sign`). v2가 고쳤습니다.

### 1.2 초기 손실과 편향 기울기: b = −10이 왜 안정시키나

학습 시작에서 임베딩이 거의 직교(cos ≈ 0)라 모든 로짓이 ≈ β입니다. 행 하나의 손실과 기울기는

- L_row = softplus(−β) + (B−1) softplus(β),
- ∂L_row/∂β = −σ(−β) + (B−1) σ(β).

| B | β 초기화 | 초기 손실(행당) | ∂L/∂β (행당) | 음성 쌍 하나의 기울기 가중 σ(β) | 음성 총합 / 양성 |
|---|---|---|---|---|---|
| 256 | 0 | 177.4 | +127.0 | 0.5 | 255 |
| 256 | −10 | 10.0 | −0.99 | 4.5e-5 | 0.012 |
| 256 | −ln(B−1) = −5.54 | 6.54 | 0 | 3.9e-3 | 1.0 |
| 32,768 | 0 | 22,713 | +16,383 | 0.5 | 32,767 |
| 32,768 | −10 | **11.49** | +0.49 | 4.5e-5 | 1.49 |
| 32,768 | −ln(B−1) = −10.40 | 11.40 | 0 | 3.1e-5 | 1.0 |
| 1,048,576 | −10 | (표 참조 `derivation_results.json`) | | | 약 47.6 |

(t = 10, 로짓 = β로 근사한 값. 표는 `derivation_checks.py` 출력.)

- **β = 0이면 모든 쌍의 확률이 0.5라서 음성 B−1개가 양성 1개를 압도합니다.** 초기 손실이 B log 2 ≈ 2.3e4(B = 32k)이고 편향 기울기가 +B/2로, 학습의 첫 스텝이 "모든 쌍을 음성이라고 말하게 만드는" 데 쓰입니다. 논문이 말한 "large initial optimization steps attempting to correct this bias"(L176–L180)와 일치합니다.
- **β = −10이면 음성 하나의 기울기 가중이 σ(−10) = 4.5e-5**라서 음성 32,767개를 합쳐도 양성 하나의 가중(0.99995)의 1.49배입니다. 초기 손실은 양성 항 10.0 + 음성 항 1.49 = 11.49입니다.
- **균형점은 β* = −ln(B−1)**입니다(σ(β)(B−1) = σ(−β) ⇒ e^β = 1/(B−1)). B = 32,768이면 −10.397이라 논문의 −10이 "배치 약 22k의 균형점"에 가깝습니다. 즉 −10은 임의의 상수가 아니라 **양성 사전확률 1/B**를 로짓으로 옮긴 값에 가깝습니다. 논문은 이 유도를 적지 않았고 "starts roughly close to the prior"라고만 씁니다(L186–L190). B = 1M이면 β* = −13.86이고 −10에서 시작하면 음성 총 가중이 양성의 약 47.6배입니다(첫 스텝이 여전히 음성 쪽으로 치우침).
- **softmax와 대비.** softmax는 한 행의 로짓에 상수를 더해도 값이 같습니다(`test_softmax_is_shift_invariant_sigmoid_is_not`). 음성 총 가중은 항상 (1 − p_ii) ≤ 1이라 B와 무관합니다. sigmoid는 이동 불변이 아니고 음성 총 가중이 (B−1)σ(β)로 B에 비례하므로, **정규화를 포기한 대가가 학습되는 편향**입니다.
- **표 4와의 관계(부분 설명).** t = 1(`log 1`), β = 0 조합(INet 53.7)이 가장 나쁜데, 초기 손실은 로짓이 cos·t + β이고 cos ≈ 0이라 t = 1과 t = 10에서 같습니다(`derivation_results.json`의 `table4_init_loss_B8192`: 둘 다 5,678). 따라서 **초기 손실 산술만으로는 "작은 t0에서 특히 나쁘다"를 설명하지 못합니다.** t가 작으면 양성과 음성의 로짓 간격(최대 2t)이 좁아 b의 균형만으로는 분리가 안 되는 학습 중 효과일 것으로 보이며 이는 유도하지 않았습니다.

### 1.3 기울기 (손 유도, autograd 대조)

g_ij = ∂L/∂ℓ_ij = −(1/B) z_ij σ(−z_ij ℓ_ij)라 하면 ∂L/∂x_i = t Σ_j g_ij y_j, ∂L/∂y_j = t Σ_i g_ij x_i, ∂L/∂t′ = t Σ_ij g_ij (x_i·y_j), ∂L/∂β = Σ_ij g_ij. `test_manual_gradients_match_autograd`가 float64에서 모두 1e-12 이내로 일치함을 확인합니다. 양성은 가중 σ(−ℓ_ii)(틀릴수록 큼), 음성은 σ(ℓ_ij)(양성처럼 보일수록 큼)이라 **쉬운 음성의 기울기는 지수적으로 작고 학습은 어려운 음성이 만듭니다.** 논문 §4.8의 "쉬운 음성만 남기면 전혀 학습되지 않고 어려운 음성만 남기면 거의 유지된다"(L574–L582)와 같은 방향입니다. 직접 시험하지는 않았습니다.

### 1.4 최적에서 양성·음성 로짓은 어떻게 갈리나

임베딩이 서로 직교(양성 cos = 1, 음성 cos = 0)라고 가정하면 행당 L(β) = softplus(−(t+β)) + (B−1) softplus(β)이고 단조 증가하는 ∂L/∂β = 0을 이분법으로 풀면(`optimal_orthogonal`), t가 클 때

β* ≈ −t/2 − ½ ln(B−1), 양성 로짓 ≈ +t/2 − ½ ln(B−1), 음성 로짓 ≈ −t/2 − ½ ln(B−1), L_min ≈ 2√(B−1) e^{−t/2}.

- **간격은 정확히 t**(양성 − 음성 = t·(1−0)), 두 로짓의 중점은 −½ ln(B−1)입니다. 테스트가 중점 합 −ln(B−1)을 확인합니다. **음성이 많을수록 두 로짓이 함께 내려가고**, B가 4배면 L_min이 2배입니다(`test_optimal_logit_split_...`).
- B = 1,024, t = 20: β* = −13.47, 양성 로짓 +6.5, 음성 −13.5, 손실 0.003(근사 0.003). B = 32,768, t = 20: β* = −15.20(근사 −15.20), 양성 +4.8, 음성 −15.2. **t = 10이고 B = 32,768이면 근사가 어긋나고(정확 β* = −10.78, 근사 −10.20), 최적에서도 양성 로짓이 −0.78로 음수**입니다. 즉 t = 10에서는 양성 쌍의 "확률"이 0.5 아래에 머무릅니다. 공식 체크포인트 데모 노트북의 학습 결과가 t = 118.2, b = −12.7로(저장된 출력, 변형은 로그상 B/16-i18n 256으로 보임) t가 초기값의 10배 이상으로 자라 있다는 점이 이와 맞습니다. **CLIP의 배율 상한 100을 넘는 값**입니다(`04` D7).
- 같은 직교 임베딩에서 softmax 손실은 log(1 + (B−1)e^{−t}): B = 32,768, t = 20이면 6.8e-5, sigmoid는 0.016. 직교에서는 softmax가 더 빨리 0으로 갑니다. 학습 가능한 편향이 있는 sigmoid의 최소 손실이 e^{−t/2}로 줄어드는 것이 "쌍마다 독립" 구조의 값입니다. 이것이 sigmoid가 낫다는 증거는 아닙니다(손실의 척도가 다름).
- **실제 임베딩 최적화**(`test_free_embedding_optimization_separates_logits`: B = 16, d = 32 자유 임베딩과 t′, β를 Adam으로): 300스텝에 손실이 초기의 1/20 미만으로 줄고 모든 양성 로짓 > 0 > 모든 음성 로짓.

### 1.5 배치 크기와 음성 쌍 수, 예제 대 쌍

배치당 양성 B개, 음성 B² − B개(L561–L566). 본 예제 수 N을 고정하면 **보는 쌍은 N·B**입니다. 논문의 9B 예제에서 배치 32k는 쌍 2.9e14개, 배치 512는 4.6e12개로 64배 차이입니다(`derivation_results.json`, `pairs`). 논문은 sigmoid가 손실이 쌍의 합이라 "예제와 쌍의 효과를 분리"할 수 있다고 하고(그림 6, 음성을 가려 비율 1:1.6까지), 무작위로 가리면 성능이 떨어지고 어려운 것만 남기면 거의 유지한다고 보고합니다. 이는 softmax에서 같은 통제를 못 한다는 것이 아니라 sigmoid에서 자연스럽다는 이야기입니다. 본 예제 수를 맞춘 비교에서 배치가 작은 쪽이 **스텝이 많고(예: 9B/16k = 55만 스텝 대 9B/512 = 1,760만 스텝)** 따라서 배치가 작은 쪽이 스텝 수에서 유리한 교란이 이미 들어 있습니다(`04` C1).

### 1.6 청크 계산의 메모리와 통신 산술

장치 D개, 장치당 m = B/D.

| B | D | m | 전체 \|B\|² (float32) | CLIP식 장치별 m×B | sigmoid 청크 m² |
|---|---|---|---|---|---|
| 32,768 | 8 | 4,096 | 4 GiB | 0.5 GiB | 0.0625 GiB |
| 32,768 | 256 | 128 | 4 GiB | 16 MiB | 64 KiB |
| 1,048,576 | 32 | 32,768 | 4 TiB | 128 GiB | 4 GiB |
| 1,048,576 | 256 | 4,096 | 4 TiB | 16 GiB | 64 MiB |

- 논문의 "\|B\|²에서 b²로"는 **전체 행렬 대 한 청크**의 비교이고, 실제 softmax 구현이 장치별로 만드는 것은 m×B 정도입니다. 이 기준으로는 m²이 m×B의 1/D입니다. 따라서 논문의 대비는 가장 불리한 softmax 구현과의 비교로 읽어야 합니다.
- **통신.** softmax 두 방향은 이미지와 텍스트를 모두 모아야 하므로 장치가 받는 임베딩 벡터가 2(D−1)m개, sigmoid 청크는 텍스트 청크를 D−1번 받아 (D−1)m개입니다(절반). 논문의 "D개의 collective permute가 두 번의 all-gather보다 보통 빠르다"(L284–L286)는 이 총량과 일치하지만 시간은 측정하지 않았습니다.
- **역전파 메모리.** 청크마다 블록 로짓이 일반 autograd에서는 역전파를 위해 저장됩니다. `count_saved_block_elements`로 장치 4개, 배치 32를 재면 블록 크기(8×8) 텐서가 저장된 원소 수가 D²·m² = 1,024 이상(전체 행렬과 같음)이고, 블록마다 `torch.utils.checkpoint`를 쓰면 0입니다(`test_memory_arithmetic_and_saved_activations`). 즉 **b² 메모리는 블록을 역전파에서 다시 계산할 때만** 얻습니다. 공식 big_vision 트레이너는 청크 구현이 없고(파일 머리 "TODO: implement chunked version with shard_map"), OpenCLIP의 `chunk_size` 구현은 블록마다 체크포인트를 씁니다(`04` D2).

### 2.1 테스트가 확인하는 것

1. 식 ↔ 알고리즘 1: 이중 반복문 식과 b 부호만 다르고 일치(§1.1).
2. 청크 합 = 전체 행렬: 장치 1, 2, 4 x 체크포인트 유무 6가지에서 **값은 상대오차 1e-12, 기울기(x, y, t′, β)는 1e-12 이내로 일치**하고 한 번에 만드는 로짓 블록은 (B/D)².
3. 쌍 단위 독립: (이미지, 텍스트) 쌍을 같은 순열로 섞으면 값이 같고(1e-12), 텍스트만 섞으면 달라집니다. 장치 5개로 나눈 청크도 같습니다.
4. 무작위 임베딩(d = 4096, B = 256)의 초기 손실이 해석값 softplus(10) + 255 softplus(−10)과 2% 이내, β = 0이면 B log 2와 2% 이내.
5. 편향 균형점에서 기울기 0, B = 32,768에서 β = 0 대 −10의 기울기가 16,383 대 0.49(1e4배 이상).
6. 완벽 정렬(직교 쌍, t = 60, β = −30)에서 손실 < 1e-9.
7. 손 유도 기울기 = autograd.
8. softmax 손실이 명시 식과 같음, softmax는 이동 불변, sigmoid는 아님.
9. 직교 임베딩의 최적 분리(§1.4).
10. 자유 임베딩 최적화가 양성/음성 로짓을 가름.
11. 메모리 산술과 저장된 블록 원소 수(§1.6).
12. 토이 모델 두 손실 3스텝 스모크 테스트(softmax에서 편향 없음, t ≤ 100).

## 3. 논문 표 재계산 (`table_recalc.py`, 학습 없음)

- **표 9(XM3600 36개 언어)의 평균 행**이 언어별 값의 산술 평균과 최대 0.05 이내로 일치합니다(예: T→I 16k 34.82 대 보고 34.8, *32k 42.64 대 42.6). 표 2의 T→I 평균과도 같습니다.
- **배치 크기에 따라 달라지는 평균 차(sigmoid − softmax, 표 8 SigLiT ImageNet)**: 18억 설정(180억 예제)에서 배치 2k–8k 평균 +0.83(3개 모두 sigmoid 우위), 16k–64k +0.20(3/3), 128k–256k +0.10(2/2). 30억 설정에서 128k–256k는 −0.05(1/1로 갈림). 450M 설정은 512–8k 평균 +1.54(5/5). **부호 검정은 칸이 3–5개라 검정력이 없어 가장 강한 경우(5/5)도 양측 p = 0.0625**입니다. 방향은 일관되지만 통계적 확증은 칸 수가 아니라 시드 반복에서 나와야 합니다(논문은 한 설정에서만 시드 5개).
- **표 5(SigLIP B/16, WebLI)**: 30억 예제에서 512–8k는 sigmoid가 +1.5–+4.1(5/5), 32k는 69.9 대 69.9(차 0.0), 98k는 −0.2. 90억 예제에서 4k–32k는 +1.8~+0.5(4/4), 98k −0.2, **307k −1.0**. 즉 `256k에서 sigmoid가 낫다`가 아니라 **매우 큰 배치에서는 sigmoid가 약간 불리**한 칸도 있습니다. 논문 서술("격차가 닫히고 크면 softmax가 98k에서 최적, sigmoid는 32k")과 일치합니다.
- **최고점의 위치.** 표 8의 18B 열에서 sigmoid 84.7은 64k, 128k, 256k, 1M에서 같고 softmax 84.6은 128k·256k에서 같습니다. 즉 "32k에서 포화"는 32k가 84.6으로 이미 0.1 이내라는 뜻이고(표 8: 32k = 84.6) 그 이후 이득은 소수 첫째 자리에서 0.1입니다. "1M에서도 이득 없음"은 맞고(84.7), 단 이 칸은 sigmoid 하나뿐이고 softmax 1M은 표에 없습니다.
- **mSigLIP 다국어 포화.** 표 9에서 36개 언어 중 30개가 240k의 T→I가 32k보다 낮고 6개가 같거나 높습니다. 평균은 34.9(32k) → 32.7(240k). 일본어는 31.3 → 18.5로 두드러지게 떨어지고(ja T→I 32k 31.3, 240k 18.5), 중국어 32.5 → 23.7. **"32k면 충분"이 아니라 "큰 배치가 평균과 일부 언어에서 오히려 해롭다"가 표의 내용입니다.** 원인(학습 스텝 수 부족, 큰 배치에서의 불안정)은 논문도 규명하지 않았습니다.
- **표 7(시드 5개).** 32k, 30억에서 softmax 69.9 ± 0.1, sigmoid 70.1 ± 0.2. 평균 차 0.2는 표준편차의 1–2배입니다. 같은 설정의 표 5는 차 0.0이라 **표 5와 표 7이 어긋납니다**(`01` §5 항목 5).
- **표 1과 본문의 79.7 대 79.8**(D8)은 `01` §5 항목 2.

## 4. 합성 도형 토이: softmax 대 sigmoid (`run_experiments.py`, `toy_results.json`)

**토이이며 논문 재현이 아닙니다.** 21만 파라미터 모델, 16x16 합성 도형, 클래스 64개(색 8 x 모양 8, 대각선 8개 조합은 학습에서 제외하고 "보지 못한 조합"으로 평가)입니다. 배치 128에서 같은 색-모양 장면이 서로 겹쳐 **배치 안에 가짜 음성이 많이 있습니다**(조합 56개 중 두 쌍이 같을 확률이 높음). 논문의 웹 이미지-텍스트 쌍과 다른 점입니다. 시드 6개(0–5), CPU 1스레드, 평균과 t 95% 구간(자유도 5), 같은 시드끼리 짝지은 차이와 짝 t 검정입니다. 평가는 보지 못한 조합 2,000개(`zs_held_out_photo`, 64-way)와 본 조합 2,000개입니다. 설정: softmax는 CLIP 기본(t 초기 1/0.07, 상한 100), sigmoid는 논문 기본(t = 10, b = −10, 상한 없음), 옵티마이저는 AdamW 2e-3, OneCycle이고 둘 다 같습니다.

**교란 통제.** clip 분석이 지적한 "배치를 줄이면 본 이미지 수도 준다"를 피하려고 두 regime을 돌렸습니다. (a) 스텝 고정 2500(배치 16, 32, 128: 본 예제 4만, 8만, 32만), (b) **본 예제 수 고정 32만**(배치 16, 32, 128, 512 → 20000, 10000, 2500, 625 스텝). 논문 그림 2도 (b) 방식입니다.

| regime | 배치 | 스텝 | softmax (보지 못한 조합) | sigmoid | sigmoid − softmax (짝지은, 95% 구간) | sigmoid가 높은 시드 | 짝 t 검정 p |
|---|---|---|---|---|---|---|---|
| (a) 스텝 고정 | 16 | 2500 | 44.1% [37.1, 51.2] | 41.2% [34.7, 47.7] | −2.9 [−12.3, +6.4] | 2/6 | 0.46 |
| (a) | 32 | 2500 | 90.0% [86.1, 93.8] | 64.1% [52.7, 75.5] | **−25.9 [−35.0, −16.8]** | 0/6 | 0.0008 |
| (a)=(b) | 128 | 2500 | 95.6% [93.3, 97.8] | 97.2% [95.1, 99.4] | +1.7 [−0.2, +3.5] | 5/6 | 0.067 |
| (b) 예제 고정 | 16 | 20000 | 96.9% [95.2, 98.6] | 99.4% [98.7, 100] | **+2.5 [+0.7, +4.2]** | 6/6 | 0.016 |
| (b) | 32 | 10000 | 98.3% [97.3, 99.3] | 98.7% [97.8, 99.6] | +0.4 [−1.2, +2.0] | 3/6 | 0.54 |
| (b) | 512 | 625 | 83.9% [80.0, 87.8] | 58.8% [43.2, 74.5] | **−25.1 [−37.7, −12.5]** | 0/6 | 0.004 |

본 조합 정확도는 배치 16·32(b)·128에서 둘 다 99.9–100%로 같고, 차이는 (a)의 작은 배치(sigmoid 51.1% 대 softmax 63.0%, 배치 16)와 (b)의 배치 512(80.7% 대 99.3%)에서만 큽니다.

**읽기.**
1. **"작은 배치에서 sigmoid가 낫다"는 토이에서 좁게만 나옵니다.** 본 예제 수를 맞춘 배치 16(스텝 2만)에서만 +2.5점(6/6 시드, p = 0.016)이고, 배치 32(b)는 차이가 없으며, 같은 스텝 수에서 배치를 줄이는 (a)에서는 **sigmoid가 오히려 크게 뒤집니다**(배치 32에서 −25.9점). 논문 그림 2의 방향(작은 배치일수록 sigmoid 우위 확대)과 일치하지 않는 칸이 있습니다. 어느 쪽도 논문이 틀렸다는 근거가 아닙니다: 데이터 규모, 모델, 최적화 스텝(2500–2만)이 전혀 다릅니다.
2. **sigmoid는 초기에 느립니다.** 손실 값은 정의가 달라 두 손실을 비교할 수 없으므로 정확도로 보면 (a)의 스텝 2500에서 배치 32와 16, 그리고 (b)의 배치 512(625스텝)에서 sigmoid가 크게 뒤집니다. 공통점은 **업데이트 스텝이 적을 때** sigmoid가 뒤진다는 것입니다. t′와 b가 Adam의 한 스텝 크기(lr 2e-3 이하)로만 움직여 t = 10, b = −10 근처에서 거의 못 벗어납니다(학습 후 t 11–15, b −9.9~−11.1: 최종 t는 softmax의 25–46에 비해 낮음). 논문의 "초기값이 중요하다"가 토이에서 **학습률 제약 때문에 과장되어** 나타난 것일 수 있습니다. 논문은 큰 스텝 수와 Adafactor에서 t가 118까지 자라는 것(`04` D7)과 다른 영역입니다.
3. **배치 128에서 sigmoid가 약간 높습니다**(+1.7, 구간이 0을 포함, 5/6). 본 조합은 둘 다 ~100%.
4. **배치 512는 둘 다 스텝 부족**(625스텝)이라 이 칸은 "큰 배치에서 비슷하다"의 시험이 아니라 "스텝이 모자라면 sigmoid가 더 뒤진다"의 관측입니다. 논문도 짧은 학습에서 큰 배치가 스텝 수 부족으로 뒤지고 충분히 길게 학습해야 이득이 나온다고 적습니다(그림 3, L347–L352).
5. **학습 후 로짓.** sigmoid의 양성 평균 로짓은 −1.5(배치 512)~+2.3, 음성은 −10~−12로 **갈립니다**(§1.4의 예측과 같은 방향: 간격 ≈ t, 음성이 −ln(B)/2보다 크게 아래). softmax는 양성 로짓 23–44, 음성 0.3–2.2로 이동에 불변이라 절대값 해석이 없습니다.
6. **편향 b = 0 초기화 절제(`sigmoid_b0`, 예제 고정 32만).** 배치 128: 52.8% [22.1, 83.4]로 b = −10의 97.2%보다 **−44.5점**(0/6, p = 0.016), 배치 512: 4.6%(우연 1.6%에 가까움)로 **−54.2점**(0/6, p = 0.0004). 학습 후 b가 −0.15, −0.01로 거의 움직이지 않아 b = 0은 §1.2의 "음성이 압도"하는 상태에서 벗어나지 못했습니다. **논문 §4.9·표 4(b = 0이 나쁨)와 같은 방향이고 크기는 토이에서 훨씬 큽니다.** b가 lr 제약으로 움직이지 못하는 토이의 특성 때문에 과장입니다.

**교란과 한계.** (i) 배치 안 가짜 음성(위), (ii) 작은 모델·작은 데이터, 두 손실에 같은 lr를 썼고 손실별 튜닝은 하지 않음, (iii) softmax와 sigmoid의 t 초기값이 다름(논문 설정을 따랐음), (iv) 구간은 시드 6개의 t 구간이고 칸이 14개라 다중 비교를 보정하지 않았음, (v) 본 예제 수를 맞추면 작은 배치가 스텝이 많은 쪽에 서는데 이 교란은 sigmoid와 softmax 두 손실에 같이 작용해 차이 비교(짝지은 차이)에는 영향이 적음.
