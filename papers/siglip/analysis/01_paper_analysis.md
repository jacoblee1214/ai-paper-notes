# 01. 논문 분석: Sigmoid Loss for Language Image Pre-Training (SigLIP, arXiv:2303.15343)

분석 판은 arXiv **v4**(2023-09-27, 최신)입니다. 위치 표기 `L숫자`는 `paper/paper.txt`의 줄입니다. 이전 판과의 차이는 마지막 절에 있습니다.

## 1. 문제

대조 사전학습(CLIP, ALIGN)은 배치 안에서 **softmax(InfoNCE)를 이미지 방향과 텍스트 방향으로 두 번** 적용합니다(§3.1, L174–L195). 이 손실은 (1) 배치 전체의 정규화 항이 필요해 분산 학습에서 임베딩을 모두 모으고 |B|×|B| 유사도 행렬을 만들어야 하고(§3.3, L198–L209), (2) 수치 안정화에 배치 전체를 한 번 더 훑어야 합니다(L41–L47). 논문은 정규화를 없애고 **쌍마다 독립인 이진 분류**로 바꿉니다(L48–L58).

## 2. 방법

| 항목 | 내용 | 위치 |
|---|---|---|
| 손실 | L = −(1/\|B\|) Σᵢ Σⱼ log σ(z_ij(t xᵢ·yⱼ + b)), z_ij = +1(i=j) / −1. 양성 \|B\|개, 음성 \|B\|²−\|B\|개 | §3.2, 알고리즘 1 (L60–L75, L204–L227) |
| 매개변수 | t = exp(t′), t′와 b를 학습. 초기값 t′ = log 10(t = 10), b = −10 | §3.2 (L184), §4.9 표 4 (L626–L635) |
| 이유 | 초기에 양성 1 대 음성 \|B\|−1의 불균형이 손실을 지배해 큰 보정 스텝이 생기므로, 사전 확률(양성이 드묾)에서 시작하게 b를 둔다 | §3.2 (L174–L190) |
| 청크 계산 | 장치 D개, 장치당 배치 b. 이미지 청크는 고정, 텍스트 청크를 이웃으로 돌리며 부분 손실을 더함. 메모리 \|B\|² → b², all-gather 없이 D번의 collective permute | §3.3, 그림 1 (L132–L171, L198–L292) |
| 구조 | ViT-B/16 등 + Transformer 텍스트. 그림에서 풀링이나 텍스트 최종 토큰 처리는 설명하지 않음 | §4.2 (L356–L367), 부록 F (L1045대) |
| 대칭 | 손실이 한 번의 합이고 이미지·텍스트에 대칭 | L69–L76 |

변형: **SigLiT**(이미지 타워 고정, 텍스트 타워만 학습; LiT 틀), **SigLIP**(두 타워 학습, WebLI 영어), **mSigLIP**(WebLI 100개 언어, 어휘 250k에 "병목 임베딩" N×K + K×W, K=96, §4.3 L378–L382).

## 4. 실험 설정 요약

- 평가: ImageNet 제로샷(주), XM3600 36개 언어 검색(다국어), v4는 ObjectNet, ImageNet-v2·ReaL, COCO 검색(§4.6).
- 옵티마이저: 기본 ScalingViT-Adafactor(β₂ = 0.95), 학습률 0.001·가중치 감쇠 0.0001을 배치 512–1M에 그대로 씀(부록 C, L880대). 하이퍼파라미터 격자(9칸 x 배치 3개)에서 기본값이 최적이거나 근접(표 6; 32k에서는 기본 68.2, 최고 69.0).
- 반복 측정: **시드 5개는 한 설정(32k, 30억 예제)만**(표 7: softmax 69.9 ± 0.1, sigmoid 70.1 ± 0.2, AdamW 70.3 ± 0.1). 나머지 격자는 단일 실행입니다.
- 학습량: 그림 2의 SigLiT 180억, SigLIP 90억, mSigLIP 300억 예제를 **본 예제 수를 맞추고** 배치를 바꿉니다. 작은 배치 쪽이 업데이트 스텝이 많습니다.

## 5. 한계와 논문 안의 모호함

1. **b의 부호가 식과 알고리즘에서 반대입니다(D1).** §3.2 식은 1/(1 + e^{z(−t x·y + b)}) = σ(z(t x·y − b))이고(L221–L222), 알고리즘 1과 공식 코드는 logits = t x·y **+** b입니다(L73). "b = −10 초기화"는 알고리즘 쪽 부호에서만 의미가 있습니다(`03` §1.1).
2. **표 1과 본문이 어긋납니다.** SigLiT B/8 행은 표 1에서 79.8(L24), 본문 §1·§4.4는 79.7(L85, L431). v1 표는 79.7이었고 v4가 표만 바꿨습니다.
3. **효율 비교의 단위가 섞여 있습니다.** "CLIP은 약 2500 TPUv3-일에 72.6%"(§4.5, L519, FLIP 논문 인용)와 "SigLIP 32 TPUv4 칩 5일"을 비교하는데, 앞은 256 **코어**, 뒤는 **칩** 기준이고 데이터(LAION 계열 대 WebLI)와 토크나이저가 다릅니다. 자릿수 비교로만 읽어야 합니다.
4. **소프트맥스 기준선의 튜닝 범위가 불명확합니다.** 부록 C의 하이퍼파라미터 격자는 sigmoid 설정에 대한 것으로 읽히고, softmax 기준선도 같은 기본값을 쓴 것으로 보입니다(문장에 명시 없음). 격차의 일부가 기준선의 최적화 부족일 가능성을 배제하지 못합니다.
5. **표 5와 표 7이 같은 설정(32k, 30억)에서 다릅니다.** 표 5는 69.9 대 69.9(차 0.0), 표 7은 70.1 대 69.9(차 0.2, 5시드 표준편차 0.1–0.2).
6. **표 3은 인과 비교가 아닙니다.** SigLIP 대 OpenCLIP·EVA-CLIP은 데이터(WebLI 대 LAION·DataComp 등), 학습량(400억 예제 과학습), 아키텍처(So400m)가 모두 다릅니다. "sigmoid 때문"으로 읽을 수 없습니다.
7. **메모리 이득은 순전파 기준 서술입니다.** b² 메모리는 한 시점에 만드는 블록 크기이고, 블록 로짓이 역전파까지 남는지는 구현(체크포인트 여부)에 달려 있습니다(`03` §1.6).
8. **모델 구조 세부가 본문에 없습니다.** 공개 체크포인트는 이미지 쪽에 attention 풀링(MAP) 헤드, 텍스트 쪽에 마지막 토큰 풀링과 비인과 마스크를 쓰지만(OpenCLIP 설정, 공식 데모 노트북) 논문은 "ViT"와 "Transformer"로만 적습니다(`04` D3).
9. **데이터(WebLI)와 학습 설정 파일이 공개되지 않았습니다.** 공식 저장소의 `siglip.py`는 손실 트레이너이고 WebLI 학습 설정이 아니라 COCO 미세조정 설정만 있습니다(`04` D4–D5).
10. **효과 크기.** 큰 배치(≥ 128k)의 sigmoid–softmax 차이는 0.1–0.5점으로 표 7의 표준편차(0.1–0.2)와 같은 규모입니다(`03` §3).
