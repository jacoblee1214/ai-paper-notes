# 04. 주장 검증과 공식 노트북 대조

구현 모드: 이후 문헌이 이 글의 주장을 확인·수정·반박한 것을 C1–C10으로, 공식 노트북과의 정적 대조를 D1–D6으로 적습니다. 판정은 "확인(우리 유도·재계산 포함) / 부분 확인 / 수정 / 미검증"입니다. 이후 문헌은 arXiv 초록(arXiv API, 2026-11-24)과 게시 페이지에서 읽은 대목만 근거로 삼았고 본문 전체를 읽지는 않았습니다. 재현하지 않았습니다. 웹 검색 4회(Towards Monosemanticity, Scaling Monosemanticity, Superposition·Memorization·Double Descent, SAE 부정 결과)와 arXiv API 조회를 썼습니다.

## 1. 주장 검증 C1–C10

### 우리가 장난감 안에서 직접 확인한 것 (재현 요약)

- 선형 모델 = 상위 m개(C1), 희소도에 따라 특징 수가 m에서 늘어남(C2), 2특징 단계도 경계(C3): `03` §1, §3, §6.
- 차원수의 계단(1/2, 2/3, 2/5 …)과 평면 다각형(2/k): `03` §7–§8.
- 확인하지 못한 것: 학습 동역학의 에너지 준위 점프, 상관 특징, 적대적 취약성, 은닉층 ReLU 모델과 abs 계산, n=3·m=2 단계도.

### 요약해서 인용에 쓸 때

- C1, C2, C3은 장난감 안의 결과로 인용할 수 있습니다(우리가 재현).
- C4, C6, C9은 이 글의 서술보다 **약하게** 인용해야 합니다("특징 = 1차원 방향", "사후 분해로 참 특징 열거", "다의성 = superposition"은 모두 후속 문헌이 수정).
- C5, C7, C8, C10의 "실제 모델에서"는 이 글이 보이지 않았고 우리도 보이지 않았습니다.

## 2. 공식 노트북 대조 D1–D6

대상: `anthropics/toy-models-of-superposition`, 커밋 `562710e079704b84a132b640db134d4cebe22466`(마지막 push 2022-09-14), MIT 라이선스, 별 159. 파일은 README, LICENSE, `toy_models.ipynb`(셀 22개) 뿐입니다. `repo/`(gitignore)에 얕게 clone해 **정적으로만** 읽었고 실행하지 않았습니다(plotly·tqdm·einops 의존, cuda가 있으면 cuda 아니면 cpu).

| # | 항목 | 논문 | 공식 노트북 | 영향 |
|---|---|---|---|---|
| D1 | 포함 범위 | 선형 모델, 단계도, 상관 특징, 은닉층 ReLU, abs 계산 등 | 소개 도표(n=5, m=2), n=100·m=20 중요도 곡선, n=200·m=20 균일 중요도의 D*와 차원수 산점도까지 3개 실험만 | 저자도 "포괄적이지 않다(공개용으로 코드를 다시 썼다)"고 적음(§Code). 선형 모델·단계도·n=400, m=30은 코드로 확인 불가 |
| D2 | 손실 | Σ_x Σ_i I_i(x_i−x'_i)² | `error = importance*(batch.abs() − out)**2; loss = reduce('b i f -> i','mean').sum()` — 배치뿐 아니라 **특징 축도 평균** | 크기만 1/n배(AdamW는 스케일에 거의 불변, weight decay 비율은 달라짐). 우리는 특징 합을 씀 |
| D3 | 타깃 | x | `batch.abs()` (입력이 비음수라 x와 같음) | 영향 없음. 다른 절의 abs 계산 코드가 섞여 있음 |
| D4 | 데이터 | x_i=0 (확률 S), 아니면 U[0,1] | `rand ≤ feature_probability`이면 U[0,1], 아니면 0 | 우리 `generate_batch`와 같음 |
| D5 | 최적화 | 글에 없음 | AdamW, lr 1e-3, 배치 1024, 10,000스텝, 상수 lr(cosine·선형 감쇠 함수는 정의돼 있으나 기본 안 씀), W에 `xavier_normal_`, b=0, 인스턴스 여러 개 동시 학습 | 우리 기본값과 같게 맞춤(우리 초기화는 표준편차 √(2/(m+n))로 xavier와 같음) |
| D6 | 차원수 | D_i = ‖W_i‖²/Σ_j(Ŵ_i·W_j)² | `dim_fracs = norms**2/interferences`, `interferences = (einsum(W_unit, W)**2).sum(-1)`, `W_unit = W/clamp(norms, 1e-6)` | 논문 정의와 같고 j=i 포함. 우리 `dimensionality`는 안 배운 특징(노름 < 1e-3)을 0으로 처리하는 점만 다름 |

추가 관찰: 노트북의 밀도 격자는 `20^-linspace(0,1)`이라 1에서 0.05까지입니다(논문 §Uniform Superposition의 그림은 더 희소한 영역까지 보임). 노트북의 선 눈금은 2/3, 2/5, 2/6, 2/7(평면 다각형 2/k)과 5/6, 4/5, 3/4, 3/8, 3/12, 3/20(3차원 이상) 이라 우리 `03` §4의 "타이트 프레임이면 D=m/k"와 같은 형태입니다.

## 3. 재현 제안 (승인 필요, 하지 않았음)

- 공식 노트북 실행: 의존성(plotly, einops, tqdm, pandas) 설치와 GPU 없이 CPU 실행 가능성 확인이 필요합니다. 우리 구현과 같은 결과를 내는지 보는 용도로 가치는 낮습니다(우리가 독립 재현을 이미 함).
- n=400, m=30 전체 규모와 n=3·m=2 단계도, 상관 특징은 CPU로 가능하나 시간이 필요합니다. 필요하면 요청하겠습니다.
- 같은 장난감에서 SAE를 학습해 정답 특징을 얼마나 복원하는지 보는 것은 31번 `sparse_autoencoders/`에서 하는 것이 맞습니다.
