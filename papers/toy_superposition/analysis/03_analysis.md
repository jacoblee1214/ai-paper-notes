## 1. 선형 모델은 상위 m개 특징만 담는다 (희소도와 무관)

**주장**(§Basic Results, §Mathematical Understanding, 각주 12): 선형 모델 x' = W^T W x + b의 최적해는 PCA와 같다 — 상위 m개.

**유도.** M = W^T W (대칭, 양반정부호, 랭크 ≤ m). 입력의 평균 μ = (1−S)/2, 분산 σ² = (1−S)/3 − (1−S)²/4이고 성분이 독립이므로 공분산은 σ² I입니다. 편향 b를 최적화하면 b = (I−M)μ𝟙이고 잔차는 (I−M)(x−μ𝟙)입니다. 그러면

L = σ² Σ_i I_i ‖(I−M) e_i‖² = σ² tr(D (I−M)²), D = diag(I_1,…,I_n).

M의 고유분해 M = Σ_{k≤m} λ_k u_k u_k^T (u_k 정규직교)를 쓰면 (I−M)² = I − Σ_k g(λ_k) u_k u_k^T, g(λ) = 2λ − λ² ≤ 1(λ=1에서 등호)이므로

L/σ² = tr D − Σ_k g(λ_k) u_k^T D u_k ≥ tr D − Σ_k u_k^T D u_k ≥ tr D − (I의 상위 m개 합).

둘째 부등식은 Ky Fan 최대 원리(정규직교 m개 벡터에 대한 tr(U^T D U)의 최댓값은 D의 상위 m개 고유값의 합)이고, 첫째에서 u_k^T D u_k ≥ 0을 썼습니다. 등호는 λ_k = 1이고 u_k가 중요도 상위 m개 좌표일 때(중요도가 서로 다를 때 유일): M = 상위 m개 좌표 투영. 따라서

L_min = σ² Σ_{i>m} I_i (중요도 정렬 후), ‖W_i‖² = 1 (i ≤ m), 0 (i > m).

**S에 대한 의존**은 σ² 한 곱셈 인자뿐이라 **선택되는 특징 집합은 희소도와 무관**합니다(논문 서술과 일치).

**검산(`results_a.json`, `test_minimal_impl.py::test_linear_model_keeps_top_m...`).** n=20, m=5, I=0.7^i, 시드 5개 평균 학습 손실과 L_min의 상대 오차: 밀도 1 → 0.01 열 개에서 −0.33% ~ +0.30%(절댓값 최대 0.33%, 밀도 0.02). 모든 시드·밀도에서 표현된 특징 수 = 5. 이론과 학습이 4자리까지 맞습니다.

## 2. ReLU 모델의 손실: 희소 패턴 분해와 간섭, 편향의 역할

**주장**(§Mathematical Understanding): L = (1−S)^n L_n + … + (1−S)S^{n−1} L_1 + S^n L_0. 정확히는 k개가 켜질 확률은 C(n,k)(1−S)^k S^{n−k}이고 L_k는 k개가 켜진 입력에서의 (특정 패턴의) 손실입니다(논문 식은 이미지라 PDF 텍스트에 없음).

**L_0.** 입력이 0이면 x'_i = ReLU(b_i)이므로 L_0 = Σ I_i ReLU(b_i)² (양의 편향에 대한 벌점).

**L_1.** 특징 i만 켜짐(x_i = x ~ U[0,1])이면 x'_i = ReLU(a_i x + b_i), a_i = ‖W_i‖², x'_j = ReLU(c_{ji} x + b_j), c_{ji} = W_j·W_i. 손실

ℓ_i = I_i ∫₀¹ (x − ReLU(a_i x + b_i))² dx + Σ_{j≠i} I_j ∫₀¹ ReLU(c_{ji} x + b_j)² dx.

적분은 f(x) = cx + b가 양인 구간 [lo, hi]에서 (f(hi)³ − f(lo)³)/(3c)입니다(`relu_integral_sq`). 따라서

- **b = 0**이면 ℓ_i = (1/3)[ I_i (1−a_i)² + Σ_{j≠i} I_j ReLU(W_i·W_j)² ]. 첫 항이 "특징 이득"(‖W_i‖²=1이면 0), 둘째 항이 "간섭"입니다.
- **음의 간섭은 공짜**: W_i·W_j ≤ 0이면 ReLU(·)=0이므로 항이 사라집니다(논문 "ReLU makes negative interference free in the 1-sparse case"). 균일 중요도·‖W_i‖=1이면 Σ_{i≠j} ReLU(cos θ_ij)²의 최소화가 구 위의 점 배치 문제(Thomson과 비슷)입니다. 대척점 쌍은 cos = −1이라 이 항이 0입니다.
- **음의 편향은 작은 양의 간섭을 걸러냄**: 0 < c ≤ −b이면 ∫ReLU(cx+b)² = 0. 일반적으로 c > −b > 0이면 (c+b)³/(3c)로 b=0의 c²/3보다 작습니다(예: c = 0.2, b = −0.2 → 0). 대가는 특징 항의 a_i x + b_i가 b만큼 낮아지는 것이라 ‖W_i‖를 키워 보상합니다(논문의 오각형이 단위원 밖에 있는 이유: ‖W_i‖ = 1/(1−b_i) 서술, §Perturbing a Single Feature. 우리는 오각형의 편향을 따로 확인하지 않았습니다).

**검산.** `test_relu_integral_matches_numeric`(6개 (c,b) 쌍을 20만 점 구적법과 1e-8 이내 비교), `test_one_sparse_loss_matches_monte_carlo`(무작위 W, b, n=6, m=2에서 L_1 닫힌 형식이 40만 표본 몬테카를로와 1% 이내). 통과.

**왜 희소도가 올라가면 superposition이 생기나.** 밀도 d = 1−S에서 k개가 켜진 패턴의 확률은 d^k 계열입니다. 특징 이득은 모든 k에서 1차(d)로 들어오는데 간섭은 **두 특징이 동시에 켜져야** 생기는 항이 대부분이라 d² 이상입니다(1-희소 간섭은 대척점·직교 배치로 0을 만들 수 있음). 밀도가 낮으면 d² ≪ d라 간섭 비용이 작아지고, 같은 차원에 특징을 더 담는 이득이 이깁니다. §3의 n=2, m=1이 이것을 닫힌 형식으로 보입니다.

**밀도 1(S=0)에서 왜 선형 모델과 같은가.** 모든 특징이 항상 켜져 있어 모든 쌍이 동시에 간섭합니다(k=n항이 지배). 우리 학습에서 밀도 1일 때 ReLU 모델의 손실은 선형 모델의 이론값과 5자리까지 같았고(0.04646), 표현된 특징 수는 5(= m)입니다. 이 결과는 증명이 아니라 학습 관측이고, n=2, m=1에서만(§3, 부등식 (1+r)/6 > min(r,1)/12) 닫힌 형식으로 확인했습니다.

## 3. 2특징·1차원: 세 가지 해와 상전이

**설정**(§Superposition as a Phase Change): n=2, m=1, W = [w1, w2](1×2), 중요도 (1, r), 밀도 d, σ² = d/3 − d²/4. 논문의 세 해: A = [1,0](특징 2 버림), B = [0,1], C = [1,−1](대척점). 논문은 닫힌 형식을 별도 노트북에 두었고 우리는 직접 유도했습니다.

- **A**: x'_1 = x_1(b_1=0), x'_2 = ReLU(b_2) = E[x_2]로 둠(b_2 = d/2). L_A = r σ².
- **B**: L_B = σ².
- **C, b=0**: 둘 다 켜짐: x'_1 = ReLU(x_1−x_2), x'_2 = ReLU(x_2−x_1) ⇒ 오차 제곱은 두 쪽 모두 min(x_1,x_2)²이므로 기댓값 (1+r) E[min²] = (1+r)/6 (E[min²] = ∫₀¹ 2t²(1−t)dt = 1/6). 하나만 켜짐: x'_other = ReLU(∓x) = 0, 오차 0. 아무것도 안 켜짐: 0. 그래서 L_C = d² (1+r)/6.
- **경계**(C가 이길 조건, b=0 근사):
 - r ≤ 1: d²(1+r)/6 < r(d/3 − d²/4) ⇔ **d < 4r/(2+5r)**
 - r ≥ 1: d²(1+r)/6 < d/3 − d²/4 ⇔ **d < 4/(5+2r)**
 - r=1이면 d* = 4/7 ≈ 0.571(S > 0.43).
- **1차 전이**: A(또는 B)는 d의 1차·2차 항, C는 순수 2차 항이라 교차점에서 기울기가 다릅니다. 최적 손실 min(L_A, L_B, L_C)의 도함수가 교차점에서 불연속이므로 논문의 "first-order phase change" 서술과 같습니다.
- 편향을 최적화하면 C의 손실이 더 낮아져 경계가 조금 움직입니다(구적법 + Adam, `three_config_losses`).

**검산 (`results_b.json`, `test_two_feature_closed_forms_match_quadrature`, `test_b0_boundary_is_where...`).**

| 경계(밀도) | r=0.25 | r=0.5 | r=1 | r=2 | r=4 |
|---|---|---|---|---|---|
| b=0 닫힌 형식 | 0.308 | 0.444 | 0.571 | 0.444 | 0.308 |
| 세 해 + 최적 b (0.02 간격 탐색의 상한) | 0.31 | 0.45 | 0.61 | 0.45 | 0.31 |

r=1 한 점만 7% 차이(0.571 대 0.61)이고 나머지는 격자 간격(0.02) 안입니다.

**학습한 단계도와의 비교.** 12×13 칸(r 12점 × 밀도 13점)에서 모집단 손실 최소화로 얻은 해의 분류(‖W_i‖² > 0.5 판정)와 세 해 이론(최적 b)의 일치는 **154/156 = 98.7%**입니다(b=0 닫힌 형식과도 같은 98.7%). 불일치 2칸은 둘 다 경계 바로 옆(r=0.25와 4, d=0.316)이고 학습 해가 [−1.04, 0.79]처럼 두 크기가 다른 "비대칭 대척점"이었습니다. 겹침으로 분류된 118칸은 전부 w_1·w_2 < 0(대척점), 그중 111칸은 두 성분의 절댓값이 1에서 0.1 이내였습니다. 한편 27칸(17%)에서 학습 손실이 세 해 중 최소보다 1e-4 넘게 낮았고(최대 상대 8.4%), 이는 세 해가 근사이고 실제 최적은 가중치 크기가 약간 달라진다는 뜻입니다(분류는 대부분 같음). 논문이 "이론과 경험 도표 모두에서 상전이"라고 한 것을 이 크기(2특징)에서는 확인합니다. n=3, m=2의 네 해 도표는 재현하지 않았습니다.

**주의.** (1) 우리의 "학습"은 표본이 아니라 모집단 손실의 결정적 최소화입니다(분류 경계의 해석적 대조가 목적). 표본으로 학습하는 (a)와 (c)는 별도입니다. (2) r=1에서는 A와 B가 같은 손실이라 어느 쪽이 나오는지는 초기값에 달려 있어 "특징 1만/특징 2만"이 퇴화합니다(격자에 r=0.8, 1.25가 있고 1.0은 없음). (3) 표현 판정 임계값 0.5는 임의 선택입니다(‖W_i‖² 값은 대부분 1 근처 또는 0 근처라 민감하지 않음).

## 4. 특징 차원수 D_i

**정의**(§Feature Dimensionality): D_i = ‖W_i‖² / Σ_j (Ŵ_i·W_j)², Ŵ_i = W_i/‖W_i‖, j=i 포함. Ŵ_i·W_j = (W_i·W_j)/‖W_i‖이므로

D_i = ‖W_i‖⁴ / Σ_j (W_i·W_j)²

(분자 ‖W_i‖⁴를 쓰는 표기와 같음). W의 크기를 c배하면 분자와 분모가 모두 c²배라 **스케일 불변**입니다.

**프레임 연산자 형태.** S = W W^T = Σ_j W_j W_j^T (m×m)로 두면 Σ_j (Ŵ_i·W_j)² = Ŵ_i^T S Ŵ_i이므로

D_i = ‖W_i‖² / (Ŵ_i^T S Ŵ_i).

**결과 1 (직교)**: W_i ⊥ W_j (i≠j)이면 분모 = ‖W_i‖²이므로 D_i = 1.

**결과 2 (정규 단체와 정다각형)**: 단위 벡터 k개가 정규 단체(m = k−1차원)를 이루면 내적 = −1/(k−1), 분모 = 1 + (k−1)/(k−1)² = k/(k−1), D = (k−1)/k. k=2(대척점): 1/2, k=3(삼각형): 2/3, k=4(정사면체): 3/4 — 논문의 계단 값 중 1/2, 2/3, 3/4와 일치. 평면의 정k각형(k≥3): Σ_j cos²(2πj/k) = k/2 ⇒ D = 2/k (k=5: 2/5, k=6: 1/3).

**결과 3 (타이트 프레임)**: S = cI이면 D_i = ‖W_i‖²/c이고 Σ_i D_i = tr(S)/c = m (정확히). 단위 벡터가 타이트 프레임이면 D_i = m/k(정사각 반프리즘: m=3, k=8 ⇒ 3/8. 논문이 말한 대로 반프리즘은 타이트 프레임이라고 가정하면 일치하지만 8점이 타이트 프레임임은 우리가 확인하지 않았음). 이것이 논문의 경험 관찰("차원수의 합이 임베딩 차원 수가 된다, 효율적으로 쌓였을 때")의 정확한 조건입니다: 직교한 타이트 프레임들의 합(텍검 곱)에서도 블록별로 성립합니다. 텍검 곱: 안 겹친 블록들 사이의 내적이 0이라 D_i는 자기 블록 안에서만 정해집니다.

**D* = m/‖W‖_F²와의 관계**: 단위 벡터 k개이면 ‖W‖_F² = k이므로 D* = m/k입니다. 타이트 프레임이면 ΣD_i = m이라 D*는 D_i의 평균과 같습니다(삼각형 + 대척점 쌍, m=3, n=5: D_i = (2/3, 2/3, 2/3, 1/2, 1/2), 평균 0.6 = D* = 3/5). 노름이 1이 아니거나 안 배운 특징이 섞이면 D*와 평균은 달라집니다(D*는 기저 불변인 전체 통계라 밀집 영역에서도 쓸 수 있다는 점이 논문이 D*를 쓴 이유).

**검산**: `test_dimensionality_*` 7개 — 직교 1, 대척점 1/2, 정삼각형·정오각형 2/k, 정사면체 3/4, 스케일 불변, 안 배운 특징 0, 텍검 곱, 타이트 프레임 합 = m(정칠각형 k=7, 합 2.0). 통과.

| ReLU 표현 수 (평균) | 5.0 | 5.0 | 6.0 | 8.0 | 8.2 | 9.8 | 10.0 | 10.2 | 10.6 | 11.4 |

- **S=0에서는 상위 5개만**, 밀도가 0.5 아래로 내려가면 6개, 8개, … 로 늘어나 밀도 0.01에서 평균 11.4개(m의 2.3배). 논문 서술("희소해지면 덜 중요한 특징부터 겹쳐 들어오고 점차 중요한 특징에도 영향")과 같은 순서입니다: 그림(시드 0)에서 밀도 0.3에 8개가 들어오고 간섭 색(노랑)이 상위 특징 일부에도 나타납니다.

- 표현된 특징의 간섭 Σ_{j≠i}(Ŵ_i·W_j)²는 superposition 영역에서 대부분 1 이상(그림 색 상한 1에서 포화). 논문 §Basic Results의 "≥1이면 다른 특징 묶음이 W_i만큼 세게 활성화할 수 있다"에 해당.
- 학습 설정이 논문과 같은지는 모릅니다(글에 설정 없음). 논문 그림의 정확한 개수와 대조하지 않았고(그림 판독 안 함) 정성적 형태만 확인했습니다.

## 7. (c) n=200, m=15, 균일 중요도: 차원수의 계단 (`results_c.json`, 그림 `own_dimensionality.png`)

시드 3개, 10,000스텝. 논문 n=400, m=30의 절반 규모입니다(시간 때문, n=400은 돌리지 않았음).

| 1−S | 1 | 0.68 | 0.46 | 0.32 | 0.22 | 0.15 | 0.10 | 0.068 | 0.046 | 0.032 | 0.022 | 0.015 | 0.01 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 표현된 특징 수(‖W_i‖²>0.5, 시드 3개) | 0 | 12–14 | 28 | 28 | 36–38 | 49–55 | 63–65 | 77–78 | 100–102 | 128 | 161–163 | 190–192 | 199–200 |

- **밀도 1**: 표현된 특징 0개 — 균일 중요도 밀집 영역에서는 아무 특징도 노름이 0.5를 못 넘고(‖W_i‖² ≈ m/n = 0.075) 기저가 특권을 갖지 않습니다. 그래서 논문이 노름 대신 기저에 무관한 D*를 쓴 것입니다. D* = 1.00.
- **1/2 계단이 선명합니다**: 밀도 0.46과 0.32에서 표현된 28개 특징 전부(시드 0)의 D_i가 1/2±0.02, D* = 0.53, 0.51, 표현된 특징 28 ≈ 2m = 30. 대척점 쌍 14개가 한 차원씩 씁니다(논문의 "끈적한" 1/2).

- **밀도 ≤ 0.15에서는 분수 계단이 안 보입니다**: D_i가 연속적으로 흩어집니다(`기타`가 전부). n=200 특징이 m=15 차원에 거의 다 들어가(밀도 0.01에서 199–200개, 13배) **특징 수가 n에 막혀** 더 기하가 이산 구조를 만들 여지가 없고, 논문 n=400, m=30보다 한 규모 작아 비교가 어렵습니다. 논문 그림이 보인다는 3/4, 3/8, 2/5 등 세밀한 계단 전체는 우리 규모에서 재현하지 못했습니다(1/2, 2/3, 2/5 부근만).
- 단일 시드 값의 차이는 작습니다(표 범위).
